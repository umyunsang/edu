1. Microsoft Windows용 CUDA 설치 가이드
◼Microsoft Windows 시스템에서 CUDA 툴킷을 설치하기 위한 지침소개
⚫CUDA는 NVIDIA에서 개발한 병렬 컴퓨팅 플랫폼 및 프로그래밍 모델. 
⚫그래픽 처리 장치(GPU)의 성능을 활용하여 컴퓨팅 성능을 극적으로 향상시킬 있음.
⚫CUDA는 몇 가지 설계 목표를 염두에 두고 개발되었음
➔병렬 알고리즘을 간단하게 구현할 수 있도록 C와 같은 표준 프로그래밍 언어에 대한 작은 확장 세트를 제공. 
➔CUDA C/C++를 사용하면 프로그래머는 알고리즘 구현에 시간을 소비하는 대신 알고리즘의 병렬화 작업에 집중할 수 있음.
➔애플리케이션이 CPU와 GPU를 모두 사용하는 이기종 연산을 지원. 
➔애플리케이션의 직렬 부분은 CPU에서 실행되고 병렬 부분은 GPU로 오프로드됨. 따라서 CUDA는 기존 애플리케이션에 점진적
으로 적용 가능. 
➔CPU와 GPU는 자체 메모리 공간을 가진 별도의 장치로 취급됨. 이 구성은 또한 메모리 리소스에 대한 경합 없이 CPU와 GPU에
서 동시에 계산할 수 있음.

2.
전체 설치 관리자(local): CUDA 툴킷의 모든 구성 요소가 포함되어 있으며 추가 다운로드가 필요 없는 인스톨러. 이 인스톨러는 네트워크 
액세스가 부족한 시스템이나 기업 배포에 유용.
•
CUDA 툴킷은 CUDA 애플리케이션을 생성, 빌드 및 실행하는 
데 필요한 CUDA 드라이버와 툴은 물론 라이브러리, 헤더 파
일 및 기타 리소스를 설치함.
•
다운로드 확인
다운로드는 https://developer.download.nvidia.com/ 
compute/cuda/12.6.3/docs/sidebar/md5sum.txt 에 게시
된 MD5 체크섬과 다운로드한 파일의 체크섬을 비교하여 확
인할 수 있습니다. 두 체크섬 중 하나가 다르면 다운로드한 
파일이 손상된 것이므로 다시 다운로드해야 함.
