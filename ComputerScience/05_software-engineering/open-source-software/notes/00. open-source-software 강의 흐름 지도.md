## 점검 포인트

- **범위:** 11개 PDF, 총 0쪽.
- **텍스트 근거:** 첫 페이지 추출 단서를 표에 남겨 제목·주제의 근거로 삼았습니다.
- **시각 자료:** 2개 파일은 첫 페이지 텍스트가 빈약하므로, HTML/SVG로 옮길 수 없는 도식은 승인된 크롭 후보로만 별도 검토합니다.
