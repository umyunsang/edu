> [!abstract] 핵심
> SQL은 관계 데이터베이스를 위한 표준 비절차적 질의어로, 데이터 정의·조작·뷰·삽입 SQL 같은 역할을 가진다.

## 구조를 먼저 구분하기

SQL은 관계 데이터베이스를 위한 표준 질의어이며 비절차적 데이터 언어다. 대화식 SQL은 DBMS에 직접 접근해 질의를 실행하고, 삽입 SQL은 프로그래밍 언어로 작성한 응용 프로그램에 SQL을 넣어 사용한다.

```mermaid
flowchart LR
    A["요구 또는 데이터"] --> B["구조화"]
    B --> C["연산 또는 관리"]
    C --> D["제약과 통제"]
    D --> E["결과 확인"]
```

| 관점 | 핵심 질문 | 점검 방법 |
| --- | --- | --- |
| 정의 | 구조와 제약 생성 | 테이블·도메인·제약을 검토한다 |
| 조작 | 데이터 조회·변경 | 조건과 변경 범위를 확인한다 |
| 사용 방식 | 대화식·삽입 SQL | 실행 주체와 연결 방식을 구분한다 |

> [!note] 적용 순서
> 먼저 스키마 정의와 데이터 조작을 구분하고, 목적에 맞는 SQL 기능을 선택한다. 뷰는 사용자에게 필요한 데이터 표현을 제공하는지, 삽입 SQL은 응용의 입력·결과 처리와 맞는지 점검한다.

## 세 관점

<Tabs>
<Tab label="개념">

SQL은 무엇을 원하는지 표현하는 비절차적 언어다. DBMS가 내부 실행 방법을 선택한다.

</Tab>
<Tab label="적용">

테이블 정의 뒤 데이터 조작을 수행하고, 뷰로 필요한 결과를 구성한다. 응용에서는 삽입 SQL의 입출력을 관리한다.

</Tab>
<Tab label="검증">

조회와 변경을 분리해 검토한다. 변경 SQL은 대상 행과 조건을 먼저 확인해야 한다.

</Tab>
</Tabs>
