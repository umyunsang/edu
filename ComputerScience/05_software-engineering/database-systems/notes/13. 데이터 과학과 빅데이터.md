> [!abstract] 핵심
> 데이터 과학은 생성·수집·저장·분석·표현을 거쳐 새로운 지식을 발견하고 문제 해결에 활용하는 활동이며, 빅데이터는 저장·분석·표현 기술의 변화를 요구한다.

## 구조를 먼저 구분하기

데이터 과학은 데이터를 수집한 뒤 분석해 숨은 지식을 발견하고 문제 해결에 활용하는 전 과정이다. 빅데이터·사물 인터넷·인공지능 환경에서는 규모와 형태가 다양해 전통적인 수집·저장만으로 한계가 생길 수 있다. 자료는 NoSQL, 데이터 마이닝, 데이터 시각화를 각각 저장·분석·표현 기술로 다룬다.

```mermaid
flowchart LR
    A["요구 또는 데이터"] --> B["구조화"]
    B --> C["연산 또는 관리"]
    C --> D["제약과 통제"]
    D --> E["결과 확인"]
```

| 관점 | 핵심 질문 | 점검 방법 |
| --- | --- | --- |
| 데이터 과학 | 지식 발견과 문제 해결의 전 과정 | 단계를 빠뜨리지 않는다 |
| 저장 | 대규모 데이터 보관 | 형태·규모 요구를 본다 |
| 분석·표현 | 규칙 발견과 전달 | 결과의 해석·시각화를 분리한다 |

> [!note] 적용 순서
> 문제에서 필요한 데이터를 정의하고 생성·수집·저장·분석·표현 단계를 연결한다. 규모·속도·형태에 맞는 저장 방식과 분석·표현 결과를 구분해 평가한다.

## 세 관점

<Tabs>
<Tab label="개념">

데이터 과학은 분석만이 아니라 데이터 생성에서 결과 표현까지의 과정이다.

</Tab>
<Tab label="적용">

데이터의 형태와 규모를 기준으로 저장 기술을 선택하고, 분석 결과를 문제 해결과 연결한다.

</Tab>
<Tab label="검증">

발견한 패턴이 실제 의사 결정에 유용한지와 표현이 오해를 만들지 않는지를 함께 검증한다.

</Tab>
</Tabs>
