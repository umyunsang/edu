> [!abstract] 핵심
> 연습문제는 데이터베이스의 실시간 접근성·계속 변화·동시 공유 같은 특성을 실제 문장과 연결해 판별하게 한다.

## 구조를 먼저 구분하기

데이터베이스는 현실 세계의 상태를 정확히 반영하기 위해 데이터를 삽입·삭제·수정해 현재 값을 유지한다. 연습문제는 이러한 계속 변화, 여러 사용자의 공동 이용인 동시 공유, 필요한 때 접근하는 특성을 정의와 사례로 연결한다.

```mermaid
flowchart LR
    A["요구 또는 데이터"] --> B["구조화"]
    B --> C["연산 또는 관리"]
    C --> D["제약과 통제"]
    D --> E["결과 확인"]
```

| 관점 | 핵심 질문 | 점검 방법 |
| --- | --- | --- |
| 실시간 접근성 | 필요한 때 접근 가능 | 요청과 응답 시점을 본다 |
| 계속 변화 | 현실을 반영한 지속 갱신 | 삽입·삭제·수정을 확인한다 |
| 동시 공유 | 여러 사용자의 공동 이용 | 공유와 통제 요구를 본다 |

> [!note] 적용 순서
> 설명 문장에서 시간 변화·동시 사용자·접근 요구를 구분하고, 해당 데이터베이스 특성과 연결한다. 한 특성에 맞는 예와 맞지 않는 예를 각각 만들어 본다.

<Tabs>
<Tab label="개념">

데이터베이스 특성은 독립된 단어 목록이 아니라 운영 상황에서 나타나는 요구다.

</Tab>
<Tab label="적용">

문장의 행위를 시간·갱신·사용자 수로 나누어 특성과 매칭한다. 사례를 직접 바꾸어 본다.

</Tab>
<Tab label="검증">

</Tab>
</Tabs>

<details>
<summary>복습 질문</summary>

</details>

> 구조, 연산, 제약을 분리해 적은 뒤 서로 어떤 조건으로 연결되는지 설명한다. 예시를 바꿀 때는 한 조건씩 바꾼다.
