> [!abstract] 핵심 요약
> 자바스크립트의 싱글 스레드 런타임은 **이벤트 루프(Event Loop)**와 **마이크로태스크 큐(Promise, async/await)**를 통해 논블로킹 I/O를 수행한다. 
> RESTful API는 HTTP 메서드(`GET`, `POST`, `PUT`, `DELETE`)와 상태 코드(`200`, `201`, `400`, `404`, `500`)를 표준으로 클라이언트-서버 상태를 통신한다.
