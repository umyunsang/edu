> 자바스크립트는 `querySelector`, `addEventListener`를 통해 DOM 노드를 동적으로 제어하며, 이벤트 전파는 **캡처링(Capturing) $ightarrow$ 타깃(Target) $ightarrow$ 버블링(Bubbling)** 3단계로 발생한다.
