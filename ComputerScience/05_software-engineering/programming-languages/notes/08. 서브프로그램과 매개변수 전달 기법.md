> [!abstract] 핵심 요약
> 서브프로그램 실행 시 스택에 **활성화 레코드(스택 프레임)**가 할당된다. 
> 매개변수 전달 기법은 실매개변수의 값을 복사하는 **값 전달(Call-by-Value)**, 메모리 주소를 전달하여 호출자 변수를 직접 수정하는 **참조 전달(Call-by-Reference)**, 그리고 텍스트 수준의 매크로 치환인 **이름 전달(Call-by-Name)**로 구분된다.

---

## 1. 매개변수 전달 기법 비교

| 전달 방식 | 동작 메커니즘 | 실매개변수 부작용 | 대표 언어 |
| :-- | :-- | :-- | :-- |
| **값 전달 (Call by Value)** | 인자의 값을 복사하여 전달 | 없음 (호출자 변수 안전) | C, Java (원시형), Python (객체 참조 복사) |
| **결과 전달 (Call by Result)** | 서브프로그램 종료 시 지역 변수를 실매개변수에 복사 | 있음 (종료 시점에 반영) | Ada `out` 모드 |
| **참조 전달 (Call by Reference)** | 실매개변수의 메모리 주소를 전달 | 즉각 반영 | C++ (`&`), Pascal (`var`), Fortran |
| **이름 전달 (Call by Name)** | 실매개변수의 텍스트 표현식을 그대로 치환 (Thunk) | 지연 평가 및 복잡한 부작용 | Algol 60 |
