## 개념을 연결하는 순서

강의 소개와 1·2장은 프로그래밍 언어를 인간과 컴퓨터 사이의 의사소통 도구로 정의하고, 가독성·작성 용이성·신뢰성·비용 같은 평가 기준과 세대별 추상화 발전을 살핀다.

- 명령어 집합 자료는 레지스터·상수·메모리·분기·입출력 명령을 작은 실행 모델로 보여 준다.
- 구문론은 무한한 프로그램을 유한한 규칙으로 표현하기 위해 재귀적 정의와 문법 생성 규칙을 사용한다.
- 이름·바인딩·영역 자료는 식별자와 객체의 연결 시점, 정적·동적 영역, 변수 수명과 가시성을 구분한다.
- 자료형 자료는 값의 모임과 연산 집합, 타입 검사·문서화·모듈화 역할을 설명한다.

| 질문 | 확인할 개념 | 스스로 해 볼 일 |
| :-- | :-- | :-- |
| 어떤 문장이 가능한가 | 문법·생성 규칙 | 문자열을 문법으로 유도 |
| 언제 연결되는가 | 바인딩 시간 | 이름·타입·저장소 연결 시점 나열 |
| 어디서 보이는가 | 영역 | 정적/동적 영역 차이 추적 |
| 무엇을 담는가 | 자료형 | 값과 허용 연산을 묶어 설명 |

연습 자료는 문법으로 생성되는 문자열을 판별하고, 식별자 판독성·정적 변수 장단점·동적 타입 바인딩·JavaScript 골격의 영역 문제를 적용하게 한다.

```html preview
<div style="font-family:system-ui,sans-serif;padding:20px;color:var(--foreground)">
  <label for="flow486392" style="font-size:14px;font-weight:600">원본 강의 단계</label>
  <div id="flow486392-out" style="font-size:30px;font-weight:700;color:var(--chart-1);margin:6px 0">언어의 목적·평가·발전</div>
  <input id="flow486392" type="range" min="1" max="3" step="1" value="1"
    style="width:100%;accent-color:var(--primary)" />
  <p style="font-size:13px;color:var(--muted-foreground)">슬라이더로 PDF에서 정리한 강의 단계를 순서대로 확인합니다.</p>
  <script>
    var flow486392 = document.getElementById('flow486392');
    var flow486392Out = document.getElementById('flow486392-out');

    flow486392.addEventListener('input', function () {
      flow486392Out.textContent = flow486392Steps[Number(flow486392.value) - 1] || '';
    });
  </script>
</div>
```
