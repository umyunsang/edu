> [!abstract] 핵심 요약
> 프로그래밍 언어는 폰 노이만 구조에 기반한 **명령형(Imperative)**에서 출발하여, 수학적 함수 모델에 기반한 **함수형(Functional)**, 술어 논리 기반의 **논리형(Logic)**, 그리고 데이터와 행위를 캡슐화한 **객체지향(Object-Oriented)** 패러다임으로 발전해왔다.

---

## 1. 프로그래밍 패러다임 4대 분류

```mermaid
flowchart TD
    ROOT["프로그래밍 패러다임 계보"]
    ROOT --> IMP["1. 명령형 (Imperative)<br/>상태(State)와 제어 흐름(Control Flow) 변경<br/>(C, Pascal, Go)"]
    ROOT --> FUN["2. 함수형 (Functional)<br/>수학적 함수 합성과 불변성(Immutability)<br/>(Lisp, Haskell, Clojure)"]
    ROOT --> OOP["3. 객체지향 (OOP)<br/>캡슐화, 상속, 다형성<br/>(Smalltalk, C++, Java)"]
    ROOT --> LOG["4. 선언형/논리형 (Declarative/Logic)<br/>규칙과 팩트 기반 추론<br/>(Prolog, SQL)"]
```
