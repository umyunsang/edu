> [!abstract] 핵심 요약
> 변수는 **이름(Name), 주소(Address/L-value), 타입(Type), 값(Value/R-value), 영역(Scope), 수명(Lifetime)**의 6대 속성을 지닌다. 
> 속성과 엔티티의 연관을 **바인딩(Binding)**이라 하며, 프로그램 텍스트 구조로 결정되는 **정적 스코프(Static/Lexical Scope)**와 런타임 호출 스택 순서로 결정되는 **동적 스코프(Dynamic Scope)**로 구분된다.

---

## 1. 정적 스코프 vs 동적 스코프 비교

```python
x = 10

def sub1():
    print(x)

def sub2():
    x = 20
    sub1()

sub2()
```

- **정적 스코프(Static Scope)**: `sub1()`이 정의된 정적 문맥을 참조하므로 **10** 출력. (C, Java, Python 등 대부분의 현대 언어)
- **동적 스코프(Dynamic Scope)**: `sub1()`을 호출한 런타임 호출자 `sub2()`의 지역 변수 `x`를 참조하므로 **20** 출력. (초기 Lisp, APL, Bash)
