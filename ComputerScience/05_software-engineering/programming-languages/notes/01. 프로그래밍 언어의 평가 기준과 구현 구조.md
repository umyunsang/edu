> [!abstract] 핵심 요약
> 프로그래밍 언어 설계는 **가독성(Readability)**, **작성력(Writability)**, **신뢰성(Reliability)**, **비용(Cost)**의 4대 기준을 바탕으로 평가된다. 
> 언어 구현 기법은 순수 컴파일(Pure Compilation), 순수 인터프리터(Pure Interpretation), 그리고 바이트코드와 JIT을 결합한 하이브리드(Hybrid) 방식으로 구분된다.

---

## 1. 언어 평가의 4대 핵심 기준

```mermaid
flowchart TD
    ROOT["프로그래밍 언어 평가 기준"]
    ROOT --> C1["1. 가독성 (Readability)<br/>코드를 읽고 이해하기 쉬운 정도 (직교성, 단순성)"]
    ROOT --> C2["2. 작성력 (Writability)<br/>문제를 코드로 쉽게 표현할 수 있는 능력 (추상화 지원)"]
    ROOT --> C3["3. 신뢰성 (Reliability)<br/>타입 검사, 예외 처리, 메모리 안전성"]
    ROOT --> C4["4. 비용 (Cost)<br/>학습 비용, 작성 비용, 컴파일/실행 비용, 유지보수 비용"]
```
