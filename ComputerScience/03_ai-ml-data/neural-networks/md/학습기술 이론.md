# 뉴럴 네트워크 학습 기술 이론

이 문서는 뉴럴 네트워크의 성능과 안정성을 향상시키는 다양한 학습 기술들을 정리합니다.

---

## 1. 최적화 알고리즘 (Optimization Algorithms)

최적화 알고리즘은 손실 함수(Loss Function)의 값을 최소화하는 모델의 파라미터(가중치와 편향)를 찾는 방법입니다.

### 1.1. 경사 하강법 (Gradient Descent)

- **개념**: 손실 함수의 기울기(gradient)를 계산하여, 기울기가 낮아지는 방향으로 파라미터를 점진적으로 업데이트하는 가장 기본적인 최적화 방법입니다.
- **업데이트 식**:
  `W = W - η * (∂L / ∂W)`
  - `W`: 가중치
  - `η` (에타): 학습률 (Learning Rate)
  - `∂L / ∂W`: 가중치 `W`에 대한 손실 함수 `L`의 편미분 (기울기)
- **종류**:
  - **배치 경사 하강법 (Batch Gradient Descent)**: 전체 학습 데이터를 사용하여 한 번에 기울기를 계산. 안정적이지만 계산 비용이 매우 큽니다.
  - **확률적 경사 하강법 (Stochastic Gradient Descent, SGD)**: 한 번에 하나의 데이터 샘플만 사용하여 기울기를 계산하고 파라미터를 업데이트. 계산 속도는 빠르지만, 업데이트 방향이 불안정하여 수렴 과정이 흔들릴 수 있습니다.
  - **미니배치 경사 하강법 (Mini-batch Gradient Descent)**: 전체 데이터를 작은 '미니배치' 단위로 나누어, 각 미니배치마다 기울기를 계산하고 파라미터를 업데이트. BGD와 SGD의 장점을 절충한 방식으로, 현재 가장 널리 사용됩니다.

### 1.2. 모멘텀 (Momentum)

- **개념**: 경사 하강법에 '관성'을 더한 방법입니다. 이전 업데이트의 방향과 속도를 기억하여 현재 업데이트에 반영합니다. 이를 통해 지역 최솟값(local minima)을 탈출하고, 수렴 속도를 높일 수 있습니다.
- **업데이트 식**:
  `v = γ * v + η * (∂L / ∂W)`
  `W = W - v`
  - `v`: 속도 (velocity) 벡터
  - `γ` (감마): 모멘텀 계수 (보통 0.9 정도의 값 사용)
- **특징**: 기울기가 같은 방향으로 계속되면 속도가 빨라지고, 방향이 자주 바뀌면 속도가 줄어들어 안정적인 수렴을 돕습니다.

### 1.3. 네스테로프 가속 경사 (Nesterov Accelerated Gradient, NAG)

- **개념**: 모멘텀을 개선한 방법입니다. 현재 위치가 아닌, '모멘텀에 의해 한 걸음 미리 나아간 위치'에서 기울기를 계산합니다. 이를 통해 불필요한 움직임을 줄이고 더 효율적으로 최적점에 접근할 수 있습니다.
- **업데이트 식**:
  1. **미리 이동**: `W_lookahead = W - γ * v_prev`
  2. **미래 위치에서 기울기 계산**: `g = ∂L / ∂W` at `W_lookahead`
  3. **속도 및 가중치 업데이트**:
     `v = γ * v_prev + η * g`
     `W = W - v`
- **특징**: 모멘텀이 너무 빠르게 나아가서 최적점을 지나치는 경우를 방지하는 데 효과적입니다.

### 1.4. 적응적 학습률 방법 (Adaptive Learning Rate Methods)

각 파라미터마다 다른 학습률을 적용하여 최적화를 더 효율적으로 만드는 방법들입니다.

#### 1.4.1. AdaGrad (Adaptive Gradient)

- **개념**: 학습 과정에서 많이 업데이트된 파라미터는 학습률을 작게, 적게 업데이트된 파라미터는 학습률을 크게 조절합니다.
- **업데이트 식**:
  `G = G + (∂L / ∂W)²`
  `W = W - (η / sqrt(G + ε)) * (∂L / ∂W)`
  - `G`: 이전까지의 모든 기울기 제곱의 합
  - `ε` (엡실론): 0으로 나누는 것을 방지하는 작은 값
- **단점**: 학습이 길어지면 `G`가 무한히 커져서 학습률이 0에 가까워지고, 결국 학습이 멈추는 '학습률 소실' 문제가 발생할 수 있습니다.

#### 1.4.2. RMSProp (Root Mean Square Propagation)

- **개념**: AdaGrad의 학습률 소실 문제를 해결하기 위해 제안되었습니다. 기울기 제곱의 합을 모두 저장하는 대신, '지수 이동 평균'을 사용하여 최근 기울기 정보에 더 큰 가중치를 둡니다.
- **업데이트 식**:
  `G = ρ * G_prev + (1 - ρ) * (∂L / ∂W)²`
  `W = W - (η / sqrt(G + ε)) * (∂L / ∂W)`
  - `ρ` (로): 지수 이동 평균의 감쇠율 (보통 0.9 사용)
- **특징**: `G`가 무한히 커지는 것을 방지하여 학습이 멈추지 않도록 합니다.

#### 1.4.3. Adam (Adaptive Moment Estimation)

- **개념**: RMSProp과 모멘텀을 결합한 방식으로, 현재 가장 널리 사용되는 최적화 알고리즘 중 하나입니다. 각 파라미터마다 적응적 학습률을 적용하면서도, 모멘텀처럼 이전 기울기의 방향을 유지하려는 성질을 가집니다.
- **업데이트 식**:
  1. **1차 모멘트(평균) 업데이트**: `m = β₁ * m + (1 - β₁) * (∂L / ∂W)`
  2. **2차 모멘트(분산) 업데이트**: `v = β₂ * v + (1 - β₂) * (∂L / ∂W)²`
  3. **편향 보정**: `m_hat = m / (1 - β₁^t)`, `v_hat = v / (1 - β₂^t)` (t는 타임스텝)
  4. **파라미터 업데이트**: `W = W - (η / sqrt(v_hat + ε)) * m_hat`
  - `β₁`, `β₂`: 모멘트 추정을 위한 지수 감쇠율 (보통 0.9, 0.999 사용)
- **특징**: 방향과 학습률을 모두 적응적으로 조절하여 빠르고 안정적인 수렴을 보입니다.

## 2. 가중치 초기화 (Weight Initialization)

뉴럴 네트워크의 학습 성패를 좌우하는 중요한 요소 중 하나입니다. 초기화를 잘못하면 기울기 소실/폭주 문제가 발생하여 학습이 제대로 이루어지지 않을 수 있습니다.

### 2.1. 기울기 소실/폭주 (Vanishing/Exploding Gradient)

- **기울기 소실**: 역전파 과정에서 기울기가 점차 작어져 0에 가까워지는 현상. 주로 Sigmoid, Tanh 함수와 같은 활성화 함수를 여러 층 쌓았을 때 발생하며, 앞쪽 레이어의 가중치가 거의 업데이트되지 않아 학습이 불가능해집니다.
- **기울기 폭주**: 기울기가 점차 커져 무한대에 가깝게 발산하는 현상. 파라미터가 비정상적으로 큰 값으로 업데이트되어 모델이 불안정해집니다.

### 2.2. LeCun 및 Xavier/Glorot 초기화

- **개념**: 활성화 함수의 종류에 따라 입/출력 노드의 개수를 고려하여 가중치를 초기화하는 방법. 각 층의 출력 분산을 입력 분산과 같게 만들어 신호가 너무 커지거나 작아지지 않도록 합니다.
- **대상 활성화 함수**: Sigmoid, Tanh
- **초기화 방법** (균등 분포의 경우):
  `W ~ U[-sqrt(6 / (n_in + n_out)), +sqrt(6 / (n_in + n_out))]`
  - `n_in`: 입력 노드 수
  - `n_out`: 출력 노드 수
- **특징**: 기울기 소실/폭주 문제를 완화하고 안정적인 학습을 가능하게 합니다.

### 2.3. He 초기화 (He Initialization)

- **개념**: ReLU 계열 활성화 함수에 최적화된 초기화 방법입니다. ReLU는 양수 값을 그대로 통과시키므로, Xavier 초기화의 분산 설정이 맞지 않습니다. He 초기화는 입력 노드의 수만 고려하여 분산을 조절합니다.
- **대상 활성화 함수**: ReLU, Leaky ReLU, ELU 등
- **초기화 방법** (정규 분포의 경우):
  `W ~ N(0, sqrt(2 / n_in))`
- **특징**: ReLU 함수를 사용한 깊은 네트워크에서 효율적인 학습을 돕습니다.

## 3. 학습 안정화를 위한 기술

### 3.1. 배치 정규화 (Batch Normalization)

- **개념**: 각 레이어에 들어가는 입력 데이터(활성화 값)의 분포를 평균 0, 분산 1로 정규화하는 기법입니다. 이를 통해 각 층이 독립적으로 학습할 수 있도록 하여 전체 학습 속도를 높이고 안정화합니다.
- **동작 방식**:
  1. 미니배치 단위로 입력 데이터의 평균과 분산을 계산합니다.
  2. 평균 0, 분산 1로 정규화합니다.
  3. 학습 가능한 파라미터 `γ`(gamma, 스케일)와 `β`(beta, 시프트)를 도입하여 정규화된 데이터의 표현력을 다시 높여줍니다. (`y = γ * x_norm + β`)
- **장점**:
  - **내부 공변량 변화(Internal Covariate Shift) 해결**: 각 층의 입력 분포가 학습 중에 변하는 현상을 줄여줍니다.
  - **학습 속도 향상**: 더 큰 학습률을 사용할 수 있게 합니다.
  - **기울기 소실 문제 완화**: 활성화 값이 비선형 함수의 비활성 영역에 머무는 것을 방지합니다.
  - **규제 효과**: 미니배치의 통계량에 의존하므로 약간의 노이즈가 추가되어 드롭아웃과 유사한 규제 효과를 냅니다.

## 4. 과적합 방지 기술 (Regularization)

모델이 학습 데이터에만 너무 잘 맞춰져서, 새로운 데이터(테스트 데이터)에 대한 성능이 떨어지는 현상을 '과적합(Overfitting)'이라고 합니다.

### 4.1. L1, L2 규제 (L1, L2 Regularization)

- **개념**: 손실 함수에 가중치의 크기에 대한 패널티 항을 추가하여, 가중치가 너무 커지지 않도록 제한하는 방법입니다.
- **L2 규제 (Weight Decay)**:
  - **패널티 항**: `λ * Σ(W²)` (가중치 제곱의 합)
  - **특징**: 가중치의 크기를 전반적으로 줄여 부드러운 모델을 만듭니다.
- **L1 규제 (Lasso)**:
  - **패널티 항**: `λ * Σ|W|` (가중치 절댓값의 합)
  - **특징**: 중요하지 않은 피처의 가중치를 0으로 만들어, '피처 선택(Feature Selection)' 효과를 가집니다. 모델을 더 희소(sparse)하게 만듭니다.

### 4.2. 드롭아웃 (Dropout)

- **개념**: 학습 과정에서 각 레이어의 뉴런 중 일부를 랜덤하게 비활성화(출력을 0으로 만듦)하는 기법입니다.
- **동작 방식**:
  - 학습 시: 매 미니배치마다 지정된 확률(p)로 뉴런을 랜덤하게 제거하고 학습을 진행합니다.
  - 테스트 시: 모든 뉴런을 사용하되, 각 뉴런의 출력에 (1-p)를 곱하여 스케일을 맞춰줍니다.
- **효과**:
  - 뉴런들이 특정 뉴런에 과도하게 의존하는 '동조화(co-adaptation)' 현상을 방지합니다.
  - 마치 여러 개의 작은 모델을 학습시켜 앙상블하는 것과 유사한 효과를 내어 일반화 성능을 높입니다.

### 4.3. 검증 데이터 (Validation Data)

- **개념**: 학습 데이터를 다시 **학습 데이터(Training Data)**와 **검증 데이터(Validation Data)**로 분리하여 모델의 일반화 성능을 평가하고, 하이퍼파라미터(학습률, 규제 강도 등)를 튜닝하는 데 사용하는 데이터입니다.
- **목적**:
  - **과적합 모니터링**: 학습 데이터의 손실은 계속 감소하지만, 검증 데이터의 손실이 증가하기 시작하는 시점을 파악하여 학습을 조기 종료(Early Stopping)할 수 있습니다.
  - **하이퍼파라미터 튜닝**: 여러 하이퍼파라미터 조합으로 모델을 학습시킨 후, 검증 데이터에서 가장 좋은 성능을 보인 조합을 선택합니다.
- **주의**: 모델의 최종 성능 평가는 반드시 한 번도 사용하지 않은 **테스트 데이터(Test Data)**로 수행해야 합니다.

### 4.4. K-겹 교차 검증 (K-fold Cross-validation)

- **개념**: 데이터셋이 작을 때 검증 성능의 신뢰도를 높이기 위한 방법입니다. 전체 데이터를 K개의 부분집합(fold)으로 나눕니다.
- **절차**:
  1. K-1개의 fold를 학습 데이터로, 나머지 1개의 fold를 검증 데이터로 사용합니다.
  2. 이 과정을 K번 반복하여 각 fold가 한 번씩 검증 데이터로 사용되도록 합니다.
  3. K개의 검증 결과를 평균내어 모델의 최종 성능을 평가합니다.
- **장점**: 모든 데이터를 학습과 검증에 활용할 수 있어, 데이터가 적을 때 더 안정적인 성능 평가가 가능합니다.
- **단점**: 모델을 K번 학습시켜야 하므로 계산 비용이 큽니다.

*참고: `Bengio's approximation`과 `expressive limitation`은 일반적인 학습 기술 용어라기보다는 특정 연구나 이론적 논의와 관련된 것으로 보입니다. 위 목록에서는 보다 보편적으로 사용되는 핵심 기술들을 중심으로 정리했습니다.*
