수치 미분은 모든 매개변수에 대해 순전파를 반복해야 하므로 $O(N)$의 계산 비용이 소요된다. **오차역전파법(Backpropagation)**은 **계산 그래프(Computational Graph)**와 **연쇄 법칙(Chain Rule)**을 이용하여 출력층의 손실(Loss)로부터 입력층 방향으로 단 한 번의 역방향 패스($O(1)$)를 통해 모든 가중치의 편미분을 고속으로 산출하는 핵심 알고리즘이다.

---

## 1. 연쇄 법칙 (Chain Rule)의 수학적 원리

합성함수 $z = f(y), y = g(x)$에 대하여$x$에 대한$z$의 미분은 국소적 미분(Local Derivative)들의 곱으로 표현된다:

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial y} \cdot \frac{\partial y}{\partial x}$$

## 2. 기본 계층별 역전파 수학적 유도

### 1) 덧셈 노드 ($z = x + y$)

$\frac{\partial z}{\partial x} = 1, \frac{\partial z}{\partial y} = 1$이므로, 상류(Upstream)에서 넘어온 기울기$\frac{\partial L}{\partial z}$를 **그대로 하류로 흘려보낸다**:
$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \cdot 1, \quad \frac{\partial L}{\partial y} = \frac{\partial L}{\partial z} \cdot 1$$

### 2) 곱셈 노드 ($z = x \cdot y$)

$\frac{\partial z}{\partial x} = y, \frac{\partial z}{\partial y} = x$ 이므로, **순전파 때의 서로 반대편 입력 신호를 곱하여 하류로 전달한다**:
$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \cdot y, \quad \frac{\partial L}{\partial y} = \frac{\partial L}{\partial z} \cdot x$$

### 3) Affine 계층 (행렬 곱 $Y = X W + B$)

배치 크기 $N$, 입력 차원$D_{\text{in}}$, 출력 차원$D_{\text{out}}$에 대하여:
$$\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y} W^T \quad (N \times D_{\text{in}} = (N \times D_{\text{out}}) \times (D_{\text{out}} \times D_{\text{in}}))$$
$$\frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y} \quad (D_{\text{in}} \times D_{\text{out}} = (D_{\text{in}} \times N) \times (N \times D_{\text{out}}))$$
$$\frac{\partial L}{\partial B} = \sum_{i=1}^N \frac{\partial L}{\partial Y_i} \quad (1 \times D_{\text{out}})$$

### 4) Softmax-with-Loss 계층

소프트맥스 함수와 교차 엔트로피 오차가 결합되었을 때의 역전파 기울기는 놀랍도록 단순한 **예측 확률과 정답 레이블의 차이**가 된다:
$$\frac{\partial L}{\partial a_k} = y_k - t_k$$

## 4. 파이썬 기반 2층 신경망 오차역전파 계층 구현

```python
import numpy as np

class MulLayer:
    def __init__(self):
        self.x = None
        self.y = None

    def forward(self, x, y):
        self.x = x
        self.y = y
        return x * y

    def backward(self, dout):
        dx = dout * self.y
        dy = dout * self.x
        return dx, dy

class Affine:
    def __init__(self, W, b):
        self.W = W
        self.b = b
        self.x = None
        self.dW = None
        self.db = None

    def forward(self, x):
        self.x = x
        return np.dot(x, self.W) + self.b

    def backward(self, dout):
        dx = np.dot(dout, self.W.T)
        self.dW = np.dot(self.x.T, dout)
        self.db = np.sum(dout, axis=0)
        return dx
```
