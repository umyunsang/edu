신경망 학습(Learning)이란 훈련 데이터로부터 가중치 매개변수 $W$와 편향 $b$의 최적값을 **손실 함수(Loss Function)의 값을 최소화**하는 방향으로 자동 갱신하는 과정이다.

---

## 1. 손실 함수 (Loss Functions)의 수학적 정의

### 1) 평균 제곱 오차 (Mean Squared Error, MSE)
회귀(Regression) 문제의 표준 손실 함수:
$$E = \frac{1}{2} \sum_{k=1}^K (y_k - t_k)^2$$
($\frac{1}{2}$은 역전파 미분 시 지수 2와 상쇄되어 계산을 단순화하기 위한 편의 상수).

### 2) 교차 엔트로피 오차 (Cross Entropy Error, CEE)
다중 클래스 분류(Classification)에서 원-핫 인코딩 정답 $t$에 대한 음의 로그 가능도(Negative Log Likelihood):
$$E = -\sum_{k=1}^K t_k \ln(y_k + \delta)$$
- **$\delta = 10^{-7}$**: $y_k=0$일 때 $\ln(0) = -\infty$가 되어 계산 불능(NaN)이 발생하는 현상을 방지하는 미소값.
- **정보 이론적 의미**: 정답 클래스($t_k=1$)의 예측 확률 $y_k$가 1에 가까울수록 손실은 0에 수렴하고, 0에 가까울수록 손실은 급격히 발산한다.

---

## 2. 수치 미분(Numerical Gradient)과 중심 차분

컴퓨터에서 $h \to 0$ 극한을 구현할 때의 오차를 최소화하기 위해 전방 차분 대신 **중심 차분(Central Difference)**을 사용한다:
$$\frac{df(x)}{dx} = \frac{f(x + h) - f(x - h)}{2h} \quad (h = 10^{-4})$$

다변수 함수 $f(x_0, x_1)$에서 모든 변수의 편미분을 모은 벡터를 **기울기(Gradient $\nabla f$)**라 하며, **기울기가 가리키는 방향은 함수의 출력값이 가장 크게 증가하는 방향**이다. 따라서 최소화 문제를 풀기 위해서는 **기울기의 반대 방향($-\nabla f$)**으로 이동해야 한다.

$$\mathbf{x} \leftarrow \mathbf{x} - \eta \nabla f(\mathbf{x})$$

## 4. 신경망 4단계 학습 알고리즘 루프

```
1. [미니배치 (Mini-batch)] : 훈련 데이터 중 일부를 무작위로 선별
2. [기울기 산출 (Gradient)] : 손실 함수를 줄이기 위해 각 가중치 W에 대한 편미분 ∂L/∂W 계산
3. [매개변수 갱신 (Update)] : 가중치를 기울기의 반대 방향으로 학습률 η만큼 갱신 (W <- W - η·∇L)
4. [반복 (Iteration)]     : 정해진 에포크(Epoch) 수만큼 1~3단계를 반복 수행
```
