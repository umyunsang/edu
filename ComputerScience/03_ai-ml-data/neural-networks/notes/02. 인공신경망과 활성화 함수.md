인공신경망(Artificial Neural Network)은 계단 함수(Step Function) 형태의 불연속적인 단일 퍼셉트론 임계 처리를 **연속적이고 미분 가능한 비선형 활성화 함수(Activation Function)**로 교체하여 경사하강법 기반의 오차 역전파 학습을 가능하게 만든 모델이다.

---

## 1. 활성화 함수의 필요성과 비선형성의 수학적 증명

신경망에서 활성화 함수 $h(x)$는 반드시 **비선형 함수(Non-linear Function)**여야 한다.

> [!IMPORTANT]
> **왜 선형 활성화 함수 $h(x) = c x$는 층을 깊게 쌓아도 무의미한가?**
> 선형 함수 $h(x) = c x$를 3층 신경망에 적용하면 출력은$y(x) = h(h(h(x))) = c \cdot c \cdot c \cdot x = c^3 x$가 된다.
> 상수 $a = c^3$로 두면$y(x) = a x$와 동일하여, **은닉층이 없는 단일 계층 선형 변환과 완전히 동등**해진다. 은닉층을 여러 층 쌓아 복잡한 특징을 계층적으로 추출하려면 반드시 비선형 함수를 적용해야 한다.

---

## 2. 주요 활성화 함수 및 도함수 유도

```text
1. [계단 함수 (Step)]    : h(x) = 0 (x <= 0), 1 (x > 0) -> 도함수가 거의 모든 곳에서 0 (학습 불가)
2. [시그모이드 (Sigmoid)]: σ(x) = 1 / (1 + e^-x)        -> σ'(x) = σ(x)(1 - σ(x)) [최댓값 0.25]
3. [하이퍼볼릭 탄젠트]  : tanh(x) = (e^x - e^-x)/(e^x + e^-x) -> tanh'(x) = 1 - tanh²(x) [원점 대칭]
4. [ReLU (경사 유지)]    : ReLU(x) = max(0, x)          -> x > 0에서 도함수 1.0 (그래디언트 소실 해소)
```

### 시그모이드(Sigmoid) 도함수의 단계별 유도

$$y = \sigma(x) = \frac{1}{1 + e^{-x}} = (1 + e^{-x})^{-1}$$
$$\frac{dy}{dx} = -1 \cdot (1 + e^{-x})^{-2} \cdot (-e^{-x}) = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}} \cdot \frac{e^{-x}}{1 + e^{-x}} = y (1 - y)$$

## 4. 다층 신경망의 순전파 (Forward Propagation) 행렬 수식

3층 신경망($2 \to 3 \to 2 \to 2$)의 순전파 계층별 텐서 계산:

$$A^{(1)} = X W^{(1)} + B^{(1)} \quad (X: 1 \times 2, W^{(1)}: 2 \times 3, B^{(1)}: 1 \times 3)$$
$$Z^{(1)} = h(A^{(1)})$$
$$A^{(2)} = Z^{(1)} W^{(2)} + B^{(2)} \quad (W^{(2)}: 3 \times 2, B^{(2)}: 1 \times 2)$$
$$Z^{(2)} = h(A^{(2)})$$
$$A^{(3)} = Z^{(2)} W^{(3)} + B^{(3)} \quad (W^{(3)}: 2 \times 2, B^{(3)}: 1 \times 2)$$
$$Y = \sigma(A^{(3)}) \quad \text{또는} \quad Y = \text{softmax}(A^{(3)})$$

## 5. 소프트맥스(Softmax) 오버플로 방지 수식

$$y_k = \frac{\exp(a_k)}{\sum_{i=1}^n \exp(a_i)} = \frac{C' \exp(a_k)}{C' \sum_{i=1}^n \exp(a_i)} = \frac{\exp(a_k + \ln C')}{\sum_{i=1}^n \exp(a_i + \ln C')} = \frac{\exp(a_k - C)}{\sum_{i=1}^n \exp(a_i - C)}$$
($C = \max(a)$로 두어 지수함수 입력의 최댓값을 0으로 고정하여 컴퓨터의 float64 한계($e^{1000} \to \text{inf}$)를 방지한다).
