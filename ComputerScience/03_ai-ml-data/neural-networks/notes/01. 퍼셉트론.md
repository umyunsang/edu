퍼셉트론(Perceptron)은 1957년 프랑크 로젠블랫(Frank Rosenblatt)이 제안한 인공 신경망의 기본 알고리즘으로, 다수의 신호를 입력받아 가중합을 계산하고 임계값을 초과할 때 단일 신호(0 또는 1)를 출력하는 수학적 이진 분류기다.

---

## 1. 단일 퍼셉트론(Single-Layer Perceptron)의 수학적 모델

### 1) 신호 전달과 임계값 수식

입력 신호 $x_1, x_2$, 각 입력에 부여되는 가중치$w_1, w_2$, 그리고 뉴런의 활성화 기준인 임계값$\theta$에 대하여:

$$y = \begin{cases} 0 & (w_1 x_1 + w_2 x_2 \le \theta) \\ 1 & (w_1 x_1 + w_2 x_2 > \theta) \end{cases}$$

### 2) 편향(Bias $b = -\theta$)을 도입한 표준 수식

임계값 $\theta$를 좌변으로 이항하여 편향$b = -\theta$로 치환하면, 퍼셉트론은 **입력 신호와 가중치의 내적에 편향을 더한 값이 0을 넘는가**를 판별하는 2차원 결정 초평면(Hyperplane) 식이 된다:

$$y = \begin{cases} 0 & (b + w_1 x_1 + w_2 x_2 \le 0) \\ 1 & (b + w_1 x_1 + w_2 x_2 > 0) \end{cases}$$

- **가중치 ($w_1, w_2$)**: 각 입력 신호가 결과에 미치는 영향력(중요도)을 조절.
- **편향 ($b$)**: 뉴런이 얼마나 쉽게 활성화(1을 출력)되는지를 결정하는 민감도 매개변수.

---

## 2. 기본 논리 게이트의 선형 분리성 (Linear Separability)

| 게이트 | $x_1$|$x_2$| 출력$y$| 매개변수 조합 예시$(w_1, w_2, b)$ | 기하학적 특성 |
| :--- | :---: | :---: | :---: | :--- | :--- |
| **AND** | 0<br>0<br>1<br>1 | 0<br>1<br>0<br>1 | 0<br>0<br>0<br>**1** | $(0.5, 0.5, -0.7)$| 직선$0.5x_1 + 0.5x_2 - 0.7 = 0$으로$(1, 1)$만 분리 |
| **NAND** | 0<br>0<br>1<br>1 | 0<br>1<br>0<br>1 | 1<br>1<br>1<br>**0** | $(-0.5, -0.5, 0.7)$ | AND의 결정 직선 부호를 반전 |
| **OR** | 0<br>0<br>1<br>1 | 0<br>1<br>0<br>1 | 0<br>**1**<br>**1**<br>**1** | $(0.5, 0.5, -0.2)$| 직선$0.5x_1 + 0.5x_2 - 0.2 = 0$으로$(0, 0)$만 분리 |
| **XOR** | 0<br>0<br>1<br>1 | 0<br>1<br>0<br>1 | 0<br>**1**<br>**1**<br>0 | **단일 직선 분리 불가능** | **비선형 영역 (Non-linear)** |

## 4. 민스키의 XOR 한계와 다층 퍼셉트론(MLP)의 해법

1969년 마빈 민스키(Marvin Minsky)와 시모어 페퍼트(Seymour Papert)는 단일 퍼셉트론으로는 비선형 분리 문제인 **XOR 게이트를 절대 해결할 수 없음**을 증명하였다.

### 다층 퍼셉트론 (2층 구조)을 통한 XOR 구현

단일 직선으로는 불가능하지만, **NAND 게이트와 OR 게이트를 1단계 은닉층($s_1, s_2$)으로 배치하고 그 출력을 AND 게이트로 결합**하면 비선형 결정 영역을 완벽하게 분리할 수 있다.

$$\text{XOR}(x_1, x_2) = \text{AND}\left( \text{NAND}(x_1, x_2), \text{OR}(x_1, x_2) \right)$$

## 5. Python NumPy 단일/다층 퍼셉트론 구현

```python
import numpy as np

def AND(x1, x2):
    x = np.array([x1, x2])
    w = np.array([0.5, 0.5])
    b = -0.7
    return 1 if np.sum(w * x) + b > 0 else 0

def NAND(x1, x2):
    x = np.array([x1, x2])
    w = np.array([-0.5, -0.5])
    b = 0.7
    return 1 if np.sum(w * x) + b > 0 else 0

def OR(x1, x2):
    x = np.array([x1, x2])
    w = np.array([0.5, 0.5])
    b = -0.2
    return 1 if np.sum(w * x) + b > 0 else 0

def XOR(x1, x2):
    s1 = NAND(x1, x2)
    s2 = OR(x1, x2)
    return AND(s1, s2)

# XOR 진리표 검증
for x1, x2 in [(0, 0), (0, 1), (1, 0), (1, 1)]:
    print(f"XOR({x1}, {x2}) -> {XOR(x1, x2)}")
```
