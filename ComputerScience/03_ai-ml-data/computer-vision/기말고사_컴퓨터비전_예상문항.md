### 문항 1. Block matching의 기본 정의

난이도: 쉬움  
유형: 용어

문제: Block matching에 대한 설명으로 가장 적절한 것은?

- A. 한 픽셀 주변 window/block을 오른쪽 영상의 후보 block들과 비교해 disparity를 고르는 local stereo 방법이다.  
- B. 월드 좌표를 카메라 좌표로 바꾸는 extrinsic 변환이다.  
- C. 3D Gaussian primitive를 영상 평면에 splatting하는 neural rendering 방법이다.  
- D. 단안 RGB 영상만으로 항상 metric depth를 정확히 복원하는 방법이다.  
- E. rotation matrix의 DoF를 계산하는 방법이다.

정답: A

해설: Block matching은 rectified stereo에서 왼쪽 block과 오른쪽 후보 block의 matching cost를 비교해 최적 disparity를 고른다.

오답 포인트: B는 Ch6 extrinsic, C는 3D Gaussian Splatting, D는 단안 depth foundation model 쪽 설명, E는 회전 기하 문제다.

### 문항 2. Block matching의 탐색 방향

난이도: 쉬움  
유형: 정의

문제: rectification 이후 Block matching이 주로 탐색하는 위치로 가장 적절한 것은?

- A. 오른쪽 영상의 같은 scanline 안에서 search range에 포함되는 후보 위치  
- B. 오른쪽 영상 전체의 모든 2D 위치  
- C. 월드 좌표계의 모든 3D 점  
- D. feature encoder의 모든 layer  
- E. 카메라 내부 파라미터의 모든 조합

정답: A

해설: rectification은 대응점 탐색을 같은 행의 1D search range로 줄여 준다.

오답 포인트: B는 rectification의 효과를 무시한다. C는 stereo matching의 영상 탐색이 아니다. D는 deep network 내부 표현이다. E는 calibration 탐색에 가깝다.

### 문항 3. SAD의 값 해석

난이도: 쉬움  
유형: 공식

문제: SAD, Sum of Absolute Difference에 대한 설명으로 옳은 것은?

- A. 대응 픽셀 차이의 절댓값 합이며, 작을수록 block이 더 유사하다.  
- B. 대응 픽셀 차이의 제곱합이며, 클수록 block이 더 유사하다.  
- C. 정규화 상관계수이며, 1에 가까울수록 관계가 없다.  
- D. disparity 후보 수를 뜻하며, search range와 같은 의미다.  
- E. smoothness term의 가중치이며, 클수록 경계가 선명해진다.

정답: A

해설: SAD는 절대 차이를 모두 더한 비용이므로 작은 값이 좋은 match를 뜻한다.

오답 포인트: B는 SSD와 값 해석을 섞었다. C는 NCC 설명을 잘못 바꾼 것이다. D는 cost volume의 disparity 차원과 관련된다. E는 global matching의 smoothness 가중치 설명이다.

### 문항 4. SSD의 penalty 특성

난이도: 쉬움  
유형: 공식

문제: SSD, Sum of Squared Difference의 특징으로 가장 적절한 것은?

- A. 큰 intensity 차이를 제곱하기 때문에 큰 오차에 더 강한 penalty를 준다.  
- B. 모든 후보 disparity에 같은 비용을 주어 textureless 문제를 없앤다.  
- C. NCC처럼 항상 -1에서 1 사이 값을 가진다.  
- D. 중심 픽셀과 주변 픽셀의 상대 순서를 bit pattern으로 바꾼다.  
- E. stage별 L1 loss를 뒤쪽 stage 중심으로 누적한다.

정답: A

해설: SSD는 차이를 제곱하므로 큰 오차가 비용에 더 크게 반영된다.

오답 포인트: B는 실제 matching cost의 역할과 반대다. C는 NCC 범위다. D는 Census transform이다. E는 RAFT-Stereo의 sequential loss 설명이다.

### 문항 5. NCC의 해석

난이도: 쉬움  
유형: 정의

문제: NCC, Normalized Cross Correlation에 대한 설명으로 옳은 것은?

- A. 정규화 상관계수이며, 1에 가까울수록 두 block이 잘 맞는다고 본다.  
- B. 절댓값 차이를 더하므로 값이 작을수록 좋다.  
- C. 제곱 차이를 더하므로 outlier에 가장 강하지 않다.  
- D. disparity 후보의 개수 D를 직접 의미한다.  
- E. 3D camera pose의 rotation 3 DoF를 뜻한다.

정답: A

해설: NCC는 SAD/SSD와 달리 similarity로 해석하며, 높은 값이 더 좋은 match를 뜻한다.

오답 포인트: B는 SAD, C는 SSD, D는 cost volume 차원, E는 Ch6 DoF 설명이다.

### 문항 6. block/window size trade-off

난이도: 쉬움  
유형: 파라미터

문제: Block matching에서 block size를 크게 할 때의 일반적 trade-off로 가장 적절한 것은?

- A. 노이즈에는 더 안정적일 수 있지만 depth edge가 뭉개질 수 있다.  
- B. 항상 계산량이 0이 되고 경계도 완벽히 보존된다.  
- C. search range가 자동으로 무한대가 된다.  
- D. NCC 값 범위가 -1에서 1이 아니라 0에서 255로 바뀐다.  
- E. extrinsic parameter가 intrinsic parameter로 바뀐다.

정답: A

해설: 큰 window는 주변 정보를 더 많이 쓰므로 안정성이 늘 수 있지만 서로 다른 깊이의 픽셀이 섞이면 경계가 흐려진다.

오답 포인트: B는 trade-off를 부정한다. C는 별도 파라미터인 search range를 섞었다. D는 NCC 정의와 무관하다. E는 카메라 파라미터 분류 오류다.

### 문항 7. search range의 의미

난이도: 쉬움  
유형: 파라미터

문제: Block matching에서 search range를 넓힐 때 생길 수 있는 결과로 옳은 것은?

- A. 큰 disparity 후보까지 찾을 수 있지만 계산량과 반복 패턴 오매칭 위험이 커질 수 있다.  
- B. disparity 후보를 하나로 고정하므로 계산량이 항상 줄어든다.  
- C. smoothness term이 자동으로 사라진다.  
- D. 카메라의 skew가 0으로 보정된다.  
- E. volume rendering이 반드시 빨라진다.

정답: A

해설: search range는 검사할 disparity 후보 범위이므로 넓을수록 후보 수와 계산 부담이 늘어난다.

오답 포인트: B는 후보 증가 방향을 반대로 말했다. C는 global matching 항과 무관하다. D는 intrinsic calibration 문제다. E는 NeRF 렌더링 설명이다.

### 문항 8. local stereo가 어려워지는 영역

난이도: 쉬움  
유형: 비교

문제: Block matching이 실패하기 쉬운 상황으로 묶인 것은?

- A. textureless region, repetitive pattern, occlusion  
- B. homogeneous coordinates, intrinsic matrix, calibration  
- C. ViT patch token, DINO teacher, DPT decoder  
- D. rotation 3 DoF, translation 3 DoF, camera pose  
- E. volume rendering, implicit function, radiance field

정답: A

해설: local matching은 단색 영역, 반복 무늬, 한쪽 영상에만 보이는 occlusion에서 대응점을 안정적으로 찾기 어렵다.

오답 포인트: B와 D는 Ch6 기하 용어다. C와 E는 LMS modern method 용어다.

### 문항 9. occlusion의 핵심 문제

난이도: 쉬움  
유형: 정의

문제: stereo matching에서 occlusion이 어려운 이유로 가장 적절한 것은?

- A. 한쪽 카메라에는 보이지만 다른 쪽 카메라에는 대응 영역이 없을 수 있기 때문이다.  
- B. 모든 block이 완전히 같은 밝기 값을 갖기 때문이다.  
- C. focal length가 항상 0이 되기 때문이다.  
- D. homogeneous 좌표의 마지막 성분을 나눌 수 없기 때문이다.  
- E. DINO가 label을 사용하지 않기 때문이다.

정답: A

해설: occlusion은 대응점 자체가 존재하지 않을 수 있는 문제라서 비용 함수만 바꾼다고 완전히 해결되지 않는다.

오답 포인트: B는 textureless 문제에 가깝다. C와 D는 카메라 기하 오류다. E는 self-supervised representation 설명이다.

### 문항 10. global matching energy의 두 항

난이도: 쉬움  
유형: 공식

문제: $E(d)=E_{data}(d)+\lambda E_{smooth}(d)$에서 $E_{smooth}$의 역할로 가장 적절한 것은?

- A. 인접 픽셀의 disparity가 지나치게 불규칙해지지 않도록 부드러움 제약을 준다.  
- B. 왼쪽 block과 오른쪽 block의 raw intensity 차이만 저장한다.  
- C. 카메라 내부 파라미터의 principal point를 저장한다.  
- D. NeRF의 density를 누적해 pixel color를 만든다.  
- E. ViT patch token의 positional vector를 제거한다.

정답: A

해설: smoothness term은 주변 disparity의 일관성을 선호해 noisy disparity map을 줄인다.

오답 포인트: B는 data term 또는 local cost에 가깝다. C는 intrinsic parameter다. D는 volume rendering이다. E는 ViT 입력 처리와 반대다.

### 문항 11. smoothness term을 너무 강하게 둘 때

난이도: 중간  
유형: 응용

문제: global matching에서 smoothness term의 영향이 지나치게 커질 때 가장 그럴듯한 문제는?

- A. 실제 depth discontinuity까지 평평하게 되어 물체 경계가 흐려질 수 있다.  
- B. textureless 영역의 비용 차이가 항상 완벽히 커진다.  
- C. Middlebury가 KITTI로 자동 변환된다.  
- D. $f_x$와 $f_y$가 반드시 같아진다.  
- E. NeRF가 explicit Gaussian primitive로 바뀐다.

정답: A

오답 포인트: B는 local evidence 문제를 과장했다. C는 benchmark 혼동이다. D는 intrinsic 파라미터 조건이 아니다. E는 implicit/explicit 표현을 섞었다.

### 문항 12. GraphCut의 위치

난이도: 중간  
유형: 비교

문제: stereo matching에서 GraphCut에 대한 설명으로 가장 적절한 것은?

- A. 픽셀과 disparity 후보를 graph로 모델링해 2D 인접관계를 반영하는 global optimization 접근이다.  
- B. 한 행만 독립적으로 처리하는 pure scanline local method이다.  
- C. 중심 픽셀 주변의 상대 밝기 순서를 bit string으로 만드는 cost이다.

- E. $K$ matrix의 skew를 뜻한다.

정답: A

해설: GraphCut은 data term과 smoothness term을 graph 에너지로 보고 minimum cut 계열 최적화를 적용하는 전역적 접근이다.

오답 포인트: B는 dynamic programming, C는 Census transform, D는 DPT decoder, E는 intrinsic parameter다.

### 문항 13. dynamic programming의 한계

난이도: 쉬움  
유형: 흐름

문제: stereo에서 dynamic programming을 scanline 단위로 적용할 때 생길 수 있는 대표 한계는?

- A. 행 사이 일관성이 약해 줄무늬나 line 간 불일치가 생길 수 있다.  
- B. 2D graph의 모든 경계를 항상 완벽히 최적화한다.

오답 포인트: B는 GraphCut 또는 global method 쪽 설명이다. C는 cost volume 정의와 다르다. D는 파라미터 분류 오류다. E는 LMS 렌더링과 무관하다.

### 문항 15. SGBM의 Semi-Global 의미

### 문항 16. Census transform의 정보

난이도: 쉬움  
유형: 정의

문제: Census transform이 SAD/SSD보다 조명 변화에 상대적으로 강한 이유로 가장 적절한 것은?

- A. 절대 밝기값보다 중심 픽셀과 주변 픽셀의 상대 밝기 순서를 bit pattern으로 사용하기 때문이다.  
- B. 모든 픽셀의 disparity를 같은 값으로 고정하기 때문이다.  
- C. camera calibration으로 focal length를 제거하기 때문이다.  
- D. volume rendering으로 color와 density를 적분하기 때문이다.  
- E. 3D Gaussian의 opacity를 0으로 두기 때문이다.

정답: A

해설: Census는 상대 순서를 사용하고 XOR와 Hamming distance로 bit string 차이를 비교한다.

오답 포인트: B는 올바른 matching이 아니다. C는 카메라 파라미터 추정이다. D는 NeRF rendering이다. E는 3DGS parameter 오류다.

### 문항 17. deep stereo pipeline 순서

난이도: 중간  
유형: 흐름

문제: deep stereo의 일반적 처리 순서로 가장 적절한 것은?

- A. feature extraction → cost volume 생성 → cost aggregation/refinement → disparity estimation  
- B. calibration → skew 제거 → principal point 삭제 → volume rendering  
- C. block size 선택 → NeRF 학습 → DINO crop 생성 → 3DGS 정렬  
- D. rotation matrix 계산 → homogeneous 나눗셈 → SSD 제거 → KITTI 변환  
- E. opacity 추정 → ViT patch 제거 → smoothness term 삭제 → disparity 포기

정답: A

해설: deep stereo는 feature를 뽑고, 후보 disparity별 cost volume을 만든 뒤, network로 정제해 disparity를 예측한다.

오답 포인트: B는 Ch6와 LMS를 뒤섞었다. C와 E는 unrelated method를 섞은 흐름이다. D는 기하와 stereo 평가 용어가 섞였다.

### 문항 18. RAFT-Stereo의 correlation pyramid

난이도: 중간  
유형: 흐름

문제: RAFT-Stereo의 correlation pyramid에 대한 설명으로 옳은 것은?
