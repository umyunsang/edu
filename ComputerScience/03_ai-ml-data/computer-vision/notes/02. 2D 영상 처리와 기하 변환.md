디지털 영상 처리는 2D 픽셀 공간에서 명암 대비를 조절하는 **점 처리(Point Processing)**, 영역 형태를 다듬는 **모폴로지(Morphology)**, 그리고 영상의 공간적 배치를 바꾸는 **기하학적 변환(Geometric Transformation)**으로 구성된다.

---

## 1. 명암 조절과 비선형 감마 보정 (Gamma Correction)

### 1) 인간 시각 특성과 베버-페히너 법칙

인간의 시각 시스템은 어두운 영역의 미세한 밝기 변화에는 매우 민감하지만, 매우 밝은 영역에서의 변화에는 상대적으로 둔감한 비선형적 로그 반응 특성을 보인다.

### 2) 감마 보정 수식 및 디스플레이 상쇄 원리

정규화된 입력 밝기 $\hat{f} = \frac{I_{\text{in}}}{255} \in [0, 1]$에 대해:
$$I_{\text{out}} = 255 \times \left( \frac{I_{\text{in}}}{255} \right)^\gamma$$

```text
[카메라 촬영 인코딩 (γ ≈ 1/2.2 ≈ 0.45)]        [모니터 디스플레이 출력 (γ ≈ 2.2)]
       밝게 부스팅하여 저장                          어둡게 감쇄되어 출력
                │                                             │
                └──────────────► 합성 감마 ≈ 1.0 ◄────────────┘
                            (인간 눈에 자연스러운 선형 밝기 복원)
```

- **$\gamma < 1$(예:$\gamma = 0.5$)**: 어두운 영역의 계조를 끌어올려 전체 영상이 밝아짐 (Shadow Detail 강조).
- **$\gamma = 1.0$**: 입력과 출력이 동일한 선형 매핑.
- **$\gamma > 1$(예:$\gamma = 2.0$)**: 중간 계조를 아래로 눌러 전체 영상이 어두워짐 (Highlight 대비 증가).

## 2. 모폴로지(Morphology) 연산과 구조 요소

이진 영상에서 객체의 외곽선과 형태를 제어하기 위해 **구조 요소(Structuring Element $B$)**를 슬라이딩하며 집합 연산을 수행한다.

```text
       [팽창 (Dilation)]                                  [침식 (Erosion)]
구조 요소 영역 내 1이 하나라도 있으면 1                 구조 요소 영역 전체가 1과 일치해야 1
  -> 작은 구멍 메움, 끊어진 선 연결                      -> 돌출부 제거, 독립 잡음 제거
```

| 연산자 | 수학적 정의 | 주요 효과 및 응용 |
| :--- | :--- | :--- |
| **팽창 (Dilation)** | $A \oplus B = \{ z \mid (\hat{B})_z \cap A \ne \emptyset \}$ | 객체 영역 확장, 내부 구멍(Hole) 채움, 끊어진 경계선 연결 |
| **침식 (Erosion)** | $A \ominus B = \{ z \mid (B)_z \subseteq A \}$ | 객체 크기 축소, 미세 돌기 제거, 배경의 고립된 잡음 픽셀 제거 |
| **열림 (Opening)** | $A \circ B = (A \ominus B) \oplus B$ | 침식 후 팽창. **전체 크기 유지하면서 작은 외곽 잡음 제거** |
| **닫힘 (Closing)** | $A \bullet B = (A \oplus B) \ominus B$ | 팽창 후 침식. **전체 크기 유지하면서 내부 미세 틈새와 구멍 메움** |

## 3. 동차좌표계 (Homogeneous Coordinates)와 2D 기하 변환

### 1) 동차좌표계의 필요성

일반 직교좌표계 $(x, y)$에서는 회전과 신축은 행렬 곱으로 표현되지만, **이동(Translation)**은 벡터 덧셈이 되어 복합 변환(Composition)을 단일 행렬 곱으로 합성할 수 없다.
2D 좌표에 스케일 계수 $w=1$을 추가하여 3차원 벡터$\begin{bmatrix} x & y & 1 \end{bmatrix}^T$로 표현하면 모든 아핀 변환을$3 \times 3$ 행렬 곱으로 일원화할 수 있다.

$$\begin{bmatrix} x \\ y \\ 1 \end{bmatrix} \sim \begin{bmatrix} kx \\ ky \\ k \end{bmatrix} \quad (k \ne 0)$$

### 2) 기본 2D 기하 변환 행렬 ($3 \times 3$)

$$\text{이동 (Translation): } T(t_x, t_y) = \begin{bmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1 \end{bmatrix}$$
$$\text{회전 (Rotation): } R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix}$$
$$\text{신축 (Scaling): } S(s_x, s_y) = \begin{bmatrix} s_x & 0 & 0 \\ 0 & s_y & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

## 5. 전방 사상 (Forward Mapping) vs 후방 사상 (Backward Mapping)

- **전방 사상 (Forward Mapping)**:
  - 입력 영상의 각 화소 $(x, y)$에 변환 행렬$M$을 곱해 출력 영상$(x', y') = M(x, y)$로 매핑.
  - 실수 좌표로 계산되어 반올림할 경우, 출력 영상에 **픽셀이 채워지지 않는 구멍(Holes/Aliasing)**이 발생함.
- **후방 사상 (Backward Mapping)**:
  - 출력 영상의 격자점 $(x', y')$에 역행렬$M^{-1}$을 곱해 입력 영상에서의 실수 좌표$(x, y) = M^{-1}(x', y')$를 역추적.
  - 주변 4개/16개 픽셀로부터 **양선형(Bilinear) 또는 3차 3선형(Bicubic) 보간법**을 적용하여 구멍 없이 매끄러운 출력 영상 획득.

## 6. OpenCV Python 실습 핵심 코드

```python
import cv2
import numpy as np

# 1. BGR 영상 로드 및 슬라이싱
img = cv2.imread('fruits.jpg')  # (H, W, 3), BGR 채널 순서
B, G, R = img[:, :, 0], img[:, :, 1], img[:, :, 2]

# 2. 감마 보정 룩업 테이블(LUT) 생성
gamma = 0.5
invGamma = 1.0 / gamma
table = np.array([((i / 255.0) ** invGamma) * 255 for i in range(256)]).astype("uint8")
gamma_corrected = cv2.LUT(img, table)

# 3. 2D 아핀 회전 및 이동 변환 (중심 기준 30도 회전 후 후방 사상)
h, w = img.shape[:2]
center = (w // 2, h // 2)
M_rot = cv2.getRotationMatrix2D(center, angle=30, scale=1.0)
M_rot[0, 2] += 40  # x방향 40px 이동
warped = cv2.warpAffine(img, M_rot, (w, h), flags=cv2.INTER_LINEAR)
```
