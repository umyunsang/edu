컴퓨터 비전(Computer Vision)은 2차원 디지털 영상(Digital Image)으로부터 3차원 실세계 환경의 기하학적 형상, 깊이, 재질, 그리고 의미론적 정보(Semantic Information)를 컴퓨터 알고리즘을 통해 복원하고 이해하는 인공지능 및 신호처리 분야다.

---

## 1. 컴퓨터 비전의 본질: 불량 설정 역문제 (Ill-Posed Inverse Problem)

컴퓨터 비전이 근본적으로 어려운 이유는 **3차원 실세계가 2차원 평면 센서로 투영(Projection)되면서 깊이 정보(Depth)가 손실**되기 때문이다.

```text
[순방향: 컴퓨터 그래픽스 (Forward Rendering)]
3D 기하 모델 + 조명/물성치  ─── (투영 행렬 연산) ───►  2D 렌더링 영상 (유일해 Well-posed)

[역방향: 컴퓨터 비전 (Inverse Reconstruction)]
2D 픽셀 격자 영상         ─── (역투영 및 의미 추론) ───►  3D 형상 + 의미 정보 (무수히 많은 해 Ill-posed)
```

- **차원 축소로 인한 정보 손실**: 3차원 공간 상의 점 $(X, Y, Z)$는 동일한 광선 상에 있는 모든 점들이 단일 2차원 픽셀 $(x, y)$로 겹쳐서 투영된다.
- **역문제(Inverse Problem)의 해결책**:
  1. **다시점 기하학 (Multi-view Geometry)**: 스테레오 카메라, 움직이는 단안 카메라(SfM/SLAM)를 통해 여러 시점에서 대상을 관측하여 삼각측량(Triangulation) 수행.
  2. **선험적 사전 지식 (Prior Knowledge)**: 소실점, 평면성, 조명 모델, 딥러닝 데이터 기반 통계적 분포 활용.

## 2. 관련 학문 분야 간의 관계 비교

| 학문 분야 | 입력 (Input) | 출력 (Output) | 주요 목표 및 처리 기법 |
| :--- | :--- | :--- | :--- |
| **디지털 영상 처리 (Image Processing)** | 2D 영상 | 2D 영상 | 영상 품질 개선, 잡음 제거, 감마 보정, 히스토그램 평활화 |
| **컴퓨터 그래픽스 (Computer Graphics)** | 3D 형상 및 조명 모델 | 2D 영상 | 래스터화(Rasterization), 레이 트레이싱, 셰이딩 |
| **컴퓨터 비전 (Computer Vision)** | 2D 영상 (단일/다중) | 3D 형상 및 의미 정보 | 특징 매칭, 호모그래피, 깊이 추정, 객체 검출/세분화 |
| **패턴 인식 (Pattern Recognition)** | 특징 벡터 | 클래스 레이블 | 서포트 벡터 머신(SVM), 신경망 기반 범주 분류 |

## 4. 영상 형성 광학계 (Image Formation Optics)

### 1) 핀홀 카메라 모델 (Pinhole Camera Model)

- 모든 광선이 핀홀(Pinhole, 투영 중심 $C$)을 통과하여 반대편 영상 평면(Image Plane)에 맺히며, 상하좌우가 반전된다.
- 초점거리 $f$를 핀홀과 영상 평면 사이의 거리로 정의하며, 수학적 편의를 위해 핀홀 앞쪽에 가상 영상 평면(Virtual Image Plane)을 설정한다:
  $$x = f \frac{X}{Z}, \quad y = f \frac{Y}{Z}$$

### 2) 렌즈와 조리개 (Lens & Aperture)

- 핀홀 크기가 너무 작으면 **회절(Diffraction)** 현상으로 상이 흐려지고, 너무 크면 **착란원(Circle of Confusion)**으로 인해 흐림이 발생한다.
- 실세계 카메라는 렌즈를 사용하여 충분한 광량을 모으면서도 초점면(Focal Plane)에 빛을 집속시킨다:
  $$\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i} \quad (\text{가우스 렌즈 방정식})$$

### 3) 디지털 센서와 베이어 패턴 (Bayer Pattern)

- CCD/CMOS 센서는 단색(Monochrome) 광량만 측정할 수 있으므로 센서 앞에 **베이어 필터 어레이(CFA: R-G-G-B)**를 부착한다.
- 인간의 눈이 녹색(Green, 555nm) 파장의 휘도 변화에 가장 민감하기 때문에 녹색 픽셀을 빨간색/파란색의 2배 비율로 배치하며, **디모자이킹(Demosaicing)** 알고리즘을 통해 풀컬러 RGB 3채널로 보간 복원한다.
