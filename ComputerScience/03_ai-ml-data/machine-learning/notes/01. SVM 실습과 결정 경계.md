# SVM 실습과 결정 경계

> [!abstract] 목표
> SVM 실습의 목적은 두 클래스를 분리하는 결정 경계 가운데 마진을 최대화하는 최적 초평면을 찾는 것이다.

## 경계를 정하는 데이터 관찰

결정 함수는 $f(X)=W^TX+b$로 나타낼 수 있고, 결정 경계는 $W^TX+b=0$이다. 경계에 가까운 서포트 벡터는 최대 마진 경계를 정하는 데 중요한 샘플이다.

```mermaid
flowchart LR
  A[두 클래스 데이터] --> B[후보 결정 경계]
  B --> C[가까운 샘플 확인]
  C --> D[서포트 벡터]
  D --> E[마진 최대화]
  E --> F[최적 결정 경계]
```

| 관찰 대상 | 질문 | 실습에서의 의미 |
| --- | --- | --- |
| 클래스 분포 | 두 집단은 어떻게 놓였는가? | 분리 가능성 확인 |
| 후보 경계 | 어느 선이 분리하는가? | 결정 함수 관찰 |
| 서포트 벡터 | 어느 샘플이 경계에 가까운가? | 경계 형성의 기준 |
| 마진 | 경계와 가까운 샘플의 간격은 어떤가? | 최대화 대상 |

> [!note] 최대 마진
> 단순히 클래스를 나누는 경계가 아니라, 가까운 두 클래스와의 여유를 크게 만드는 경계를 찾는 것이 SVM의 핵심 관점이다.

<Tabs>
<Tab label="데이터">
두 클래스의 특성을 좌표 공간에 놓고 분포와 겹침을 먼저 관찰한다.
</Tab>
<Tab label="경계">
결정 함수가 0이 되는 위치를 경계로 보고, 양쪽의 부호가 어떻게 달라지는지 확인한다.
</Tab>
<Tab label="마진">
경계에 가장 가까운 샘플과의 간격을 비교하며 최대 마진의 의미를 해석한다.
</Tab>
</Tabs>

<details>
<summary>시각화에서 확인할 질문</summary>

- 결정 경계가 두 클래스를 분리하는가?
- 경계에 가장 가까운 샘플은 무엇인가?
- 다른 후보 경계보다 마진이 큰가?
- 경계의 방향과 위치는 가중치와 편향으로 어떻게 표현되는가?
</details>

> [!tip] 경계 하나를 바꿔 보기
> 분리 가능한 경계를 여러 개 상상해 본 뒤 가장 가까운 샘플과의 간격을 비교하면 최대 마진의 이유가 더 선명해진다.

> [!warning] 분리 그림의 과도한 일반화
> 실습 데이터에서 잘 분리되는 모양만으로 모든 데이터에서 같은 성능을 기대하지 않는다. 입력 특성과 평가 데이터를 함께 확인한다.
