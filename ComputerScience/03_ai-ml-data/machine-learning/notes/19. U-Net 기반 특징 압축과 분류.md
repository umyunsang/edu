> [!IMPORTANT]
> 이 문서는 같은 강의자료의 U-Net 구간만 다룬다. 앞선 CNN·LeNet-5의 분류 입출력과 기본 구조는 반복하지 않는다.

U-Net은 2015년 semantic segmentation 기법으로 등장했다. encoder에서 입력 특징을 압축하고 decoder에서 segmentation map이나 복원 이미지를 생성하며, skip connection으로 앞쪽 feature map을 뒤쪽에 전달한다.

---

## U-Net이 결합하는 두 경로

<Tabs>
  <Tab label="Encoder">입력 이미지에서 특징을 학습하고, pooling으로 공간 크기를 줄여 정보가 담긴 압축 vector를 만든다.</Tab>
  <Tab label="Decoder">압축 vector에서 전치 합성곱과 합성곱을 거쳐 공간 크기를 복원하고 출력 이미지를 만든다.</Tab>
  <Tab label="Skip connection">encoder의 학습된 feature map을 decoder로 직접 전달해 더 정교한 segmentation map 생성을 돕는다.</Tab>
</Tabs>

## 실습 encoder·decoder 구조

합성곱은 filter size 5×5, stride 1, padding 2로 공간 크기를 유지한다. 두 번의 average pooling은 kernel 2, stride 2로 크기를 줄인다.

| 구간 | 연산 | 채널 또는 형상 |
| --- | --- | --- |
| 입력 | Image | $32 \times 32 \times 3$ |
| Encoder 1 | Conv $[5 \times 5 \times 3] \times 6$, ReLU | 6 channels |
| Encoder 1 | Conv $[5 \times 5 \times 6] \times 16$, ReLU | 16 channels |
| 축소 1 | AvgPool, kernel 2, stride 2 | $16 \times 16$ |
| Encoder 2 | Conv $[5 \times 5 \times 16] \times 24$, ReLU | 24 channels |
| Encoder 2 | Conv $[5 \times 5 \times 24] \times 32$, ReLU | 32 channels |
| 축소 2 | AvgPool, kernel 2, stride 2 | $8 \times 8 \times 32$ |
| Decoder 1 | Transposed Conv $[4 \times 4 \times 32] \times 24$, stride 2, padding 1 + ReLU | $16 \times 16 \times 24$ |
| Decoder 1 | Conv $[5 \times 5 \times 24] \times 16$, ReLU | 16 channels |
| Decoder 2 | Transposed Conv $[4 \times 4 \times 16] \times 6$, stride 2, padding 1 + ReLU | $32 \times 32 \times 6$ |
| 출력 | Conv $[5 \times 5 \times 6] \times 3$, ReLU | $32 \times 32 \times 3$ |

## 전치 합성곱의 업샘플링

강의자료의 일반 설정은 feature map을 $N$배 키울 때 kernel size $2N$, stride $N$, padding $0.5N$으로 둔다. 실습의 $N=2$ 설정은 kernel 4, stride 2, padding 1이다.

<details>
<summary>합성곱과 전치 합성곱의 역할</summary>

일반 합성곱과 pooling은 encoder에서 정보를 압축한다. 전치 합성곱은 decoder에서 up-sampling을 수행한다. 실습은 kernel 4, stride 2, padding 1을 두 번 사용해 $8 \rightarrow 16 \rightarrow 32$로 공간 크기를 복원한다.

</details>

## 압축 vector를 분류에 연결하기

복원 경로와 별도로 $8 \times 8 \times 32=2{,}048$개 값을 평탄화해 fully connected 분류기로 보낸다.

| 단계 | 연결 |
| ---: | --- |
| 평탄화 | $2{,}048$ |
| FC 1 + ReLU | $2{,}048 \rightarrow 120$ |
| FC 2 + ReLU | $120 \rightarrow 84$ |
| FC 3 | $84 \rightarrow 10$ |
| 결과 | $10 \times 1$ |

이 구성은 autoencoder의 압축 표현을 CIFAR-10 분류 특징으로 재사용하면서, decoder의 입력 이미지 복원도 함께 구조에 포함한다.

---

## 구현 점검

1. padding 2인 5×5 합성곱이 공간 크기를 유지하는지 확인한다.
2. 두 pooling 뒤 압축 형상이 $8 \times 8 \times 32$인지 확인한다.
3. 전치 합성곱의 kernel 4, stride 2, padding 1을 확인한다.
4. decoder 채널 흐름 $32 \rightarrow 24 \rightarrow 16 \rightarrow 6 \rightarrow 3$을 맞춘다.
5. 분류기는 2,048개 값을 $120 \rightarrow 84 \rightarrow 10$으로 연결한다.
6. skip connection은 encoder feature map을 decoder에 전달한다.
