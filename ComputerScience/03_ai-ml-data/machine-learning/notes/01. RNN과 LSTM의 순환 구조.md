## 언어 모델에서 순환 모델까지

Language Model은 인간의 언어를 이해하고 생성하도록 설계된 인공지능 모델이다. Large Language Model은 방대한 데이터로 학습한 많은 parameter를 가진다.

강의자료는 기존 language model이 RNN 기반이었고 Transformer가 RNN 기반 모델의 문제를 해결해 높은 성능을 냈다고 정리한다.

## 시계열 데이터와 DNN의 차이

시계열 데이터는 시간 흐름에 따라 관측되며 현재 상태가 과거 상태의 영향을 받는 데이터다.

<Tabs>
  <Tab label="DNN">현재 입력을 독립적으로 처리한다. hidden layer를 통과한 현재 정보만으로 출력을 계산한다.</Tab>
  <Tab label="RNN">현재 입력과 이전 hidden state를 함께 사용한다. 같은 parameter를 시점마다 공유하며 순서 정보를 전달한다.</Tab>
  <Tab label="Seq2Seq">순차적인 입력 Many로 순차적인 출력 Many를 예측한다. 예시는 한글 문장을 영어 문장으로 번역하는 문제다.</Tab>
</Tabs>

## RNN 상태 계산

강의자료는 세 학습 parameter를 구분한다.

| parameter | 연결 |
| --- | --- |
| $W_{xh}$ | 입력 $x_t$에서 hidden state로 |
| $W_{hh}$ | 이전 hidden state에서 현재 hidden state로 |
| $W_{hy}$ | hidden state에서 출력으로 |

원문 식은 다음과 같이 제시된다.

$$
h_t=f(W_{xh}x_t+W_{hh}x_{t-1}+\mathrm{bias})
$$

$$
y_i=f(W_{hy}h_i+\mathrm{bias})
$$

> [!WARNING]
> 첫 식은 recurrent 항에 $x_{t-1}$을 인쇄했지만 같은 슬라이드의 구조도는 이전 hidden state $h_{t-1}$가 $W_{hh}$를 거쳐 전달되는 것으로 그린다. 이 표기 불일치를 조용히 고치지 않는다.

각 parameter는 모든 시점에서 같은 값을 쓰는 shared parameter다.

## RNN 학습과 BPTT

현재 출력의 loss는 현재 계산만이 아니라 이전 hidden state들의 연쇄를 통해 $W_{hh}$와 $W_{xh}$에 영향을 준다. 강의자료는 시점 $0$부터 $t$까지의 미분 항을 합하는 형태로 이 역전파를 전개한다.

\`\`\`mermaid
flowchart RL
  L["시점 t의 Loss"] --> Y["출력 y(t)"]
  Y --> Ht["hidden h(t)"]
  Ht --> H1["hidden h(t-1)"]
  H1 --> H0["더 과거 hidden"]
  Ht --> Why["W(hy) 갱신"]
  H1 --> Whh["공유 W(hh) 갱신"]
  H0 --> Wxh["공유 W(xh) 갱신"]
\`\`\`

<details>
<summary>Shared parameter의 의미</summary>

시점마다 서로 다른 weight를 만드는 것이 아니다. 펼친 RNN의 모든 cell이 $W_{xh}$, $W_{hh}$, $W_{hy}$를 공유하므로 여러 시점에서 생긴 gradient가 같은 parameter 업데이트에 모인다.

</details>

## 장기 의존성과 기울기 소실

sequence가 길어질수록 과거 정보 학습이 어려워진다. 강의자료의 $t=0$부터 $t=100$ 예시는 0–1 범위의 미분 항이 길게 곱해지면 과거 영향이 약 $0$으로 수렴해 parameter가 업데이트되지 않는다고 설명한다.

영어 **Don’t look up**과 한글 **위를 쳐다보지 마세요**의 예에서 입력 **Don’t**와 출력 **마세요**는 의미상 가깝지만 시점 거리가 멀다. 이 관계가 학습에 반영되지 않으면 정확도가 낮아질 수 있다.

> [!CAUTION]
> RNN의 순차 입력·출력 구조는 긴 의존성을 약하게 만들고 병렬 처리도 어렵게 한다.

## LSTM의 cell state와 세 gate

LSTM은 장기 정보를 유지하는 cell state $C_t$와 단기 정보를 유지하는 hidden state $h_t$를 구분한다.

| gate | 역할 | 출력 범위 |
| --- | --- | --- |
| Forget gate $f_t$ | 불필요한 과거 정보를 잊음 | sigmoid 0–1 |
| Input gate $i_t$ | 현재 정보를 기억함 | sigmoid 0–1 |
| Output gate $o_t$ | cell state를 hidden state에 얼마나 반영할지 결정 | sigmoid 0–1 |

$$
f_t=\sigma(W_{xhf}x_t+W_{hhf}h_{t-1}+\mathrm{bias})
$$

$$
i_t=\sigma(W_{xhi}x_t+W_{hhi}h_{t-1}+\mathrm{bias})
$$

$$
o_t=\sigma(W_{xho}x_t+W_{hho}h_{t-1}+\mathrm{bias})
$$

cell state는 불필요한 정보를 제거한 이전 $C_{t-1}$와 input gate가 선택한 현재 후보 정보를 더해 갱신한다.

## LSTM 이후의 한계

1. LSTM은 장기 의존성을 완화하지만 sequence가 길어지면 여전히 한계가 있다.
2. 강의자료는 Seq2Seq가 이 문제를 완화한다고 설명한다.
3. RNN과 LSTM은 순차 구조라 병렬 처리가 어렵다.
4. Transformer는 self-attention으로 위 문제를 해결하는 방향을 제시한다.
