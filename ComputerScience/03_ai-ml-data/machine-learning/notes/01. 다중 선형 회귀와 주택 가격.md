다중 선형 회귀는 여러 독립 변수로 하나의 종속 변수를 예측한다. 자료는 kc_house_data에서 price를 목표로 두고, Gaussian normalization과 최소제곱법으로 특성 조합을 비교한다.

> [!IMPORTANT]
> 수치와 열 이름은 원본 실습 자료에 적힌 값만 사용했다. 상관관계가 높다는 사실은 인과관계를 뜻하지 않는다.

---

## 데이터와 전처리

자료가 열거한 열 가운데 id, date는 예측에 불필요해 삭제하고 결측 행도 제거한다. 이후 각 열을 평균 0, 표준편차 1로 변환한다.

$$
x' = \frac{x-\mu}{\sigma},
\qquad
x = x'\sigma+\mu
$$

원본의 데이터 설명에는 price, bedrooms, bathrooms, sqft_living, sqft_lot, floors, waterfront가 포함되고 뒤에 더 많은 열이 이어진다.

## price와의 상관관계

상관계수 행렬에서 가격과 양의 상관이 큰 특성은 다음과 같다.

| 특성 | 상관계수 |
| --- | ---: |
| sqft_living | 0.702 |
| grade | 0.667 |
| sqft_above | 0.606 |
| sqft_living15 | 0.585 |

낮은 상관의 예시는 zipcode -0.053, condition 0.036, long 0.022, sqft_lot 0.090이다.

## 특성 조합과 MSE

자료는 세 가지 입력 구성을 차례로 보여준다.

- 18개 특성: sqft_living, grade, sqft_above, bathrooms, sqft_living15, bedrooms, floors, waterfront, view, condition, sqft_basement, yr_built, yr_renovated, zipcode, lat, long, sqft_lot, sqft_lot15
- 상위 3개 특성: sqft_living, grade, sqft_above → MSE 0.45
- 최종 예시 2개 특성: sqft_living, grade → 자료 요약의 MSE 0.33

최소제곱 모델은 bias 열을 추가한 뒤

$$
\theta=(X^TX)^{-1}X^TY
$$

를 계산한다. MSE는 정답과 예측의 차이를 제곱해 평균한다.

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(Y_i-\hat{Y}_i)^2
$$

## 새 주택 예측

새 입력 예시는 실내 면적 sqft_living=1000, 등급 grade=8이다.

1. 학습 데이터의 평균·표준편차로 두 입력을 정규화한다.
2. X_new=[[sqft_living, grade]]를 만든다.
3. 학습한 모델로 $\hat{Y}$를 계산한다.
4. 가격 평균·표준편차로 역정규화해 실제 단위로 해석한다.
