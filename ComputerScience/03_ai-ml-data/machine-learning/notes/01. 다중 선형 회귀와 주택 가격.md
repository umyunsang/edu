> [!NOTE]
> 다중 선형 회귀는 여러 주택 특성을 동시에 입력해 가격을 설명한다. 이 사례의 핵심은 상관계수로 후보를 살피고, 서로 다른 특성 묶음의 평가 오차를 비교한 뒤 새 표본에도 같은 전처리를 적용하는 것이다.

---

## 여러 입력을 하나의 예측으로

단일 입력의 가중치를 여러 열로 확장하면 예측은 다음처럼 표현할 수 있다.

$$
\hat{Y}=XW+b
$$

각 행은 한 채의 주택, 각 열은 한 가지 특성, $W$는 열마다 대응하는 가중치다.

| 역할 | 이 사례의 값 |
| :-- | :-- |
| 목표 변수 | price |
| 후보 입력 | id와 date를 제외한 주택 특성 |
| 결측값 | 제거 |
| 데이터 분리 | 평가 비율 0.2, 난수 시드 1234 |

---

## 상관이 작은 후보

| 특성 | price와의 상관계수 |
| :-- | --: |
| zipcode | -0.053 |
| condition | 0.036 |
| long | 0.022 |
| sqft_lot | 0.090 |

이 표는 후보를 무조건 버리는 규칙이 아니라, 특성 묶음을 바꿔 평가할 이유를 보여준다.

---

## 전처리에서 평가까지

\`\`\`mermaid
flowchart LR
    Raw[주택 데이터] --> Clean[열 정리]
    Clean --> Scale[표준화]
    Scale --> Fit[모델 학습]
    Fit --> Error[MSE 비교]
\`\`\`

모든 수치형 열은 평균과 표준편차로 크기를 맞춘다.

$$
z=\frac{x-\mu}{\sigma}
$$

> [!TIP]
> 학습에 사용한 평균과 표준편차를 보관해야 새 주택 입력을 같은 공간으로 옮기고, 표준화된 가격 예측을 다시 실제 단위로 되돌릴 수 있다.

## 특성 묶음과 평가 오차

원본 코드는 입력 열을 다시 지정하며 세 가지 후보를 실험한다.

| 후보 | 입력 구성 | 제시된 MSE |
| :-- | :-- | --: |
| 전체 특성 | id와 date를 뺀 18개 특성 | 0.33 |
| 상관 상위 묶음 | sqft_living, grade, sqft_above | 0.45 |
| 축소 묶음 | sqft_living, grade | 제시되지 않음 |

<Tabs>
  <Tab label="해석">

원본 실행값에서는 전체 특성 묶음의 MSE가 상위 세 특성 묶음보다 작다. 그러나 두 특성 묶음은 수치가 없어 같은 방식으로 순위를 매길 수 없다.

  </Tab>
  <Tab label="선택">

입력 수만 보고 결정하지 않고, 같은 분할과 같은 전처리에서 평가 오차를 비교한다. 값이 없는 후보는 직접 실행해 확인해야 한다.

  </Tab>
</Tabs>

## LSM 모델과 손실

여러 입력도 편향 열을 붙인 설계 행렬로 정규방정식을 적용한다.

$$
\theta=(X^{T}X)^{-1}X^{T}Y
$$

평가는 표준화된 출력 공간의 평균제곱오차를 사용한다.

$$
\operatorname{MSE}=\frac{1}{N}\sum_{i=1}^{N}\left(Y_i-\hat{Y}_i\right)^2
$$

> [!CAUTION]
> 이 구현은 역행렬을 직접 사용한다. $X^{T}X$가 가역이 아니면 계산이 실패하므로 입력 열의 선형 의존성을 점검해야 한다.

<details>
<summary>새 입력에 적용하는 순서</summary>

1. sqft_living은 1000, grade는 8로 입력한다.
2. 각 값을 학습 때 저장한 입력 평균과 표준편차로 표준화한다.
3. 선택한 특성 묶음과 열 순서를 맞춰 모델에 넣는다.
4. 출력 평균과 표준편차로 가격 예측을 역변환한다.

원본은 이 예측 절차를 보여주지만 최종 가격 숫자는 제시하지 않는다.

</details>

> [!WARNING]
> 원본 요약은 MSE 범위를 0.33–0.46으로 적지만 코드 주석에 확인되는 값은 0.33과 0.45다. 이 노트는 두 표현을 임의로 합치지 않고 표에는 코드 주석의 값만 옮겼다.
