트랜스포머 인코더의 핵심 엔진은 **스케일드 닷 프로덕트 셀프 어텐션(Scaled Dot-Product Self-Attention)**과 여러 개의 관점으로 문맥을 동시 포착하는 **다중 헤드 어텐션(Multi-Head Attention)**이다.

---

## 1. 셀프 어텐션(Self-Attention)의 수학적 원리

### 1) Q, K, V 행렬의 생성

입력 토큰 행렬 $X \in \mathbb{R}^{N \times d_{\text{model}}}$에 각각의 학습 가능한 가중치 행렬$W^Q, W^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$와$W^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$를 곱하여 세 가지 역할을 하는 행렬을 생성한다:

$$Q = X W^Q \quad (\text{Query: 질문하는 주체})$$
$$K = X W^K \quad (\text{Key: 질문과 대조할 대상의 색인})$$
$$V = X W^V \quad (\text{Value: 실제 참조할 정보의 내용})$$

### 2) Scaled Dot-Product Attention 수식

$$\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V$$

> [!IMPORTANT]
> **왜 $\sqrt{d_k}$로 나누어 스케일링하는가?**
> $q$와$k$의 각 원소가 평균$0$, 분산$1$인 독립 확률변수일 때, 두 벡터의 내적$q \cdot k = \sum_{i=1}^{d_k} q_i k_i$의 평균은$0$, **분산은$d_k$**가 된다.
> $d_k$가 커질수록 내적 값의 크기가 매우 커져 소프트맥스 함수의 기울기가 거의$0$에 수렴하는 **그래디언트 소실(Vanishing Gradient)**이 발생한다.
> 따라서 $\sqrt{d_k}$로 나누어 분산을 다시$1$로 안정화시킨다.

## 3. Multi-Head Attention (다중 헤드 주의집중)

하나의 어텐션만 사용할 경우 모든 토큰의 평균적인 관계만 학습하는 경향이 있다. Multi-Head Attention은 $d_{\text{model}}$차원을$h$개의 헤드로 나누어 서로 다른 표현 부분공간(Subspaces)을 독립적으로 학습한다.

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \text{head}_2, \dots, \text{head}_h) W^O$$
$$\text{where } \text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)$$

- **차원 분할**: $d_k = d_v = d_{\text{model}} / h$(예:$d_{\text{model}}=512, h=8 \implies d_k=64$).
- **역할 분담**:
  - Head 1: 문법적 주어-동사 호응 관계 포착
  - Head 2: 대명사가 지칭하는 선행사(Coreference) 연결
  - Head 3: 문맥적 수식어와 피수식어 관계 집중

### 1) 잔차 연결 (Residual Connection)

$$\text{Output} = x + \text{SubLayer}(x)$$
신경망의 깊이가 수십~수백 층으로 깊어질 때 그래디언트가 손실 없이 역전파되도록 고속도로(Highway)를 제공한다.

### 2) 층 정규화 (Layer Normalization)

배치 정규화(BatchNorm)와 달리, 각 샘플마다 특징 차원 $d_{\text{model}}$에 대해 독립적으로 평균$\mu$과 분산$\sigma^2$을 계산하여 정규화한다:
$$\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$$

### 3) 피드포워드 신경망 (Position-wise FFN)

각 토큰의 위치마다 동일하게 독립적으로 적용되는 2층 완전연결 신경망(ReLU 활성화)이다:
$$\text{FFN}(x) = \max(0, x W_1 + b_1) W_2 + b_2$$
($W_1 \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}}$,$W_2 \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}}$, 통상$d_{\text{ff}} = 4 \times d_{\text{model}} = 2048$).

## 5. PyTorch 기반 Scaled Dot-Product Attention 완전 구현

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class ScaledDotProductAttention(nn.Module):
    def __init__(self, d_k):
        super().__init__()
        self.d_k = d_k

    def forward(self, Q, K, V, mask=None):
        # 1. Matmul(Q, K^T) 및 스케일링 (Batch, Head, Seq_Q, Seq_K)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)

        # 2. 마스킹 적용 (Look-ahead or Padding mask)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)

        # 3. Softmax 확률 산출
        attn_weights = F.softmax(scores, dim=-1)

        # 4. Value와의 가중합
        output = torch.matmul(attn_weights, V)
        return output, attn_weights

# 텐서 동작 확인: Batch=1, Head=1, SeqLen=4, d_k=64
d_k = 64
attention = ScaledDotProductAttention(d_k)
Q = torch.randn(1, 1, 4, d_k)
K = torch.randn(1, 1, 4, d_k)
V = torch.randn(1, 1, 4, d_k)

out, weights = attention(Q, K, V)
print("어텐션 출력 형상:", out.shape)          # (1, 1, 4, 64)
print("어텐션 가중치 행렬 합:", weights.sum(dim=-1))  # 각 행의 합 = 1.0
```
