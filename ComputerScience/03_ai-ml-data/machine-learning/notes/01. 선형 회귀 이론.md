> [!abstract] 핵심
> 회귀는 관측된 데이터로 변수 사이의 관계를 추정하고, 그 관계를 이용해 새 입력의 목표값을 예측하는 방법이다. 단일 선형 회귀는 이를 $y = wx + b$로 표현한다.

## 문제를 식으로 바꾸기

입력 $x$와 목표값 $y$가 있을 때, 모델은 기울기 $w$와 절편 $b$를 찾아 예측선 $hat{y}=wx+b$를 만든다. 학습의 기준은 데이터마다 생기는 오차를 작게 만드는 것이다.

```mermaid
flowchart LR
  A[관측 데이터] --> B[관계 가정]
  B --> C[파라미터 추정]
  C --> D[오차 비교]
  D --> E[새 입력 예측]
```

| 요소 | 역할 | 단일 선형 회귀에서의 모습 |
| --- | --- | --- |
| 입력 | 설명에 쓰는 변수 | $x$ |
| 목표 | 예측하려는 값 | $y$ |
| 기울기 | 입력 변화의 반영량 | $w$ |
| 절편 | 기준점의 이동 | $b$ |

> [!note] 선형과 비선형
> 선형 회귀는 변수 사이의 관계를 일차식으로 표현한다. 관계가 더 복잡하면 다른 함수 형태를 검토해야 한다.

<Tabs>
<Tab label="문제 정의">
입력과 목표값을 짝으로 모으고, 무엇을 예측할지 먼저 고정한다.
</Tab>
<Tab label="해법 비교">
최소제곱법은 식으로 파라미터를 구하고, 경사 하강법은 반복 갱신으로 오차를 줄인다.
</Tab>
<Tab label="검증 관점">
학습에 쓰지 않은 입력에도 예측선이 자연스럽게 작동하는지 확인한다.
</Tab>
</Tabs>

<details>
<summary>학습 후 설명할 수 있어야 할 질문</summary>

- 왜 같은 데이터에도 서로 다른 후보식이 생길 수 있는가?
- 오차가 더 작은 식을 고르는 이유는 무엇인가?
- 새 입력에서 예측을 하려면 무엇이 고정되어야 하는가?
</details>

> [!tip] 오차를 말로 확인하기
> 예측값과 실제값의 차이를 각 관측치에서 비교하면, 모델이 어디에서 어긋나는지 구체적으로 설명할 수 있다.

> [!warning] 표현 범위 점검
> 데이터의 관계가 직선으로 잘 설명되지 않으면 선형식만으로 결론을 내리지 말고 다른 형태의 모델을 함께 검토한다.
