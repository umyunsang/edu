## 표준화와 배열 모양

각 변수는 평균을 빼고 표준편차로 나눈다.

$$
z=\frac{x-\mu}{\sigma}
$$

<Tabs>
  <Tab label="입력과 출력">

sqft_living과 price를 각각 표준화한다. 예측을 실제 가격 단위로 해석하려면 출력에 사용한 평균과 표준편차가 다시 필요하다.

  </Tab>
  <Tab label="모델 입력">

원본 코드는 한 열짜리 입력과 출력을 2차원 배열로 확장한다. 이렇게 해야 행렬 곱과 파라미터 차원이 일치한다.

  </Tab>
</Tabs>

> [!IMPORTANT]
> 학습 데이터와 평가 데이터는 test_size 0.2, random_state 1234로 분리한다. 같은 난수 시드를 사용하면 원본과 같은 분할을 재현할 수 있다.

## LSM 구현과 확인값

편향 열을 추가한 입력 행렬로 파라미터를 계산한다.

$$
\theta=(X^{T}X)^{-1}X^{T}Y
$$

| 출력 | 원본 실행 결과 |
| :-- | --: |
| 가중치 $W$ | 0.70406843 |
| 편향 $b$ | 0.00267388 |

> [!CAUTION]
> $X^{T}X$가 가역이 아니면 이 구현은 역행렬을 계산할 수 없다. 입력 열이 서로 의존하거나 정보가 부족한지 먼저 확인해야 한다.

## GDM 구현의 반복 구조

| 설정 또는 단계 | 원본 구현 |
| :-- | :-- |
| 초기화 | 가중치와 편향을 0으로 둠 |
| 예측 | 현재 파라미터로 선형 출력 계산 |
| 오차 | 예측과 정답의 차이 계산 |
| 갱신 | MSE의 기울기를 학습률만큼 반영 |
| 실행 | 1,000회 반복, 학습률 0.1 |

<details>
<summary>클래스 기본값과 실제 호출 구분</summary>

클래스 생성자의 기본 학습률은 $10^{-4}$로 적혀 있고, 별도 주석에는 $0.1$이 제시된다. 실제 학습 객체를 만드는 호출은 1,000회와 $0.1$을 사용한다.

</details>

> [!WARNING]
> 원본의 쪽수 표시는 마지막에서 34/33으로 적혀 실제 34쪽 구성과 맞지 않는다. 또한 GDM 클래스의 기본 학습률과 실제 호출값이 다르며, 최종 GDM 가중치와 편향의 숫자 출력은 제공되지 않는다. 이 노트는 실제 호출값만 실행 설정으로 적고 없는 결과는 추정하지 않았다.

## 재현 체크

- 데이터 파일 경로와 열 이름을 먼저 확인한다.
- 입력과 출력에 각각 저장한 평균과 표준편차를 사용한다.
- 분할 시드와 평가 비율을 원본과 맞춘다.
- LSM 결과는 제시된 수치와 비교한다.
- GDM 결과는 실행 로그로 확인하되 원본에 없는 숫자를 정답처럼 사용하지 않는다.
