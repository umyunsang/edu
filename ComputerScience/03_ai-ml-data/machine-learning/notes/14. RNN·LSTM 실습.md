## 1. 실습 데이터셋: 훈민정음 서문 (현대어 번역본)

> *"나라의 말이 중국과 달라 문자와 서로 통하지 아니하니, 이런 까닭으로 어리석은 백성이 이르고자 할 바가 있어도 마침내 제 뜻을 능히 펴지 못할 사람이 많으니라. 내가 이를 위하여 가엾이 여겨 새로 스물여덟 자를 만드노니 사람마다 하여금 쉬이 익혀 날로 쓰는 데 편하게 하고자 할 따름이니라."*

### 데이터 전처리 파이프라인

1. **문장부호 정제 및 토큰화**: 특수문자(`,`, `.`)를 제거하고 공백 기준으로 분절하여 $N$개의 단어 리스트 추출.
2. **단어 사전 구축 (`word_to_idx` & `idx_to_word`)**: 중복 없는 고유 단어 집합 $V$ 생성.
3. **입력-정답 시퀀스 쌍 생성**:
   - 입력 시퀀스 $X$: `["나라의", "말이", "중국과", "달라", ...]`
   - 정답 시퀀스 $Y$: `["말이", "중국과", "달라", "문자와", ...]`

## 3. 순환 신경망 계층 수식 및 파라미터 공유

### 1) 은닉 상태 및 출력 계산

매 타임스텝 $t$마다 동일한 가중치 행렬($W_{xh}, W_{hh}, W_{hy}$)을 재사용한다:
$$h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$$
$$y_t = \text{softmax}(W_{hy} h_t + b_y)$$

### 2) LSTM 게이트 확장

긴 문장에서 초반부 단어(`"나라의"`)의 정보가 끝부분까지 전달되지 못하고 희석되는 문제를 방지하기 위해 4개 게이트 구조의 LSTM 셀로 교체한다:

- 삭제 게이트: $f_t = \sigma(W_{xf} x_t + W_{hf} h_{t-1} + b_f)$
- 입력 게이트: $i_t = \sigma(W_{xi} x_t + W_{hi} h_{t-1} + b_i)$
- 셀 상태 갱신: $C_t = f_t \odot C_{t-1} + i_t \odot \tanh(W_{xc} x_t + W_{hc} h_{t-1} + b_c)$
- 은닉 상태 갱신: $h_t = \sigma(W_{xo} x_t + W_{ho} h_{t-1} + b_o) \odot \tanh(C_t)$

## 4. PyTorch 기반 텍스트 생성 모델 학습 코드

```python
import torch
import torch.nn as nn
import numpy as np

text = "나라의 말이 중국과 달라 문자와 서로 통하지 아니하니 이런 까닭으로 어리석은 백성이 이르고자 할 바가 있어도"
words = text.split()
vocab = sorted(list(set(words)))
word_to_idx = {w: i for i, w in enumerate(vocab)}
idx_to_word = {i: w for i, w in enumerate(vocab)}
vocab_size = len(vocab)

class TextRNN(nn.Module):
    def __init__(self, vocab_size, hidden_dim=64):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, hidden_dim)
        self.lstm = nn.LSTM(hidden_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)

    def forward(self, x, hidden=None):
        embeds = self.embedding(x)
        out, hidden = self.lstm(embeds, hidden)
        logits = self.fc(out)
        return logits, hidden

# 모델 초기화
model = TextRNN(vocab_size, hidden_dim=32)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# 학습 데이터 준비 (x: 0~T-1, y: 1~T)
input_seq = torch.tensor([word_to_idx[w] for w in words[:-1](word_to_idx[w] for w in words[:-1.md)])
target_seq = torch.tensor([word_to_idx[w] for w in words[1:](word_to_idx[w] for w in words[1:.md)])

for epoch in range(200):
    optimizer.zero_grad()
    logits, _ = model(input_seq)
    loss = criterion(logits.view(-1, vocab_size), target_seq.view(-1))
    loss.backward()
    optimizer.step()

print(f"최종 훈련 손실: {loss.item():.4f}")
```
