\*\*선형 회귀(Linear Regression)\*\*는 독립 변수 $X$와 종속 변수 $y$ 간의 선형 상관관계를 모델링하는 가장 기초적이며 강력한 지도학습 알고리즘으로, 해석적 닫힌 해(Closed-form Solution)를 구하는 \*\*최소제곱법(LSM)\*\*과 수치 최적화 기법인 \*\*경사하강법(GDM)\*\*의 두 가지 해법 체계를 갖는다.

---

## 1. 선형 회귀의 수학적 공식화와 두 해법 유도

### 1) 평균제곱오차(MSE) 손실 함수 정의

데이터셋 $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^n$ ($\mathbf{x}\_i \in \mathbb{R}^d$)에 대한 예측 모델:

$$\hat{y}_i = \mathbf{w}^T \mathbf{x}_i + b$$

편향 $b$를 가중치 벡터 $\mathbf{w} \in \mathbb{R}^{d+1}$와 확장 특징 행렬 $\mathbf{X} \in \mathbb{R}^{n \times (d+1)}$에 흡수시킬 때 MSE 비용 함수:

$$J(\mathbf{w}) = \frac{1}{2n} \|\mathbf{X}\mathbf{w} - \mathbf{y}\|_2^2 = \frac{1}{2n} (\mathbf{X}\mathbf{w} - \mathbf{y})^T (\mathbf{X}\mathbf{w} - \mathbf{y})$$

### 2) 해법 1: 최소제곱법 (LSM / Normal Equation 정규 방정식)

비용 함수 $J(\mathbf{w})$를 $\mathbf{w}$에 대해 벡터 미분하여 $0$으로 설정:

$$\nabla_{\mathbf{w}} J(\mathbf{w}) = \frac{1}{n} \mathbf{X}^T (\mathbf{X}\mathbf{w} - \mathbf{y}) = \mathbf{0}$$

$$\mathbf{X}^T \mathbf{X} \mathbf{w} = \mathbf{X}^T \mathbf{y} \implies \hat{\mathbf{w}}_{\text{LSM}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

- **특징**: 행렬 역행렬 연산 $\mathcal{O}(d^3)$ 소요 ($d$가 작을 때 즉각적인 전역 최적해 계산 가능).

### 3) 해법 2: 경사하강법 (GDM / Gradient Descent Method)

$$\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla_{\mathbf{w}} J(\mathbf{w}_t) = \mathbf{w}_t - \frac{\eta}{n} \mathbf{X}^T (\mathbf{X}\mathbf{w}_t - \mathbf{y})$$

- **특징**: 대규모 고차원 데이터셋($n, d \gg 10^5$)에서도 행렬 역연산 없이 점진적 갱신 가능.

---

## 2. LSM vs GDM 비교 분석

| 비교 항목 | 최소제곱법 (LSM / Normal Equation) | 경사하강법 (GDM / Gradient Descent) |
| :--- | :--- | :--- |
| **학습률 $\eta$ 설정** | 불필요 | 적절한 하이퍼파라미터 탐색 필요 |
| **반복 루프 (Iterations)** | 0회 (단일 행렬식 계산) | 수렴할 때까지 $T$회 반복 갱신 |
| **시간 복잡도** | $\mathcal{O}(n d^2 + d^3)$ | $\mathcal{O}(T \cdot n d)$ |
| **적합한 데이터 규모** | 특징 수 $d \le 10,000$ 소형/중형 데이터 | 대규모 데이터 및 스트리밍 환경 |

(function() {
  var data = [1, 2.5], [2, 4.4], [3, 6.6], [4, 8.3], [5, 10.5](1, 2.5], [2, 4.4], [3, 6.6], [4, 8.3], [5, 10.5.md);

  var slLr = document.getElementById('lr-slider');
  var slSteps = document.getElementById('lr-steps');
  var tLr = document.getElementById('lr-txt-val');
  var tSteps = document.getElementById('lr-txt-steps');
  var rLsm = document.getElementById('lsm-res-eq');
  var rGdm = document.getElementById('gdm-res-eq');
  var rGdmLoss = document.getElementById('gdm-res-loss');

  // Calculate LSM
  var sumX = 0, sumY = 0, sumXY = 0, sumXX = 0;
  for (var i = 0; i < n; i++) {
    sumX += data[i][0]; sumY += data[i][1];
    sumXY += data[i][0] * data[i][1];
    sumXX += data[i][0] * data[i][0];
  }
  var lsmW = (n * sumXY - sumX * sumY) / (n * sumXX - sumX * sumX);
  var lsmB = (sumY - lsmW * sumX) / n;
  rLsm.textContent = 'y = ' + lsmW.toFixed(2) + 'x + ' + lsmB.toFixed(2);

  function updateGDM() {
    var lr = parseFloat(slLr.value);
    var steps = parseInt(slSteps.value, 10);
    tLr.textContent = lr.toFixed(2);
    tSteps.textContent = steps;

    var w = 0.0, b = 0.0;
    for (var s = 0; s < steps; s++) {
      var dw = 0.0, db = 0.0;
      for (var i = 0; i < n; i++) {
        var err = (w * data[i][0] + b) - data[i][1];
        dw += err * data[i][0];
        db += err;
      }
      w -= (lr / n) * dw;
      b -= (lr / n) * db;
    }

    var loss = 0.0;
    for (var i = 0; i < n; i++) {
      var err = (w * data[i][0] + b) - data[i][1];
      loss += err * err;
    }
    loss /= (2 * n);

    rGdm.textContent = 'y = ' + w.toFixed(2) + 'x + ' + b.toFixed(2);
    rGdmLoss.textContent = 'MSE 손실: ' + loss.toFixed(4);
  }

  slLr.addEventListener('input', updateGDM);
  slSteps.addEventListener('input', updateGDM);
  updateGDM();
})();
</script>
