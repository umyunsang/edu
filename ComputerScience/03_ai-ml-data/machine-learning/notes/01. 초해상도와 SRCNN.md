> [!IMPORTANT]
> Super Resolution은 저해상도 영상에서 고해상도 영상을 만드는 문제다. SRCNN은 먼저 보간한 저해상도 영상 ILR을 입력하고 원본 HR을 정답으로 학습하는 3-layer CNN이다.

---

## SR 문제와 전통적 접근

<Tabs>
  <Tab label="Single Image SR">저해상도 이미지 1개를 입력해 고해상도 이미지 1개를 출력한다.</Tab>
  <Tab label="Multi Image SR">저해상도 이미지 여러 개를 입력해 고해상도 이미지 1개 또는 여러 개를 출력한다.</Tab>
  <Tab label="Interpolation">픽셀 사이 값을 예측한다. 평균값 참조로 부드럽고 자연스럽지만 smoothing 때문에 선명도와 고주파 복원력이 떨어진다.</Tab>
  <Tab label="Example-based">현재 또는 외부 이미지 patch를 이용한다. 우수한 성능에는 큰 database가 필요해 검색이 느리고, 적절한 match가 없으면 주관적 화질이 크게 떨어질 수 있다.</Tab>
</Tabs>

SR의 응용으로 고해상도 재방영, 압축 artifact reduction, image colorization, image style transfer가 제시된다.

```
## 성능 평가

객관 평가는 PSNR, SSIM, MS-SSIM을 사용하고, 주관 평가는 사람이 점수를 부여한 평균인 MOS를 사용한다.

$$
\mathrm{MSE}=\frac{1}{w h}\sum_{i=1}^{w h}(O_i-R_i)^2
$$

$$
\mathrm{PSNR}=10\log_{10}\left(\frac{\mathrm{MAX}^2}{\mathrm{MSE}}\right)
=20\log_{10}\left(\frac{\mathrm{MAX}}{\mathrm{MSE}}\right)
$$

8-bit 영상에서는 $\mathrm{MAX}=255$이며 PSNR은 log scale이므로 dB 단위를 쓴다.

| 복원 결과 | PSNR |
| --- | ---: |
| Bicubic interpolation ILR | 30.4304 dB |
| SRCNN prediction | 31.1327 dB |

## SRCNN 구조

SRCNN은 image-input, image-output의 3-layer CNN이며 2배·3배·4배 해상도로 학습할 수 있다. 강의 예시는 3배 모델에서 $32 \times 32$ 입력이 $96 \times 96$ 출력에 대응한다고 설명한다.

| layer | filter | channel 변화 | 활성화 |
| ---: | --- | --- | --- |
| 1 | $[9 \times 9 \times 3] \times 64$ | $3 \rightarrow 64$ | ReLU |
| 2 | $[1 \times 1 \times 64] \times 32$ | $64 \rightarrow 32$ | ReLU |
| 3 | $[5 \times 5 \times 32] \times 3$ | $32 \rightarrow 3$ | 출력 |

> [!WARNING]
> 모델 학습 슬라이드는 두 번째 1×1 layer를 stride 1, padding 2로 표기한다. 같은 슬라이드의 image-input·image-output 형상과 맞지 않는 표기지만, 여기서는 원문 오류 가능성을 숨기지 않는다. 첫 layer는 stride 1, padding 4, 세 번째 layer는 stride 1, padding 2로 제시된다.

## 데이터셋 구성

Training은 scale 4로 구성한다.

| 구분 | 데이터셋 | 수량 | 처리 |
| --- | --- | ---: | --- |
| Training | T-91 | 91장 | 각 영상을 $32 \times 32$ patch로 분할 |
| Testing | Set5 | 5장 | image patch를 수행하지 않음 |
| 입력 | ILR | $32 \times 32$ patch | LR을 bicubic interpolation |
| 정답 | HR | $32 \times 32$ patch | 원본 영상 |

<details>
<summary>Data loader의 세 메서드</summary>

- __init__: 데이터셋 전처리와 training image patch를 수행한다.
- __len__: 데이터셋 개수를 반환한다.
- __getitem__: 주어진 index의 데이터를 반환한다.
- Test dataset은 image patch를 수행하지 않는다는 주의사항이 있다.

</details>

## 학습과 검증

\`\`\`mermaid
flowchart TD
A["HR 원본 준비"] --> B["Down-sampling으로 LR 생성"]
B --> C["Bicubic으로 ILR 생성"]
C --> D["ILR·HR pair 구성"]
D --> E["SRCNN forward"]
E --> F["예측과 HR의 loss 정의"]
F --> G["최적화"]
G --> H["Test 영상 복원"]
H --> I["PSNR 측정"]
H --> J["MOS 측정"]
```

> [!NOTE]
> Training은 loss function 정의와 최적화로 구성되고, Test는 PSNR과 MOS 측정으로 구성된다.
