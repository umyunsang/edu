## 원본 열과 모델 역할

| 구분 | 열 |
| :-- | :-- |
| 목표 | fare_amount |
| 출발 위치 | pickup_x, pickup_y |
| 도착 위치 | dropoff_x, dropoff_y |
| 추가 입력 | passenger_count |
| 제거 | Unnamed, key, pickup_datetime |

결측 행을 제거한 뒤 좌표 자체 대신 좌표 사이의 차이를 요약한 특성을 만든다.

---

## 두 가지 거리 특성

맨해튼 형태의 거리는 두 축의 절댓값 차이를 더한다.

$$
L_1=|pickup_x-dropoff_x|+|pickup_y-dropoff_y|
$$

유클리드 형태의 거리는 두 축 차이의 제곱합에 제곱근을 취한다.

$$
L_2=\sqrt{(pickup_x-dropoff_x)^2+(pickup_y-dropoff_y)^2}
$$

| 특성 | 이동을 요약하는 방식 |
| :-- | :-- |
| $L_1$ | 축별 이동량을 각각 더함 |
| $L_2$ | 출발점과 도착점의 직선 차이를 계산함 |

> [!IMPORTANT]
> 원본은 두 값이 실제 거리와 비례한다고 설명한다. 좌표 단위와 도로 경로를 직접 검증한 결과는 제공하지 않으므로, 여기서는 모델 입력용 거리 특성이라는 범위로 해석한다.

## LSM 학습과 평가

편향 열을 포함한 설계 행렬에서 정규방정식으로 파라미터를 계산한다.

$$
\theta=(X^{T}X)^{-1}X^{T}Y
$$

평가 지표는 평균제곱오차다.

$$
\operatorname{MSE}=\frac{1}{N}\sum_{i=1}^{N}\left(Y_i-\hat{Y}_i\right)^2
$$

<details>
<summary>예측을 실제 요금으로 되돌리는 순서</summary>

- 새 입력을 학습 통계로 표준화한다.
- 학습 때와 같은 세 열 순서로 모델에 넣는다.
- 표준화된 요금 예측을 얻는다.
- fare_amount의 표준편차를 곱하고 평균을 더한다.

</details>

## 구현 점검표

| 점검 지점 | 확인할 내용 |
| :-- | :-- |
| 열 정리 | 식별자와 시간 열이 입력에 남지 않았는가 |
| 거리 계산 | 출발·도착 좌표 차이에 각 공식을 적용했는가 |
| 전처리 | 학습 통계를 새 입력에도 재사용했는가 |
| 열 순서 | 학습과 예측의 세 입력 순서가 같은가 |
| 단위 복원 | 출력만 요금 단위로 역변환했는가 |

> [!WARNING]
> 원본은 평균과 표준편차를 이용한 변환을 “가우시안 정규화”라고 부르며 정규분포로 바꾸고 이상치 영향을 줄인다고 설명한다. 제시된 식이 직접 수행하는 것은 중심화와 척도 조정이므로, 이 노트는 그 식을 구현 기준으로 삼고 분포 변환·이상치 완화 주장은 검증되지 않은 원본 설명으로 남긴다.

## 핵심 정리

- 좌표 네 개를 두 거리 특성으로 재구성한다.
- 거리 특성과 승객 수를 함께 회귀 입력으로 사용한다.
- 새 입력과 모델 출력을 서로 다른 통계로 변환한다.
- 원본에 없는 최종 요금은 추정해 채우지 않는다.
