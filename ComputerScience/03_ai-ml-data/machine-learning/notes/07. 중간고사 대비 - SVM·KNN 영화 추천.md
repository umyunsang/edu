머신러닝 중간고사 실습 문제는 2차원 특성 공간(Action 점수 $x_1$, Romance 점수$x_2$)에서 표준화(Gaussian Normalization)를 거친 후, **One-vs-Rest (OvR) SVM** 및 **KNN ($K=3$)** 모델을 직접 구현하여 맞춤형 영화를 추천한다.

> [!IMPORTANT]
>
> - **영화 클래스 정의**:
>   - Class 0: **John Wick** (높은 Action 선호)
>   - Class 1: **The Notebook** (높은 Romance 선호)
>   - Class 2: **Leon** (중간/복합 장르 선호)
> - **One-vs-Rest (OvR) 다중 클래스 분류**: 3개의 이진 분류기 $f_0(x), f_1(x), f_2(x)$를 학습시킨 뒤$\arg\max_k f_k(x)$로 최종 클래스 결정.

## 1. 액션/로맨스 선호도 기반 영화 추천 인터랙티브 시뮬레이터

    // OvR 선형 결정 함수 모델 가중치
    // f0 (John Wick): 높은 액션, 낮은 로맨스
    var f0 = 1.2 * zAct - 0.9 * zRom - 0.2;
    // f1 (The Notebook): 높은 로맨스, 낮은 액션
    var f1 = -1.0 * zAct + 1.3 * zRom - 0.1;
    // f2 (Leon): 낮은 액션, 낮은 로맨스 (중간/어두운 톤)
    var f2 = -0.5 * zAct - 0.6 * zRom + 0.5;

    sc0.textContent = (f0 >= 0 ? '+' : '') + f0.toFixed(2);
    sc1.textContent = (f1 >= 0 ? '+' : '') + f1.toFixed(2);
    sc2.textContent = (f2 >= 0 ? '+' : '') + f2.toFixed(2);

    if (f0 >= f1 && f0 >= f2) {
      recTitle.textContent = '🎬 John Wick (존 윅)';
      recTitle.style.color = 'var(--chart-1)';
      recReason.textContent = '액션 지향 성향이 가장 강하게 반영되어 Class 0 SVM 점수 1위';
    } else if (f1 >= f0 && f1 >= f2) {
      recTitle.textContent = '🎬 The Notebook (노트북)';

    }
  }

## 2. 평가 기준 및 점검 항목

- **특성 표준화**: 입력 데이터의 스케일 불균형을 해소하기 위해 Z-score 정규화 필수 적용.
- **분류기 결합**: OvR 방식에서 동점 발생 시 점수 절대값이 가장 큰 클래스를 채택.
