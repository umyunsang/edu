자연어 처리(NLP)에서 텍스트를 컴퓨터가 이해할 수 있는 수치 벡터로 변환하는 기법은 \*\*원-핫 인코딩(One-hot Encoding)\*\*에서 \*\*밀집 분산 표현(Dense Distributed Representation)\*\*인 **Word2Vec**로 진화했다.

---

## 1. 단어 표현 방식의 진화: 원-핫 인코딩 vs 단어 임베딩

### 원-핫 인코딩의 구조적 한계

어휘 사전의 크기가 $\vert V\vert  = 100,000$일 때, 단어 하나를 표현하기 위해 100,000차원의 희소 벡터(Sparse Vector)를 생성한다.

- **차원의 저주와 메모리 낭비**: 벡터 내 하나의 원소만 $1$이고 나머지$99,999$개는$0$인 극단적 희소성 발생.
- **단어 간 의미적 유사도 측정 불가 (직교성)**:
  임의의 두 단어 벡터 $\mathbf{u}, \mathbf{v}$에 대해 내적을 구하면 항상$0$이 된다:
  $$\mathbf{u} \cdot \mathbf{v} = 0 \implies \cos(\theta) = 0$$
  즉, `cat`과 `dog`가 `cat`과 `apple`보다 의미상 가깝다는 언어적 유의성을 전혀 학습할 수 없다.

### Word2Vec의 핵심 아이디어: 분포 가설 (Distributional Hypothesis)

> *"비슷한 문맥(Context)에서 함께 등장하는 단어들은 유사한 의미를 가진다." (Harris, 1954; Firth, 1957)*

Word2Vec은 고차원의 원-핫 벡터를 저차원 ($d \ll \vert V\vert$, 보통 $d \in [50, 300]$)의 실수 밀집 벡터(Dense Vector)로 압축 매핑한다.

```text
원-핫 벡터 (100,000차원)        임베딩 가중치 행렬 W_1 (100,000 x d)        밀집 임베딩 벡터 (d차원)
   [0, 0, 1, 0, ..., 0]  ----->  [단어 'almost'에 대응하는 W_1 행 추출]  ----->  [0.12, -0.45, 0.88, ..., 0.31]
```

## 3. Word2Vec 학습 방식 심층 분석: CBOW vs Skip-Gram

```text
[CBOW (Continuous Bag-of-Words)]               [Skip-Gram]
주변 문맥 단어들 (Context Words)                중심 단어 (Target Word)
   "The", "cat", "on", "the"                        "sat"
              │                                       │
              ▼                                       ▼
     [임베딩 투영층 평균]                             [임베딩 투영층]
              │                                       │
              ▼                                       ▼
    중심 타겟 단어 예측                           주변 문맥 단어들 예측
           "sat"                               "The", "cat", "on", "the"
```

### 1) CBOW (Continuous Bag-of-Words)

- **메커니즘**: 주변 $2C$개 문맥 단어의 원-핫 벡터들을 가중치 행렬$W\_{\vert V\vert  \times d}$에 곱해 얻은 임베딩 벡터들의 **평균**을 은닉층 벡터$\mathbf{h}$로 사용한다:
  $$\mathbf{h} = \frac{1}{2C} \sum_{i=1}^{2C} W^T \mathbf{x}_i$$
- 은닉 벡터 $\mathbf{h}$에 출력 가중치 행렬$W'\_{d \times \vert V\vert }$를 곱해 소프트맥스를 취한 뒤, 중심 단어$y$와의 교차 엔트로피 손실(Cross-Entropy Loss)을 최소화한다.
- **장점**: 문맥 단어들을 평균내어 학습하므로 연산 속도가 빠르고 빈번하게 등장하는 단어 표현에 효과적이다.

### 2) Skip-Gram

- **메커니즘**: 중심 단어 $w_t$를 입력으로 받아 주변$2C$개의 문맥 단어$[w\_{t-C}, \dots, w\_{t+C}]$ 각각이 등장할 확률을 예측한다.
- **목적 함수**:
  $$\mathcal{L}_{\text{Skip-Gram}} = \sum_{t=1}^T \sum_{-C \le j \le C, j \ne 0} \log P(w_{t+j} \mid w_t)$$
  $$P(w_O \mid w_I) = \frac{\exp({v'_{w_O}}^T v_{w_I})}{\sum_{w=1}^{\vert V\vert} \exp({v'_w}^T v_{w_I})}$$
- **장점**: 하나의 중심 단어로 여러 문맥 쌍을 독립적으로 학습하므로, \*\*출현 빈도가 낮은 희귀 단어(Rare Words)\*\*의 임베딩 품질이 CBOW보다 월등히 우수하다.

## 4. 학습 최적화 기법: 계층적 소프트맥스와 네거티브 샘플링

분모의 $\sum\_{w=1}^{\vert V\vert } \exp({v'_w}^T v\_{w_I})$는 어휘 사전 크기$\vert V\vert$가 수십만 개에 달할 때 매 스텝마다 계산하기에 계산 복잡도$O(\vert V\vert )$가 너무 크다.

| 최적화 기법 | 핵심 동작 원리 | 계산 복잡도 | | |
| :--- | :--- | :--- | - | - |
| **계층적 소프트맥스 (Hierarchical Softmax)** | 단어들을 허프만 트리(Huffman Tree) 리프 노드로 구성하고, 루트에서 리프까지의 이진 분류 경로 확률의 곱으로 근사 | $O(\log_2 \vert  V \vert  )$ |
| **네거티브 샘플링 (Negative Sampling, SGNS)** | 전체 다중 분류를 1개의 실제 단어(Positive)와 $K$개의 노이즈 단어(Negative)를 구분하는 이진 로지스틱 회귀로 변환 |$O(K) \quad (K \approx 5 \sim 20)$ | | |

## 5. Python NumPy 기반 Word2Vec 순전파 및 역전파 구현

```python
import numpy as np

class Word2VecCBOW:
    def __init__(self, vocab_size, embed_dim=2, lr=0.01):
        self.V = vocab_size
        self.d = embed_dim
        self.lr = lr
        # 가중치 행렬 초기화: W1 (입력 임베딩), W2 (출력 임베딩)
        self.W1 = np.random.randn(self.V, self.d) * 0.1
        self.W2 = np.random.randn(self.d, self.V) * 0.1

    def forward(self, context_indices):
        # 1. 문맥 단어들의 임베딩 벡터 평균 (은닉층 h)
        self.h = np.mean(self.W1[context_indices], axis=0, keepdims=True)  # (1, d)
        # 2. 출력 로짓 및 소프트맥스 확률
        self.z = np.dot(self.h, self.W2)  # (1, V)
        exp_z = np.exp(self.z - np.max(self.z))
        self.y_hat = exp_z / np.sum(exp_z)
        return self.y_hat

    def backward(self, target_idx, context_indices):
        # 1. 출력 오차 (y_hat - y)
        e = self.y_hat.copy()
        e[0, target_idx] -= 1.0  # (1, V)

        # 2. 기울기 계산
        grad_W2 = np.dot(self.h.T, e)          # (d, V)
        grad_h = np.dot(e, self.W2.T)           # (1, d)

        # 3. 파라미터 갱신
        self.W2 -= self.lr * grad_W2
        for idx in context_indices:
            self.W1[idx] -= (self.lr / len(context_indices)) * grad_h.ravel()

# 4개 단어 단어장 ('I', 'love', 'cute', 'cat')
w2v = Word2VecCBOW(vocab_size=4, embed_dim=2, lr=0.05)
# "I" (0)와 "cat" (3)으로 중간 단어 "love" (1) 학습
for epoch in range(500):
    pred = w2v.forward([0, 3])
    w2v.backward(target_idx=1, context_indices=[0, 3])

print("학습 완료 후 'love' 예측 확률:", w2v.forward([0, 3])[0, 1])
print("학습된 단어 임베딩 행렬 (W1):\n", w2v.W1)
```
