SVM은 데이터를 가장 잘 분리하는 최적 결정 경계를 찾고 마진을 최대화하는 지도학습 알고리즘이다.

> [!IMPORTANT]
>
> - **결정 초평면 및 마진 경계**:
>   - 중심 결정 경계: $w^T x + b = 0$
>   - 양성 마진 경계 ($+1$클래스):$w^T x + b = +1$
>   - 음성 마진 경계 ($-1$클래스):$w^T x + b = -1$
> - **마진 너비**: $\text{Margin} = \frac{2}{\\vert w\\vert }$
> - **힌지 손실**: $L(y, f(x)) = \max(0, 1 - y_i(w^T x_i + b))$

## 2. 서포트 벡터(Support Vectors)의 핵심 성질

- 결정 초평면은 오직 마진 경계선 상에 위치한 **서포트 벡터(Support Vectors)**들에 의해서만 결정된다.
- 마진 바깥쪽에 위치한 수많은 비서포트 데이터들은 초평면의 위치와 방향에 어떠한 영향도 미치지 않으므로, 데이터 효율성과 일반화 성능이 매우 뛰어나다.
