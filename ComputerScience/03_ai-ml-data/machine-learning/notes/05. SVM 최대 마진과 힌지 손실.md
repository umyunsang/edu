\*\*서포트 벡터 머신(SVM, Support Vector Machine)\*\*은 클래스 간의 \*\*기하학적 마진(Geometric Margin)\*\*을 최대화하는 최적 초평면(Hyperplane)을 결정하여 일반화 성능을 극대화하는 강력한 분류 알고리즘이다.

---

## 1. SVM 마진 최대화와 힌지 손실의 수학적 공식화

### 1) 기하학적 마진과 하드 마진(Hard Margin) 원시 문제

결정 초평면 $\mathbf{w}^T \mathbf{x} + b = 0$에 대해 두 지지 초평면 $\mathbf{w}^T \mathbf{x} + b = \pm 1$ 사이의 거리(마진, Margin):

$$\text{Margin } \gamma = \frac{2}{\|\mathbf{w}\|_2}$$

마진을 최대화하는 것은 $\|\mathbf{w}\|\_2^2$를 최소화하는 것과 동치이므로:

$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|_2^2 \quad \text{subject to} \quad y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1, \quad \forall i=1, \dots, n$$

### 2) 소프트 마진(Soft Margin)과 슬랙 변수($\xi_i$)

선형 비분리 데이터셋에서 오분류를 허용하기 위해 슬랙 변수 $\xi_i \ge 0$와 정규화 하이퍼파라미터 $C > 0$를 도입:

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \left( \frac{1}{2} \|\mathbf{w}\|_2^2 + C \sum_{i=1}^n \xi_i \right) \quad \text{s.t.} \quad y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0$$

- $C$가 클수록 하드 마진에 가까워지며 과적합 위험 증가.
- $C$가 작을수록 마진이 넓어지며 이상치에 덜 민감해짐.

### 3) 힌지 손실 (Hinge Loss) 표현식

소프트 마진 최적화 문제는 무제약(Unconstrained) 힌지 손실 최소화 문제로 재구성된다:

$$L_{\text{SVM}}(\mathbf{w}, b) = \frac{1}{2} \|\mathbf{w}\|_2^2 + C \sum_{i=1}^n \max\Big( 0, \; 1 - y_i (\mathbf{w}^T \mathbf{x}_i + b) \Big)$$
