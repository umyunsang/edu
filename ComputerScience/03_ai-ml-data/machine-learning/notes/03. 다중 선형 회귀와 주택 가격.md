다중 선형 회귀(Multiple Linear Regression)는 여러 개의 독립 변수 $x_1, x_2, \dots, x_d$의 선형 결합으로 연속형 종속 변수$y$를 예측하는 모델이다.

> [!IMPORTANT]
>
> - **다중 선형 회귀 방정식**:
>   $\hat{y} = w_1 x_1 + w_2 x_2 + \dots + w_d x_d + b = \mathbf{w}^T \mathbf{x} + b$
> - **결정계수 ($R^2$, Coefficient of Determination)**:
>   $R^2 = 1 - \frac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}} = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2} \in [0, 1]$
>   (모델이 종속 변수의 전체 분산을 얼마나 잘 설명하는지 나타내는 척도)

## 2. 특성 스케일링 (Feature Scaling)의 필요성

특징들 간의 값 범위(Scale)가 크게 다를 경우(예: 면적 $10 \sim 100$vs 방 개수$1 \sim 5$), 손실 함수의 등고선이 타원형으로 찌그러져 경사 하강법 수렴 속도가 급격히 저하된다.

- **표준화 (Standardization / Z-score)**:
  $$x' = \frac{x - \mu}{\sigma}$$
- **정규화 (Min-Max Normalization)**:
  $$x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \in [0, 1]$$
