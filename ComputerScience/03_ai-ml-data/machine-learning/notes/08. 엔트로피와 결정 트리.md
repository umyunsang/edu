결정 트리(Decision Tree)는 데이터셋의 불순도(Impurity)를 가장 크게 감소시키는 질문(임계값 Threshold)을 순차적으로 탐색하여 하위 노드로 분할하는 비모수적 지도학습 모델이다.

> [!IMPORTANT]
> - **섀넌 엔트로피 (Shannon Entropy)**:
>   $$H(S) = -\sum_{i=1}^C p_i \log_2 p_i$$
> - **정보 획득량 (Information Gain, $IG$)**:
>   $$IG(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(S_v)$$
>   (분할 전 엔트로피에서 분할 후 가중 평균 엔트로피를 뺀 값으로, $IG$가 최대인 분기를 선택)

  var totalPos = 10, totalNeg = 10;
  var totalAll = totalPos + totalNeg;

  var sLPos = document.getElementById('dt-left-pos');
  var sLNeg = document.getElementById('dt-left-neg');

  var valRNeg = document.getElementById('dt-right-neg-val');

  var hLeftEl = document.getElementById('dt-h-left');
  var hRightEl = document.getElementById('dt-h-right');
  var igValEl = document.getElementById('dt-ig-val');
  var igStatusEl = document.getElementById('dt-ig-status');

  function ent(pos, neg) {
    var tot = pos + neg;
    if (tot === 0) return 0;
    var p1 = pos / tot;
    var p2 = neg / tot;
    if (p1 <= 0 || p2 <= 0) return 0;
    return -(p1 * Math.log2(p1) + p2 * Math.log2(p2));
  }

  function update() {
    var lPos = parseInt(sLPos.value, 10);
    var lNeg = parseInt(sLNeg.value, 10);
    var rPos = totalPos - lPos;
    var rNeg = totalNeg - lNeg;

    valLPos.textContent = lPos;
    valLNeg.textContent = lNeg;
    valRPos.textContent = rPos;
    valRNeg.textContent = rNeg;

    var hLeft = ent(lPos, lNeg);
    var hRight = ent(rPos, rNeg);

    hLeftEl.textContent = hLeft.toFixed(3);
    hRightEl.textContent = hRight.toFixed(3);

    var nLeft = lPos + lNeg;
    var nRight = rPos + rNeg;
    var hAfter = (nLeft / totalAll) * hLeft + (nRight / totalAll) * hRight;
    var ig = 1.0 - hAfter; // H(S) = 1.0

    igValEl.textContent = ig.toFixed(3) + ' bit';

    if (ig > 0.5) {
      igStatusEl.textContent = '🌟 우수한 분기 (높은 불순도 감소 효과)';
      igStatusEl.style.color = 'var(--chart-2)';

      igStatusEl.style.color = 'var(--destructive)';
    }
  }

## 2. 결정 트리의 과적합(Overfitting) 방지 기법

- **최대 깊이 제한 (Max Depth)**: 트리가 너무 깊게 자라나 개별 노이즈까지 암기하는 현상 차단.
- **최소 샘플 분할 수 (Min Samples Split)**: 노드를 더 분할하기 위해 필요한 최소 샘플 수 지정.
- **가지치기 (Pruning)**: 검증 데이터셋의 성능을 기준으로 불필요한 서브트리를 제거하여 일반화 성능 개선.
