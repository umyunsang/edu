\*\*결정 트리(Decision Tree)\*\*는 데이터를 특징(Feature) 값에 따라 계층적으로 분할하여 규칙 기반의 예측 모델을 생성하는 지도학습 알고리즘으로, 노드 분할 시 불순도(Impurity) 감소량을 최대화한다.

---

## 1. 노드 불순도와 정보 획득량의 수학적 공식화

### 1) 섀넌 엔트로피(Shannon Entropy)와 지니 불순도(Gini Impurity)

클래스 $c$개의 확률 분포 $\mathbf{p} = (p_1, p_2, \dots, p_c)$에 대해:

- **엔트로피 (Entropy)**:
  $$H(S) = -\sum_{i=1}^c p_i \log_2 p_i \quad (0 \le H(S) \le \log_2 c)$$
- **지니 불순도 (Gini Impurity)**:
  $$\text{Gini}(S) = 1 - \sum_{i=1}^c p_i^2 = \sum_{i=1}^c p_i (1 - p_i) \quad \left(0 \le \text{Gini}(S) \le 1 - \frac{1}{c}\right)$$

### 2) 정보 획득량 (Information Gain, ID3 알고리즘)

부모 노드 $S$를 특징 $A$의 고유값 집합 ${v_1, \dots, v_k}$에 따라 분할할 때의 불순도 감소량:

$$IG(S, A) = H(S) - \sum_{j=1}^k \frac{|S_j|}{|S|} H(S_j)$$

- C4.5에서는 다중 분할 특징에 편향되는 한계를 극복하기 위해 분할 정보량(Intrinsic Value $IV$)으로 정규화한 \*\*정보 획득률(Gain Ratio)\*\*을 사용:
  $$IGR(S, A) = \frac{IG(S, A)}{IV(S, A)}, \quad IV(S, A) = -\sum_{j=1}^k \frac{|S_j|}{|S|} \log_2 \left(\frac{|S_j|}{|S|}\right)$$

  }
