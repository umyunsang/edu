## 실습 문제 정의

RNN은 시간 순서가 있는 데이터를 순차적으로 입력하고 이전 상태를 현재 학습에 반영한다. 실습 문장은 **나라의 말이 중국과 달라…따름이니라**로 이어지는 훈민정음 서문 현대어 번역본이다.

\`\`\`mermaid
flowchart LR
  A["첫 단어 입력"] --> B["현재 hidden 계산"]
  B --> C["다음 단어 예측"]
  C --> D["예측 단어를 다음 입력으로 사용"]
  D --> B
  C --> E["전체 문장 sequence 출력"]
\`\`\`

<Tabs>
  <Tab label="입력">문장의 첫 단어와 이전 시점 hidden state를 사용한다.</Tab>
  <Tab label="출력">각 시점에서 다음 단어 확률과 새 hidden state를 출력한다.</Tab>
  <Tab label="학습">전체 예측 sequence와 정답 sequence의 loss를 계산한다.</Tab>
</Tabs>

## 자연어를 vector로 바꾸기

컴퓨터가 단어를 직접 이해하지 못하므로 각 단어를 숫자 vector로 변환한다. 강의의 단순 embedding 예시는 한 단어를 $[0.5,0.3,0.8]$로 표현한다.

| 표현 | 정의 | 실습에서의 의미 |
| --- | --- | --- |
| One-hot encoding | 문장 단어 집합 길이의 vector에서 한 원소만 1이고 나머지는 0 | 단어와 index를 일대일 대응 |
| Word2Vec | 주어진 단어를 vector로 변환하는 machine learning model | 밀집 embedding의 대안 |
| 출력 해석 | 가장 큰 값의 index | index를 다시 단어로 변환 |

훈민정음 문장에서는 **나라의**부터 **따름이니라**까지 각 단어에 index를 부여한다. 입력 one-hot의 길이와 출력 class 수는 전체 문장 단어 집합 길이와 같다.

## RNN network architecture

각 RNN cell은 입력 $x_t$와 이전 hidden state $h_{t-1}$를 이용한다. MLP layer를 정의하고 Tanh를 거쳐 출력과 현재 hidden state $h_t$를 만든 뒤, 이 계산을 전체 sequence에 반복한다.

원문에 제시된 식은 다음과 같다.

$$
h_t=f(W_{xh}x_t+W_{hh}x_{t-1}+\mathrm{bias})
$$

$$
y_i=f(W_{hy}h_i+\mathrm{bias})
$$

> [!WARNING]
> 구조도는 $W_{hh}$가 이전 hidden state $h_{t-1}$를 전달한다고 그리지만 식은 $x_{t-1}$를 인쇄한다. 이 source 표기 불일치를 그대로 기록한다.

| layer | 입력 | 출력 |
| --- | --- | --- |
| 입력 변환 | $x_t$ | hidden 후보 |
| 순환 변환 | $h_{t-1}$ | hidden 후보 |
| Tanh | 두 후보의 결합 | $h_t$ |
| 출력 변환 | $h_t$ | $y_t$ |

---

## Training process

1. 초기 입력 값을 정의한다.
2. RNN 반복 구조로 전체 sequence를 예측한다.
3. 예측한 전체 sequence와 정답 데이터의 loss를 계산한다.
4. loss를 이용해 parameter를 갱신한다.
5. 첫 단어에서 시작해 문장 전체가 이어지는지 확인한다.

> [!NOTE]
> 실습 자료는 모델 구조와 학습 순서를 제시하지만 epoch, learning rate, hidden dimension의 구체 값은 제시하지 않는다.

## LSTM network architecture

LSTM은 이전 cell state $C_{t-1}$, 이전 hidden state $h_{t-1}$, 현재 입력 $x_t$를 사용한다.

$$
f_t=\sigma(W_{xhf}x_t+W_{hhf}h_{t-1}+\mathrm{bias})
$$

$$
i_t=\sigma(W_{xhi}x_t+W_{hhi}h_{t-1}+\mathrm{bias})
$$

$$
\widetilde{C}_t=\tanh(W_{xhc}x_t+W_{hhc}h_{t-1}+\mathrm{bias})
$$

$$
o_t=\sigma(W_{xho}x_t+W_{hho}h_{t-1}+\mathrm{bias})
$$

## 실습 점검

- 한글 외 문자를 제거한 뒤 단어 list를 만들었는가?

- one-hot 입력과 다음 단어 정답을 한 칸 이동해 구성했는가?
