서포트 벡터 머신(SVM)은 원 문제(Primal)에서 **힌지 손실(Hinge Loss)**을 미분하여 경사 하강법(GD)으로 풀거나, 쌍대 문제(Dual)에서 **2차 계획법(Quadratic Programming, QP)**으로 라그랑주 승수 $\alpha_i$를 구하는 두 가지 방식으로 구현된다.

> [!IMPORTANT]
> - **힌지 손실(Hinge Loss) 함수**:
>   $$L(z) = \max(0, 1 - z) \quad (\text{단, } z = y_i(w^T x_i + b))$$
> - **손실 및 그래디언트 분기**:
>   - $z \ge 1$: 올바른 분류 및 마진 외곽 $\to L(z) = 0$, $\nabla_w L = 0$ (손실 없음).
>   - $z < 1$: 마진 침범 또는 오분류 $\to L(z) = 1 - z$, $\nabla_w L = -y_i x_i$, $\nabla_b L = -y_i$.

## 2. 경사 하강법(GD) vs 2차 계획법(QP) 비교

| 비교 항목 | 경사 하강법 (Primal GD) | 2차 계획법 (Dual QP) |
| :--- | :--- | :--- |
| **최적화 대상** | 가중치 벡터 $w$와 편향 $b$ | 라그랑주 승수 $\alpha_i \ge 0$ |
| **비선형 커널 확장** | 무한 차원 매핑 시 직접 계산 불가 | **커널 트릭 $K(x_i, x_j)$ 적용 용이** |
| **서포트 벡터 추출** | $1 - y_i(w^T x_i + b) \approx 0$ 샘플 추적 | **$\alpha_i > 0$인 샘플이 곧 서포트 벡터** |
