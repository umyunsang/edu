# 01. Word2Vec과 순환 신경망 리뷰

> [!abstract] 핵심
> Word2Vec은 원-핫 표현의 한계를 완화하는 임베딩을 학습하고, RNN·LSTM 리뷰는 순서와 장기 의존성의 문제를 연결한다.

## 문제를 모델로 바꾸기

원-핫 벡터는 어휘 수만큼 차원을 요구하고 단어 사이의 유사성을 직접 표현하기 어렵다. Word2Vec은 더 낮은 차원의 임베딩 벡터를 학습해 벡터 사이의 유사도로 단어 관계를 다룰 수 있게 한다. 순서가 있는 언어 입력에서는 RNN 계열이 문맥을 상태로 전달하고, LSTM은 긴 의존성의 어려움을 완화한다.

flowchart LR
    A["입력 또는 관찰"] --> B["표현과 전처리"]
    B --> C["학습 규칙"]
    C --> D["예측 또는 판단"]
    D --> E["검증과 해석"]
```

| 관점 | 이 노트에서 확인할 질문 | 학습할 때의 점검 |
| --- | --- | --- |
| 원-핫 표현 | 어휘마다 독립 축을 배정 | 차원과 희소성을 확인한다 |
| 임베딩 | 학습된 조밀 벡터 | 유사도와 과제 성능을 분리해 본다 |
| 순환 모델 | 순서가 있는 벡터 처리 | 장기 문맥과 순차 처리 제약을 점검한다 |

> [!note] 흐름
> 단어를 정수 또는 원-핫 표현에서 임베딩 벡터로 바꾸고, 벡터가 문맥과 함께 어떻게 쓰이는지 구분한다. 임베딩 품질은 유사도 예시뿐 아니라 실제 과제의 손실과 예측으로 확인한다.

## 관점을 나누어 보기

<Tabs>
<Tab label="개념">

Word2Vec의 목표는 단어를 벡터로 표현해 관계를 다룰 수 있게 하는 것이다. 임베딩 차원은 학습 전에 정하는 하이퍼파라미터다.

</Tab>
<Tab label="실행">

언어 입력은 벡터화 뒤 시퀀스로 모델에 전달된다. RNN·LSTM은 이전 단계 정보와 현재 입력을 연결해 처리한다.

</Tab>
<Tab label="검증">

벡터가 그럴듯해 보여도 과제에 필요한 문맥을 담는지는 별도의 평가가 필요하다. 임베딩 차원과 모델 용량을 함께 비교한다.

</Tab>
</Tabs>
