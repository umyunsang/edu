# 01. SVM과 KNN 대비 문제

> [!abstract] 핵심
> 힌지 손실을 이용한 SVM 학습과 거리 기반 KNN 선택을 한 분류 과제의 서로 다른 해결 전략으로 비교한다.

## 문제를 모델로 바꾸기

SVM은 $y_i(w^T x_i+b)\ge1$의 마진 조건을 만족시키는 경계를 찾고, 위반이 있으면 힌지 손실에 따라 가중치와 편향을 갱신한다. KNN은 학습된 선형 경계 대신 새 입력과 기존 표본 사이의 거리를 이용한다. 두 방법을 비교할 때는 같은 정규화와 같은 테스트 기준이 필요하다.

flowchart LR
    A["입력 또는 관찰"] --> B["표현과 전처리"]
    B --> C["학습 규칙"]
    C --> D["예측 또는 판단"]
    D --> E["검증과 해석"]
```

| 관점 | 이 노트에서 확인할 질문 | 학습할 때의 점검 |
| --- | --- | --- |
| 마진 조건 | 경계와 표본의 여유 | 위반 표본이 손실에 미치는 영향을 본다 |
| 힌지 손실 | 마진 미달에 대한 벌점 | 학습률과 반복 수를 함께 기록한다 |
| 이웃 투표 | 근처 표본의 집계 | 동점과 거리 척도 규칙을 정한다 |

> [!note] 흐름
> 범주별 모델의 입력과 라벨을 준비한 뒤, 반복 학습에서 손실과 파라미터 변화를 확인한다. KNN은 여러 홀수 $K$의 검증 성능을 비교해 한 값을 선택한다.

## 관점을 나누어 보기

<Tabs>
<Tab label="개념">

SVM은 데이터 사이에 넓은 여유를 두는 경계를 지향한다. KNN은 분포의 지역적 구조를 새 입력 근처에서 사용한다.

</Tab>
<Tab label="실행">

SVM은 파라미터를 초기화하고 손실을 줄이는 방향으로 반복 갱신한다. KNN은 학습 데이터를 정리하고 거리 계산을 수행한다.

</Tab>
<Tab label="검증">

마진을 크게 하는 것과 테스트 정확도를 높이는 것은 같은 목표가 아닐 수 있다. $K$도 한 데이터셋에서만 좋은 값이 될 수 있다.

</Tab>
</Tabs>

<summary>복습 질문</summary>

SVM에서 라벨의 부호가 마진식에 왜 필요한가? KNN에서 $K$를 홀수로 두는 실무적 이유는 무엇인가?

</details>

> [!tip] 학습 전략
> 입력, 모델의 가정, 평가 기준을 한 문장씩 연결해 설명해 본다. 계산 결과만 적지 말고 어떤 선택이 결과를 바꾸는지도 기록한다.

> [!warning] 해석 주의
> 학습률이 너무 크면 손실이 안정적으로 줄지 않을 수 있고, 너무 작은 $K$는 개별 표본의 잡음에 민감해질 수 있다.
