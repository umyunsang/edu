# 01. 머신러닝 대비 문제

> [!abstract] 핵심
> 두 장르 선호도를 입력으로 여러 영화 범주를 예측하는 과제를 통해 정규화, 다중 분류, SVM, KNN의 검증 순서를 정리한다.

## 문제를 모델로 바꾸기

입력은 두 장르에 대한 점수이고 출력은 세 영화 중 하나의 범주다. 다중 분류는 범주별 이진 SVM을 구성해 점수를 비교하는 방식으로 다룰 수 있으며, KNN은 거리상 가까운 관측값의 다수결을 쓴다. 두 방법 모두 입력 축의 단위를 맞추어야 거리가 한 특성에 지배되지 않는다.

flowchart LR
    A["입력 또는 관찰"] --> B["표현과 전처리"]
    B --> C["학습 규칙"]
    C --> D["예측 또는 판단"]
    D --> E["검증과 해석"]
```

| 관점 | 이 노트에서 확인할 질문 | 학습할 때의 점검 |
| --- | --- | --- |
| 입력 | 장르별 점수 두 개 | 두 축을 동일한 방식으로 정규화한다 |
| SVM | 범주별 경계와 점수 | 훈련 자료만으로 파라미터를 갱신한다 |
| KNN | 가까운 관측값의 투표 | 후보 $K$의 테스트 누수를 막는다 |

> [!note] 흐름
> 각 특성의 평균과 표준편차를 학습 자료에서 구해 정규화한다. 학습·테스트를 분리하고, SVM의 파라미터와 KNN의 여러 홀수 $K$를 학습 구간에서 정한 뒤 테스트에 한 번 적용한다.

## 관점을 나누어 보기

<Tabs>
<Tab label="개념">

문제의 핵심은 입력 벡터에서 영화 범주를 예측하는 것이다. 범주가 셋이면 이진 판단을 조합하는 설계가 필요하다.

</Tab>
<Tab label="실행">

정규화, 데이터 분리, 모델 학습, 예측을 순서대로 수행한다. 같은 분할을 사용하면 방법 간 성능을 비교할 수 있다.

</Tab>
<Tab label="검증">

학습용 설정 선택과 최종 평가는 역할이 다르다. 테스트 결과를 보고 설정을 다시 바꾸면 평가가 낙관적으로 변한다.

</Tab>
</Tabs>

<details>
<summary>복습 질문</summary>

정규화 통계를 전체 데이터로 계산하면 어떤 정보가 학습 단계에 섞이는가? 세 범주의 SVM 점수가 충돌할 때 어떤 비교 규칙을 명시해야 하는가?

</details>

> [!tip] 학습 전략
> 입력, 모델의 가정, 평가 기준을 한 문장씩 연결해 설명해 본다. 계산 결과만 적지 말고 어떤 선택이 결과를 바꾸는지도 기록한다.

> [!warning] 해석 주의
> 테스트 구간을 여러 번 보며 $K$나 학습률을 조정하면 최종 정확도는 실제 일반화 성능보다 높게 보일 수 있다.
