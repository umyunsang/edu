> [!abstract]
> 파이썬의 변수와 실행 방식은 데이터를 다루는 출발점이고, 평균제곱오차(MSE)는 예측값과 실제값의 차이를 한 방향으로 상쇄하지 않도록 측정하는 대표 지표다.

## 값을 이름으로 다루기

변수는 메모리의 값에 붙이는 이름이다. 대입 연산은 오른쪽 값을 왼쪽 변수에 저장하며, 변수에는 수치뿐 아니라 문자열 같은 데이터도 담을 수 있다. 대화식 모드는 명령을 즉시 확인하고, 스크립트 모드는 코드를 파일로 저장해 실행한다.

<Tabs>
<Tab title="대화식 모드">
한 줄 또는 짧은 식을 실행해 결과를 빠르게 확인할 때 적합하다.
</Tab>
<Tab title="스크립트 모드">
여러 명령을 파일에 정리하고 반복 실행 가능한 작업으로 만들 때 적합하다.
</Tab>
<Tab title="변수">
값 자체가 아니라 값을 가리키는 이름으로, 데이터 흐름을 읽기 쉽게 만든다.
</Tab>
</Tabs>

```mermaid
flowchart LR
    A[입력 데이터] --> B[변수에 저장]
    B --> C[연산과 예측]
    C --> D[실제값과 비교]
    D --> E[오차 지표]
```

> [!important]
> 데이터 분석 코드에서 변수 이름은 계산의 중간 의미를 드러낸다. 값만 맞추는 것보다, 어떤 값이 입력·예측·실제 타깃인지 구분해 두는 편이 검증과 재사용에 유리하다.

```html preview h=165px

  <strong>예측 검증의 두 값</strong>
  <div style="display:grid;grid-template-columns:1fr auto 1fr;gap:12px;align-items:center;margin-top:14px">

```

<details>
<summary>왜 오차를 그냥 더하면 안 될까?</summary>

양의 오차와 음의 오차는 단순 합에서 서로 상쇄될 수 있다. 평균제곱오차는 차이를 제곱하므로 부호 상쇄를 막고, 큰 오차에 더 큰 비중을 준다.
</details>

## 평균제곱오차 읽기

MSE는 실제값과 예측값의 차이를 제곱해 평균한 값이다. 값이 작을수록 이 데이터에서 예측과 실제가 가깝다는 뜻이지만, 목표 변수의 단위와 데이터 규모를 함께 읽어야 한다.

```html preview h=170px
<div style="font-family:system-ui,sans-serif;padding:16px;border:1px solid var(--border);border-radius:12px;background:var(--card);color:var(--foreground)">
  <div style="display:flex;gap:10px;align-items:end">
    <span style="height:32px;flex:1;background:var(--chart-2);border-radius:6px 6px 0 0"></span>
    <span style="height:62px;flex:1;background:var(--chart-3);border-radius:6px 6px 0 0"></span>
    <span style="height:96px;flex:1;background:var(--chart-4);border-radius:6px 6px 0 0"></span>
  </div>
  <p style="margin:12px 0 0">제곱은 큰 차이에 더 큰 페널티를 준다.</p>
</div>
```

<details>
<summary>작은 MSE만으로 모형을 고를 수 있을까?</summary>

같은 데이터 분할, 같은 타깃 단위, 같은 검증 조건에서 비교해야 한다. 또한 몇 개의 큰 오류가 평균을 지배하는지, 예측이 특정 구간에서만 나쁜지도 함께 살핀다.
</details>

> [!warning]
> 대화식으로 확인한 결과를 그대로 결론으로 두지 않는다. 입력·분할·지표 계산을 스크립트나 기록으로 남겨야 재현 가능한 비교가 된다.

**핵심 연결:** 변수는 데이터를 조직하고, 실행 방식은 작업을 반복 가능하게 하며, MSE는 그 예측의 오차를 확인한다.

### 스스로 점검

- MSE에서 제곱이 필요한 이유를 설명할 수 있는가?
- 지표 비교에 같은 검증 조건을 사용했는가?
