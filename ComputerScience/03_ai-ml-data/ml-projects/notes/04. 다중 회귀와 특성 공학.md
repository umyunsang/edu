> [!abstract]
> 다중 회귀는 여러 특성을 함께 사용해 하나의 타깃을 예측한다. 특성 공학은 기존 열을 변환·조합해 모형이 볼 수 있는 표현을 넓히는 작업이다.

## 여러 축에서 예측하기

특성이 하나면 선형 회귀는 직선으로 생각할 수 있고, 특성이 둘이면 평면으로 볼 수 있다. 더 많은 특성에서는 눈으로 공간을 그릴 수 없어도, 모형은 여러 계수를 조합해 예측을 만든다.

<Tabs>
<Tab title="원래 특성">
길이·높이·두께처럼 측정된 값을 입력 열로 둔다.
</Tab>
<Tab title="확장 특성">
각 열의 제곱이나 두 열의 곱처럼 기존 값에서 새 열을 만든다.
</Tab>
<Tab title="예측식">
각 특성에 계수를 곱해 더하고 절편을 결합해 타깃을 계산한다.
</Tab>
</Tabs>

```mermaid
flowchart LR
    A[원래 특성] --> B[특성 공학]
    B --> C[제곱과 상호작용 특성]
    C --> D[학습/검증 분할]
    D --> E[다중 선형 회귀]
    E --> F[타깃 예측]
```

> [!important]
> 특성이 많아진 선형 회귀를 단순히 “직선이라 약한 모델”로 단정할 수는 없다. 입력 공간의 조합이 늘면 표현할 수 있는 관계도 달라진다.

```html preview h=170px
<div style="font-family:system-ui,sans-serif;padding:16px;border:1px solid var(--border);border-radius:12px;background:var(--card);color:var(--foreground)">
  <strong>특성 공학의 흐름</strong>
  <div style="display:flex;flex-wrap:wrap;gap:9px;margin-top:14px">
    <span style="padding:8px;border-radius:7px;background:var(--chart-1);color:var(--background)">길이</span>
    <span style="padding:8px;border-radius:7px;background:var(--chart-2);color:var(--background)">높이</span>

  </div>
</div>
```

<details>
<summary>상호작용 특성은 왜 만들까?</summary>

두 특성의 곱은 한 특성의 효과가 다른 특성의 수준에 따라 달라질 가능성을 입력으로 표현한다. 필요한 조합인지 여부는 학습과 검증 결과로 확인한다.
</details>

## 데이터 분할과 해석

특성을 확장한 뒤에도 훈련 데이터와 테스트 데이터를 구분한다. 결과를 해석할 때는 좋은 점수뿐 아니라 어떤 열이 추가되었고, 그 열이 실제 문제에서 어떤 의미인지 함께 기록한다.

```html preview h=170px
<div style="font-family:system-ui,sans-serif;padding:16px;border:1px solid var(--border);border-radius:12px;background:var(--card);color:var(--foreground)">

    <span style="padding:12px;border:1px solid var(--border);border-radius:8px">특성 생성</span>
    <span style="padding:12px;border:1px solid var(--border);border-radius:8px">검증</span>
  </div>
</div>
```

<details>
<summary>확장 특성이 항상 유리한가?</summary>

열을 많이 만들면 훈련 데이터에 더 잘 맞을 수 있지만, 새로운 데이터에서도 좋아진다는 보장은 없다. 특성 선택과 성능 평가는 분리된 검증 절차에서 함께 수행한다.
</details>

> [!warning]
> 특성 공학은 숫자 열을 무작정 늘리는 일이 아니다. 데이터 의미, 누수 가능성, 검증 성능을 기준으로 선택한다.

**핵심 연결:** 다중 회귀는 여러 입력을 결합하고, 특성 공학은 그 입력의 언어를 확장한다.

> [!tip]
> 학습 팁: 핵심 개념을 작은 입력 예시로 다시 설명하고, 검증 기준을 한 문장으로 적어 본다.

### 스스로 점검

- 원래 특성과 생성 특성을 구분해 설명할 수 있는가?
- 곱 특성이 어떤 관계를 표현하는가?
- 특성 확장 뒤에도 독립 테스트를 남겨 두었는가?
