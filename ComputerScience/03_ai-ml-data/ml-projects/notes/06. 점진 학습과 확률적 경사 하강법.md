> [!abstract]
> 점진 학습은 데이터를 작은 묶음으로 받아 기존 모형을 이어서 갱신한다. 확률적 경사 하강법은 손실을 줄이는 방향으로 조금씩 이동하는 대표적인 방법이다.

## 데이터가 계속 도착할 때

모든 훈련 데이터를 한 번에 보관해 다시 학습하면 저장과 연산 부담이 커질 수 있다. 점진 학습은 미니배치 단위로 데이터를 주입하며, 이전에 학습한 모형을 버리지 않고 갱신하는 방식을 취한다.

<Tabs>
<Tab title="확률적">
훈련 샘플 하나를 무작위로 골라 갱신한다.
</Tab>
<Tab title="미니배치">
무작위로 고른 여러 샘플을 한 묶음으로 사용한다.
</Tab>
<Tab title="배치">
전체 훈련 세트를 사용해 한 번의 갱신을 계산한다.
</Tab>
</Tabs>

```mermaid
flowchart LR
    A[도착한 미니배치] --> B[현재 모형]
    B --> C[손실 계산]
    C --> D[경사 방향 갱신]
    D --> E[다음 미니배치]
    E --> B
```

> [!important]
> 에포크는 훈련 세트를 한 번 모두 사용하는 과정이다. 온라인 학습에서도 에포크 수는 학습이 부족한지, 지나친지를 판단하는 중요한 축이다.

<details>
<summary>작은 묶음이 항상 안전한가?</summary>

작은 묶음은 빠르고 메모리 부담이 작지만, 데이터 순서나 한 묶음의 특성에 더 민감할 수 있다. 도착 데이터가 기존 분포를 충분히 대표하는지도 확인해야 한다.
</details>

## 손실, 에포크, 조기 종료

손실 함수는 모형의 예측이 얼마나 맞지 않는지를 수치로 만든다. 에포크가 너무 적으면 과소적합, 너무 많으면 훈련 데이터에만 맞는 과대적합이 생길 수 있다. 검증 성능 향상이 멈추면 학습을 멈추는 조기 종료가 실용적인 제어 장치가 된다.

<details>
<summary>partial_fit은 무엇을 뜻할까?</summary>

자료에서는 SGDClassifier의 partial_fit 호출이 한 에포크씩 이어 훈련하는 방식으로 소개된다. 반복 호출 자체보다, 매 호출 뒤 검증 기준을 어떻게 적용하는지가 중요하다.
</details>

> [!warning]
> 새 데이터만 계속 주입하면 과거 패턴을 잊거나, 데이터 분포 변화에 잘못 반응할 수 있다. 유지할 데이터와 평가 창을 명시한다.

**핵심 연결:** 점진 학습은 메모리 제약을 다루고, 경사 하강법은 손실을 줄이는 갱신 규칙을 제공하며, 조기 종료는 일반화 성능을 지키는 신호다.

> [!tip]
> 학습 팁: 핵심 개념을 작은 입력 예시로 다시 설명하고, 검증 기준을 한 문장으로 적어 본다.

- 조기 종료의 기준을 검증 데이터에서 읽는가?
