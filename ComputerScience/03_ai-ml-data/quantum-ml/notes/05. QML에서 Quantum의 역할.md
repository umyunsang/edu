양자 머신러닝에서 양자 프로세서(QPU)는 고전 컴퓨터를 완전히 대체하는 것이 아니라, 고전 알고리즘이 병목을 겪는 **특정 수학적 연산(고차원 내적, 조합 최적화, 복잡한 확률 분포 샘플링)**을 전담하는 **양자 가속기(Quantum Co-processor)**로 동작한다.

## 2. 하이브리드 양자-고전 신경망 (Hybrid QNN) 파이프라인

$$\mathbf{x} \xrightarrow{\text{Classical Preprocessing}} \tilde{\mathbf{x}} \xrightarrow{\text{Quantum Feature Map } U_\Phi(\tilde{\mathbf{x}})} |\Phi(\tilde{\mathbf{x}})\rangle \xrightarrow{\text{Variational Layers } W(\boldsymbol{\theta})} |\psi(\tilde{\mathbf{x}}, \boldsymbol{\theta})\rangle \xrightarrow{\text{Measurement } \langle \hat{\mathbf{Z}} \rangle} \hat{y} \xrightarrow{\text{Loss \& Update } \boldsymbol{\theta}} \text{Next Iteration}$$

## 3. 인터랙티브 QNN 순전파 & 매개변수 $\theta$ 학습 시뮬레이터
