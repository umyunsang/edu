> [!abstract] 한 줄 요약
> Bit를 계속 늘리는 것도 **가능하긴 하다.**
> 다만 네 가지 문제가 따라오고, 그것들은 수량으로 풀리지 않는다.

## Bit란 무엇인가

> [!quote] 슬라이드 근거
> `pdf/day02_02_bit_and_qubit_lecture.pdf` p.2

**Bit(Binary Digit)** 는 컴퓨터가 사용하는 가장 작은 정보 단위다. 0(OFF/꺼짐) 또는 1(ON/켜짐), **두 가지 상태 중 하나만** 가질 수 있다.

## 그럼 Bit를 더 늘리면 되지 않는가

> `pdf/day02_02_bit_and_qubit_lecture.pdf` p.3

> 그래서 ==정보 표현 방식 자체를 바꿀 필요== 가 생긴다.

## Qubit의 등장

> [!quote] 슬라이드 근거
> `pdf/day02_02_bit_and_qubit_lecture.pdf` p.4

**Qubit = Quantum Bit** — 양자역학의 원리를 이용해 정보를 표현하는 새로운 기본 단위다.

$$
\lvert 0 \rangle \;+\; \lvert 1 \rangle
$$

| 표기 | 의미 | 기존 Bit 대응 |
| :--: | :-- | :-- |
| $\lvert 0 \rangle$ | 0 상태 | Bit의 0 |
| $\lvert 1 \rangle$ | 1 상태 | Bit의 1 |

> [!tip] 슬라이드의 마무리 문장
> Qubit은 **0과 1을 동시에 가질 수 있는** 새로운 방식의 정보 단위다.

## Bit 와 Qubit 비교

| | Bit | Qubit |
| :-- | :-- | :-- |
| 정체 | Binary Digit | Quantum Bit |
| 가지는 것 | 0 또는 1 중 하나 | 0과 1을 동시에 |
| 근거 | 전압의 유무 | 양자역학의 원리 |
| 한계 | 복잡한 관계 표현이 어렵다 | 하드웨어가 아직 초기 단계 |

> [!caution] "동시에 가진다"를 오해하기 쉬운 지점
> 측정하면 **결국 0 또는 1 하나로** 결정된다. 동시에 가지는 것은 값이 아니라 **가능성**이다.
> 이 구분은 [07. 상태변화 분석](<./07. 상태변화 분석.md>) 에서 실측으로 확인한다.

## 핵심 정리

| 개념 | 정의 | 왜 중요한가 |
| :-- | :-- | :-- |
| Bit | 0 또는 1, 둘 중 하나 | 고전 정보 표현의 바닥 |
| Bit 확장의 한계 | 크기·계산량·메모리·관계표현 | 수량으로 풀리지 않는 문제가 있다 |
| Qubit | 양자역학 기반 정보 단위 | 표현 방식 자체를 바꿔 한계를 우회 |
| $\lvert 0 \rangle, \lvert 1 \rangle$ | 켓(ket) 표기 | 이후 모든 노트가 쓰는 표기법 |

> [!question]- 스스로 점검
> **Q.** Bit를 충분히 많이 쓰면 Qubit 없이도 되지 않는가?
>
> **A.** 저장량·계산량 문제는 자원으로 어느 정도 밀릴 수 있다. 그러나 슬라이드가 꼽은 네 번째 — 복잡한 관계를 0과 1로 표현하는 어려움 — 은 수량으로 해결되지 않는 문제다.
