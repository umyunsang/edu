## 2. $2^n$ 지수적 상태 공간 팽창

고전 $n$비트 레지스터는 $2^n$개의 가능한 조합 중 **단 1개의 확정된 상태**만을 저장하지만, $n$개 큐비트 양자 레지스터는 $2^n$개 모든 기저 상태의 중첩 $|\psi\rangle = \sum_{x=0}^{2^n-1} c_x |x\rangle$을 단일 물리 시스템에 동시에 보관한다:

$$\text{Qubits } n = 50 \implies 2^{50} \approx 1.125 \times 10^{15} \text{ 개의 복소 진폭 (약 16 PB 고전 메모리 필요)}$$
$$\text{Qubits } n = 300 \implies 2^{300} \approx 2 \times 10^{90} > \text{우주 전체의 모든 원자 수}$$

## 3. 인터랙티브 $n$-큐비트 지수적 표현력 & 고전 메모리 비교기

(function() {

    else if (bytes < 1024*1024) ramTxt.textContent = (bytes / 1024).toFixed(1) + ' KB';
