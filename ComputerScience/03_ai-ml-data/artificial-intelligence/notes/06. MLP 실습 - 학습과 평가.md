신경망 모델을 설계한 후에는 학습 데이터셋 전체를 여러 번 반복 학습하는 **에포크(Epoch)** 루프와, 각 에포크 내에서 미니배치 단위로 가중치를 갱신하는 **이터레이션(Iteration)** 루프를 구축하고, 테스트 데이터셋을 통해 과적합 여부와 일반화 정확도를 평가해야 한다.

---

## 1. 에포크(Epoch) vs 이터레이션(Iteration)의 개념 비교

```
• 전체 학습 데이터셋 크기 (N) : 60,000장
• 미니배치 크기 (Batch Size, B) : 100장
• 1 에포크 당 이터레이션 횟수  : 60,000 / 100 = 600 회 (1 Epoch = 600 Iterations)
• 총 15 에포크 학습 시 총 갱신 횟수 : 15 x 600 = 9,000 회
```

---

## 2. PyTorch 4단계 이터레이션 학습 루프 메커니즘

1. **`optimizer.zero_grad()`**: 이전 배치의 기울기 누적치를 0으로 초기화 (PyTorch는 기본적으로 기울기를 더해나가는 구조이므로 필수 호출).
2. **`outputs = model(images)`**: 현재 미니배치 입력에 대한 순전파 예측 로짓(Logit) 산출.
3. **`loss = criterion(outputs, labels)`**: `CrossEntropyLoss`를 통해 손실 스칼라 계산.
4. **`loss.backward()`**: 연쇄 법칙을 따라 모든 가중치의 편미분 $\frac{\partial L}{\partial W}$ 역전파 계산.
5. **`optimizer.step()`**: 계산된 기울기와 학습률을 곱해 가중치 갱신 ($W \leftarrow W - \eta \cdot \nabla_W L$).

## 4. 전체 학습 및 무기울기 평가 파이썬 코드

```python
import torch
import torch.nn as nn
from torchvision import datasets, transforms

# 1. 하이퍼파라미터 및 데이터로더 설정
batch_size = 100
learning_rate = 0.1
num_epochs = 15

train_loader = torch.utils.data.DataLoader(
    datasets.MNIST('./data', train=True, download=True, transform=transforms.ToTensor()),
    batch_size=batch_size, shuffle=True
)
test_loader = torch.utils.data.DataLoader(
    datasets.MNIST('./data', train=False, transform=transforms.ToTensor()),
    batch_size=batch_size, shuffle=False
)

model = TwoLayerMLP()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=learning_rate)

# 2. 훈련 루프
for epoch in range(num_epochs):
    model.train()
    for images, labels in train_loader:
        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()

# 3. 테스트 데이터 평가 (무기울기 모드)
model.eval()
correct = 0
total = 0
with torch.no_grad():
    for images, labels in test_loader:
        outputs = model(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

print(f'Test Accuracy: {100 * correct / total:.2f}%')
```
