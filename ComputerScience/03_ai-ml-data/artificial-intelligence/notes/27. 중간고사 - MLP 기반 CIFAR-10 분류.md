중간고사 실습 프로젝트의 핵심 과제는 **합성곱(CNN)을 사용하지 않고 오직 완전연결 계층(MLP)만으로 CIFAR-10(10개 클래스, 32x32x3) 영상 분류 성능을 극대화**하는 것이다.

---

## 1. MLP의 구조적 한계와 성능 천장 (Accuracy Ceiling)

2D 영상 $32 \times 32 \times 3$을 1차원 벡터 $\mathbf{x} \in \mathbb{R}^{3072}$로 평탄화하면 픽셀 간의 인접성(Locality)이 파괴된다.

## 2. 9계층 심층 MLP 최적화 설계 아키텍처

$$3072 \to 2048 \to 1024 \to 512 \to 256 \to 128 \to 64 \to 32 \to 16 \to 10$$

```python
import torch.nn as nn

class MidtermMLP(nn.Module):
    def __init__(self, in_dim=3072, num_classes=10):
        super().__init__()
        layers = []
        dims = [3072, 2048, 1024, 512, 256, 128, 64, 32, 16, num_classes]
        
        for i in range(len(dims) - 1):
            layers.append(nn.Linear(dims[i], dims[i+1]))
            if i < len(dims) - 2:
                layers.append(nn.BatchNorm1d(dims[i+1]))
                layers.append(nn.LeakyReLU(0.1, inplace=True))
                layers.append(nn.Dropout(0.2))
                
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        x = x.view(x.size(0), -1) # 1D 평탄화
        return self.net(x)
```
