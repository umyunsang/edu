CIFAR-10 데이터셋은 $32 \times 32$ 해상도의 컬러 이미지 60,000장(훈련 50,000장, 테스트 10,000장)으로 구성되어 있으며, 10개 클래스(비행기, 자동차, 새, 고양이, 사슴, 개, 개구리, 말, 배, 트럭)를 분류하는 컴퓨터 비전의 대표 벤치마크이다.

---

## 1. CIFAR-10 데이터 전처리 및 강력한 데이터 증강

```python
import torchvision.transforms as transforms

# 과적합 방지를 위한 훈련용 데이터 증강 파이프라인
train_transform = transforms.Compose([
    transforms.RandomCrop(32, padding=4),       # 4픽셀 패딩 후 무작위 32x32 크롭
    transforms.RandomHorizontalFlip(p=0.5),     # 50% 확률로 좌우 반전
    transforms.ToTensor(),
    transforms.Normalize(
        mean=(0.4914, 0.4822, 0.4465),          # CIFAR-10 RGB 채널별 평균
        std=(0.2470, 0.2435, 0.2616)           # CIFAR-10 RGB 채널별 표준편차
    )
])

test_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616))
])
```

## 2. 모델별 CIFAR-10 테스트 정확도 벤치마크

| 모델 아키텍처 | 주요 기법 및 특징 | 테스트 정확도 (Test Acc) |
| :--- | :--- | :---: |
| **선형 로지스틱 회귀** | 픽셀 평탄화 단순 선형 분류 | ~38.5% |
| **다층 퍼셉트론 (3-Layer MLP)** | FC(3072 $\to$ 512 $\to$ 256 $\to$ 10) | ~52.3% |
| **단순 CNN (2 Conv + 2 FC)** | Conv(32, 64) + MaxPool | ~72.8% |
| **VGG-11 (BatchNorm 포함)** | 3x3 Conv 적층 + BN + Dropout | ~89.4% |
| **ResNet-18 (스킵 연결)** | 잔차 블록 + Data Augmentation | **~93.8%** |
