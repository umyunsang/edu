# MLP 이론: 다층 표현

> [!abstract] 핵심
> 다층 퍼셉트론은 여러 개의 층으로 구성된 퍼셉트론 모델이다. 입력층, 은닉층, 출력층을 거치며 각 노드는 가중합에 활성화 함수를 적용한다.

## 노드 하나에서 층 전체까지

한 노드는 입력 $x$와 가중치 $w$, 편향 $b$를 받아 $y=h(w_1x_1+\cdots+w_nx_n+b)$를 계산한다. 여러 노드를 한 층에 배치하면 행렬 연산으로 같은 구조를 표현할 수 있다.

```mermaid
flowchart LR
  A[입력층] --> B[가중합]
  B --> C[활성화 함수]
  C --> D[은닉층 표현]
  D --> E[출력층]
```

| 구성 요소 | 역할 | 층에서의 의미 |
| --- | --- | --- |
| 입력 | 관측 데이터 | 첫 계산의 재료 |
| 가중치 | 입력별 영향 | 연결마다 달라짐 |
| 편향 | 계산 기준 이동 | 노드마다 존재 |
| 활성화 함수 | 가중합 변환 | 노드 출력 생성 |
| 은닉층 | 중간 표현 | 다층 구조의 핵심 |

> [!note] 행렬 표현
> 여러 노드의 가중치와 입력을 행렬로 묶으면, 한 층의 계산을 $q=\sigma(W^Tx+b)$와 같이 표현할 수 있다.

<Tabs>
<Tab label="입력층">
입력층은 모델이 받아들이는 데이터를 각 연결로 전달한다.
</Tab>
<Tab label="은닉층">
은닉층은 가중합과 활성화 함수를 반복해 중간 표현을 만든다.
</Tab>
<Tab label="출력층">
출력층은 마지막 표현을 과제의 출력 형식으로 계산한다.
</Tab>
</Tabs>

<details>
<summary>MLP 구조를 읽는 질문</summary>

- 한 노드의 입력, 가중치, 편향은 무엇인가?
- 활성화 함수는 어느 시점에 적용되는가?
- 여러 노드의 계산은 어떻게 행렬 하나로 묶이는가?
</details>

> [!tip] 한 노드부터 확인하기
> 층 전체의 행렬식을 보기 전에 한 노드의 가중합과 활성화 계산을 적어 보면 구조를 더 쉽게 확장할 수 있다.

> [!warning] 층 수와 역할 구분
> 은닉층이 늘어나도 각 층의 입출력 크기와 활성화 함수가 맞물려야 한다. 연결 크기를 확인하지 않고 층만 추가하지 않는다.
