단일 퍼셉트론의 선형 분리 한계를 극복하기 위해 입력층과 출력층 사이에 하나 이상의 **은닉층(Hidden Layer)**을 배치한 구조를 **다층 퍼셉트론(Multi-Layer Perceptron, MLP)**이라 한다. 은닉층의 각 뉴런은 입력 공간을 비선형적으로 왜곡·매핑하여 복잡한 결정 경계를 형성한다.

---

## 1. 전결합 계층(Fully Connected Layer, FC Layer)의 수학적 정의

이전 층의 모든 노드가 다음 층의 모든 노드와 개별 가중치 $w_{i,j}$로 연결되는 계층이다.

```
[입력층 x: N_in 차원] ───► [ 가중치 행렬 W: N_in x N_out ] ───► [ 출력층 y: N_out 차원 ]
                            + 편향 벡터 b: N_out 차원
```

### 매개변수(Parameter) 개수 산출 공식
- **가중치(Weight) 개수**: $N_{\text{weights}} = N_{\text{in}} \times N_{\text{out}}$
- **편향(Bias) 개수**: $N_{\text{bias}} = N_{\text{out}}$
- **계층 전체 파라미터**: $N_{\text{total}} = (N_{\text{in}} + 1) \times N_{\text{out}}$

> [!NOTE]
> **예시**: 입력 노드 10개, 은닉층 1 노드 30개, 출력 노드 2개인 2층 신경망:
> 1. 은닉층 1: $10 \times 30 = 300$개 가중치, $30$개 편향 $\implies 330$개 파라미터
> 2. 출력층: $30 \times 2 = 60$개 가중치, $2$개 편향 $\implies 62$개 파라미터
> 3. 모델 전체 매개변수 총합: $330 + 62 = 392$개

## 2. 은닉층 및 출력층 활성화 함수 비교

### 1) 은닉층 활성화: ReLU vs Leaky ReLU
- **ReLU (Rectified Linear Unit)**:
  $$h(z) = \max(0, z) = \begin{cases} z & (z > 0) \\ 0 & (z \le 0) \end{cases}$$
  - 단순 $O(1)$ 임계 연산으로 고속 학습 가능.
  - 양수 영역에서 기울기가 1로 유지되어 **기울기 소실(Vanishing Gradient) 문제를 원천 차단**.
- **Leaky ReLU**:
  $$h(z) = \max(\alpha z, z) = \begin{cases} z & (z > 0) \\ \alpha z & (z \le 0) \end{cases} \quad (\alpha = 0.1 \text{ 또는 } 0.01)$$
  - 음수 영역에서 작은 기울기($\alpha$)를 흘려보내 뉴런이 영구히 비활성화되는 **Dying ReLU 현상 방지**.

### 2) 다중 클래스 분류 출력층: 소프트맥스(Softmax)
$C$개 클래스에 대해 각 노드의 로짓(Logit) $z_i$를 확률 $y_i \in [0, 1]$ ($\sum_{i=1}^C y_i = 1$)로 변환:
$$y_i = \frac{e^{z_i - \max(\mathbf{z})}}{\sum_{j=1}^C e^{z_j - \max(\mathbf{z})}}$$

## 4. 다중 클래스 교차 엔트로피 손실 (Cross Entropy Error, CEE)

정답 원-핫 레이블 $\mathbf{t} = [t_1, t_2, \dots, t_C]$와 모델 예측 확률 $\mathbf{y} = [y_1, y_2, \dots, y_C]$에 대하여:

$$\text{CEE}(\mathbf{y}, \mathbf{t}) = -\sum_{k=1}^C t_k \ln(y_k + \epsilon) \quad (\epsilon = 10^{-7})$$

- **정답이 3번 클래스($\mathbf{t} = [0, 0, 1, 0]$)이고 예측 확률이 $y_3 = 0.8$인 경우**:
  $$\text{CEE} = -1 \cdot \ln(0.8) \approx 0.2231$$
- **예측 확률이 $y_3 = 0.1$로 오답에 가까운 경우**:
  $$\text{CEE} = -1 \cdot \ln(0.1) \approx 2.3026 \quad (\text{손실이 10배 이상 급증})$$
