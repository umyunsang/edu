합성곱 계층을 통과할 때 특징 맵의 가로·세로 공간 해상도는 커널 크기, 스트라이드, 패딩에 의해 결정되며, 채널 수는 독립적인 특징 필터의 개수에 의해 확장된다.

---

## 1. 출력 공간 해상도 (Output Dimension) 산출 공식

입력 크기 $H \times W$, 커널 크기 $K_h \times K_w$, 패딩 $P$, 스트라이드 $S$에 대하여 출력 크기 $O_h \times O_w$는 다음과 같이 정의된다:

$$O_h = \left\lfloor \frac{H - K_h + 2P}{S} \right\rfloor + 1, \quad O_w = \left\lfloor \frac{W - K_w + 2P}{S} \right\rfloor + 1$$

## 2. 3D 다중 채널(Multi-channel) 합성곱 연산 및 파라미터 계산

- **입력 텐서**: $\mathbf{X} \in \mathbb{R}^{C_{\text{in}} \times H \times W}$ (예: RGB 컬러 영상은 $C_{\text{in}} = 3$)
- **가중치 필터 텐서**: $\mathbf{W} \in \mathbb{R}^{C_{\text{out}} \times C_{\text{in}} \times K_h \times K_w}$
- **편향 벡터**: $\mathbf{b} \in \mathbb{R}^{C_{\text{out}}}$
- **출력 텐서**: $\mathbf{Y} \in \mathbb{R}^{C_{\text{out}} \times O_h \times O_w}$

### 총 학습 파라미터 수 (Parameter Count) 공식
$$\text{Parameters} = C_{\text{out}} \times (C_{\text{in}} \times K_h \times K_w + 1)$$
*(여기서 $+1$은 필터당 편향(Bias) 파라미터)*

## 4. PyTorch `nn.Conv2d` 구현 및 텐서 연산 예제

```python
import torch
import torch.nn as nn

# 1. Conv2d 계층 선언 (in_channels=3, out_channels=64, kernel_size=3, padding=1, stride=1)
conv_layer = nn.Conv2d(
    in_channels=3,
    out_channels=64,
    kernel_size=3,
    stride=1,
    padding=1,
    bias=True
)

# 2. 임의의 미니배치 영상 텐서 입력: (Batch=4, Channels=3, Height=32, Width=32)
x = torch.randn(4, 3, 32, 32)
out = conv_layer(x)

print("출력 텐서 형상:", out.shape)  # torch.Size([4, 64, 32, 32])
print("학습 파라미터 수:", sum(p.numel() for p in conv_layer.parameters()))  # 1792
```
