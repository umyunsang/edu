- **데이터셋 구성**: 학습용(Train) 60,000장, 평가용(Test) 10,000장
- **픽셀 정규화**: 흑백 명암값 $[0, 255] \to [0.0, 1.0]$ (`transforms.ToTensor()`)

## 2. PyTorch 기반 신경망 클래스 선언 필수 규격

PyTorch에서 모든 사용자 정의 신경망은 `torch.nn.Module`을 상속하며 반드시 다음 두 메서드를 구현해야 한다:
1. **`__init__(self)`**: 학습 가능한 가중치 계층(`nn.Linear`, `nn.BatchNorm1d` 등) 및 활성화 함수를 인스턴스 멤버로 초기화.
2. **`forward(self, x)`**: 입력 텐서 $x$가 각 계층을 순차적으로 통과하는 순전파(Forward Pass) 연산 그래프 기술.

## 4. PyTorch 2-Layer MLP 클래스 완전 구현 코드

```python
import torch
import torch.nn as nn

class TwoLayerMLP(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=256, output_dim=10):
        super(TwoLayerMLP, self).__init__()
        # 1. 은닉층 선형 변환: 784 -> 256
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        # 2. 비선형 활성화 함수: ReLU
        self.relu = nn.ReLU()
        # 3. 출력층 선형 변환: 256 -> 10
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        # 2D 이미지 배치 (B, 1, 28, 28)를 1D 벡터 (B, 784)로 평탄화
        out = x.view(-1, 784)
        out = self.fc1(out)
        out = self.relu(out)
        out = self.fc2(out)
        return out  # CrossEntropyLoss에 직접 전달되는 로짓(Logit)
```
