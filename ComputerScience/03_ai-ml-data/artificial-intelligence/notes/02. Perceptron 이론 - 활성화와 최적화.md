단순 퍼셉트론의 계단 함수(Step Function)는 모든 지점에서 도함수가 0이므로 경사하강법으로 학습할 수 없다. 이를 해결하기 위해 출력을 $[0, 1]$ 구간의 연속 확률로 변환하는 **시그모이드(Sigmoid) 활성화 함수**와 **이진 교차 엔트로피(Binary Cross Entropy) 손실 함수**를 도입한다.

---

## 1. 활성화 함수: 계단 함수 vs 시그모이드 함수

```
[계단 함수 (Step Function)]
z = w^T x + b
y = 1 if z > 0 else 0
-> 미분값 dy/dz = 0 (z != 0), z=0에서 불연속
-> 기울기 기반 최적화(Gradient-based Optimization) 불가능

[시그모이드 함수 (Sigmoid / Logistic Function)]
σ(z) = 1 / (1 + e^-z)
-> 모든 실수 z에 대해 매끄러운 S자 곡선 (0 < σ(z) < 1)
-> 도함수: dσ/dz = σ(z)(1 - σ(z))
-> 양성 클래스(y=1)에 속할 확률 P(Y=1|X)로 자연스럽게 해석 가능
```

---

## 2. 이진 교차 엔트로피 (Binary Cross Entropy, BCE) 손실 유도

데이터셋 $\{(\mathbf{x}_i, y_i)\}_{i=1}^N$ ($y_i \in \{0, 1\}$)에 대하여 모델의 예측 확률을 $\hat{y}_i = \sigma(\mathbf{w}^T \mathbf{x}_i + b)$라 할 때:

### 1) 베르누이 우도 함수 (Likelihood)
$$P(\mathbf{y} \mid X, \mathbf{w}, b) = \prod_{i=1}^N \hat{y}_i^{y_i} (1 - \hat{y}_i)^{1 - y_i}$$

### 2) 음의 로그 우도(NLL) 및 최종 손실 함수 $L(\mathbf{w}, b)$
$$L(\mathbf{w}, b) = -\frac{1}{N} \ln P(\mathbf{y} \mid X, \mathbf{w}, b) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln \hat{y}_i + (1 - y_i) \ln(1 - \hat{y}_i) \right]$$

- **정답 $y_i = 1$일 때**: 손실은 $-\ln(\hat{y}_i)$이 되며, $\hat{y}_i \to 1$이면 손실 0, $\hat{y}_i \to 0$이면 손실 $\infty$로 폭증.
- **정답 $y_i = 0$일 때**: 손실은 $-\ln(1 - \hat{y}_i)$이 되며, $\hat{y}_i \to 0$이면 손실 0, $\hat{y}_i \to 1$이면 손실 $\infty$로 폭증.

---

## 3. 손실 함수의 가중치 편미분 $\frac{\partial L}{\partial \mathbf{w}}$ 단계별 유도

합성함수 연쇄 법칙(Chain Rule)에 의해:
$$\frac{\partial L}{\partial w_j} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w_j}$$

1. $\frac{\partial L_i}{\partial \hat{y}_i} = -\frac{y_i}{\hat{y}_i} + \frac{1 - y_i}{1 - \hat{y}_i} = \frac{\hat{y}_i - y_i}{\hat{y}_i(1 - \hat{y}_i)}$
2. $\frac{\partial \hat{y}_i}{\partial z_i} = \hat{y}_i(1 - \hat{y}_i)$
3. $\frac{\partial z_i}{\partial w_j} = x_{i,j}$

따라서 $\hat{y}_i(1 - \hat{y}_i)$ 항이 깔끔하게 상쇄되어 최종 기울기는 다음과 같다:
$$\frac{\partial L}{\partial w_j} = \frac{1}{N} \sum_{i=1}^N (\hat{y}_i - y_i) x_{i,j}$$
$$\frac{\partial L}{\partial b} = \frac{1}{N} \sum_{i=1}^N (\hat{y}_i - y_i)$$

## 5. 경사하강법 파이썬 구현 예제

```python
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def binary_cross_entropy_loss(y_true, y_pred):
    eps = 1e-15
    y_pred = np.clip(y_pred, eps, 1 - eps)
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

# 로지스틱 회귀 단일 스텝 갱신
def train_step(X, y, W, b, lr=0.1):
    N = len(y)
    # 순전파
    z = np.dot(X, W) + b
    y_pred = sigmoid(z)
    loss = binary_cross_entropy_loss(y, y_pred)

    # 역전파 기울기
    grad_W = (1.0 / N) * np.dot(X.T, (y_pred - y))
    grad_b = (1.0 / N) * np.sum(y_pred - y)

    # 매개변수 갱신
    W -= lr * grad_W
    b -= lr * grad_b
    return W, b, loss
```
