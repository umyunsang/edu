과적합을 억제하고 일반화 오차를 줄이기 위해 목적 함수에 가중치 복잡도에 대한 페널티를 부과하는 **가중치 규제(Weight Regularization)**, 무작위 뉴런 비활성화 기법인 **드롭아웃(Dropout)**, 검증 손실 기반의 **조기 종료(Early Stopping)**를 적용한다.

---

## 1. $L_1$ 규제 vs $L_2$ 규제의 수학적 및 기하학적 비교

목적 함수: $\tilde{L}(\mathbf{w}) = L(\mathbf{w}) + \lambda \Omega(\mathbf{w}) \quad (\lambda \ge 0)$

| 구분 | $L_1$ 정규화 (Lasso) | $L_2$ 정규화 (Ridge / Weight Decay) |
| :--- | :--- | :--- |
| **페널티 항 $\Omega(\mathbf{w})$** | $\sum_{i=1}^n \vert w_i\vert$ (절댓값 합) | $\frac{1}{2} \sum_{i=1}^n w_i^2$ (제곱합) |
| **가중치 갱신식** | $w \leftarrow w - \eta \frac{\partial L}{\partial w} - \eta \lambda \text{sgn}(w)$ | $w \leftarrow (1 - \eta \lambda) w - \eta \frac{\partial L}{\partial w}$ |
| **제약 영역 형상** | **마름모 (Diamond, 모서리에 접함)** | **원형 (Circle, 매끄러운 구형)** |
| **핵심 효과** | 덜 중요한 가중치를 완전히 0으로 만들어 **희소성(Sparsity)** 확보 | 모든 가중치를 골고루 0 근처로 축소(**Weight Shrinkage**) |

---

## 2. 드롭아웃 (Dropout)과 조기 종료 (Early Stopping)

### 1) 드롭아웃 (Dropout, Srivastava et al., 2014)
- **학습 시**: 각 은닉 뉴런을 확률 $p$ (통상 $0.5$)로 무작위 비활성화.
- **효과**: 뉴런 간의 상호 동조화(Co-adaptation)를 파괴하고 매 배치마다 서로 다른 하위 신경망을 학습시켜 **지수 함수적 개수의 신경망 앙상블(Ensemble) 효과**를 창출.
- **평가 시**: 모든 뉴런을 활성화하며 출력을 $1 - p$로 스케일링하거나, 학습 시 역 드롭아웃(Inverted Dropout: $\frac{1}{1-p}$)을 적용.

### 2) 조기 종료 (Early Stopping)
검증 손실(Validation Loss)이 $P$회(Patience) 연속으로 감소하지 않고 상승하면 학습을 강제 중단하고 가장 낮은 검증 손실을 기록했던 최적 체크포인트 모델을 복원한다.

## 4. PyTorch 드롭아웃 및 Weight Decay 구현 코드

```python
import torch.nn as nn
import torch.optim as optim

class RegularizedMLP(nn.Module):
    def __init__(self):
        super(RegularizedMLP, self).__init__()
        self.fc1 = nn.Linear(784, 512)
        self.relu = nn.ReLU()
        # 50% 확률로 뉴런 무작위 드롭아웃
        self.dropout = nn.Dropout(p=0.5)
        self.fc2 = nn.Linear(512, 10)

    def forward(self, x):
        out = x.view(-1, 784)
        out = self.dropout(self.relu(self.fc1(out)))
        out = self.fc2(out)
        return out

model = RegularizedMLP()
# L2 가중치 감쇠(weight_decay = 1e-4) 적용
optimizer = optim.SGD(model.parameters(), lr=0.1, weight_decay=1e-4)
```
