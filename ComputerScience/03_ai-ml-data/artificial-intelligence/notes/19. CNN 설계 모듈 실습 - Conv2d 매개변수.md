PyTorch의 `nn.Conv2d`는 2차원 공간 상에서 가중치 커널을 슬라이딩하여 특징 맵을 생성하는 가장 핵심적인 모듈이다. 입력 텐서의 형태 $(N, C_{\text{in}}, H_{\text{in}}, W_{\text{in}})$로부터 출력 텐서의 형태 $(N, C_{\text{out}}, H_{\text{out}}, W_{\text{out}})$를 결정짓는 파라미터 관계를 실습한다.

## 2. 텐서 차원 및 파라미터 계산 공식

$$H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2P - d(K - 1) - 1}{S} \right\rfloor + 1$$
$$\text{Weight Parameters} = C_{\text{out}} \times C_{\text{in}} \times K_h \times K_w$$
$$\text{Bias Parameters} = C_{\text{out}} \quad (\text{bias=True 시})$$

## 4. PyTorch 실습 코드

```python
import torch
import torch.nn as nn

# CIFAR-10 컬러 이미지 (3x32x32) 대응 합성곱 계층
conv1 = nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, stride=1, padding=1)
pool1 = nn.MaxPool2d(kernel_size=2, stride=2)

x = torch.randn(8, 3, 32, 32)
h1 = conv1(x)
p1 = pool1(h1)

print("Conv1 후 형상:", h1.shape)   # torch.Size([8, 64, 32, 32])
print("MaxPool 후 형상:", p1.shape)  # torch.Size([8, 64, 16, 16])
```
