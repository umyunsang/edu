기본 SGD는 한 방향으로는 가파르고 다른 방향으로는 완만한 협곡(Ravine) 지형에서 가파른 축을 따라 심하게 진동하며 진행이 정체된다. **모멘텀(Momentum)** 기법은 물리학의 운동량 법칙을 도입하여 이전 이동 방향의 **관성(Inertia)**을 누적함으로써 지그재그 진동을 상쇄하고 전진 속도를 극대화한다.

### 수학적 갱신 공식

$$\mathbf{v}_t = \gamma \mathbf{v}_{t-1} + \eta \nabla_{\mathbf{W}} L(\mathbf{W}_t) \quad (\gamma \approx 0.9)$$
$$\mathbf{W}_{t+1} = \mathbf{W}_t - \mathbf{v}_t$$

- **$\mathbf{v}_t$**: 현재 속도 벡터 (Velocity)
- **$\gamma$**: 관성 감쇠 계수(Momentum Decay Coefficient, 통상 0.9)로 공기 저항이나 마찰력의 역할을 수행.
- **$\eta \nabla L$**: 현재 위치에서 가해지는 외력(Force).

## 2. Nesterov Accelerated Gradient (NAG)의 개선점

기본 모멘텀은 관성 때문에 최적점을 지나쳐 크게 튕겨 나가는 오버슈팅(Overshooting)이 발생할 수 있다. NAG는 **현재의 관성으로 먼저 한 걸음 이동한 미래 지점**에서 기울기를 측정하여 제동을 건다:

$$\mathbf{v}_t = \gamma \mathbf{v}_{t-1} + \eta \nabla_{\mathbf{W}} L(\mathbf{W}_t - \gamma \mathbf{v}_{t-1})$$
$$\mathbf{W}_{t+1} = \mathbf{W}_t - \mathbf{v}_t$$

(function() {
  var gamma = 0.9;

  function simulate() {
    path = [{ x: -6.0, y: 2.0 }];
    var x = -6.0, y = 2.0;

      el.setAttribute('stroke', 'var(--border)');

    });

    // 궤적 선

## 4. PyTorch Momentum Optimizer 적용 코드

```python
import torch.optim as optim

# PyTorch 내장 모멘텀 SGD 옵티마이저 선언
optimizer = optim.SGD(
    model.parameters(),
    lr=0.01,
    momentum=0.9,     # 관성 계수 gamma = 0.9
    nesterov=True      # Nesterov 가속 경사 활성화
)
```
