단일 퍼셉트론은 2차원 공간을 하나의 직선($w_1 x_1 + w_2 x_2 + b = 0$)으로 양분하는 선형 판별기다. 따라서 AND, OR, NAND 논리 게이트는 단일 퍼셉트론으로 구현할 수 있으나, 비선형 분리가 요구되는 XOR 게이트는 **NAND + OR $\to$ AND 2층 다층 퍼셉트론(MLP)**으로 구성해야 한다.

---

## 1. 4대 논리 게이트의 진리표와 가중치·편향 매개변수 설계

가중합 $s = w_1 x_1 + w_2 x_2 + b$에 계단 함수 활성화 $y = \begin{cases} 1 & (s > 0) \\ 0 & (s \le 0) \end{cases}$를 적용한다.

| 게이트 (Gate) | $(0,0)$ 출력 ($s$) | $(1,0)$ 출력 ($s$) | $(0,1)$ 출력 ($s$) | $(1,1)$ 출력 ($s$) | 가중치 $w_1, w_2$ | 편향 $b$ |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **AND Gate** | $0 \ (-0.7)$ | $0 \ (-0.2)$ | $0 \ (-0.2)$ | $\mathbf{1 \ (+0.3)}$ | $w_1=0.5, w_2=0.5$ | $b=-0.7$ |
| **OR Gate** | $0 \ (-0.2)$ | $\mathbf{1 \ (+0.3)}$ | $\mathbf{1 \ (+0.3)}$ | $\mathbf{1 \ (+0.8)}$ | $w_1=0.5, w_2=0.5$ | $b=-0.2$ |
| **NAND Gate** | $\mathbf{1 \ (+0.7)}$ | $\mathbf{1 \ (+0.2)}$ | $\mathbf{1 \ (+0.2)}$ | $0 \ (-0.3)$ | $w_1=-0.5, w_2=-0.5$ | $b=+0.7$ |
| **XOR Gate** | $0$ | $\mathbf{1}$ | $\mathbf{1}$ | $0$ | **단일 층 구현 불가 (비선형 분리)** | **2층 MLP 필요** |

---

## 2. XOR 다층 퍼셉트론 결합 파이프라인

$$s_1 = \text{NAND}(x_1, x_2), \quad s_2 = \text{OR}(x_1, x_2)$$
$$y = \text{AND}(s_1, s_2) = \text{XOR}(x_1, x_2)$$

## 4. Python / NumPy 기반 논리 게이트 및 XOR 구현

```python
import numpy as np

def AND(x1, x2):
    x = np.array([x1, x2])
    w = np.array([0.5, 0.5])
    b = -0.7
    return 1 if np.sum(w * x) + b > 0 else 0

def OR(x1, x2):
    x = np.array([x1, x2])
    w = np.array([0.5, 0.5])
    b = -0.2
    return 1 if np.sum(w * x) + b > 0 else 0

def NAND(x1, x2):
    x = np.array([x1, x2])
    w = np.array([-0.5, -0.5])
    b = 0.7
    return 1 if np.sum(w * x) + b > 0 else 0

def XOR(x1, x2):
    s1 = NAND(x1, x2)
    s2 = OR(x1, x2)
    return AND(s1, s2)
```
