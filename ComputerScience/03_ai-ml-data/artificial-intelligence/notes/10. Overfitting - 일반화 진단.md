신경망 학습의 궁극적인 목표는 훈련 데이터에 대한 단순 암기가 아니라, 본 적 없는 새로운 데이터(Unseen Test Data)에 대해 정확히 예측하는 **일반화 능력(Generalization Ability)**을 확보하는 것이다.

---

## 1. 과소적합 vs 적합 vs 과적합의 3대 상태 비교

```
[1. 과소적합 (Underfitting)]     [2. 최적 적합 (Good Fit)]        [3. 과적합 (Overfitting)]
• 높은 편향 (High Bias)        • 적절한 편향 & 분산 균형        • 높은 분산 (High Variance)
• 모델 용량이 데이터 복잡도에   • 데이터의 기저 패턴(Pattern)을   • 데이터 내의 무작위 잡음(Noise)까지
  미치지 못해 훈련 손실도 큼      정확히 포착하여 일반화 성공       전부 암기하여 검증 손실 발산
```

## 2. 편향-분산 분해 (Bias-Variance Decomposition)의 수학적 유도

목표 함수 $y = f(x) + \epsilon$ ($\mathbb{E}[\epsilon]=0, \text{Var}(\epsilon)=\sigma^2$)와 추정 모델 $\hat{f}(x)$에 대하여 평균 제곱 오차(MSE)의 기댓값은 다음과 같이 3개의 독립된 항으로 분해된다:

$$\mathbb{E}\left[ (y - \hat{f}(x))^2 \right] = \text{Bias}(\hat{f}(x))^2 + \text{Var}(\hat{f}(x)) + \sigma^2$$

1. **편향의 제곱 ($\text{Bias}^2 = (\mathbb{E}[\hat{f}(x)] - f(x))^2$)**: 모델의 잘못된 단순화 가정으로 인한 오차.
2. **분산 ($\text{Var} = \mathbb{E}[(\hat{f}(x) - \mathbb{E}[\hat{f}(x)])^2]$)**: 특정 훈련 세트의 변동에 모델이 민감하게 흔들리는 정도.
3. **기약 오차 ($\sigma^2$, Irreducible Error)**: 데이터 자체에 내재된 본질적 잡음 한계.

## 4. 과적합 발생의 3대 근본 원인과 진단 지표

1. **모델 용량(Capacity) 과다**: 파라미터 수 $P$가 훈련 샘플 수 $N$에 비해 너무 큼 ($P \gg N$).
2. **학습 데이터 부족 및 다양성 결여**: 특정 조건의 데이터만 존재하여 편향된 상관관계를 학습.
3. **과도한 에포크 학습**: 검증 손실이 증가하기 시작한 이후에도 훈련을 멈추지 않고 계속 진행함.
