인공신경망의 모태가 된 **퍼셉트론(Perceptron)**은 생물학적 뇌의 신경세포(Neuron) 동작 메커니즘을 수학적으로 모델링하여, 다수의 입력 신호에 가중치를 부여하고 편향과 결합하여 이진 결정을 내리는 기초 선형 분류기다.

---

## 1. 인공지능의 역사적 패러다임: 기호주의 vs 연결주의

```
[기호주의 인공지능 (Symbolism AI)]
• 대표 학자: 마빈 민스키 (Marvin Minsky)
• 핵심 철학: 인간의 이성과 지식을 컴퓨터가 처리 가능한 명시적 규칙(Rule)과 기호(Symbol) 논리로 정의
• 한계: 예외 처리가 무수히 많거나 데이터 패턴이 복잡한 시각·음성 인식 문제에서 지식 병목(Knowledge Bottleneck) 직면

[연결주의 인공지능 (Connectionism AI)]
• 대표 학자: 프랑크 로젠블랫 (Frank Rosenblatt)
• 핵심 철학: 인간 두뇌의 신경망(Neural Network) 구조를 모방하여 데이터로부터 스스로 가중치를 학습
• 1958년 퍼셉트론 발표 -> 1980년대 오차역전파(Backpropagation) -> 2010년대 대규모 빅데이터와 GPU 병렬 연산으로 딥러닝 혁명 달성
```

## 2. 생물학적 뉴런과 인공 퍼셉트론의 구조적 매핑

| 생물학적 신경세포 (Biological Neuron) | 인공 퍼셉트론 구성요소 (Artificial Perceptron) | 수학적 기호 및 역할 |
| :--- | :--- | :--- |
| **수상돌기 (Dendrite)** | 입력 노드 (Input Features) | $x_1, x_2, \dots, x_n$ (입력 데이터) |
| **시냅스 연결 강도 (Synaptic Weight)** | 가중치 (Weights) | $w_1, w_2, \dots, w_n$ (각 입력의 중요도 계수) |
| **세포체 전위 축적 (Cell Body / Soma)** | 가중합 및 편향 (Weighted Sum + Bias) | $z = \sum_{i=1}^n w_i x_i + b$ (총 입력 신호) |
| **활동전위 역치 (Action Potential Threshold)** | 편향 (Bias) | $b = -\theta$ (활성화 민감도 기준값) |
| **축삭돌기 발화 (Axon / Firing)** | 활성화 함수 및 출력 (Activation & Output) | $y = f(z)$ (최종 출력 결정) |

## 3. 퍼셉트론의 응용 분야: 회귀(Regression) vs 분류(Classification)

### 1) 회귀 (Regression): 연속적인 실수값 예측
- **공부 시간($x$) 기반 시험 점수($y$) 예측**:
  $$y = w_1 x + b$$
- **다변량 주택 가격 예측** (넓이 $x_1$, 교통 편리성 $x_2$, 세대수 $x_3$, 층수 $x_4$):
  $$y = w_1 x_1 + w_2 x_2 + w_3 x_3 + w_4 x_4 + b = \mathbf{w}^T \mathbf{x} + b$$

### 2) 분류 (Classification): 이산적인 클래스 레이블 결정
- **중간고사 점수($x_1$)와 기말고사 점수($x_2$) 기반 Pass($y=1$) / Non-pass($y=0$) 판별**:
  $$y = \begin{cases} 1 & (w_1 x_1 + w_2 x_2 + b > 0) \quad [\text{Pass}] \\ 0 & (w_1 x_1 + w_2 x_2 + b \le 0) \quad [\text{Non-pass}] \end{cases}$$
- **결정 초평면 (Decision Boundary)**:
  2차원 평면 상에서 합격과 불합격을 나누는 경계선은 $w_1 x_1 + w_2 x_2 + b = 0$이라는 1차 직선 방정식이 된다.

## 5. 퍼셉트론 학습 규칙 (Perceptron Learning Rule)

오분류된 데이터 포인트 $(\mathbf{x}^{(k)}, y^{(k)})$에 대해 가중치와 편향을 반복 갱신하는 델타 규칙:

$$w_i \leftarrow w_i + \eta (y^{(k)} - \hat{y}^{(k)}) x_i^{(k)}$$
$$b \leftarrow b + \eta (y^{(k)} - \hat{y}^{(k)})$$

- 정답 $y=1$인데 예측 $\hat{y}=0$인 경우 ($y - \hat{y} = +1$): 가중치를 입력 벡터 방향으로 증가시켜 $z$를 높임.
- 정답 $y=0$인데 예측 $\hat{y}=1$인 경우 ($y - \hat{y} = -1$): 가중치를 입력 벡터 반대 방향으로 감소시켜 $z$를 낮춤.
- 데이터가 선형 분리 가능(Linearly Separable)하다면, **퍼셉트론 수렴 정리(Perceptron Convergence Theorem)**에 의해 유한한 스텝 내에 오차가 0인 결정 경계를 반드시 찾아낸다.
