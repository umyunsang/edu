> [!abstract] 핵심
> 데이터 확보·증식, 조기 종료, L1·L2 정규화는 학습 데이터에만 과도하게 맞는 현상을 완화하기 위한 서로 다른 접근이다.

## 문제를 학습 흐름으로 바꾸기

데이터 증식은 회전·이동·자르기·대칭처럼 입력 이미지를 인위적으로 확장한다. 조기 종료는 반복 학습 중 특정 시점에서 멈추는 방식이고, L1·L2 정규화는 큰 파라미터에 제약을 주는 방식이다. 세 방법은 서로 대체되는 단일 버튼이 아니라, 데이터·모델·학습 과정을 다르게 다룬다.

```mermaid
flowchart LR
    A["입력 또는 목표"] --> B["표현과 준비"]
    B --> C["모델 또는 규칙"]
    C --> D["학습 또는 생성"]
    D --> E["검증과 해석"]
```

| 관점 | 확인할 질문 | 학습할 때의 점검 |
| --- | --- | --- |
| 데이터 증식 | 입력 변형으로 학습 사례 확장 | 라벨 의미가 유지되는 변형인지 본다 |
| 조기 종료 | 특정 반복 지점에서 학습 중단 | 검증 지표의 기준을 정한다 |
| L1·L2 정규화 | 파라미터 크기에 제약 | 강도와 손실 항의 변화를 기록한다 |

> [!note] 흐름
> 먼저 검증 지표로 멈출 기준을 정하고, 증식 규칙과 정규화 강도를 기록한다. 한 방법의 효과를 판단할 때는 다른 조건을 고정하고 같은 검증 자료에서 비교한다.

## 관점을 나누어 보기

<Tabs>
<Tab label="개념">

데이터 증식은 새 관측을 수집하는 것과는 다르지만 학습 입력의 변형을 늘린다. 변형이 과제의 라벨을 바꾸면 안 된다.

</Tab>
<Tab label="실행">

조기 종료는 학습이 충분히 진행됐는지와 과적합 신호를 같이 본다. 멈출 시점은 검증 지표로 정한다.

</Tab>
<Tab label="검증">

규제 강도가 커질수록 모델의 자유도가 줄 수 있다. 학습·검증 성능을 동시에 보며 강도를 고른다.

</Tab>
</Tabs>
