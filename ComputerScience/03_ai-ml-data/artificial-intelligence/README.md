1. 퍼셉트론과 MLP로 표현의 기본 단위를 익힙니다.
2. 역전파·최적화·일반화 진단으로 학습 동작을 연결합니다.
3. CNN의 합성곱·공간 크기·설계 모듈을 거쳐 분류 실습으로 적용합니다.
4. 필기 과제 자료는 텍스트 추출 한계를 먼저 확인한 뒤 원본을 별도로 검토합니다.
