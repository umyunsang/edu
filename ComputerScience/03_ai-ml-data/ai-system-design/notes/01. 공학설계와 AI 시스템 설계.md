**공학설계(Engineering Design)**는 인간의 필요(Needs)와 현실의 제약 조건(비용, 시간, 안전성, 윤리)을 만족시키기 위해 수학, 자연과학, 공학 지식을 체계적으로 적용하여 새로운 시스템이나 프로세스를 창출하는 의사결정 과정이다.

## 2. CDIO 공학 설계 사이클과 5대 핵심 축

1. **Conceive (개념 구상)**: 고객 요구 파악, 시장 분석, 비즈니스 및 공학적 문제 정의.
2. **Design (설계)**: 시스템 아키텍처, 데이터 스키마, 모델 선정, 인터페이스 및 UI/UX 설계.
3. **Implement (구현)**: 데이터 전처리, 모델 훈련, 검증, 백엔드 API 및 프론트엔드 연동.
4. **Operate (운영)**: 클라우드 배포, A/B 테스팅, 데이터 드리프트 모니터링, MLOps 재학습.

(function() {
