## 2. KIPRIS 선행기술조사(Prior Art Search) 3단계 프로세스

1. **키워드 및 IPC/CPC 특허 분류 코드 도출**: 인공지능(G06N), 데이터 처리(G06F).
2. **불리언(Boolean) 검색식 구성**: `((인공지능 OR 머신러닝) AND (음성인식) AND (잡음제거))`.
3. **청구항(Claim) 대비 분석**: 구성요소 완비의 법칙(All Elements Rule)을 적용하여 침해 여부(FTO) 및 회피 설계(Design Around) 검토.

## 3. 인터랙티브 AI 스타트업 수익성 & 손익분기점(BEP) 시뮬레이터

월간 유료 구독자 수(100 ~ 5,000명)를 슬라이더로 조절하면 월간 구독 매출, GPU 인프라 비용 및 순이익 손익분기점(Break-Even Point)이 실시간으로 계산된다.

<script>
(function() {
  var sSub = document.getElementById('bm-sub-slider');
  var subVal = document.getElementById('bm-sub-val');
  var revTxt = document.getElementById('bm-rev-txt');
  var costTxt = document.getElementById('bm-cost-txt');
  var profTxt = document.getElementById('bm-prof-txt');

  function render() {
    var subs = parseInt(sSub.value, 10);
    subVal.textContent = subs.toLocaleString() + ' 명';

    // 구독료: 인당 29,000원
    var rev = subs * 0.0029; // 백만원 단위
    // 고정비 500만원 + 가변 GPU 비용 (인당 7,000원)
    var cost = 5.0 + subs * 0.0007;
    var profit = rev - cost;

    revTxt.textContent = Math.round(rev * 10) / 10 + ' 만원';
    costTxt.textContent = Math.round(cost * 10) / 10 + ' 만원';

    if (profit >= 0) {
      profTxt.textContent = '+ ' + Math.round(profit * 10) / 10 + ' 만원';
      profTxt.style.color = 'var(--chart-2)';
    } else {
      profTxt.textContent = '- ' + Math.abs(Math.round(profit * 10) / 10) + ' 만원';
      profTxt.style.color = 'var(--destructive)';
    }
  }

  sSub.addEventListener('input', render);
  render();
})();
</script>
