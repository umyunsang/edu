자연어 텍스트를 LLM에 입력하기 위해서는 \*\*토큰화(Tokenization)\*\*를 거쳐 정수 ID로 변환해야 하며, 시맨틱 검색을 위해서는 고차원 밀집 벡터로 변환하는 \*\*임베딩(Embedding)\*\*과 고속 검색 엔진인 **Faiss**가 필수적이다.

---

## 1. 벡터 공간 유사도 및 Faiss 인덱싱의 수학적 모델링

### 1) L2 정규화와 코사인 유사도(Cosine Similarity) 내적 동치성

임베딩 벡터 $\mathbf{v} \in \mathbb{R}^d$에 대한 $L_2$ 단위 벡터 정규화는 다음과 같이 정의된다:

$$\hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|_2} = \frac{\mathbf{v}}{\sqrt{\sum_{i=1}^d v_i^2}}$$

단위 구(Unit Sphere) 표면으로 정규화된 질의 벡터 $\hat{\mathbf{q}}$와 문서 벡터 $\hat{\mathbf{d}}$에 대해, 코사인 유사도는 단순 내적(Inner Product) 연산과 완벽히 동치이다:

$$\text{Sim}_{\text{cos}}(\mathbf{q}, \mathbf{d}) = \frac{\mathbf{q} \cdot \mathbf{d}}{\|\mathbf{q}\|_2 \|\mathbf{d}\|_2} = \hat{\mathbf{q}}^T \hat{\mathbf{d}} = \text{IP}(\hat{\mathbf{q}}, \hat{\mathbf{d}})$$

또한 유클리드 거리(L2 Distance)와의 관계는 $D\_{L_2}(\hat{\mathbf{q}}, \hat{\mathbf{d}})^2 = 2 - 2(\hat{\mathbf{q}}^T \hat{\mathbf{d}})$로 직결된다.

### 2) Faiss $k$-최근접 이웃 ($k$-NN) 최적화 목적 함수

전체 문서 데이터베이스 $\mathcal{D} = \{\mathbf{d}\_1, \dots, \mathbf{d}\_N\}$에서 질의 $\mathbf{q}$와 가장 유사한 상위 $k$개의 문서 부분집합 $S_k^*$를 탐색하는 최적화 문제는 다음과 같다:

$$S_k^* = \arg\max_{S \subseteq \mathcal{D}, |S|=k} \sum_{\mathbf{d}_i \in S} \hat{\mathbf{q}}^T \hat{\mathbf{d}}_i$$

## 2. tiktoken 인코딩 모델 및 주요 함수

\| 모델 계열 | tiktoken 인코딩 명칭 | 어휘집 크기 ($|V|$) | 주력 사용 모델 |
\| :--- | :--- | :--- | :--- |
\| `gpt-4o`, `gpt-4o-mini` | `o200k_base` | 200,000 | 차세대 옴니 멀티모달 모델 (비영어권 토큰 압축률 대폭 향상) |
\| `gpt-4`, `gpt-3.5-turbo` | `cl100k_base` | 100,000 | 표준 챗 완료 모델 |
\| `text-davinci-003` | `p50k_base` | 50,000 | 레거시 GPT-3 완성 모델 |

```python
import tiktoken

# 모델에 맞는 인코딩 로드
enc = tiktoken.encoding_for_model("gpt-4o-mini")

text = "인공지능과 거대언어모델(LLM)을 학습합니다."
token_ids = enc.encode(text)

print(f"토큰 ID 리스트: {token_ids}")
print(f"총 토큰 개수: {len(token_ids)}")
print(f"디코딩 복원 텍스트: {enc.decode(token_ids)}")
```

## 3. OpenAI Embedding 생성 및 Faiss 벡터 유사도 검색 실습

```python
import os
import numpy as np
import faiss
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 1. 말뭉치(Corpus) 준비
documents = [
    "파이썬은 데이터 과학과 인공지능에 널리 사용되는 프로그래밍 언어입니다.",
    "쿠버네티스는 클라우드 네이티브 환경에서 컨테이너를 관리합니다.",
    "양자 컴퓨팅은 중첩과 얽힘을 이용해 특정 연산을 지수적으로 가속합니다.",
    "트랜스포머의 셀프 어텐션 메커니즘은 자연어 처리의 표준입니다."
]

# 2. 텍스트 임베딩 생성 (text-embedding-3-small: 1536차원)
emb_response = client.embeddings.create(
    model="text-embedding-3-small",
    input=documents
)

doc_vectors = np.array([e.embedding for e in emb_response.data], dtype=np.float32)
# 코사인 유사도 검색을 위한 L2 정규화
faiss.normalize_L2(doc_vectors)

# 3. Faiss 내적(IndexFlatIP) 인덱스 생성 및 벡터 등록
dimension = doc_vectors.shape[1] # 1536
index = faiss.IndexFlatIP(dimension)
index.add(doc_vectors)
print(f"Faiss 인덱스에 등록된 문서 수: {index.ntotal}")

# 4. 사용자 질의(Query) 검색
query = "자연어 처리와 어텐션 모델의 원리"
query_res = client.embeddings.create(model="text-embedding-3-small", input=query)
query_vec = np.array([query_res.data[0].embedding], dtype=np.float32)
faiss.normalize_L2(query_vec)

# 상위 k=2개 검색
k = 2
distances, indices = index.search(query_vec, k)

print(f"\n=== 검색 질의: '{query}' ===")
for rank, (idx, dist) in enumerate(zip(indices[0], distances[0])):
    print(f"[{rank+1}위] 유사도(Cosine): {dist:.4f} | 문서: {documents[idx]}")
```

<script>
(function() {
  var sAng = document.getElementById('faiss-ang-slider');
  var vAng = document.getElementById('faiss-ang-val');
  var svg = document.getElementById('faiss-svg');
  var rankBox = document.getElementById('faiss-rank-box');

  var docs = [
    { id: 1, name: '문서 1 (NLP/트랜스포머)', deg: 40, color: 'var(--chart-1)' },
    { id: 2, name: '문서 2 (파이썬/데이터)', deg: 75, color: 'var(--chart-2)' },
    { id: 3, name: '문서 3 (클라우드/k8s)', deg: 160, color: 'var(--chart-3)' },

  ];

  function render() {
    var qDeg = parseFloat(sAng.value);
    vAng.textContent = qDeg + '°';

    var cx = 180, cy = 100, r = 80;
    var qRad = (qDeg * Math.PI) / 180;
    var qx = cx + r * Math.cos(qRad);
    var qy = cy - r * Math.sin(qRad);

    var htmlSvg = '<circle cx="' + cx + '" cy="' + cy + '" r="' + r + '" fill="none" stroke="var(--border)" stroke-dasharray="3,3"/>' +
      '<line x1="20" y1="' + cy + '" x2="340" y2="' + cy + '" stroke="var(--border)"/>' +
      '<line x1="' + cx + '" y1="10" x2="' + cx + '" y2="190" stroke="var(--border)"/>' +

      '<circle cx="' + qx.toFixed(1) + '" cy="' + qy.toFixed(1) + '" r="5" fill="var(--primary)"/>' +
      '<text x="' + (qx + 8).toFixed(1) + '" y="' + (qy + 4).toFixed(1) + '" font-size="10" font-weight="800" fill="var(--primary)">Query</text>';

    var scored = docs.map(function(d) {
      var dRad = (d.deg * Math.PI) / 180;
      var dx = cx + r * Math.cos(dRad);
      var dy = cy - r * Math.sin(dRad);
      var sim = Math.cos(qRad - dRad);

      htmlSvg += '<line x1="' + cx + '" y1="' + cy + '" x2="' + dx.toFixed(1) + '" y2="' + dy.toFixed(1) + '" stroke="' + d.color + '" stroke-width="1.5"/>' +

      return { doc: d, sim: sim };
    });

    svg.innerHTML = htmlSvg;

    // Sort by cosine similarity descending
    scored.sort(function(a, b) { return b.sim - a.sim; });

    var htmlRank = '';
    scored.forEach(function(item, idx) {
      var bg = (idx === 0) ? 'var(--primary)' : 'var(--card)';
      var color = (idx === 0) ? '#fff' : 'var(--foreground)';
      var subColor = (idx === 0) ? '#eee' : 'var(--muted-foreground)';

      htmlRank += '<div style="padding:8px;background:' + bg + ';color:' + color + ';border:1px solid var(--border);border-radius:var(--radius)">' +
        '<div style="font-size:9px;font-weight:700">' + (idx + 1) + '위 (D' + item.doc.id + ')</div>' +
        '<div style="font-size:12px;font-weight:800;margin:2px 0">' + item.sim.toFixed(3) + '</div>' +
        '<div style="font-size:8px;color:' + subColor + '">' + item.doc.name.split(' ')[1] + '</div>' +
      '</div>';
    });

    rankBox.innerHTML = htmlRank;
  }

  sAng.addEventListener('input', render);
  render();
})();
