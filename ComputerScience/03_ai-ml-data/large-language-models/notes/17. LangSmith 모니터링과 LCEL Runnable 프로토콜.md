**LCEL(LangChain Expression Language)**은 파이프 연산자(`|`)를 사용하여 프롬프트, 모델, 파서를 직관적으로 선언하고, 모든 컴포넌트가 표준 **Runnable 프로토콜**을 따르도록 하여 동기·비동기·배치·스트리밍을 즉시 지원하는 표준 인터페이스이다.

---

## 1. Runnable 프로토콜 4대 핵심 인터페이스

| 메서드 | 동작 방식 | 주요 활용 시나리오 |
| :--- | :--- | :--- |
| `invoke(input)` | 단일 입력을 받아 동기적으로 최종 결과 반환 | 1회성 함수 호출, 기본 CLI 작업 |
| `batch([in1, in2])` | 여러 입력을 스레드 풀을 통해 일괄 병렬 처리 | 대량 데이터셋 전처리, 일괄 번역 |
| `stream(input)` | 생성되는 토큰 청크(Chunk)를 실시간 이터레이터로 반환 | 웹 챗봇의 타이핑 효과 구현 |
| `ainvoke(input)` | 비동기(async/await) 이벤트 루프에서 논블로킹 실행 | FastAPI 등 고성능 비동기 웹 서버 백엔드 |

## 2. LCEL 파이프라인 및 batch/stream 실습 코드

```python
import os
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser
from dotenv import load_dotenv

load_dotenv()

prompt = ChatPromptTemplate.from_template("{topic}의 핵심 특징 1가지를 간결하게 설명하세요.")
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.3)
parser = StrOutputParser()

# LCEL 파이프 연산자로 체인 합성
chain = prompt | model | parser

# 1. batch 메서드를 활용한 일괄 병렬 처리
topics = ["지구 공전", "화산 활동", "대륙 이동"]
batch_results = chain.batch([{"topic": t} for t in topics])

print("=== batch 병렬 실행 결과 ===")
for t, res in zip(topics, batch_results):
    print(f"[{t}] {res}")

# 2. stream 메서드를 활용한 실시간 스트리밍 출력
print("\n=== stream 실시간 스트리밍 ===")
for chunk in chain.stream({"topic": "초신성 폭발"}):
    print(chunk, end="", flush=True)
print()
```

(function() {
  var btn = document.getElementById('lcel-play-btn');
  var out = document.getElementById('lcel-stream-out');
  var cursor = document.getElementById('lcel-cursor');

  var text = "LCEL(LangChain Expression Language)은 모든 컴포넌트에 스트리밍과 배치 처리를 기본 내장하여 최적의 사용자 경험을 제공합니다.";
  var chunks = text.split(" ");
  var idx = 0;
  var timer = null;

  btn.addEventListener('click', function() {
    if (timer) clearInterval(timer);
    out.textContent = '';
    cursor.style.display = 'inline';
    idx = 0;

    timer = setInterval(function() {
      if (idx < chunks.length) {
        out.textContent += (idx === 0 ? '' : ' ') + chunks[idx];
        idx++;
      } else {
        clearInterval(timer);
        timer = null;
        cursor.style.display = 'none';
      }
    }, 120);
  });
})();
</script>
