대규모 언어 모델(**LLM, Large Language Model**)은 수십억 개 이상의 매개변수를 갖추고 인터넷 규모의 방대한 텍스트 코퍼스를 사전학습(Pre-training)하여 인간의 자연어를 이해하고 생성하는 최첨단 딥러닝 모델이다.

---

## 1. 자연어 처리(NLP) 기술의 4단계 패러다임 진화

자연어 처리 기술은 이산 기호(Discrete Symbol) 기반의 규칙·통계 모델에서 벡터 공간의 분산 표현(Distributed Representation)을 거쳐, 문맥을 병렬로 파악하는 **어텐션 기반 파운데이션 모델**로 진화하였다.

### 시대별 수학적 모델링 및 핵심 한계

| 발전 단계 | 핵심 수학 공식 / 원리 | 주요 장점 | 구조적 한계점 |
| :--- | :--- | :--- | :--- |
| **1. 규칙 및 통계 ($N$-gram)** | $P(w_t \vert w\_{t-n+1:t-1}) = \frac{C(w_{t-n+1:t})}{C(w_{t-n+1:t-1})}$ | 빠른 계산 속도, 단순성 | 희소성($\text{Sparsity}$), $\text{OOV}$ 미등록어 취약 |
| **2. 밀집 임베딩 (Word2Vec)** | $\mathcal{L} = \sum\_{t=1}^T \sum\_{-c \le j \le c, j \ne 0} \log P(w\_{t+j} \vert w_t)$ | 단어 간 유의미한 벡터 거리 | 동음이의어/다의어($\text{Polysemy}$) 문맥 구분 불가 |
| **3. 순환 신경망 (RNN/LSTM)** | $h_t = \tanh(W x_t + U h\_{t-1} + b)$ | 가변 길이 시퀀스 처리 | 기울기 소실($\text{Vanishing Gradient}$), 병목($\text{Bottleneck}$) |
| **4. 어텐션 & LLM (Transformer)** | $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$ | 완전 병렬화, 장기 의존성 극복 | 높은 계산 복잡도($O(N^2)$), 대규모 컴퓨팅 자원 필요 |

## 3. 원-핫 인코딩 vs 분산 표상(Distributed Representation) 수식 비교

### 원-핫 인코딩 (One-Hot Vector)

어휘집 크기 $|V|$에서 특정 단어 $w_i$만 1이고 나머지는 0인 희소 벡터:

$$\mathbf{v}(w_i) = [0, \dots, 0, \underbrace{1}_{i\text{-th}}, 0, \dots, 0]^T \in \{0, 1\}^{|V|}$$

임의의 서로 다른 두 단어 $w_i \ne w_j$의 내적(유사도)은 항상 0이다:

$$\mathbf{v}(w_i) \cdot \mathbf{v}(w_j) = 0 \quad (\text{단어 간 의미적 연관성 측정 불가})$$

### 밀집 임베딩 (Dense Embedding)

단어를 $d$차원 ($d \ll |V|$) 연속 벡터 공간 $\mathbb{R}^d$에 사상하여 코사인 유사도($S_C$) 계산 가능:

$$S_C(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} = \frac{\sum_{k=1}^d u_k v_k}{\sqrt{\sum_{k=1}^d u_k^2} \sqrt{\sum_{k=1}^d v_k^2}}$$
