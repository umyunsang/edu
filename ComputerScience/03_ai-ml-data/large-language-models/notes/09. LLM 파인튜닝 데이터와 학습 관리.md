\*\*파인튜닝(Fine-Tuning)\*\*은 사전학습된 거대 언어 모델에 도메인 특화 대화 데이터셋을 전이학습(Transfer Learning)시켜, 프롬프트에 매번 긴 예시(Few-shot)를 주입하지 않고도 높은 정확도와 일관된 출력 형식을 얻는 기법이다.

---

## 1. 지도 미세조정(SFT)의 수학적 손실 함수 모델링

### 1) 완성 토큰 마스킹 교차 엔트로피 손실 (Completion Token Cross-Entropy)

$N$개의 지도 훈련 데이터 쌍 $\{(x^{(i)}, y^{(i)})\}\_{i=1}^N$ (여기서 $x$는 프롬프트, $y$는 목표 응답)에 대해, 모델은 프롬프트 토큰 $x$에 대해서는 손실을 계산하지 않고, 정답 완성 토큰 $y$의 조건부 로그 우도만을 최대화하도록 최적화된다:

$$\mathcal{L}_{\text{SFT}}(\theta) = -\frac{1}{N} \sum_{i=1}^N \sum_{t=1}^{|y^{(i)}|} \log P_\theta\left( y_t^{(i)} \mid x^{(i)}, y_{<t}^{(i)} \right)$$

### 2) 사전학습 지식 보존 정규화

사전학습된 기본 가중치 $\theta_0$로부터의 과도한 이탈(Catastrophic Forgetting)을 방지하기 위한 정규화 제약식:

$$\theta^* = \arg\min_\theta \left[ \mathcal{L}_{\text{SFT}}(\theta) + \frac{\lambda}{2} \|\theta - \theta_0\|_2^2 \right]$$

## 2. JSONL 훈련 데이터 포맷 및 유효성 검증

학습 데이터는 한 줄에 하나의 JSON 객체가 포함된 `.jsonl` 형식이어야 한다:

```json
{"messages": [{"role": "system", "content": "당신은 법률 상담 AI입니다."}, {"role": "user", "content": "전세 보증금 반환 절차는 어떻게 되나요?"}, {"role": "assistant", "content": "내용증명 발송 후 임차권등기명령 신청 및 반환 청구 소송을 진행할 수 있습니다."}]}
```

```python
import json

# JSONL 포맷 유효성 검증 스크립트
def validate_jsonl(file_path):
    with open(file_path, "r", encoding="utf-8") as f:
        for idx, line in enumerate(f):
            try:
                data = json.loads(line.strip())
                assert "messages" in data, "messages 키가 누락되었습니다."
                assert len(data["messages"]) >= 2, "최소 2개 이상의 대화가 필요합니다."
            except Exception as e:
                print(f"❌ {idx+1}번째 라인 오류: {e}")
                return False
    print("✓ JSONL 데이터셋 포맷 검증 통과!")
    return True
```

## 3. 파인튜닝 수명 주기(Lifecycle) 파이썬 실습 코드

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 1. 훈련 파일 업로드 (purpose='fine-tune')
file_obj = client.files.create(
    file=open("train_data.jsonl", "rb"),
    purpose="fine-tune"
)
print(f"업로드된 파일 ID: {file_obj.id}")

# 2. 파인튜닝 작업(Job) 생성
job = client.fine_tuning.jobs.create(
    training_file=file_obj.id,
    model="gpt-4o-mini-2024-07-18",
    hyperparameters={
        "n_epochs": 3,
        "batch_size": "auto",
        "learning_rate_multiplier": "auto"
    }
)
print(f"파인튜닝 작업 시작 ID: {job.id}")

# 3. 작업 진행 상태 확인
status = client.fine_tuning.jobs.retrieve(job.id)
print(f"현재 상태: {status.status}") # validating_files, queued, running, succeeded

# 4. 완료된 파인튜닝 모델로 추론 요청
if status.status == "succeeded":
    fine_tuned_model_id = status.fine_tuned_model
    test_res = client.chat.completions.create(
        model=fine_tuned_model_id,
        messages=[
            {"role": "user", "content": "계약 만료 후 보증금을 못 받고 있습니다."}
        ]
    )
    print("파인튜닝 모델 응답:", test_res.choices[0].message.content)
```

(function() {

    }
  }

  render();
