**Chat Completion API**는 메시지의 리스트(`messages`)를 입력받아 AI가 이전 맥락을 기억하는 상태로 연속적인 상호작용을 수행하는 표준 대화형 인터페이스이다.

---

## 1. 메시지 3대 역할 (Message Roles)

| 역할 (`role`) | 주체 | 핵심 기능 및 지침 |
| :--- | :--- | :--- |
| `system` | 시스템 관리자 | AI의 행동 양식, 페르소나, 말투, 출력 포맷(JSON 등), 금기 사항 규정 |
| `user` | 인간 사용자 | 실제 질문, 요청 사항, 분석할 원문 텍스트 주입 |
| `assistant` | 인공지능 모델 | AI 모델의 이전 응답 기록 (다중 턴 문맥 유지용) |

---

## 2. 다중 턴 대화 및 문장 교정 파이썬 실습 코드

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 1. 다중 턴(Multi-turn) 대화 컨텍스트 구성
messages = [
    {"role": "system", "content": "당신은 IT 전문 테크니컬 라이터입니다. 친절하고 간결하게 설명하세요."},
    {"role": "user", "content": "쿠버네티스(Kubernetes)의 핵심 개념을 한 문장으로 알려줘."},
    {"role": "assistant", "content": "쿠버네티스는 컨테이너화된 애플리케이션의 자동 배포, 스케일링 및 관리를 제공하는 오픈소스 오케스트레이션 플랫폼입니다."},
    {"role": "user", "content": "그렇다면 도커(Docker)와의 가장 큰 차이점은 무엇인가요?"}
]

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=messages,
    temperature=0.7,
    max_tokens=200
)
print("=== Chat Completion 응답 ===")
print(response.choices[0].message.content)

# 2. 문장 교정 및 윤문 실습
proofread_prompt = """다음 문장의 맞춤법을 교정하고, 전문적인 비즈니스 이메일 톤으로 수정해 주세요.
원문: '프로젝트 일정이 쫌 늦어져서 내일까지 보내드리기 힘들꺼가타요 죄송해요'"""

proof_res = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "당신은 비즈니스 커뮤니케이션 교정 전문가입니다."},
        {"role": "user", "content": proofread_prompt}
    ],
    temperature=0.2
)
print("\n=== 비즈니스 교정 결과 ===")
print(proof_res.choices[0].message.content)
```

## 3. 인터랙티브 멀티 턴 대화 컨텍스트 토큰 누적 시뮬레이터

대화 턴(Turn)이 진행될 때마다 전체 메시지 히스토리가 매 요청마다 재전송되면서 소비되는 토큰량과 비용의 지수적 증가를 실시간으로 확인한다.

<script>
(function() {
  var sTurn = document.getElementById('chat-turn-slider');
  var turnVal = document.getElementById('chat-turn-val');
  var curTok = document.getElementById('chat-cur-tok');
  var totTok = document.getElementById('chat-tot-tok');
  var recTxt = document.getElementById('chat-rec-txt');

  function render() {
    var turns = parseInt(sTurn.value, 10);
    turnVal.textContent = turns + ' 턴 (총 ' + (turns * 2 + 1) + '개 메시지)';

    // 시스템 프롬프트: 100 토큰, 사용자 질문: 150 토큰, 어시스턴트 답변: 150 토큰
    // n번째 턴에서의 프롬프트 = 100 + (n-1)*300 + 150
    var curPrompt = 100 + (turns - 1) * 300 + 150;
    // 누적 토큰 = sum_{i=1..turns} (100 + (i-1)*300 + 150 + 150)
    var total = 0;
    for (var i = 1; i <= turns; i++) {
      total += 100 + (i - 1) * 300 + 300;
    }

    curTok.textContent = curPrompt.toLocaleString() + ' 토큰';
    totTok.textContent = total.toLocaleString() + ' 토큰';

    if (turns > 12) {
      recTxt.textContent = '⚠️ 메모리 요약(BufferWindow) 필요';
      recTxt.style.color = 'var(--destructive)';
    } else {
      recTxt.textContent = '정상 유지 범위';
      recTxt.style.color = 'var(--chart-2)';
    }
  }

  sTurn.addEventListener('input', render);
  render();
})();
</script>
