LangChain은 서로 다른 API 프로토콜을 가진 **OpenAI, Anthropic Claude, Google Gemini**를 동일한 `ChatModel` 인터페이스로 추상화하며, Pydantic을 활용한 **JsonOutputParser**로 비정형 텍스트를 완벽한 구조화된 데이터 객체로 변환한다.

---

## 1. 3대 주요 Chat Model 클래스

```python
# 1. OpenAI Chat Model
from langchain_openai import ChatOpenAI
openai_model = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 2. Anthropic Claude Model
from langchain_anthropic import ChatAnthropic
claude_model = ChatAnthropic(model="claude-3-5-sonnet-20240620", temperature=0)

# 3. Google Gemini Model
from langchain_google_genai import ChatGoogleGenerativeAI
gemini_model = ChatGoogleGenerativeAI(model="gemini-1.5-pro", temperature=0)
```

---

## 2. Pydantic BaseModel 기반 구조화된 JSON 파서 실습

```python
from pydantic import BaseModel, Field
from typing import List
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import JsonOutputParser
from langchain_openai import ChatOpenAI
from dotenv import load_dotenv

load_dotenv()

# 1. 추출할 자료구조 스키마 정의 (Pydantic)
class CuisineRecipe(BaseModel):
    recipe_name: str = Field(description="요리의 공식 명칭")
    ingredients: List[str] = Field(description="필요한 식재료 목록")
    prep_time_minutes: int = Field(description="예상 조리 시간(분)")
    difficulty: str = Field(description="난이도 (쉬움 / 보통 / 어려움)")

# 2. JSON 파서 생성 및 포맷 지시어 추출
parser = JsonOutputParser(pydantic_object=CuisineRecipe)

prompt = PromptTemplate(
    template="사용자가 요청한 요리의 레시피를 작성하세요.\n{format_instructions}\n요리: {dish}\n",
    input_variables=["dish"],
    partial_variables={"format_instructions": parser.get_format_instructions()}
)

model = ChatOpenAI(model="gpt-4o-mini", temperature=0.2)
chain = prompt | model | parser

# 3. 파이프라인 실행 (출력은 순수 파이썬 딕셔너리 객체)
result = chain.invoke({"dish": "김치볶음밥"})
print("=== 파싱된 Pydantic 구조화 데이터 ===")
print(f"요리명: {result['recipe_name']}")
print(f"재료: {', '.join(result['ingredients'])}")
print(f"조리시간: {result['prep_time_minutes']}분")
print(f"난이도: {result['difficulty']}")
```
