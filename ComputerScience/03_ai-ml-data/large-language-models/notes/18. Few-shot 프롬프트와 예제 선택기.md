**Few-shot 프롬프팅**은 모델에게 몇 가지 입력-출력 예시 쌍을 직접 제공하여 지시문만으로는 모호할 수 있는 출력 스타일, 특수 문법, 분류 기준을 즉각 적응시키는 강력한 인컨텍스트 학습 기법이다.

---

## 1. 인컨텍스트 학습(ICL) 및 예제 선택의 수학적 모델링

### 1) $K$-Shot 데모 조건부 사후 확률 분포

$K$개의 시범 예제 집합 $\mathcal{E}_K = \{(x_1, y_1), (x_2, y_2), \dots, (x_K, y_K)\}$와 새로운 테스트 입력 $x_{\text{test}}$가 주어졌을 때, 타겟 출력 $y\_{\text{test}}$의 생성 확률은 다음과 같다:

$$P\left( y_{\text{test}} \mid x_{\text{test}}, \mathcal{E}_K \right) = \prod_{t=1}^{|y_{\text{test}}|} P_\theta\left( y_t \mid \mathcal{E}_K, x_{\text{test}}, y_{<t} \right)$$

가중치 업데이트 없이 사전학습된 어텐션 계층 내부에서 예제 간 상관 패턴(In-Context Demonstration)을 학습한다.

### 2) 시맨틱 유사도 기반 최적 예제 선택기 (Semantic Example Selector)

전체 예제 풀 $\mathcal{P} = \{(x_i, y_i)\}_{i=1}^M$에서 테스트 질문 $x_{\text{test}}$와의 임베딩 코사인 유사도가 가장 높은 상위 $K$개의 부분집합 $\mathcal{E}\_K^\*$를 추출하는 최적화 식:

$$\mathcal{E}_K^* = \arg\max_{\mathcal{E} \subseteq \mathcal{P}, |\mathcal{E}|=K} \sum_{(x_i, y_i) \in \mathcal{E}} \frac{\mathbf{e}(x_{\text{test}})^T \mathbf{e}(x_i)}{\|\mathbf{e}(x_{\text{test}})\|_2 \|\mathbf{e}(x_i)\|_2}$$

## 3. 동적 Few-shot 프롬프트 파이썬 실습 코드

```python
from langchain_core.prompts import PromptTemplate, FewShotPromptTemplate
from langchain_core.example_selectors import LengthBasedExampleSelector

# 1. 예제 데이터셋 정의 (반의어 생성 태스크)
examples = [
    {"input": "행복", "output": "슬픔"},
    {"input": "높다", "output": "낮다"},
    {"input": "빠르다", "output": "느리다"},
    {"input": "밝다", "output": "어둡다"},
    {"input": "거대하다", "output": "왜소하다"}
]

example_prompt = PromptTemplate(
    input_variables=["input", "output"],
    template="단어: {input}\n반의어: {output}"
)

# 2. 길이 기반 예제 선택기 생성 (최대 100자 이내로 예제 제한)
example_selector = LengthBasedExampleSelector(
    examples=examples,
    example_prompt=example_prompt,
    max_length=100
)

# 3. FewShotPromptTemplate 구성
dynamic_prompt = FewShotPromptTemplate(
    example_selector=example_selector,
    example_prompt=example_prompt,
    prefix="주어진 단어의 반의어를 작성하세요.",
    suffix="단어: {input}\n반의어:",
    input_variables=["input"]
)

# 짧은 입력 시 예제들이 풍부하게 포함됨
formatted = dynamic_prompt.format(input="뜨겁다")
print("=== 완성된 동적 Few-shot 프롬프트 ===")
print(formatted)
```
