OpenAI 플랫폼은 텍스트 생성을 넘어 **Whisper 오디오 전사**, **TTS 음성 합성**, **무료 Moderation 콘텐츠 안전 필터**, 그리고 고난도 논리 연산을 자율적으로 사고하는 **`o1` 추론 모델**을 통합 제공한다.

## 1. 오디오(Whisper & TTS) 및 모더레이션 API 실습 코드

```python
import os
from pathlib import Path
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 1. Whisper-1 음성 인식 (STT) 실습
with open("lecture_sample.mp3", "rb") as audio_file:
    transcription = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        response_format="verbose_json",
        timestamp_granularities=["word"]
    )
print("=== Whisper 음성 전사 결과 ===")
print(transcription.text)

# 2. Text-to-Speech (TTS) 음성 합성 실습
speech_file_path = Path(__file__).parent / "speech_output.mp3"
tts_res = client.audio.speech.create(
    model="tts-1-hd",
    voice="nova", # alloy, echo, fable, onyx, nova, shimmer
    input="환영합니다! OpenAI 멀티모달 API 실습을 시작합니다."
)
tts_res.stream_to_file(speech_file_path)
print(f"✓ TTS 음성 파일 저장 완료: {speech_file_path}")

# 3. Moderation 유해성 검사 (무료 엔드포인트)
mod_res = client.moderations.create(
    model="omni-moderation-latest",
    input="인공지능을 이용해 안전하고 유익한 교육 플랫폼을 구축합니다."
)
results = mod_res.results[0]
print(f"\n유해 콘텐츠 여부 (flagged): {results.flagged}")
print(f"폭력성 점수 (violence): {results.category_scores.violence:.6f}")
```

## 2. o1 추론(Reasoning) 모델 아키텍처

`o1` 및 `o1-mini` 모델은 즉각적인 토큰 생성을 시작하기 전, 내부적으로 장문의 **사고 사슬(Chain of Thought)**을 거쳐 복잡한 수학, 코딩, 과학적 가설 검증을 수행한다.

```python
# o1 모델을 통한 고난도 행렬 전치 스크립트 작성 요청
reasoning_res = client.chat.completions.create(
    model="o1-mini",
    messages=[
        {
            "role": "user",
            "content": "문자열 '[1,2],[3,4],[5,6]' 형식으로 입력된 2D 행렬을 전치(Transpose)하여 동일한 형식으로 출력하는 순수 Bash 스크립트를 작성해줘."
        }
    ]
)
print("=== o1 추론 응답 ===")
print(reasoning_res.choices[0].message.content)
```
