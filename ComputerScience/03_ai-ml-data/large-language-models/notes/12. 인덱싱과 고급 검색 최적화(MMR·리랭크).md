## 2. MMR (Maximal Marginal Relevance) 수식 유도

후보 문서 집합 $R$과 이미 선택된 문서 집합 $S$에 대해, 다음으로 추가할 최적의 문서 $d_i$는 아래 목적 함수를 최대화하는 문서로 결정된다:

$$\text{MMR} = \arg\max_{d_i \in R \setminus S} \left[ \lambda \cdot \text{Sim}_1(d_i, q) - (1 - \lambda) \cdot \max_{d_j \in S} \text{Sim}_2(d_i, d_j) \right]$$

- $\lambda = 1.0$: 순수 유사도 기반 검색 (다양성 고려 안 함, 중복 문서 위험).
- $\lambda = 0.5$: 관련성과 다양성의 균형 표준치.
- $\lambda = 0.0$: 극단적인 다양성 추구 (질문과의 관련성 저하).

## 3. LangChain 기반 Chroma 색인 및 MMR 검색 파이프라인 코드

```python
import os
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain.retrievers.multi_query import MultiQueryRetriever
from dotenv import load_dotenv

load_dotenv()
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 1. 벡터 데이터베이스(Chroma) 색인 구축
texts = [
    "트랜스포머 아키텍처는 인코더와 디코더의 셀프 어텐션 블록으로 구성됩니다.",
    "어텐션 메커니즘은 입력 시퀀스 전체에서 중요한 토큰 가중치를 계산합니다.",
    "쿠버네티스 파드는 하나 이상의 컨테이너 그룹을 실행하는 최소 배포 단위입니다.",
    "도커 컨테이너는 운영체제 수준의 가상화를 통해 격리된 프로세스를 제공합니다."
]
vectorstore = Chroma.from_texts(texts=texts, embedding=embeddings)

# 2. MMR 기반 Retriever 생성 (k=2, fetch_k=4, lambda_mult=0.5)
mmr_retriever = vectorstore.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 2, "fetch_k": 4, "lambda_mult": 0.5}
)

# 3. MultiQuery Retriever 연동
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
mq_retriever = MultiQueryRetriever.from_llm(
    retriever=mmr_retriever,
    llm=llm
)

results = mq_retriever.invoke("트랜스포머의 어텐션 구조에 대해 설명해줘")
print(f"최종 반환된 고품질 근거 문서 수: {len(results)}")
for r in results:
    print(f"- {r.page_content}")
```
