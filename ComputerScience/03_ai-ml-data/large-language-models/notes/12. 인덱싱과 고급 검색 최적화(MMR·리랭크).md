## 2. MMR 및 고급 검색의 수학적 공식화

### 1) MMR (Maximal Marginal Relevance) 목적 함수

후보 문서 집합 $R$과 이미 선택된 문서 부분집합 $S$에 대해, 다음에 추가될 최적의 문서 $d^*$는 아래 목적 함수를 최대화하는 원소로 결정된다:

$$\text{MMR}(q, R, S) = \arg\max_{d_i \in R \setminus S} \left[ \lambda \cdot \text{Sim}_1(d_i, q) - (1 - \lambda) \cdot \max_{d_j \in S} \text{Sim}_2(d_i, d_j) \right]$$

- $\lambda = 1.0$: 순수 유사도 기반 검색 (다양성 고려 안 함, 중복 문서 위험).
- $\lambda = 0.5$: 관련성과 다양성의 균형 표준치.
- $\lambda = 0.0$: 극단적인 다양성 추구 (질문과의 관련성 저하).

### 2) Cross-Encoder Reranker 정밀 채점 모델

질의 $q$와 문서 $d$를 결합하여 심층 셀프 어텐션 계층에 통과시키는 Cross-Encoder 적합도 점수:

$$s_{\text{rerank}}(q, d) = \sigma\left( \mathbf{w}^T \text{Transformer}([q \; \Vert \; d]) \right)$$

### 3) MultiQuery 역상호순위 융합 (RRF, Reciprocal Rank Fusion)

$M$개의 확장 질의 집합 ${q_1, q_2, \dots, q_M}$에 대해, 각 질의 검색 결과에서의 순위 $r_m(d)$를 결합하는 RRF 점수:

$$\text{RRF}(d) = \sum_{m=1}^M \frac{1}{k_0 + r_m(d)} \quad (k_0 \approx 60)$$

## 3. LangChain 기반 Chroma 색인 및 MMR 검색 파이프라인 코드

```python
import os
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain.retrievers.multi_query import MultiQueryRetriever
from dotenv import load_dotenv

load_dotenv()
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 1. 벡터 데이터베이스(Chroma) 색인 구축
texts = [
    "트랜스포머 아키텍처는 인코더와 디코더의 셀프 어텐션 블록으로 구성됩니다.",
    "어텐션 메커니즘은 입력 시퀀스 전체에서 중요한 토큰 가중치를 계산합니다.",
    "쿠버네티스 파드는 하나 이상의 컨테이너 그룹을 실행하는 최소 배포 단위입니다.",
    "도커 컨테이너는 운영체제 수준의 가상화를 통해 격리된 프로세스를 제공합니다."
]
vectorstore = Chroma.from_texts(texts=texts, embedding=embeddings)

# 2. MMR 기반 Retriever 생성 (k=2, fetch_k=4, lambda_mult=0.5)
mmr_retriever = vectorstore.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 2, "fetch_k": 4, "lambda_mult": 0.5}
)

# 3. MultiQueryRetriever 결합 실습
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
multi_query_retriever = MultiQueryRetriever.from_llm(
    retriever=mmr_retriever,
    llm=llm
)

query = "트랜스포머의 핵심 동작 원리"
results = multi_query_retriever.invoke(query)
print(f"=== MultiQuery + MMR 검색 결과 (총 {len(results)}건) ===")
for r in results:
    print(f"• {r.page_content}")
```

    </div>
    <input id="mmr-lambda-slider" type="range" min="0.0" max="1.0" step="0.05" value="0.5" style="width:100%;accent-color:var(--primary)" />
  </div>

  <!-- 결과 리스트 -->
  <div id="mmr-doc-list" style="background:var(--background);border:2px dashed var(--border);border-radius:var(--radius);padding:12px;display:flex;flex-direction:column;gap:8px">
    <!-- 동적 생성 -->

<script>
(function() {
  var sLam = document.getElementById('mmr-lambda-slider');
  var vLam = document.getElementById('mmr-lambda-val');
  var list = document.getElementById('mmr-doc-list');

  var rawDocs = [
    { id: 1, title: '문서 1: 트랜스포머 셀프 어텐션 구조', qSim: 0.95, d1Sim: 1.0 },
    { id: 2, title: '문서 2: 트랜스포머 셀프 어텐션 수식 (중복 높음)', qSim: 0.93, d1Sim: 0.92 },
    { id: 3, title: '문서 3: 멀티헤드 어텐션 병렬 처리', qSim: 0.88, d1Sim: 0.65 },
    { id: 4, title: '문서 4: 트랜스포머 위치 인코딩(Positional)', qSim: 0.82, d1Sim: 0.35 }
  ];

  function render() {
    var lam = parseFloat(sLam.value);
    var label = ' (균형 검색)';
    if (lam > 0.8) label = ' (유사도 집중 / 중복 위험)';
    else if (lam < 0.2) label = ' (다양성 극대화 / 관련성 저하)';
    vLam.textContent = lam.toFixed(2) + label;

    // Rank 1 is always Doc 1
    var scored = [
      { doc: rawDocs[0], score: rawDocs[0].qSim, mmr: rawDocs[0].qSim }
    ];

    // For Doc 2, 3, 4 compute MMR against Doc 1
    var remaining = rawDocs.slice(1).map(function(d) {
      var mmrScore = (lam * d.qSim) - ((1.0 - lam) * d.d1Sim);
      return { doc: d, mmr: mmrScore };
    });

    remaining.sort(function(a, b) { return b.mmr - a.mmr; });
    var top2 = remaining[0];

    var html = '<div style="font-size:11px;font-weight:700;color:var(--foreground);margin-bottom:4px">[MMR Top-2 선택 결과]</div>';

    // 1st Doc
    html += '<div style="padding:8px;background:var(--card);border:1px solid var(--primary);border-radius:var(--radius);font-size:11px">' +
      '<div style="font-weight:700;color:var(--primary)">1위 선택: ' + rawDocs[0].title + '</div>' +
      '<div style="font-size:9px;color:var(--muted-foreground)">질의 유사도: ' + rawDocs[0].qSim + ' (최초 기준 문서)</div>' +
    '</div>';

    // 2nd Doc
    var badgeColor = (top2.doc.id === 2) ? 'var(--destructive)' : 'var(--chart-2)';
    var badgeText = (top2.doc.id === 2) ? '⚠️ 중복 문서 선택됨' : '✓ 다양성 확보 문서 선택';

    html += '<div style="padding:8px;background:var(--card);border:1px solid var(--border);border-radius:var(--radius);font-size:11px">' +
      '<div style="display:flex;justify-content:space-between">' +
        '<span style="font-weight:700;color:var(--foreground)">2위 선택: ' + top2.doc.title + '</span>' +
        '<span style="font-size:10px;font-weight:800;color:' + badgeColor + '">' + badgeText + '</span>' +
      '</div>' +
      '<div style="font-size:9px;color:var(--muted-foreground);margin-top:2px">' +
        '질의 유사도: ' + top2.doc.qSim + ' | 기존 문서와의 유사도: ' + top2.doc.d1Sim + ' | 최종 MMR 점수: ' + top2.mmr.toFixed(3) +
      '</div>' +
    '</div>';

    list.innerHTML = html;
  }

  sLam.addEventListener('input', render);
  render();
})();
</script>
