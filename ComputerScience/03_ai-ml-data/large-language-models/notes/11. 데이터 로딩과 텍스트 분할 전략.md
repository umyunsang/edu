RAG 파이프라인의 첫 관문은 웹 페이지, PDF, 텍스트 문서 등 다양한 비정형 소스로부터 데이터를 읽어 들이는 **문서 로딩(Loading)**과, LLM의 컨텍스트 제한 및 검색 정확도를 최적화하기 위해 문맥을 보존하며 자르는 **텍스트 분할(Text Splitting)**이다.

---

## 1. 주요 Document Loader 클래스

| 로더 클래스 | 패키지 경로 | 지원 데이터 소스 |
| :--- | :--- | :--- |
| `WebBaseLoader` | `langchain_community.document_loaders` | HTML 웹사이트 URL (BeautifulSoup 파싱) |
| `PyPDFLoader` | `langchain_community.document_loaders` | PDF 문서 (페이지별 Document 객체 분할) |
| `DirectoryLoader` | `langchain_community.document_loaders` | 로컬 폴더 내 모든 파일 일괄 로드 |
| `TextLoader` | `langchain_community.document_loaders` | `.txt`, `.md` 등 일반 텍스트 파일 |

## 2. RecursiveCharacterTextSplitter 분할 파이프라인 실습

```python
from langchain_community.document_loaders import WebBaseLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 1. 웹 문서 로딩
url = "https://ko.wikipedia.org/wiki/거대언어모델"
loader = WebBaseLoader(url)
raw_docs = loader.load()
print(f"로딩된 원문 길이: {len(raw_docs[0].page_content)} 글자")

# 2. 재귀적 문자 텍스트 분할기 설정
# 줄바꿈(\n\n) -> 단락(\n) -> 띄어쓰기(' ') -> 글자 단위로 우선순위 분할
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,       # 한 청크당 최대 글자 수
    chunk_overlap=100,     # 청크 간 겹치는 중첩 글자 수 (문맥 보존)
    length_function=len,
    separators=["\n\n", "\n", " ", ""]
)

split_docs = text_splitter.split_documents(raw_docs)
print(f"분할된 총 청크 개수: {len(split_docs)} 개")
print(f"[1번 청크 예시]\n{split_docs[0].page_content[:150]}...")
```

(function() {
  var sSize = document.getElementById('spl-size-slider');
  var sOv = document.getElementById('spl-ov-slider');
  var sizeVal = document.getElementById('spl-size-val');
  var ovVal = document.getElementById('spl-ov-val');
  var chunkCnt = document.getElementById('spl-chunk-cnt');
  var stepVal = document.getElementById('spl-step-val');
  var evalTxt = document.getElementById('spl-eval-txt');

  function render() {
    var size = parseInt(sSize.value, 10);
    var ov = parseInt(sOv.value, 10);
    if (ov >= size) {
      ov = size - 50;
      sOv.value = ov;
    }

    sizeVal.textContent = size + ' 자';
    var ratio = ((ov / size) * 100).toFixed(0);
    ovVal.textContent = ov + ' 자 (' + ratio + '%)';

    var step = size - ov;
    stepVal.textContent = step + ' 자';

    var totalChars = 10000;
    var count = Math.ceil((totalChars - ov) / step);
    chunkCnt.textContent = count + ' 개';

    if (ratio < 10) {
      evalTxt.textContent = '⚠️ 문맥 단절 위험 (Overlap 부족)'; evalTxt.style.color = 'var(--destructive)';
    } else if (ratio > 35) {
      evalTxt.textContent = '⚠️ 중복 연산 과다 (Overlap 과다)'; evalTxt.style.color = 'var(--chart-1)';
    } else {
      evalTxt.textContent = '⭐ 표준 권장 밸런스 (15~25%)'; evalTxt.style.color = 'var(--chart-2)';
    }
  }

  sSize.addEventListener('input', render);
  sOv.addEventListener('input', render);
  render();
})();
</script>
