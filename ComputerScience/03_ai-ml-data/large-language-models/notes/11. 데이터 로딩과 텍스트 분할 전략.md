RAG 파이프라인의 첫 관문은 웹 페이지, PDF, 텍스트 문서 등 다양한 비정형 소스로부터 데이터를 읽어 들이는 \*\*문서 로딩(Loading)\*\*과, LLM의 컨텍스트 제한 및 검색 정확도를 최적화하기 위해 문맥을 보존하며 자르는 \*\*텍스트 분할(Text Splitting)\*\*이다.

---

## 1. 슬라이딩 윈도우 텍스트 분할(Chunking)의 수학적 모델링

### 1) 청크 구간 및 총 청크 수 산출 수식

전체 문서의 문자 길이 $L$, 단일 청크 최대 크기 $C$ (`chunk_size`), 인접 청크 간 중첩 크기 $O$ (`chunk_overlap`, $0 \le O < C$)에 대해, 유효 스트라이드(Step)는 $S = C - O$이다.

$k$번째 분할 청크 $S_k$의 문자 범위 인덱스와 생성되는 총 청크 개수 $N\_{\text{chunks}}$는 다음과 같이 정의된다:

$$S_k = \big[ k \cdot (C - O), \; \min(k \cdot (C - O) + C, \; L) \big], \quad k \in \{0, 1, \dots, N_{\text{chunks}}-1\}$$

$$N_{\text{chunks}} = \left\lceil \frac{L - O}{C - O} \right\rceil = \left\lceil \frac{L - O}{S} \right\rceil$$

### 2) 문맥 단절 방지를 위한 최적 중첩률

문맥 연속성(Contextual Continuity)을 보장하기 위한 권장 중첩 비율은 일반적으로 $10% \sim 25%$ 범위이다:

$$\text{Overlap Ratio} = \frac{O}{C} \in [0.10, 0.25]$$

| 로더 클래스 | 패키지 경로 | 지원 데이터 소스 |

## 3. RecursiveCharacterTextSplitter 분할 파이프라인 실습

```python
from langchain_community.document_loaders import WebBaseLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 1. 웹 문서 로딩
url = "https://ko.wikipedia.org/wiki/거대언어모델"
loader = WebBaseLoader(url)
raw_docs = loader.load()
print(f"로딩된 원문 길이: {len(raw_docs[0].page_content)} 글자")

# 2. 재귀적 문자 텍스트 분할기 설정
# 줄바꿈(\n\n) -> 단락(\n) -> 띄어쓰기(' ') -> 글자 단위로 우선순위 분할
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,       # 한 청크당 최대 글자 수
    chunk_overlap=100,     # 청크 간 겹치는 중첩 글자 수 (문맥 보존)
    length_function=len,
    separators=["\n\n", "\n", " ", ""]
)

split_docs = text_splitter.split_documents(raw_docs)
print(f"분할된 총 청크 개수: {len(split_docs)} 개")
print(f"[1번 청크 예시]\n{split_docs[0].page_content[:150]}...")
```

(function() {

  }

  sOv.addEventListener('input', render);
  render();
