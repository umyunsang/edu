**LlamaIndex**는 비정형 사내 데이터를 손쉽게 수집(Loading), 구조화된 지식 인덱스로 변환(Indexing), 그리고 자연어 질의응답 인터페이스(Querying)로 제공하는 데이터 중심의 RAG 전용 프레임워크이다.

---

## 1. LlamaIndex 쿼리 엔진의 응답 정제(Refine) 수학적 모델링

### 1) 순차적 반복 정제(Compact & Refine) 합성 수식

검색된 $K$개의 노드 청크 시퀀스 $(N_1, N_2, \dots, N_K)$와 사용자 질문 $q$에 대해, 쿼리 엔진은 첫 번째 노드로 초기 답변 $\hat{y}\_1$을 생성한 뒤 나머지 노드들을 순차적으로 주입하여 답변을 점진적으로 갱신한다:

$$\hat{y}_1 = \text{LLM}\big(\text{prompt}_{\text{init}}(q, N_1)\big)$$

$$\hat{y}_k = \text{LLM}\big(\text{prompt}_{\text{refine}}(\hat{y}_{k-1}, q, N_k)\big), \quad k \in \{2, 3, \dots, K\}$$

최종 응답 $y^\* = \hat{y}\_K$는 전체 $K$개 노드의 지식을 충실히 반영하게 된다.

### 2) 계층적 노드 요약 트리(Summary Tree Index) 집약

부모 노드 임베딩 $\mathbf{e}\_{\text{parent}}$는 하위 $m$개 자식 노드들의 임베딩 벡터 집합의 풀링(Pooling) 또는 요약 연산으로 구성된다:

$$\mathbf{e}_{\text{parent}} = f_{\text{LLM\_Emb}}\left( \text{Summarize}\big( \{N_1, N_2, \dots, N_m\} \big) \right)$$

## 3. LlamaIndex + Faiss 벡터 저장소 파이썬 실습 코드

```python
import os
import faiss
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader, StorageContext
from llama_index.vector_stores.faiss import FaissVectorStore
from dotenv import load_dotenv

load_dotenv()

# 1. 문서 로딩
documents = SimpleDirectoryReader("data").load_data()
print(f"로드된 문서 수: {len(documents)} 개")

# 2. Faiss 1536차원 인덱스 생성 및 LlamaIndex 벡터 스토어 바인딩
d = 1536
faiss_index = faiss.IndexFlatIP(d)
vector_store = FaissVectorStore(faiss_index=faiss_index)
storage_context = StorageContext.from_defaults(vector_store=vector_store)

# 3. 인덱스 빌드 및 질의 엔진 생성
index = VectorStoreIndex.from_documents(
    documents,
    storage_context=storage_context
)

query_engine = index.as_query_engine(similarity_top_k=3)
response = query_engine.query("프로젝트의 핵심 목표와 배포 일정을 요약해줘.")

print("\n=== LlamaIndex 응답 ===")
print(response)
```
