**Streamlit**은 복잡한 프론트엔드(HTML/CSS/JS) 개발 없이 순수 파이썬 코드만으로 직관적인 대시보드와 대화형 RAG 챗봇 서비스를 신속하게 구축할 수 있는 오픈소스 프레임워크이다.

---

## 1. RAG 웹 애플리케이션의 지연 시간(Latency) 수학적 모델링

사용자가 질문을 전송한 시점부터 최종 답변 생성이 완료될 때까지의 총 지연 시간 $T\_{\text{total}}$은 4단계 파이프라인의 합으로 분해된다:

$$T_{\text{total}} = T_{\text{emb}}(q) + T_{\text{ret}}(\mathcal{D}, k) + T_{\text{TTFT}}(q, \mathcal{C}) + \sum_{t=2}^{N_{\text{out}}} T_{\text{TPOT}}^{(t)}$$

- $T\_{\text{emb}}(q)$: 질의 텍스트의 1536차원 임베딩 변환 시간.
- $T\_{\text{ret}}(\mathcal{D}, k)$: 벡터 DB에서의 Top-$k$ 최근접 이웃 탐색 시간.
- $T\_{\text{TTFT}}$: LLM이 프롬프트(질문 + 검색 문맥 $\mathcal{C}$)를 읽고 **첫 번째 토큰을 출력하기까지의 시간(Time To First Token)**.
- $T\_{\text{TPOT}}$: 연속된 **출력 토큰당 생성 시간(Time Per Output Token)**.

실시간 스트리밍(`stream=True`)을 적용하면 사용자가 체감하는 대기 시간은 $T\_{\text{total}}$에서 $T\_{\text{TTFT}}$로 획기적으로 단축된다:

$$\text{Latency Improvement Factor} = \frac{T_{\text{total}}}{T_{\text{TTFT}}} \gg 1$$

## 2. Streamlit 챗봇 핵심 컴포넌트

| 컴포넌트 | 역할 및 사용법 |
| :--- | :--- |
| `st.session_state` | 사용자의 페이지 리로드 간 대화 내역(`messages`) 및 벡터 인덱스 메모리 유지 |
| `st.chat_message("user"/"assistant")` | 말풍선 형태의 대화 블록 렌더링 |
| `st.chat_input("질문을 입력하세요")` | 하단 고정 채팅 입력 인터페이스 |
| `st.spinner("답변 생성 중...")` | LLM 추론 및 검색 중 로딩 인디케이터 표시 |

## 3. Streamlit + LangChain RAG 통합 소스 코드 (`app.py`)

```python
import streamlit as st
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain.chains import create_retrieval_chain
from langchain.chains.combine_documents import create_stuff_documents_chain
from langchain_core.prompts import ChatPromptTemplate
from dotenv import load_dotenv

load_dotenv()

st.set_page_config(page_title="RAG 지능형 Q&A 서비스", page_icon="🤖")
st.title("🤖 사내 문서 기반 지능형 질의응답 시스템")

# 1. 세션 상태 초기화
if "messages" not in st.session_state:
    st.session_state.messages = []

# 2. RAG 체인 캐싱 (반복 로딩 방지)
@st.cache_resource
def get_rag_chain():
    embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
    vectorstore = Chroma(persist_directory="./chroma_db", embedding_function=embeddings)
    retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
    
    system_prompt = (
        "당신은 사내 지식 기반 질의응답 AI입니다. "
        "다음 검색된 문서(context)를 바탕으로 정확하게 답변하세요:\n\n{context}"
    )
    prompt = ChatPromptTemplate.from_messages([
        ("system", system_prompt),
        ("human", "{input}")
    ])
    
    llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.2)
    question_answer_chain = create_stuff_documents_chain(llm, prompt)
    return create_retrieval_chain(retriever, question_answer_chain)

rag_chain = get_rag_chain()

# 3. 이전 대화 기록 렌더링
for msg in st.session_state.messages:
    with st.chat_message(msg["role"]):
        st.markdown(msg["content"])

# 4. 사용자 입력 처리
if user_query := st.chat_input("질문을 입력하세요..."):
    st.session_state.messages.append({"role": "user", "content": user_query})
    with st.chat_message("user"):
        st.markdown(user_query)

    with st.chat_message("assistant"):
        with st.spinner("지식 베이스 검색 및 답변 생성 중..."):
            response = rag_chain.invoke({"input": user_query})
            answer = response["answer"]
            st.markdown(answer)
            
            # 근거 문서 아코디언 표시
            with st.expander("📚 참조한 근거 문서 확인"):
                for i, doc in enumerate(response["context"]):
                    st.write(f"**[문서 {i+1}]** {doc.page_content}")
    
    st.session_state.messages.append({"role": "assistant", "content": answer})
```

(function() {
  var input = document.getElementById('st-input-txt');
  var btn = document.getElementById('st-send-btn');
  var msgBox = document.getElementById('st-msg-box');

  function send() {
    var txt = input.value.trim();
    if (!txt) return;

    // Append User Msg
    var userHtml = '<div style="display:flex;gap:8px;align-items:flex-start;justify-content:flex-end">' +
      '<div style="background:var(--primary);color:#fff;padding:8px 12px;border-radius:8px;max-width:80%">' + txt + '</div>' +

    '</div>';
    msgBox.innerHTML += userHtml;
    input.value = '';
    msgBox.scrollTop = msgBox.scrollHeight;

    // Append Assistant Response after delay
    setTimeout(function() {
      var aiHtml = '<div style="display:flex;gap:8px;align-items:flex-start">' +
        '<div style="width:24px;height:24px;border-radius:50%;background:var(--primary);color:#fff;display:flex;align-items:center;justify-content:center;font-size:11px">AI</div>' +

        '</div>' +
      '</div>';
      msgBox.innerHTML += aiHtml;
      msgBox.scrollTop = msgBox.scrollHeight;
    }, 400);
  }

  btn.addEventListener('click', send);
  input.addEventListener('keypress', function(e) {
    if (e.key === 'Enter') send();
  });
})();
</script>
