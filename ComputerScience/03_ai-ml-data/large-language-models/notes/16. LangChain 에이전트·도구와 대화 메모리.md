\*\*에이전트(Agent)\*\*는 고정된 순서로 실행되는 체인과 달리, LLM이 사용자의 입력 상태를 분석하여 \*\*'생각(Thought) ➔ 행동(Action) ➔ 관찰(Observation)'\*\*의 ReAct 루프를 돌며 자율적으로 외부 도구를 호출하여 문제를 해결한다.

---

## 1. ReAct 에이전트의 상태 전이 수학적 모델링

### 1) 상태 전이 튜플 및 정책 실행

시점 $t$에서의 에이전트 컨텍스트 상태를 $s_t = \big(x, (c_1, a_1, o_1), \dots, (c\_{t-1}, a\_{t-1}, o\_{t-1})\big)$라 하자 ($x$: 원본 질의, $c_i$: 사고(Thought), $a_i$: 행동(Action), $o_i$: 도구 관찰 결과(Observation)).

에이전트의 다음 단계 실행은 다음과 같이 모델링된다:

$$c_t \sim \pi_\theta(\text{thought} \mid s_t)$$

$$a_t \sim \pi_\theta(\text{action} \mid s_t, c_t)$$

$$o_t = \mathcal{E}_{\text{tool}}(a_t)$$

$$s_{t+1} = s_t \mathbin{\Vert} (c_t, a_t, o_t)$$

종료 조건 $a_t = \text{Finish}(y^*)$가 만족될 때까지 이 루프를 반복하며, $y^*$가 최종 답변으로 반환된다.

### 2) 대화 윈도우 메모리(Conversation Window Buffer) 절단

최대 허용 윈도우 크기 $W$에 대해, $k$번째 턴에서의 활성 메모리 집합 $M_k$는 다음과 같다:

$$M_k = \{(u_j, a_j)\}_{j=\max(1, k-W+1)}^k$$

## 3. 에이전트 도구 바인딩 및 메모리 실습 코드

```python
import os
from langchain_openai import ChatOpenAI
from langchain.agents import load_tools, initialize_agent, AgentType
from langchain.memory import ConversationBufferMemory
from dotenv import load_dotenv

load_dotenv()
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 1. 도구(Tools) 로드 (SerpAPI 웹검색, 계산기)
tools = load_tools(["serpapi", "llm-math"], llm=llm)

# 2. 대화 기록 메모리 구성
memory = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True
)

# 3. ReAct 에이전트 초기화
agent = initialize_agent(
    tools=tools,
    llm=llm,
    agent=AgentType.CHAT_CONVERSATIONAL_REACT_DESCRIPTION,
    memory=memory,
    verbose=True # 추론 과정 콘솔 출력
)

query = "현재 서울의 기온을 섭씨로 찾아서, 거기에 5를 곱한 값을 계산해줘."
res = agent.run(query)
print("=== 에이전트 최종 실행 결과 ===")
print(res)
```
