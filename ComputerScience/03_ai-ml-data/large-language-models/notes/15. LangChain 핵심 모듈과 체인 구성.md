**LangChain**은 LLM을 기반으로 복잡한 컴포넌트(프롬프트, 모델, 외부 도구, 데이터베이스)를 모듈화하고 체인(Chain) 형태로 엮어 애플리케이션을 완성하도록 지원하는 대표적인 엔지니어링 프레임워크이다.

---

## 1. 체인 파이프라인의 함수 합성 대수학(Function Composition Algebra)

### 1) 단일 체인의 사상 합성

사용자 입력 공간 $\mathcal{X}$, 프롬프트 공간 $\mathcal{P}$, 원시 모델 출력 공간 $\mathcal{M}$, 최종 파싱 데이터 공간 $\mathcal{Y}$에 대해, 단일 체인은 세 가지 수학적 사상의 순차 합성(Composition)으로 엄밀히 정의된다:

$$f_{\text{chain}} = f_{\text{parser}} \circ f_{\text{model}} \circ f_{\text{prompt}} : \mathcal{X} \to \mathcal{Y}$$

$$y = f_{\text{chain}}(x) = f_{\text{parser}}\Big( f_{\text{model}}\big( f_{\text{prompt}}(x) \big) \Big)$$

### 2) 다단계 순차 체인(Multi-Chain) 전이

선행 체인 $f\_{\text{chain}_1}: \mathcal{X} \to \mathcal{Z}$의 출력 결과를 후행 체인 $f\_{\text{chain}_2}: \mathcal{Z} \to \mathcal{Y}$의 입력 인자로 주입하는 결합 함수:

$$f_{\text{multi}}(x) = \big( f_{\text{chain}_2} \circ f_{\text{chain}_1} \big)(x) = f_{\text{chain}_2}\Big( f_{\text{chain}_1}(x) \Big)$$

## 3. 기본 체인 및 멀티 체인(Multi-Chain) 실습 코드

```python
import os
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser
from dotenv import load_dotenv

load_dotenv()
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.3)
parser = StrOutputParser()

# 1. 단일 체인 (Prompt -> Model -> Parser)
prompt1 = ChatPromptTemplate.from_template("{topic}에 대해 초등학생도 이해할 수 있게 2문장으로 설명해줘.")
chain1 = prompt1 | model | parser

res1 = chain1.invoke({"topic": "블랙홀"})
print("=== 단일 체인 결과 ===")
print(res1)

# 2. 멀티 체인 (체인 1의 출력을 체인 2의 입력으로 연결)
# 체인 1: 주제 설명 생성
# 체인 2: 생성된 한국어 설명을 세련된 영어로 번역
prompt2 = ChatPromptTemplate.from_template("다음 한국어 설명을 자연스러운 영어로 번역해줘:\n\n{korean_text}")
chain2 = prompt2 | model | parser

multi_chain = (
    {"korean_text": chain1}
    | chain2
)

final_res = multi_chain.invoke({"topic": "양자 컴퓨팅"})
print("\n=== 멀티 체인 번역 최종 결과 ===")
print(final_res)
```
