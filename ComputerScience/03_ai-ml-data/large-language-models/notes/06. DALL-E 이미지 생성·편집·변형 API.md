OpenAI의 **Images API**는 자연어 텍스트 프롬프트를 바탕으로 고해상도 이미지를 생성(`generate`), 기존 이미지의 특정 영역을 마스킹하여 수정(`edit`), 또는 원본의 분위기를 유지하며 새로운 구도를 합성(`create_variation`)하는 기능을 제공한다.

---

## 1. DALL-E 확산 모델(Diffusion Model)의 수학적 원리

### 1) 텍스트 조건부 역확산(Reverse Denoising) 샘플링

DALL-E 3는 텍스트 프롬프트 임베딩 $\mathbf{c}$를 조건으로 받아 표준 가우시안 노이즈 $\mathbf{z}\_T \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$로부터 단계적으로 노이즈를 제거하여 고화질 잠재 벡터 $\mathbf{z}\_0$를 복원한다:

$$\mathbf{z}_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( \mathbf{z}_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}} \boldsymbol{\epsilon}_\theta(\mathbf{z}_t, t, \mathbf{c}) \right) + \sigma_t \boldsymbol{\epsilon}$$

여기서 $\alpha_t = 1 - \beta_t$, $\bar{\alpha}_t = \prod_{s=1}^t \alpha_s$, $\boldsymbol{\epsilon}\_\theta$는 U-Net 신경망이 예측한 노이즈 벡터이다.

### 2) 마스크 인페인팅(Inpainting) 영역 합성

수정할 영역을 나타내는 이진 마스크 행렬 $\mathbf{M} \in \{0, 1\}^{H \times W}$ ($1$: 수정 영역, $0$: 원본 유지 영역)에 대해, 각 디노이징 스텝 $t$마다 결합된 잠재 표현 $\mathbf{z}\_t^{\text{mixed}}$은 다음과 같이 합성된다:

$$\mathbf{z}_t^{\text{mixed}} = \mathbf{M} \odot \mathbf{z}_t^{\text{gen}} + (\mathbf{1} - \mathbf{M}) \odot \mathbf{z}_t^{\text{orig}}$$

여기서 $\odot$는 원소별 아다마르 곱(Hadamard Product)이다.

## 2. Images API의 3대 핵심 기능

| 기능 | API 메서드 | 주요 매개변수 | 설명 |
| :--- | :--- | :--- | :--- |
| **텍스트 생성** | `client.images.generate()` | `prompt`, `model`, `size`, `quality`, `style` | 텍스트 지시문으로부터 새로운 이미지 생성 (DALL-E 3 지원) |
| **마스크 편집** | `client.images.edit()` | `image`, `mask`, `prompt`, `size` | 원본 이미지에서 마스크(투명 RGBA) 영역만 프롬프트로 재합성 |
| **이미지 변형** | `client.images.create_variation()` | `image`, `n`, `size` | 원본 이미지의 특징을 보존하며 새로운 구도/스타일 변형 생성 |

## 3. 파이썬 이미지 생성 및 마스킹 편집 실습 코드

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 1. DALL-E 3 텍스트 프롬프트 이미지 생성
gen_response = client.images.generate(
    model="dall-e-3",
    prompt="미래지향적인 스마트 시티의 야경을 그린 사이버펑크 스타일 디지털 아트",
    size="1024x1024",
    quality="standard", # standard 또는 hd
    style="vivid",      # vivid (극적/초현실적) 또는 natural (자연스러운 톤)
    n=1
)
image_url = gen_response.data[0].url
print(f"생성된 이미지 URL: {image_url}")

# 2. 마스크 기반 이미지 편집 (Inpainting) 실습
# 주의: image와 mask는 RGBA 4채널 PNG 파일이어야 함
with open("original.png", "rb") as img_file, open("mask.png", "rb") as mask_file:
    edit_response = client.images.edit(
        model="dall-e-2",
        image=img_file,
        mask=mask_file,
        prompt="맑은 하늘에 떠 있는 붉은색 열기구",
        n=1,
        size="1024x1024"
    )
print(f"편집된 이미지 URL: {edit_response.data[0].url}")
```
