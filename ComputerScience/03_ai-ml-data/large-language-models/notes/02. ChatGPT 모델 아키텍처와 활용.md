ChatGPT는 사용자의 질문 메시지를 입력받아 이전까지 생성된 모든 토큰을 다시 자신의 입력으로 재주입하는 **자기회귀(Autoregressive)** 방식을 통해 유려한 대화형 답변을 생성한다.

## 2. OpenAI 주요 모델 엔진 비교

| 모델 엔진 | 주요 특징 | 컨텍스트 윈도우 | 주요 활용 사례 | 비용 특성 |
| :--- | :--- | :--- | :--- | :--- |
| `gpt-3.5-turbo` | 빠르고 경제적인 대화형 표준 | $16\text{K}$ 토큰 | 고객지원 챗봇, 일반 질의응답 | 저비용 ($\sim \$0.50 / 1\text{M}$) |
| `gpt-4o-mini` | 고지능 경량화 멀티모달 모델 | $128\text{K}$ 토큰 | 모바일 앱, 실시간 고속 API | 초저비용 ($\sim \$0.15 / 1\text{M}$) |
| `gpt-4o` | 텍스트·시각·음성 통합 플래그십 | $128\text{K}$ 토큰 | 복잡한 코딩, 다국어 심층 추론 | 중비용 ($\sim \$2.50 / 1\text{M}$) |
| `o1` / `o1-mini` | 다단계 CoT 사고 추론 모델 | $200\text{K}$ 토큰 | 알고리즘 설계, 수학·과학 연구 | 고비용 ($\sim \$15.00 / 1\text{M}$) |

## 3. ChatGPT 활용의 4대 한계 및 대응 전략

1. **환각 현상 (Hallucination)**: 존재하지 않는 사실을 그럴듯하게 날조 ➔ **RAG(검색 증강 생성) 또는 Few-shot 예시 주입으로 해결**.
2. **지식 컷오프 (Knowledge Cutoff)**: 모델이 학습된 시점 이후의 최신 정보 부재 ➔ **실시간 검색 API 연동**.
3. **복잡한 수학 및 논리 연산 오류**: 토큰 확률 기반 생성으로 인한 계산 취약성 ➔ **코드 인터프리터(Code Interpreter) 또는 `o1` 추론 모델 활용**.
4. **데이터 보안 및 프라이버시**: 민감 기업 데이터 유출 우려 ➔ **Enterprise Zero Data Retention 정책 및 로컬 LLM(Ollama) 도입**.
