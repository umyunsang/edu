자연어 처리(Natural Language Processing)는 이산적인 기호(Symbolic) 처리에서 시작하여, 단어 간 의미적 유사도를 연속 벡터로 표현하는 **분산 표상(Distributed Representation)**과 시퀀스의 정보 병목을 해결한 **어텐션(Attention)**으로 혁신되었다.

## 2. 바흐다나우(Bahdanau) 가산 어텐션 공식

디코더의 $i$번째 상태 $s_i$와 인코더의 $j$번째 상태 $h_j$ 사이의 정렬 점수(Score) 및 어텐션 가중치 $\alpha_{ij}$:

$$e_{ij} = v_a^T \tanh\left( W_a s_{i-1} + U_a h_j \right), \qquad \alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_x} \exp(e_{ik})}$$

## 3. 인터랙티브 영어 ➔ 한국어 번역 어텐션 가중치($\alpha_{ij}$) 히트맵

(function() {
  var srcWords = ['The', 'quantum', 'computer', 'processes', 'data'];
  var weights = [
