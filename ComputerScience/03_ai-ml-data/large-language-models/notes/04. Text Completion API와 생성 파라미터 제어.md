**Text Completion API**는 단일 텍스트 프롬프트를 입력받아 모델이 학습한 언어 패턴에 따라 뒤이어 올 가장 적절한 텍스트를 완성(Completion)하는 전통적인 생성 엔드포인트이다.

---

## 1. Text Completion API 핵심 파라미터 명세

| 매개변수 | 데이터 타입 | 기본값 | 기능 및 동작 원리 |
| :--- | :--- | :--- | :--- |
| `model` | `string` | 필수 | 사용할 모델 이름 (예: `gpt-3.5-turbo-instruct`) |
| `prompt` | `string` / `list` | 필수 | 모델이 이어서 작성할 시작 프롬프트 텍스트 |
| `temperature` | `float` | `1.0` | 샘플링 무작위성 ($0.0$: 결정론적/정확함, $2.0$: 극도의 창의성) |
| `top_p` | `float` | `1.0` | 핵 샘플링(Nucleus Sampling) 누적 확률 임계값 |
| `max_tokens` | `integer` | `16` | 생성할 최대 토큰 수 |
| `frequency_penalty` | `float` | `0.0` | 기존 등장 빈도에 비례하여 동일 단어 반복 억제 ($-2.0 \sim 2.0$) |
| `presence_penalty` | `float` | `0.0` | 이미 한 번 등장한 주제를 피하고 새로운 주제 도입 유도 ($-2.0 \sim 2.0$) |
| `stop` | `string` / `list` | `null` | 출력을 즉시 중단할 종료 시퀀스 (최대 4개) |
| `n` | `integer` | `1` | 단일 요청당 생성할 후보 응답 개수 |
| `stream` | `boolean` | `false` | 생성 진행 과정을 청크(Chunk) 단위로 실시간 스트리밍 |

---

## 2. 목적별 권장 파라미터 조합표

1. **사실 기반 정확하고 간결한 응답 (FAQ, 기술 요약, 번역)**:
   - `temperature = 0.2`, `frequency_penalty = 0.0`, `presence_penalty = 0.0`
2. **창의적이고 독창적인 텍스트 생성 (스토리 작성, 시, 브레인스토밍)**:
   - `temperature = 1.5`, `frequency_penalty = 0.5`, `presence_penalty = 1.5`
3. **중복을 피하면서 적절한 창의성 유지 (블로그 아티클, 마케팅 문구)**:
   - `temperature = 1.0`, `frequency_penalty = 1.0`, `presence_penalty = 1.0`

## 3. 질의응답·요약·번역 실습 코드

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 1. 질의응답 실습
qa_response = client.completions.create(
    model="gpt-3.5-turbo-instruct",
    prompt="인공지능의 정의와 핵심 기술에 대해 알려주세요.",
    temperature=0.2,
    max_tokens=300
)
print("=== 질의응답 결과 ===")
print(qa_response.choices[0].text.strip())

# 2. 한-영 번역 실습
trans_prompt = """한국어를 영어로 번역합니다.
한국어: 대한민국의 민주주의는 국민이 지킵니다.
영어:"""

trans_response = client.completions.create(
    model="gpt-3.5-turbo-instruct",
    prompt=trans_prompt,
    temperature=0.0,
    max_tokens=100
)
print("\n=== 번역 결과 ===")
print(trans_response.choices[0].text.strip())

# 3. 토큰 사용량 확인
print("\n=== Token Usage ===")
print(f"Prompt Tokens: {trans_response.usage.prompt_tokens}")
print(f"Completion Tokens: {trans_response.usage.completion_tokens}")
print(f"Total Tokens: {trans_response.usage.total_tokens}")
```

## 5. 인터랙티브 Temperature & Top-P 토큰 확률 분포 시뮬레이터

Temperature($T$)와 Top-P($p$)를 슬라이더로 조작하면 다음 토큰 후보들의 확률 분포 소프트맥스($\text{softmax}(z_i / T)$)가 실시간으로 변형된다.

```html preview

  <!-- 슬라이더 컨트롤 -->
  <div style="display:grid;grid-template-columns:1fr 1fr;gap:12px;margin-bottom:14px">
    <div>
      <div style="display:flex;justify-content:space-between;font-size:12px;font-weight:600;margin-bottom:4px">
        <span>Temperature (T):</span>
        <span id="cmp-temp-val" style="color:var(--primary);font-weight:700">0.70</span>
      </div>
      <input id="cmp-temp-slider" type="range" min="0.1" max="2.0" step="0.1" value="0.7" style="width:100%;accent-color:var(--primary)" />
    </div>

    <div>
      <div style="display:flex;justify-content:space-between;font-size:12px;font-weight:600;margin-bottom:4px">
        <span>Top-P (Nucleus Sampling):</span>
        <span id="cmp-topp-val" style="color:var(--chart-2);font-weight:700">0.90 (상위 90%)</span>
      </div>
      <input id="cmp-topp-slider" type="range" min="0.1" max="1.0" step="0.05" value="0.9" style="width:100%;accent-color:var(--primary)" />
    </div>
  </div>

  <!-- 토큰 후보군 확률 바 차트 -->
  <div style="background:var(--background);border:2px dashed var(--border);border-radius:var(--radius);padding:14px">
    <div style="font-size:11px;color:var(--muted-foreground);margin-bottom:8px">다음 생성 토큰 후보 확률 (Softmax with T & Top-P Cutoff):</div>
    <div id="cmp-bars-container" style="display:flex;flex-direction:column;gap:6px"></div>
  </div>
</div>

<script>
(function() {
  var tokens = [
    { text: '"데이터"', logit: 3.5 },
    { text: '"알고리즘"', logit: 2.8 },
    { text: '"모델"', logit: 2.2 },
    { text: '"컴퓨터"', logit: 1.4 },
    { text: '"우주선"', logit: 0.2 }
  ];

  var sT = document.getElementById('cmp-temp-slider');
  var sP = document.getElementById('cmp-topp-slider');
  var tVal = document.getElementById('cmp-temp-val');
  var pVal = document.getElementById('cmp-topp-val');
  var container = document.getElementById('cmp-bars-container');

  function render() {
    var T = parseFloat(sT.value);
    var P = parseFloat(sP.value);

    tVal.textContent = T.toFixed(1);
    pVal.textContent = P.toFixed(2) + ' (' + (P * 100).toFixed(0) + '%)';

    // Softmax with temperature
    var exps = tokens.map(function(t) { return Math.exp(t.logit / T); });
    var sumExp = exps.reduce(function(a, b) { return a + b; }, 0);
    var probs = exps.map(function(e) { return e / sumExp; });

    // Top-P filtering
    var cumSum = 0;
    var valid = [];
    for (var i = 0; i < probs.length; i++) {
      cumSum += probs[i];
      valid.push(cumSum <= P || i === 0);
    }

    container.innerHTML = '';
    tokens.forEach(function(t, idx) {
      var p = probs[idx];
      var isIncluded = valid[idx];

      var row = document.createElement('div');
      row.style.display = 'grid';
      row.style.gridTemplateColumns = '70px 1fr 60px';
      row.style.alignItems = 'center';
      row.style.gap = '8px';

      var lbl = document.createElement('div');
      lbl.style.fontSize = '11px';
      lbl.style.fontWeight = '700';
      lbl.style.color = isIncluded ? 'var(--foreground)' : 'var(--muted-foreground)';
      lbl.textContent = t.text;

      var barBg = document.createElement('div');
      barBg.style.height = '12px';
      barBg.style.background = 'var(--card)';
      barBg.style.borderRadius = '2px';
      barBg.style.overflow = 'hidden';

      var barFill = document.createElement('div');
      barFill.style.height = '100%';
      barFill.style.width = (p * 100).toFixed(1) + '%';
      barFill.style.background = isIncluded ? (idx === 0 ? 'var(--primary)' : 'var(--chart-2)') : 'var(--muted)';
      barBg.appendChild(barFill);

      var num = document.createElement('div');
      num.style.fontSize = '10px';
      num.style.textAlign = 'right';
      num.style.fontWeight = '700';
      num.style.color = isIncluded ? 'var(--foreground)' : 'var(--muted-foreground)';
      num.textContent = (p * 100).toFixed(1) + '%' + (isIncluded ? '' : ' (컷)');

      row.appendChild(lbl);
      row.appendChild(barBg);
      row.appendChild(num);
      container.appendChild(row);
    });
  }

  sT.addEventListener('input', render);
  sP.addEventListener('input', render);
  render();
})();
</script>
```
