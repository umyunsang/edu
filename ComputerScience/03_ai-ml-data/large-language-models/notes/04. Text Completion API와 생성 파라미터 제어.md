**Text Completion API**는 단일 텍스트 프롬프트를 입력받아 모델이 학습한 언어 패턴에 따라 뒤이어 올 가장 적절한 텍스트를 완성(Completion)하는 전통적인 생성 엔드포인트이다.

---

## 1. 텍스트 생성 하이퍼파라미터의 수학적 모델링

### 1) 온도(Temperature) 기반 소프트맥스 스케일링

언어 모델의 마지막 계층에서 계산된 어휘 집합 로짓(Logit) 벡터 $\mathbf{z} \in \mathbb{R}^{|V|}$에 대해 온도 매개변수 $T > 0$가 적용된 다음 토큰 확률 분포는 다음과 같다:

$$P(w_i \mid \mathbf{z}, T) = \frac{\exp(z_i / T)}{\sum_{j=1}^{|V|} \exp(z_j / T)}$$

- $T \to 0$: 가장 큰 로짓을 가진 단어의 확률이 1에 수렴하여 **결정론적(Argmax / Greedy) 탐색** 수행.
- $T = 1.0$: 모델의 기본 학습 확률 분포 유지.
- $T > 1.0$: 확률 분포가 평탄화(Flatten)되어 다양한 토큰이 샘플링되는 **창의적 생성** 유도.

### 2) Top-$p$ 핵 샘플링 (Nucleus Sampling)

확률이 높은 순서로 정렬된 후보 단어들의 누적 확률이 임계값 $p \in (0, 1]$에 도달할 때까지의 최소 단어 부분집합 $V^{(p)} \subseteq V$를 선택한다:

$$V^{(p)} = \arg\min_{S \subseteq V} |S| \quad \text{s.t.} \quad \sum_{w \in S} P(w) \ge p$$

선택된 집합 $V^{(p)}$ 내에서 확률을 재정규화(Re-normalization)하여 샘플링을 진행함으로써 신뢰성 없는 꼬리(Tail) 분포를 동적으로 차단한다.

### 3) 로짓 페널티 보정 (Frequency & Presence Penalty)

동일 단어의 과도한 반복을 억제하고 새로운 주제 도입을 장려하기 위해 로짓 $z_i$를 다음과 같이 보정한다:

$$z_i' = z_i - \alpha \cdot \text{count}(w_i) - \beta \cdot \mathbb{I}(\text{count}(w_i) > 0)$$

여기서 $\alpha = \text{frequency\_penalty}$, $\beta = \text{presence\_penalty}$, $\mathbb{I}(\cdot)$는 지시 함수(Indicator Function)이다.

## 2. Text Completion API 핵심 파라미터 명세

| 매개변수 | 데이터 타입 | 기본값 | 기능 및 동작 원리 |
| :--- | :--- | :--- | :--- |
| `model` | `string` | 필수 | 사용할 모델 이름 (예: `gpt-3.5-turbo-instruct`) |
| `prompt` | `string` / `list` | 필수 | 모델이 이어서 작성할 시작 프롬프트 텍스트 |
| `temperature` | `float` | `1.0` | 샘플링 무작위성 ($0.0$: 결정론적, $2.0$: 극도의 창의성) |
| `top_p` | `float` | `1.0` | 핵 샘플링(Nucleus Sampling) 누적 확률 임계값 |
| `max_tokens` | `integer` | `16` | 생성할 최대 토큰 수 |
| `frequency_penalty` | `float` | `0.0` | 기존 등장 빈도에 비례하여 동일 단어 반복 억제 ($-2.0 \sim 2.0$) |
| `presence_penalty` | `float` | `0.0` | 이미 한 번 등장한 주제를 피하고 새로운 주제 도입 유도 ($-2.0 \sim 2.0$) |
| `stop` | `string` / `list` | `null` | 출력을 즉시 중단할 종료 시퀀스 (최대 4개) |
| `n` | `integer` | `1` | 단일 요청당 생성할 후보 응답 개수 |
| `stream` | `boolean` | `false` | 생성 진행 과정을 청크(Chunk) 단위로 실시간 스트리밍 |

## 3. 목적별 권장 파라미터 조합표

1. **사실 기반 정확하고 간결한 응답 (FAQ, 기술 요약, 번역)**:
   - `temperature = 0.2`, `frequency_penalty = 0.0`, `presence_penalty = 0.0`
2. **창의적이고 독창적인 텍스트 생성 (스토리 작성, 시, 브레인스토밍)**:
   - `temperature = 1.5`, `frequency_penalty = 0.5`, `presence_penalty = 1.5`
3. **중복을 피하면서 적절한 창의성 유지 (블로그 아티클, 마케팅 문구)**:
   - `temperature = 1.0`, `frequency_penalty = 1.0`, `presence_penalty = 1.0`

## 4. 질의응답·요약·번역 실습 코드

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# 1. 질의응답 실습
qa_response = client.completions.create(
    model="gpt-3.5-turbo-instruct",
    prompt="인공지능의 정의와 핵심 기술에 대해 알려주세요.",
    temperature=0.2,
    max_tokens=300
)
print("=== 질의응답 결과 ===")
print(qa_response.choices[0].text.strip())

# 2. 한-영 번역 실습
trans_prompt = """한국어를 영어로 번역합니다.
한국어: 대한민국의 민주주의는 국민이 지킵니다.
영어:"""

trans_response = client.completions.create(
    model="gpt-3.5-turbo-instruct",
    prompt=trans_prompt,
    temperature=0.0,
    max_tokens=100
)
print("\n=== 번역 결과 ===")
print(trans_response.choices[0].text.strip())

# 3. 토큰 사용량 확인
print("\n=== Token Usage ===")
print(f"Prompt Tokens: {trans_response.usage.prompt_tokens}")
print(f"Completion Tokens: {trans_response.usage.completion_tokens}")
print(f"Total Tokens: {trans_response.usage.total_tokens}")
```

<script>
(function() {
  var sTemp = document.getElementById('param-temp-slider');
  var sTopP = document.getElementById('param-topp-slider');
  var vTemp = document.getElementById('param-temp-val');
  var vTopP = document.getElementById('param-topp-val');
  var chart = document.getElementById('param-token-chart');

  var rawLogits = [
    { token: '데이터(Data)', logit: 4.5 },
    { token: '알고리즘(Algorithm)', logit: 3.8 },
    { token: '신경망(Neural Net)', logit: 3.2 },
    { token: '컴퓨터(Computer)', logit: 2.1 },
    { token: '바나나(Banana)', logit: 0.5 }
  ];

  function render() {
    var T = parseFloat(sTemp.value);
    var topP = parseFloat(sTopP.value);

    vTemp.textContent = T.toFixed(2);
    vTopP.textContent = topP.toFixed(2);

    // 1. Softmax with Temperature
    var expLogits = rawLogits.map(function(item) {
      return { token: item.token, val: Math.exp(item.logit / T) };
    });
    var sumExp = expLogits.reduce(function(acc, cur) { return acc + cur.val; }, 0);
    var probs = expLogits.map(function(item) {
      return { token: item.token, p: item.val / sumExp };
    });

    // 2. Top-P Cutoff
    var cumSum = 0;
    var html = '';

    probs.forEach(function(item) {
      cumSum += item.p;
      var inTopP = (cumSum - item.p < topP);
      var pct = (item.p * 100).toFixed(1);

      var color = inTopP ? 'var(--primary)' : 'var(--muted-foreground)';
      var badge = inTopP ? '<span style="color:var(--chart-2);font-weight:700">✓ 포함</span>' : '<span style="color:var(--destructive)">✗ 제외(Top-P)</span>';

      html += '<div style="display:flex;align-items:center;gap:8px;font-size:11px">' +
        '<span style="width:120px;font-weight:600;color:var(--foreground)">' + item.token + '</span>' +
        '<div style="flex:1;background:var(--card);height:14px;border-radius:4px;overflow:hidden;border:1px solid var(--border)">' +
          '<div style="width:' + pct + '%;height:100%;background:' + color + '"></div>' +
        '</div>' +
        '<span style="width:45px;text-align:right;font-weight:700;color:var(--foreground)">' + pct + '%</span>' +
        '<span style="width:70px;text-align:right;font-size:10px">' + badge + '</span>' +
      '</div>';
    });

    chart.innerHTML = html;
  }

  sTemp.addEventListener('input', render);
  sTopP.addEventListener('input', render);
  render();
})();
</script>
