## 학습 시 확인할 것

- 프롬프트로 해결할 문제와 추가 학습이 필요한 문제를 구분한다.
- 데이터에서 학습해야 할 속성과 우연히 반복된 속성을 분리한다.
- 생성 결과의 시각적 인상과 실제 사용 가능성·성능을 나누어 평가한다.
- 원문에 있는 표기 오류는 해당 노트 안에서 별도로 표시한다.
