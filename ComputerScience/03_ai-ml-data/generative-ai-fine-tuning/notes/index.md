* [01. 생성형 AI 생태계와 멀티모달 디자인 혁신 - 파운데이션 모델, T2I 확산 모델과 인터페이스 제어](./01.%20%EC%83%9D%EC%84%B1%ED%98%95%20AI%20%EC%83%9D%ED%83%9C%EA%B3%84%EC%99%80%20%EB%A9%80%ED%8B%B0%EB%AA%A8%EB%8B%AC%20%EB%94%94%EC%9E%90%EC%9D%B8%20%ED%98%81%EC%8B%A0%20-%20%ED%8C%8C%EC%9A%B4%EB%8D%B0%EC%9D%B4%EC%85%98%20%EB%AA%A8%EB%8D%B8%2C%20T2I%20%ED%99%95%EC%82%B0%20%EB%AA%A8%EB%8D%B8%EA%B3%BC%20%EC%9D%B8%ED%84%B0%ED%8E%98%EC%9D%B4%EC%8A%A4%20%EC%A0%9C%EC%96%B4.md) - 텍스트·이미지·3D를 아우르는 생성형 AI(Generative AI)의 발전사, 파운데이션 모델(Foundation Models)의 스케일링 법칙, Text-to-Image(T2I) 잠재 확산 모델(Latent Diffusion Models - Stable Diffusion), 멀티모달 프롬프트 엔지니어링, 그리고 건축·제품·엔터테인먼트 산업에서의 비주얼 디자인 탐색 워크플로를 인터랙티브 잠재 확산 노이즈 제거 시뮬레이터로 학습한다.
* [01. 생성형 AI와 파인튜닝 - LLM 진화와 3단계 학습 파이프라인 (Generative AI & Fine-Tuning)](./01.%20%EC%83%9D%EC%84%B1%ED%98%95%20AI%EC%99%80%20%ED%8C%8C%EC%9D%B8%ED%8A%9C%EB%8B%9D.md) - 생성형 AI 모델의 진화 과정, 대규모 사전학습(Pretraining) ➔ 지도 미세조정(SFT) ➔ 인간 피드백 정렬(RLHF/DPO)의 3단계 파이프라인, 풀 파인튜닝과 PEFT의 연산 비용 비교를 인터랙티브 파인튜닝 메모리 계산기로 심층 학습한다.
* [02. 매개변수 효율적 미세조정(PEFT)과 LoRA 수학적 원리 - 저차원 행렬 분해(W = W0 + BA), 랭크 r과 스케일링 알파](./02.%20%EB%A7%A4%EA%B0%9C%EB%B3%80%EC%88%98%20%ED%9A%A8%EC%9C%A8%EC%A0%81%20%EB%AF%B8%EC%84%B8%EC%A1%B0%EC%A0%95%28PEFT%29%EA%B3%BC%20LoRA%20%EC%88%98%ED%95%99%EC%A0%81%20%EC%9B%90%EB%A6%AC%20-%20%EC%A0%80%EC%B0%A8%EC%9B%90%20%ED%96%89%EB%A0%AC%20%EB%B6%84%ED%95%B4%28W%20%3D%20W0%20%2B%20BA%29%2C%20%EB%9E%AD%ED%81%AC%20r%EA%B3%BC%20%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81%20%EC%95%8C%ED%8C%8C.md) - 거대언어모델 및 확산 모델의 전체 가중치 파인튜닝(Full Fine-Tuning)의 엄청난 메모리 비용을 해결하는 PEFT(Parameter-Efficient Fine-Tuning), 저차원 행렬 분해 LoRA(Low-Rank Adaptation: W = W0 + Delta W = W0 + (alpha / r) * B * A, B in R^(d x r), A in R^(r x k), r << min(d,k)), 랭크 r과 스케일링 팩터 alpha의 수학적 상호작용, 그리고 추론 시 서빙 오버헤드가 전혀 없는 Zero Inference Latency 병합 공식을 인터랙티브 LoRA 파라미터 절감 계산기로 학습한다.
* [03. 이미지 생성 모델 LoRA 학습과 실전 튜닝 - Stable Diffusion Checkpoint, 캡셔닝 태깅과 체크포인트 병합](./03.%20%EC%9D%B4%EB%AF%B8%EC%A7%80%20%EC%83%9D%EC%84%B1%20%EB%AA%A8%EB%8D%B8%20LoRA%20%ED%95%99%EC%8A%B5%EA%B3%BC%20%EC%8B%A4%EC%A0%84%20%ED%8A%9C%EB%8B%9D%20-%20Stable%20Diffusion%20Checkpoint%2C%20%EC%BA%A1%EC%85%94%EB%8B%9D%20%ED%83%9C%EA%B9%85%EA%B3%BC%20%EC%B2%B4%ED%81%AC%ED%8F%AC%EC%9D%B8%ED%8A%B8%20%EB%B3%91%ED%95%A9.md) - Stable Diffusion WebUI 및 Kohya-ss 기반 이미지 LoRA 학습 실전 파이프라인, 고품질 데이터셋 구축(해상도 512/1024 버킷팅, 이미지 크롭 및 정제), 자동 캡셔닝(BLIP / WD14 Tagger)과 트리거 워드(Trigger Word) 주입, 네트워크 랭크(Network Dim / Alpha) 및 학습률(UNet LR vs TE LR) 설정, 그리고 다양한 화풍/캐릭터 어댑터를 결합하는 가중치 병합(LoRA Merge & Weight Blending)을 인터랙티브 LoRA 가중치 블렌더 시뮬레이터로 학습한다.
* [15. 멀티모달 생성 워크플로 - 잠재 확산 모델과 Cross-Attention 메커니즘 (Latent Diffusion Models)](./15.%20%EB%A9%80%ED%8B%B0%EB%AA%A8%EB%8B%AC%20%EC%83%9D%EC%84%B1%20%EC%9B%8C%ED%81%AC%ED%94%8C%EB%A1%9C.md) - 텍스트-투-이미지(Text-to-Image) 생성을 위한 잠재 확산 모델(LDM/Stable Diffusion)의 3대 핵심 모듈(CLIP 텍스트 인코더, VAE 인코더/디코더, UNet/DiT 디노이저)과 Cross-Attention 원리를 인터랙티브 디노이징 스텝 시뮬레이터로 심층 학습한다.
* [26. 디자인 탐색과 제어 - ControlNet 공간 제어와 IP-Adapter 일관성 유지 (ControlNet & Conditioning)](./26.%20%EB%94%94%EC%9E%90%EC%9D%B8%20%ED%83%90%EC%83%89%EA%B3%BC%20%EC%A0%9C%EC%96%B4.md) - 확산 모델의 생성 제어력을 극대화하는 ControlNet(Zero Convolution, Canny/Depth/OpenPose 전처리기)과 IP-Adapter(Decoupled Cross-Attention 이미지 프롬프트)의 수학적 원리를 인터랙티브 조건화 가중치 시뮬레이터로 심층 학습한다.

LoRA와 파라미터 효율 미세조정 - 저순위 분해와 QLoRA 양자화 기술 (LoRA & QLoRA)](./40.%20LoRA%EC%99%80%20%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0%20%ED%9A%A8%EC%9C%A8%20%EB%AF%B8%EC%84%B8%EC%A1%B0%EC%A0%95.md) - 사전학습 가중치 동결 후 저순위 행렬 B·A를 학습하는 LoRA(Low-Rank Adaptation)의 수학적 원리, 스케일링 팩터 α/r, 그리고 4-bit NormalFloat(NF4) 기반 QLoRA 기법을 인터랙티브 LoRA 파라미터 계산기로 심층 학습한다.
