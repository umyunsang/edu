이미지 LoRA(Image LoRA) 훈련은 소수(15 ~ 30장)의 타겟 이미지로 특정 인물, 캐릭터, 화풍(Art Style)을 확산 모델에 주입하면서도, 사전학습된 지식을 잊지 않도록 **정규화 데이터셋(Prior Preservation / Class Regularization)**을 병행 훈련하는 기법이다.

---

## 1. 언어 표류(Language Drift) 방지를 위한 2중 손실 함수

타겟 인물 이미지($x$)와 일반 클래스 정규화 이미지($x_{\text{reg}}$)를 동시에 훈련하여 원본 클래스(예: `a person`)의 일반적 개념이 파괴되는 것을 방지:

$$\mathcal{L}_{\text{total}} = \mathbb{E}\left[ \|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\mathbf{z}_t, t, c_{\text{target}})\|^2 \right] + \lambda_{\text{prior}} \mathbb{E}\left[ \|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\mathbf{z}_{t, \text{reg}}, t, c_{\text{class}})\|^2 \right]$$

## 2. 인터랙티브 LoRA 가중치(Weight Multiplier) 블렌딩 시뮬레이터

(function() {

    }
  }

  s1.addEventListener('input', render);
  s2.addEventListener('input', render);
  render();
})();
