## 2. Catalyst 최적화 엔진과 Tungsten 프로젝트

Spark SQL은 사용자가 작성한 SQL 쿼리나 DataFrame 코드를 **Catalyst Optimizer**를 통해 4단계(Analysis $\to$ Logical Optimization $\to$ Physical Planning $\to$ Code Generation)로 최적화한다:
1. **조건절 푸시다운(Predicate Pushdown)**: 필터 조건을 데이터 소스(Parquet 파일 등) 레벨로 내려 읽기 I/O 대폭 절감.
2. **프로젝션 프루닝(Projection Pruning)**: 필요한 열(Column)만 선택적으로 로드.
3. **Tungsten 프로젝트**: JVM GC 오버헤드를 우회하는 오프힙(Off-heap) 바이너리 메모리 관리 및 런타임 바이트코드 생성(Whole-Stage CodeGen).
