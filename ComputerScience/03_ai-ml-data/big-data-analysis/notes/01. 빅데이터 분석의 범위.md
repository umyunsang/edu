빅데이터(Big Data)는 기존의 단일 데이터베이스 관리 시스템(RDBMS)의 용량 한계와 처리 속도를 초과하는 거대한 데이터 집합으로, 분산 병렬 컴퓨팅 프레임워크를 기반으로 수집·저장·처리·분석·시각화되는 종합적인 데이터 생태계를 의미한다.

1. **데이터(Data)**: 가공되지 않은 순수한 객관적 사실 및 측정값 (예: 센서 수치 $28.5^\circ\text{C}$).
2. **정보(Information)**: 데이터에 문맥(Context)과 의미를 부여하여 가공한 결과 (예: 현재 서버실 온도가 $28.5^\circ\text{C}$로 평상시보다 높음).
3. **지식(Knowledge)**: 축적된 정보 간의 상관관계와 규칙을 체계화 (예: 서버실 온도가 $30^\circ\text{C}$를 초과하면 서버 다운 위험 $80\%$ 증가).
4. **지혜(Wisdom)**: 지식을 기반으로 미래를 예측하고 올바른 의사결정을 수행 (예: 냉각 칠러를 즉시 가동하고 부하를 백업 클러스터로 분산).
