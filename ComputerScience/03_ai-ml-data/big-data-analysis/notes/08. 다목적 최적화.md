현실의 빅데이터 및 MLOps 엔지니어링 문제에서는 단일 목적 함수가 아닌 **서로 상충(Trade-off)하는 여러 목적**(예: 클라우드 서버 비용 $f_1$ 최소화 vs 모델 추론 지연 시간 $f_2$ 최소화)을 동시에 최적화해야 한다.

---

## 1. 파레토 지배 (Pareto Dominance)와 파레토 프론트의 수학적 정의

벡터 목적 함수 $\mathbf{F}(\mathbf{x}) = (f_1(\mathbf{x}), f_2(\mathbf{x}), \dots, f_k(\mathbf{x}))^T$에 대하여:

### 1) 파레토 지배 ($\mathbf{u} \prec \mathbf{v}$)

해 $\mathbf{u}$가 $\mathbf{v}$를 지배한다는 것은 다음 두 조건을 모두 만족함을 의미한다:

1. 모든 목적 $i$에 대해 $\mathbf{u}$가 $\mathbf{v}$보다 나쁘지 않음: $\forall i \in \{1,\dots,k\}, f_i(\mathbf{u}) \le f_i(\mathbf{v})$
2. 적어도 하나의 목적 $j$에 대해 $\mathbf{u}$가 $\mathbf{v}$보다 엄격히 우수함: $\exists j \in \{1,\dots,k\}, f_j(\mathbf{u}) < f_j(\mathbf{v})$

### 2) 파레토 최적해 (Pareto Optimality)

다른 어떤 해에 의해서도 지배당하지 않는 비지배 해(Non-dominated Solution)들의 집합을 **파레토 집합(Pareto Set)**이라 하며, 이를 목적 공간에 투영한 곡면을 **파레토 프론트(Pareto Frontier)**라 부른다.

---

## 2. 인터랙티브 2목적(비용 vs 지연시간) 파레토 프론트 시뮬레이터

가중치 $w_1$ (비용 중요도)과 $w_2 = 1 - w_1$ (지연시간 중요도)을 조절하면 가중치 총합법 $\min [w_1 f_1 + w_2 f_2]$에 의해 파레토 프론트 곡선 상에서 선택되는 최적 타협점(Trade-off Point)이 실시간으로 계산된다.

(function() {
  var sW = document.getElementById('mo-w-slider');
  var wVal = document.getElementById('mo-w-val');
  var f1Txt = document.getElementById('mo-f1-txt');
  var f2Txt = document.getElementById('mo-f2-txt');
  var descTxt = document.getElementById('mo-desc-txt');
  var svg = document.getElementById('mo-svg');

  function render() {
    var w1 = parseFloat(sW.value);
    var w2 = 1.0 - w1;
    wVal.textContent = 'w₁ = ' + w1.toFixed(2) + ' (비용) | w₂ = ' + w2.toFixed(2) + ' (속도)';

    // 파레토 프론트 곡선: f1 * f2 = 10000 (f2 = 10000 / f1)
    // f1 범위: 100 ~ 500
    // min [w1 * f1 + w2 * (10000 / f1)] ➔ f1* = sqrt(10000 * w2 / w1)
    var optF1 = Math.sqrt(10000.0 * w2 / w1);
    optF1 = Math.max(100, Math.min(500, optF1));
    var optF2 = 10000.0 / optF1;

    f1Txt.textContent = '$ ' + optF1.toFixed(0);
    f2Txt.textContent = optF2.toFixed(1) + ' ms';

    if (w1 > 0.7) {
      descTxt.textContent = '비용 최우선 절감형'; descTxt.style.color = 'var(--chart-1)';
    } else if (w1 < 0.3) {
      descTxt.textContent = '초저지연 고성능형'; descTxt.style.color = 'var(--chart-2)';
    } else {
      descTxt.textContent = '균형 잡힌 타협안'; descTxt.style.color = 'var(--primary)';
    }

    // SVG 렌더링
    svg.innerHTML = '';
    var ox = 40, oy = 130, wBox = 270, hBox = 110;

    // 축
    var axX = document.createElementNS('http://www.w3.org/2000/svg', 'line');
    axX.setAttribute('x1', ox); axX.setAttribute('y1', oy);
    axX.setAttribute('x2', ox + wBox); axX.setAttribute('y2', oy);
    axX.setAttribute('stroke', 'var(--border)');
    svg.appendChild(axX);

    var axY = document.createElementNS('http://www.w3.org/2000/svg', 'line');
    axY.setAttribute('x1', ox); axY.setAttribute('y1', oy - hBox);
    axY.setAttribute('x2', ox); axY.setAttribute('y2', oy);
    axY.setAttribute('stroke', 'var(--border)');
    svg.appendChild(axY);

    // 파레토 프론트 곡선 Path
    var dPath = '';
    for (var f1 = 100; f1 <= 500; f1 += 10) {
      var f2 = 10000.0 / f1;
      var px = ox + ((f1 - 100) / 400.0) * wBox;
      var py = oy - ((f2 - 20) / 80.0) * hBox;
      dPath += (f1 === 100 ? 'M ' : ' L ') + px + ' ' + py;
    }

    var path = document.createElementNS('http://www.w3.org/2000/svg', 'path');
    path.setAttribute('d', dPath);
    path.setAttribute('fill', 'none');
    path.setAttribute('stroke', 'var(--primary)');
    path.setAttribute('stroke-width', '2.5');
    svg.appendChild(path);

    // 최적점 Dot
    var curX = ox + ((optF1 - 100) / 400.0) * wBox;
    var curY = oy - ((optF2 - 20) / 80.0) * hBox;

    var dot = document.createElementNS('http://www.w3.org/2000/svg', 'circle');
    dot.setAttribute('cx', curX); dot.setAttribute('cy', curY);
    dot.setAttribute('r', 6);
    dot.setAttribute('fill', 'var(--destructive)');
    dot.setAttribute('stroke', 'var(--background)');
    dot.setAttribute('stroke-width', '2');
    svg.appendChild(dot);
  }

  sW.addEventListener('input', render);
  render();
})();
</script>
