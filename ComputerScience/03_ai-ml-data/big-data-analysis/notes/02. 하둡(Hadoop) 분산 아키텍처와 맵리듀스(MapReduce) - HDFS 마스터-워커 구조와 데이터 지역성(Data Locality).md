> [!abstract] 핵심 요약
> 대규모 데이터를 중앙 서버로 전송하여 연산하는 기존 방식은 네트워크 대역폭 병목을 유발한다.
> **하둡(Hadoop)**은 데이터를 대용량 블록(기본 128MB)으로 분할하여 여러 노드에 복제 저장하는 **HDFS**와, 데이터가 위치한 물리적 노드로 코드를 전송하여 병렬 처리하는 **데이터 지역성(Data Locality)** 기반의 **맵리듀스(MapReduce)** 엔진을 통해 페타바이트급 분산 연산을 가능하게 했다.

---

## 1. HDFS 마스터-워커 아키텍처 및 복제 정책

```mermaid
flowchart TD
    CLIENT["클라이언트 (Client)"] -->|"1. 메타데이터 조회"| NN["NameNode (Master)<br/>메모리 상 파일 시스템 트리 & 블록 위치"]
    CLIENT -->|"2. 128MB 블록 직접 읽기/쓰기"| DN1["DataNode 1 (Worker)<br/>로컬 디스크 블록 저장"]
    CLIENT -->|"2. 병렬 스트리밍"| DN2["DataNode 2 (Worker)"]
    CLIENT -->|"2. 병렬 스트리밍"| DN3["DataNode 3 (Worker)"]
    DN1 -.->|"3. 블록 파이프라인 복제 (3x)"| DN2
    DN2 -.->|"3. 랙 간 복제"| DN3
    DN1 -->|"하트비트 & 블록 리포트 (3초 주기)"| NN
    DN2 --> NN
    DN3 --> NN
```

## 2. 맵리듀스(MapReduce) 3단계 데이터 흐름

```mermaid
flowchart LR
    INPUT["입력 파일 분할 (Input Splits)"] --> MAP["Map 단계<br/>키-값 쌍 생성: $(k_1, v_1) \to [(k_2, v_2)]$"]
    MAP --> SHUFFLE["Shuffle & Sort 단계<br/>동일 키 기준 그룹화 및 네트워크 전송"]
    SHUFFLE --> REDUCE["Reduce 단계<br/>집계 연산: $(k_2, [v_2]) \to [(k_3, v_3)]$"]
    REDUCE --> HDFS_OUT["HDFS 출력 파일 저장"]
```
