Apache Hadoop은 저비용 상용 서버(Commodity Hardware) 클러스터를 묶어 대용량 데이터를 안전하게 저장하는 **HDFS(분산 파일 시스템)**와 이를 병렬 분산 처리하는 **MapReduce(연산 엔진)**를 핵심 축으로 동작한다.

- **블록 기본 크기**: $128\text{MB}$ (탐색 비용 Seek Time 최소화).
- **랙 인지(Rack Awareness) 3중 복제 규칙**:
  1. 클라이언트와 동일한 로컬 노드(DataNode 1)에 1번째 복제본 저장.
  2. 동일 랙 내 다른 노드(DataNode 2)에 2번째 복제본 저장 (네트워크 대역폭 절약).
  3. 물리적으로 분리된 다른 랙의 노드(DataNode 3)에 3번째 복제본 저장 (랙 전원 차단 장애 대비).

```html preview
<script>
(function() {
  var inTxt = document.getElementById('mr-input-txt');
  var mapBox = document.getElementById('mr-map-box');
  var shuffleBox = document.getElementById('mr-shuffle-box');
  var reduceBox = document.getElementById('mr-reduce-box');

  function render() {
    var raw = inTxt.value.trim().toLowerCase();
    var words = raw.split(/\s+/).filter(Boolean);

    // 1. Map
    mapBox.innerHTML = '';
    words.forEach(function(w) {
      var d = document.createElement('div');
      d.style.padding = '3px 6px';
      d.style.background = 'var(--card)';
      d.style.border = '1px solid var(--chart-1)';
      d.style.borderRadius = '2px';
      d.textContent = '(' + w + ', 1)';
      mapBox.appendChild(d);
    });

    // 2. Shuffle & Sort
    var grouped = {};
    words.forEach(function(w) {
      if (!grouped[w]) grouped[w] = [];
      grouped[w].push(1);
    });

    shuffleBox.innerHTML = '';
    var keys = Object.keys(grouped).sort();
    keys.forEach(function(k) {
      var d = document.createElement('div');
      d.style.padding = '3px 6px';
      d.style.background = 'var(--card)';
      d.style.border = '1px solid var(--destructive)';
      d.style.borderRadius = '2px';
      d.textContent = k + ' ➔ [' + grouped[k].join(', ') + ']';
      shuffleBox.appendChild(d);
    });

    // 3. Reduce
    reduceBox.innerHTML = '';
    keys.forEach(function(k) {
      var count = grouped[k].length;
      var d = document.createElement('div');
      d.style.padding = '3px 6px';
      d.style.background = 'var(--primary)';
      d.style.color = '#fff';
      d.style.fontWeight = '700';
      d.style.borderRadius = '2px';
      d.textContent = '(' + k + ', ' + count + ')';
      reduceBox.appendChild(d);
    });
  }

  inTxt.addEventListener('input', render);
  render();
})();
</script>
```

## 3. MapReduce의 한계와 Spark의 등장 배경

1. **디스크 I/O 병목**: 반복 알고리즘(머신러닝 k-Means, PageRank) 실행 시 매 반복(Iteration)마다 중간 결과를 HDFS 디스크에 쓰고 다시 읽는 극심한 I/O 오버헤드 발생.
2. **높은 지연 시간 (High Latency)**: 실시간 인터랙티브 쿼리 및 스트리밍 처리에 부적합하여 인메모리 분산 엔진인 **Apache Spark**로 패러다임이 전환됨.
