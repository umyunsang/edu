Apache Spark는 디스크 I/O 기반의 Hadoop MapReduce 한계를 극복하기 위해 버클리 대학 AMPLab에서 개발된 **인메모리(In-Memory) 기반 대규모 분산 데이터 처리 프레임워크**이다. 반복적인 머신러닝 연산 및 대화형 데이터 분석에서 최대 100배 이상의 압도적인 속도 향상을 제공한다.

## 2. 4대 핵심 컴포넌트의 역할

1. **드라이버 프로그램(Driver Program)**: 사용자의 `main()` 함수를 실행하고, `SparkContext`를 생성하여 코드를 DAG(Directed Acyclic Graph) 실행 계획으로 컴파일한 뒤 태스크 단위로 쪼개어 스케줄링.
2. **클러스터 매니저(Cluster Manager)**: 클러스터 전체의 물리적 리소스(CPU 코어, RAM)를 조율 (YARN, Kubernetes, Standalone, Mesos 지원).
3. **익스큐터(Executor)**: 워커 노드에서 실행되는 JVM 프로세스로, 할당된 태스크(Task)를 다중 스레드로 병렬 연산하고 데이터를 메모리/디스크에 캐시(Cache).
4. **태스크(Task)**: 1개 데이터 파티션(Partition)에 대해 단일 스레드로 실행되는 가장 작은 작업 실행 단위.

## 3. 인터랙티브 Spark vs Hadoop MapReduce 성능 벤치마크 시뮬레이터

(function() {
  var sIter = document.getElementById('spk-iter-slider');

  var sparkTime = document.getElementById('spk-spark-time');

    var tSpark = 5 + iters * 1.1;

    mrTime.textContent = tMR.toFixed(0) + ' 초';
    sparkTime.textContent = tSpark.toFixed(1) + ' 초';

    mrBar.style.width = '100%';
    sparkBar.style.width = Math.min(100, (tSpark / tMR) * 100).toFixed(1) + '%';

    speedupTxt.textContent = speedup.toFixed(2) + ' 배 가속';
    ioTxt.textContent = (iters - 1) + ' 회 디스크 I/O 생략';
  }

  sIter.addEventListener('input', render);
  render();
})();
