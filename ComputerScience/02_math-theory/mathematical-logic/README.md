> [!abstract] 이 과목은
> 현재 폴더에는 강의용 원본 PDF가 없어, 수리논리학 내용을 추정해 노트로 만들지 않는다.

## 자료 상태

원본 PDF가 확인되지 않아 강의 흐름과 페이지 근거를 구성할 수 없다. PDF가 추가되면 논리 개념, 증명 절차, 예제를 실제 순서대로 분리한다.

## 정리문서

원본 PDF 부재로 재구성된 정리문서는 없다. 기존 링크는 현재 문서 트리와 맞지 않아 제거했다.

> [!note] 재개 조건
> source PDF의 수식이나 도식이 HTML/SVG로 손실될 때만 승인된 크롭 예외를 적용한다.
