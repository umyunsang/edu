이산수학 과제(Homework)는 명제 논리 증명, 집합 연산, 관계의 동치성 판정, 그래프 악수 정리 및 오일러 표수 계산을 총 18개 문항(각 10점, 총점 180점)으로 점검한다.

> [!IMPORTANT]
>
> - **필수 표기 정보**: 분반 번호, 학번, 성명, 문항 번호별 풀이 과정.
> - **파일 제출 형식**: 단일 PDF 파일 (`[학번]-[성명].pdf`).
> - **풀이 원본 출처 명시**: 외부 참고 문헌 인용 필수.

---

<script>
(function() {
  var sections = [
    { name: '1. 명제 논리 및 진리표 증명 (Q1~Q4)', pts: 40 },
    { name: '2. 집합 연산 및 드모르간 법칙 증명 (Q5~Q8)', pts: 40 },
    { name: '3. 이항 관계 및 동치류 분류 (Q9~Q12)', pts: 40 },

  var countEl = document.getElementById('hw-checked-count');
  var scoreEl = document.getElementById('hw-est-score');

  var inName = document.getElementById('hw-in-name');

  var checked = [false, false, false, false, false];

  function update() {
    var cCount = 0;
    var totalScore = 0;
    checked.forEach(function(isChk, idx) {
      if (isChk) {
        cCount++;
        totalScore += sections[idx].pts;
      }
    });

    countEl.textContent = cCount + ' / 5 영역';
    scoreEl.textContent = totalScore;

    var sId = inId.value.trim() || '학번';
    var sName = inName.value.trim() || '이름';
    outFilename.textContent = sId + '-' + sName + '.pdf';
  }

  sections.forEach(function(sec, idx) {
    var row = document.createElement('label');
    row.style.display = 'flex';
    row.style.alignItems = 'center';
    row.style.gap = '8px';
    row.style.padding = '8px 10px';
    row.style.background = 'var(--background)';
    row.style.border = '1px solid var(--border)';
    row.style.borderRadius = 'var(--radius)';
    row.style.cursor = 'pointer';
    row.style.fontSize = '12px';

    var chk = document.createElement('input');
    chk.type = 'checkbox';
    chk.style.accentColor = 'var(--primary)';
    chk.addEventListener('change', function() {
      checked[idx] = chk.checked;
      update();
    });

    var span = document.createElement('span');
    span.style.flex = '1';
    span.textContent = sec.name;

    var ptsSpan = document.createElement('strong');
    ptsSpan.style.color = 'var(--chart-2)';
    ptsSpan.textContent = sec.pts + '점';

    row.appendChild(chk);
    row.appendChild(span);
    row.appendChild(ptsSpan);
    clEl.appendChild(row);
  });

  inId.addEventListener('input', update);
  inName.addEventListener('input', update);

  update();
})();
</script>

## 2. 과제 제출 시 주의사항

- **출처 미표기 방지**: 타인 자료 인용 시 출처를 기재하지 않으면 0점 처리될 수 있으므로 반드시 레퍼런스를 명시한다.
- **문항 번호 일치**: 문제 번호가 누락되지 않도록 답안지에 Q1~Q18을 명확히 표기한다.
- **단일 파일 병합**: 스캔본이 여러 장일 경우 하나의 PDF 파일로 결합하여 업로드한다.
