관계(Relation)는 두 집합 사이의 원소들의 연관성을 데카르트 곱(Cartesian Product)의 부분집합으로 모델링한 것이며, 함수(Function)는 모든 정의역 원소가 오직 하나의 공역 원소에 대응되는 특수한 관계다.

> [!IMPORTANT]
>
> - **동치 관계(Equivalence Relation)**: **반사성(Reflexive)** + **대칭성(Symmetric)** + **추이성(Transitive)**을 모두 만족하는 관계.
> - **단사(Injective, 일대일)**: $f(a) = f(b) \implies a = b$.
> - **전사(Surjective, 위로의 함수)**: 공역(Codomain) $=$ 치역(Range).
> - **전단사(Bijective, 일대일 대응)**: 단사이면서 동시에 전사 $\iff$**역함수($f^{-1}$) 존재 조건**.

## 2. 관계의 4대 핵심 성질

| 성질 | 수학적 정의 | 행렬 $M_R$에서의 시각적 특징 |
| :--- | :--- | :--- |
| **반사성 (Reflexive)** | $\forall x \in A, (x, x) \in R$ | 주 대각선 원소가 모두 1 |
| **대칭성 (Symmetric)** | $(x, y) \in R \implies (y, x) \in R$| 전치 행렬과 동일 ($M_R = M_R^T$) |
| **반대칭성 (Antisymmetric)** | $(x, y) \in R \land (y, x) \in R \implies x = y$| 대각선 외 원소에서$M_{ij}=1 \implies M_{ji}=0$ |
| **추이성 (Transitive)** | $(x, y) \in R \land (y, z) \in R \implies (x, z) \in R$|$M_R^2 \le M_R$ (부울 행렬 곱) |

## 3. 함수의 분류

- **단사 함수 (Injective / One-to-One)**: 서로 다른 입력에 대해 항상 서로 다른 출력이 대응됨.
- **전사 함수 (Surjective / Onto)**: 공역의 모든 원소가 적어도 하나의 정의역 원소와 연결됨.
- **전단사 함수 (Bijective / One-to-One Correspondence)**: 단사이자 전사인 함수로, 역함수가 반드시 존재함.
