\*\*트리(Tree)\*\*는 순환(Cycle)이 존재하지 않는 단순 연결 무향 그래프로, 네트워크 최소 비용 연결(MST)과 데이터 무손실 압축(Huffman Coding)의 수학적 기반이다.

---

## 1. 신장 트리와 최소 신장 트리(MST)의 수학적 공식화

### 1) 신장 트리(Spanning Tree)의 성질

정점 집합 $V$의 크기가 $n$인 연결 그래프 $G$의 신장 트리 $T = (V, E_T)$:

$$|E_T| = n - 1$$

### 2) 최소 신장 트리(MST) 알고리즘 비교

- **크루스칼 알고리즘 (Kruskal's Algorithm)**:
  모든 간선을 가중치 오름차순으로 정렬한 뒤, 사이클을 형성하지 않는(Disjoint Set / Union-Find) $n-1$개의 간선을 탐욕적(Greedy)으로 선택:
  $$\mathcal{O}(|E| \log |E|)$$
- **프림 알고리즘 (Prim's Algorithm)**:
  임의의 시작 정점에서 출발하여 현재 트리에 인접한 간선 중 최소 가중치 간선을 우선순위 큐(Min-Heap)로 확장:
  $$\mathcal{O}(|E| \log |V|)$$

---

## 2. 허프만 코딩(Huffman Coding) 접두어 트리 대수학

심볼 집합 $S = {s_1, s_2, \dots, s_k}$와 각 심볼의 출현 확률 $p_i$, 이진 코드 길이 $l_i$에 대해:

$$\text{평균 비트 길이 } L = \sum_{i=1}^k p_i l_i \ge H(S) = -\sum_{i=1}^k p_i \log_2 p_i \quad (\text{섀넌 엔트로피 하한})$$

허프만 알고리즘은 빈도수가 가장 낮은 두 서브트리를 우선순위 큐에서 반복적으로 결합하여 접두어 성질(Prefix Property)을 만족하는 최적 이진 트리를 생성한다.

---
