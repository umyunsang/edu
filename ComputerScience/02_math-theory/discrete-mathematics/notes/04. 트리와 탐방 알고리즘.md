트리(Tree)는 사이클(Cycle)이 없는 연결 무방향 그래프다. $N$개의 정점을 가진 트리는 반드시 **$N-1$개의 간선**을 갖는다.

> [!IMPORTANT]
>
> - **생성 트리(Spanning Tree)**: 그래프 $G$의 모든 정점을 포함하면서 사이클이 없는 부분 트리.
> - **DFS (깊이 우선 탐색)**: 스택(Stack) 또는 재귀를 활용하여 한 경로를 끝까지 탐색 후 되돌아옴(Backtracking).
> - **BFS (너비 우선 탐색)**: 큐(Queue)를 활용하여 시작 정점으로부터 가까운 레벨 순서대로 탐색 $\to$ **최단 경로(가중치 없을 때)** 보장.

## 2. DFS와 BFS 특성 비교표

| 비교 항목 | DFS (깊이 우선 탐색) | BFS (너비 우선 탐색) |
| :--- | :--- | :--- |
| **핵심 자료구조** | **스택(Stack)** 또는 재귀 함수 | **큐(Queue)** |
| **방문 순서** | 루트 $\to$ 리프까지 깊게 이동 | 시작 노드 $\to$ 인접 1레벨 $\to$ 2레벨 |
| **공간 복잡도** | $O(h)$ ($h$는 트리 높이, 메모리 효율적) | $O(w)$ ($w$는 최대 너비) |
| **주요 활용** | 사이클 검출, 위상 정렬, 미로 해결 | **최단 경로 탐색**, 최소 신장 트리 |

## 3. 최소 생성 트리 (MST) 알고리즘

- **크루스칼(Kruskal) 알고리즘**: 간선 가중치를 오름차순 정렬한 뒤 Union-Find 자료구조로 사이클이 생기지 않도록 간선을 $N-1$개 선택 ($O(E \log E)$).
- **프림(Prim) 알고리즘**: 시작 정점에서 출발하여 현재 트리에 인접한 가장 작은 가중치의 간선을 우선순위 큐로 확장 ($O(E \log V)$).
