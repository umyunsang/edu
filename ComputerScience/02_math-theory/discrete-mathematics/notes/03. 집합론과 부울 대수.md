> [!abstract] 핵심 요약
> **집합론(Set Theory)**은 모든 이산 구조(관계, 함수, 그래프, 데이터베이스 릴레이션)의 기반 언어이다.
> 원소 수가 $n$인 유한 집합의 멱집합 크기는 $|\mathcal{P}(S)| = 2^n$이며, 자연수와 일대일 대응되는 **가산 집합(Countable: $\mathbb{N}, \mathbb{Z}, \mathbb{Q}$)**과 대응 불가능한 **비가산 집합(Uncountable: $\mathbb{R}$)**으로 구분된다. 또한 **포함-배제 원리(Principle of Inclusion-Exclusion)**는 교집합의 중복을 배제하여 합집합의 기수를 계산하는 기본 공식이다.

---

## 1. 집합의 기수성과 멱집합(Power Set)

```mermaid
flowchart TD
    ROOT["집합의 가산성(Countability) 분류"]
    ROOT --> FIN["유한 집합 (Finite Set)<br/>|S| = n (n ∈ N)"]
    ROOT --> INF["무한 집합 (Infinite Set)"]

    INF --> COUNT["가산 무한 집합 (Countably Infinite)<br/>자연수 집합 N과 1:1 전단사 함수 존재 (Aleph-0)<br/>예: Z, Q"]
    INF --> UNCOUNT["비가산 무한 집합 (Uncountable)<br/>칸토르 대각선 논법으로 1:1 대응 불가능 증명<br/>예: 실수 집합 R, 복소수 집합 C"]
```

$$|\mathcal{P}(S)| = 2^{|S|}$$

---

## 2. 포함-배제 원리(Principle of Inclusion-Exclusion)

```mermaid
flowchart LR
    subgraph PIE_Formula["포함-배제 원리 벤 다이어그램 구조"]
        A["|A| 더함"] --> INTER["- |A ∩ B| 뺌 (중복 배제)"]
        B["|B| 더함"] --> INTER
        INTER --> TOTAL["= |A ∪ B|"]
    end
```

### 1) 2개 집합
$$|A \cup B| = |A| + |B| - |A \cap B|$$

### 2) 3개 집합
$$|A \cup B \cup C| = |A| + |B| + |C| - (|A \cap B| + |B \cap C| + |C \cap A|) + |A \cap B \cap C|$$
