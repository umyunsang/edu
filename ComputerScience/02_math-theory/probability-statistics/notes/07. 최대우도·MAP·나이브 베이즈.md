통계적 추론의 두 축인 빈도주의(Frequentist) **최대우도추정(MLE)**과 베이지안(Bayesian) **최대사후확률(MAP)**은 관측 데이터로부터 모델의 모수 $\theta$를 추정하는 핵심 기법이다.

> [!IMPORTANT]
>
> - **MLE (Maximum Likelihood Estimation)**:
>   $$\hat{\theta}_{\text{MLE}} = \arg\max_\theta P(\mathcal{D} \mid \theta) = \arg\max_\theta \sum_{i=1}^N \log P(x_i \mid \theta)$$
> - **MAP (Maximum A Posteriori)**:
>   $$\hat{\theta}_{\text{MAP}} = \arg\max_\theta P(\theta \mid \mathcal{D}) = \arg\max_\theta \left[ \log P(\mathcal{D} \mid \theta) + \log P(\theta) \right]$$
>   (사전 확률 $P(\theta)$이 정규화 정규화 항(Regularizer) 역할을 수행)

## 2. 나이브 베이즈 (Naive Bayes) 분류 원리

특징 벡터 $\mathbf{x} = (x_1, x_2, \dots, x_d)$가 주어졌을 때 각 클래스$C_k$에 속할 사후 확률:
$$P(C_k \mid \mathbf{x}) \propto P(C_k) \prod_{i=1}^d P(x_i \mid C_k)$$
모든 특징(Feature)들이 클래스 조건부 독립(Conditional Independence)이라는 가정(Naive)을 통해 계산 복잡도를 획기적으로 낮춘다.
