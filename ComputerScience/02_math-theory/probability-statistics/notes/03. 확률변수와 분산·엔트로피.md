**확률변수(Random Variable)** $X: \Omega \to \mathbb{R}$는 표본 공간의 결과를 실수 값으로 사상하는 함수이며, 그 분포의 중심 경향과 산포도는 기댓값, 분산, 정보 엔트로피로 정량화된다.

---

## 1. 확률변수 모멘트와 엔트로피의 수학적 정의

### 1) 기댓값(Expectation)과 LOTUS

- **기댓값의 선형성 (Linearity of Expectation)**:
  $$\mathbb{E}[a X + b Y + c] = a \mathbb{E}[X] + b \mathbb{E}[Y] + c$$
- **무의식적 통계학자의 법칙 (LOTUS)**:
  $$\mathbb{E}[g(X)] = \sum_{x} g(x) p_X(x)$$

### 2) 분산(Variance)과 표준편차($\sigma$) 유도

$$\text{Var}(X) = \mathbb{E}\big[ (X - \mathbb{E}[X])^2 \big] = \mathbb{E}[X^2] - \big( \mathbb{E}[X] \big)^2$$

$$\text{Var}(a X + b) = a^2 \text{Var}(X), \quad \sigma_X = \sqrt{\text{Var}(X)}$$

### 3) 섀넌 정보 엔트로피 (Shannon Entropy)

이산확률변수 $X$의 불확실성과 평균 정보량(Bits):

$$H(X) = -\sum_{x} p(x) \log_2 p(x) \quad (0 \le H(X) \le \log_2 |\mathcal{X}|)$$

균등 분포(Uniform Distribution)일 때 엔트로피가 최대가 된다.

  var rE = document.getElementById('rv-res-e');

    var sum = p1 + p2 + p3;
    if (sum <= 0) sum = 1;
    p1 /= sum; p2 /= sum; p3 /= sum;

    var exp = (1 * p1) + (2 * p2) + (3 * p3);
    var exp2 = (1 * 1 * p1) + (4 * p2) + (9 * p3);
    var variance = exp2 - (exp * exp);

    var ent = 0;
    [p1, p2, p3].forEach(function(p) {
      if (p > 0) ent -= p * Math.log2(p);
    });

    rE.textContent = exp.toFixed(2);
    rV.textContent = Math.max(0, variance).toFixed(2);
    rH.textContent = ent.toFixed(2) + ' bits';
  }

  [ip1, ip2, ip3].forEach(function(el){ el.addEventListener('input', update); });
  update();
})();
