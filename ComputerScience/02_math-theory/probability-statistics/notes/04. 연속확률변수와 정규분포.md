\*\*연속확률변수(Continuous Random Variable)\*\*는 특정 구간 내의 연속적인 실숫값을 가지며, 특정 한 점의 확률 $P(X = x) = 0$이므로 구간에 대한 **확률밀도함수(PDF)의 정적분**으로 확률을 정의한다.

---

## 1. 연속확률변수의 대수적 정의와 정규분포

### 1) PDF와 CDF의 미적분 관계식

$$\int_{-\infty}^\infty f_X(x) \, dx = 1, \quad F_X(x) = P(X \le x) = \int_{-\infty}^x f_X(t) \, dt, \quad f_X(x) = \frac{d}{dx} F_X(x)$$

$$P(a \le X \le b) = \int_a^b f_X(x) \, dx = F_X(b) - F_X(a)$$

### 2) 가우스 정규분포 (Gaussian Normal Distribution) $X \sim \mathcal{N}(\mu, \sigma^2)$

$$f(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right)$$

- **표준화 (Standardization)**:
  $$Z = \frac{X - \mu}{\sigma} \sim \mathcal{N}(0, 1)$$
- **68-95-99.7 경험적 법칙**:
  $$P(\mu - \sigma \le X \le \mu + \sigma) \approx 0.6827$$
  $$P(\mu - 2\sigma \le X \le \mu + 2\sigma) \approx 0.9545$$
  $$P(\mu - 3\sigma \le X \le \mu + 3\sigma) \approx 0.9973$$

### 3) 중심 극한 정리 (Central Limit Theorem, CLT)

평균이 $\mu$, 분산이 $\sigma^2$인 임의의 모집단으로부터 추출한 독립동등분포(i.i.d.) 표본들의 표본 평균 $\bar{X}\_n$:

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i \xrightarrow{d} \mathcal{N}\left( \mu, \; \frac{\sigma^2}{n} \right) \quad \text{as } n \to \infty$$

(function() {

  var slSig = document.getElementById('norm-sl-sigma');

    var pdf = (1.0 / (sig * Math.sqrt(2 * Math.PI))) * Math.exp(-0.5 * z * z);
