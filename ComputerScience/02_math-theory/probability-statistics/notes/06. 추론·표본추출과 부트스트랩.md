정확한 확률밀도 함수를 알기 어려울 때 표본으로 모집단을 추론한다. 자료는 귀무·대립가설, p-value, 표본 통계량과 부트스트랩 절차를 제시한다.

```mermaid
flowchart LR
  A["모집단"] --> B["표본 추출"]
  B --> C["통계량 계산"]
  C --> D["부트스트랩 재표본화"]
  D --> E["분포·p-value"]
  E --> F["가설 판단"]
```

<Tabs>
  <Tab label="가설">귀무가설은 차이가 없다는 기준, 대립가설은 차이가 있다는 주장이다.</Tab>
  <Tab label="p-value">귀무가설이 참일 때 관찰된 데이터 이상을 얻을 확률로 해석한다.</Tab>
  <Tab label="Bootstrap">관측 표본에서 복원추출해 통계량의 변동을 근사한다.</Tab>
</Tabs>

| 용어 | 자료의 해석 |
| --- | --- |
| H₀ | 모집단과 추정치에 차이가 없다는 기준 |
| H₁ | 차이가 있다는 대안 |
| p-value | H₀ 아래 관측 데이터의 가능성 |
| 0.05·0.01 | 흔히 쓰는 기준 예, 절대 규칙은 아님 |

> [!CAUTION]
> p-value가 작다고 효과의 크기나 인과관계가 자동으로 증명되지는 않는다. 표본 설계와 가설을 함께 기록한다.
