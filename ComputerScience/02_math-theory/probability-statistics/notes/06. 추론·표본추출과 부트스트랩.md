\*\*통계적 추론(Statistical Inference)\*\*은 한정된 표본 데이터로부터 미지의 모집단 모수(Parameter $\theta$)를 추정하고 불확실성을 평가하며, \*\*부트스트랩(Bootstrap)\*\*은 복원 추출(Resampling with Replacement)을 통해 비모수적으로 표준 오차와 신뢰구간을 산출한다.

---

## 1. 불편 추정량과 부트스트랩 대수학

### 1) 표본 분산의 불편성(Unbiasedness)과 자유도 $n-1$

모평균 $\mu$를 알지 못해 표본 평균 $\bar{X}$로 대체할 때 발생하는 편향을 보정:

$$S^2 = \frac{1}{n - 1} \sum_{i=1}^n (X_i - \bar{X})^2 \implies \mathbb{E}[S^2] = \sigma^2$$

### 2) 비모수적 부트스트랩(Bootstrap) 알고리즘

경험적 분포 함수 $\hat{F}\_n$으로부터 크기 $n$의 표본을 복원 추출하여 $B$개의 부트스트랩 복제본 $\mathbf{x}^{*(1)}, \dots, \mathbf{x}^{*(B)}$ 생성:

- **부트스트랩 표준 오차**:
  $$\text{SE}_{\text{boot}}(\hat{\theta}) = \sqrt{\frac{1}{B - 1} \sum_{b=1}^B \big( \hat{\theta}^{*(b)} - \bar{\theta}^* \big)^2}$$
- **백분위수 $95%$ 신뢰구간 (Percentile CI)**:
  $$[\hat{\theta}^*_{(0.025)}, \; \hat{\theta}^*_{(0.975)}]$$

(function() {
  var sample = [12, 18, 25, 30, 42];
  var btn = document.getElementById('bt-btn-run');
  var rSe = document.getElementById('bt-boot-se');

  btn.addEventListener('click', function() {
    var B = 500;
    var n = sample.length;
    var bootMeans = [];

    for (var b = 0; b < B; b++) {
      var sum = 0;
      for (var i = 0; i < n; i++) {
        var idx = Math.floor(Math.random() * n);
        sum += sample[idx];
      }
      bootMeans.push(sum / n);
    }

    var mBoot = bootMeans.reduce(function(a,b){return a+b;}, 0) / B;
    var varBoot = bootMeans.reduce(function(a,b){return a + Math.pow(b - mBoot, 2);}, 0) / (B - 1);
    var seBoot = Math.sqrt(varBoot);

    rSe.textContent = seBoot.toFixed(2);
  });
})();
</script>
