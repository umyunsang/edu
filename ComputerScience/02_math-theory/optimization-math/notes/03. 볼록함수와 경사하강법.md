\*\*볼록 최적화(Convex Optimization)\*\*는 목적 함수와 제약 조건이 볼록성을 만족하는 최적화 문제로, \*\*모든 국소 최적점(Local Minimum)이 곧 전역 최적점(Global Minimum)\*\*이라는 강력한 수학적 성질을 갖는다.

---

## 1. 볼록성의 대수적 조건과 경사하강법 수렴성

### 1) 볼록 함수(Convex Function)의 3대 판정 조건

- **정의 (Jensen's Inequality)**:
  $$\forall \mathbf{x}, \mathbf{y} \in \text{dom}(f), \; \forall \theta \in [0, 1], \quad f\big(\theta \mathbf{x} + (1 - \theta)\mathbf{y}\big) \le \theta f(\mathbf{x}) + (1 - \theta) f(\mathbf{y})$$
- **1계 조건 (First-Order Condition)**:
  $$f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^T (\mathbf{y} - \mathbf{x})$$
- **2계 조건 (Second-Order Condition)**:
  $$\nabla^2 f(\mathbf{x}) \succeq 0 \quad (\text{헤시안 행렬이 모든 점에서 양의 준정부호, Positive Semi-Definite})$$

### 2) 경사하강법 (Gradient Descent)과 수렴 속도

$$\mathbf{x}_{t+1} = \mathbf{x}_t - \eta \nabla f(\mathbf{x}_t)$$

- 목적 함수가 $L$-립시츠 연속 그래디언트를 가질 때, 학습률 $\eta \le \frac{1}{L}$로 설정 시 $T$회 반복 후 수렴 오차:
  $$f(\mathbf{x}_T) - f(\mathbf{x}^*) \le \frac{L \|\mathbf{x}_0 - \mathbf{x}^*\|^2}{2 T} \in \mathcal{O}\left( \frac{1}{T} \right)$$

(function() {
  var slLr = document.getElementById('gd-sl-lr');
  var slX0 = document.getElementById('gd-sl-x0');
  var tLr = document.getElementById('gd-txt-lr');
  var tX0 = document.getElementById('gd-txt-x0');

  var iter = 0;

    rX.textContent = curX.toFixed(4);
    rT.textContent = iter;
    rFx.textContent = (curX * curX).toFixed(4);
  }

  slLr.addEventListener('input', function() { tLr.textContent = parseFloat(slLr.value).toFixed(2); });
  slX0.addEventListener('input', function() {

    curX = parseFloat(slX0.value);
    iter = 0;
    render();
  });

  btnStep.addEventListener('click', function() {
    var lr = parseFloat(slLr.value);
    var grad = 2 * curX; // f'(x) = 2x
    curX = curX - lr * grad;
    iter++;
    render();
  });

  btnReset.addEventListener('click', function() {
    curX = parseFloat(slX0.value);
    iter = 0;
    render();
  });

  render();
})();
</script>
