행렬은 원소를 행과 열로 배열한 구조다. 자료는 일반 행렬과 정방행렬을 정의하고 덧셈·뺄셈·스칼라배, 영행렬, 교환·결합 법칙으로 확장한다.

```mermaid
flowchart LR
  A["행·열 차원 확인"] --> B["원소별 연산"]
  B --> C["행렬식·곱셈 조건"]
  C --> D["정리와 변환"]
  D --> E["최적화 식에 대입"]
```

<Tabs>
  <Tab label="정의">A=(aᵢⱼ)로 원소와 크기를 표시하며 m=n이면 정방행렬이다.</Tab>
  <Tab label="연산">A+B, A−B, cA는 같은 위치 원소 또는 스칼라를 이용한다.</Tab>
  <Tab label="법칙">자료는 A+B=B+A 같은 교환법칙과 행렬 연산의 조건을 구분한다.</Tab>
</Tabs>

| 확인 | 질문 |
| --- | --- |
| 차원 | 두 행렬의 행·열 크기가 연산에 맞는가 |
| 원소 | aᵢⱼ가 어느 행·열에 놓이는가 |
| 구조 | 영행렬·정방행렬인가 |
| 적용 | 뒤의 2차 형식·최적화에 어떻게 쓰이는가 |
