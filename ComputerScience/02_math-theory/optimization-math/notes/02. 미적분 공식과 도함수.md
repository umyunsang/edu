미분(Differentiation)은 함수의 순간 변화율을 구하는 연산이며, 다변수 함수의 편미분(Partial Derivative)과 기울기 벡터(Gradient, $\nabla f$)는 최적화 방향을 결정하는 핵심 도구다.

> [!IMPORTANT]
>
> - **연쇄 법칙(Chain Rule)**:
>   $$\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)$$
>   (딥러닝 역전파 알고리즘의 수학적 근간)
> - **그레디언트(Gradient $\nabla f$)**: 함수가 **가장 가파르게 증가하는 방향**을 가리키는 편미분 벡터.

## 1. 2차 함수 $f(x) = x^2$ 접선 기울기 인터랙티브 탐색기

(function() {
  var slider = document.getElementById('diff-x-slider');

## 2. 기본 도함수 공식 요약

| 함수 $f(x)$ | 도함수 $f'(x)$ | 머신러닝 활용처 |
| :--- | :--- | :--- |
| $x^n$ | $n x^{n-1}$ | 다항식 회귀 (Polynomial Regression) |
| $e^x$ | $e^x$ | 소프트맥스 함수 (Softmax) |
| $\ln(x)$ | $\frac{1}{x}$ | 교차 엔트로피 손실 함수 (Cross-Entropy Loss) |
| $\sigma(x) = \frac{1}{1 + e^{-x}}$ | $\sigma(x)(1 - \sigma(x))$ | 로지스틱 회귀 및 시그모이드 활성화 함수 |
