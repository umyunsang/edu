>
> 그런데 `pdftotext` 가 뽑아내는 글자는 페이지당 평균 **40자 남짓**이고, 3장은 60쪽 중 **45쪽이 0자**다. 계산·증명·직관은 거의 전부 파랑·초록·빨강 세 색의 **손글씨**로만 존재하며 텍스트 추출에 한 글자도 잡히지 않는다.

## 세 장을 관통하는 한 줄

1장이 $\mathbf{x}^T A\mathbf{x}$ 를 만들고(대칭 → 고윳값 → 대각화 → 양의 정부호 → 이차형식 → 볼록함수), 2장이 그것을 2차 테일러 전개의 세 번째 항으로 다시 꺼내며(기울기 → 헤세 → 야코비), 3장이 그 함수를 실제로 최소화한다. 그리고 마지막에 데이터가 들어와 같은 모양의 함수를 스스로 만들어 낸다.

1장 64쪽 — 번호도 설명도 손글씨도 없는 곡면 세 장(definite / semidefinite / indefinite) — 이 그 연결을 말없이 가리키는 표지판이다.
