# Creative Writing Assignment Skill

이 스킬은 이 폴더의 창의적글쓰기 과제를 강의자료 기반으로 작성하거나 수정할 때 사용한다.

## Inputs

- 과제 프롬프트 또는 주제
- 요구 형식, 분량, 제출 조건
- 사용할 강의 범위 또는 PDF 페이지가 있으면 그 범위
- 사용자의 기존 초안이 있으면 해당 파일

## Required Process

1. 과제 조건을 요약한다. 조건이 없으면 기존 퀴즈 예시의 형식, 즉 제목/형식/서론/본론1-3/결론/암기 키워드 흐름을 기본값으로 둔다.
2. `python3 tools/search_sources.py "<핵심어>"`를 여러 번 실행해 강의자료 근거를 찾는다.
3. 원본 강의자료와 기존 정리 내용이 다르면 원본 강의자료를 우선한다.
4. 글의 큰 구조를 먼저 만든다: 주제문, 독자, Why/How 형식, 1'-2'-2'-2'-4' 문단 배치, 각 문장의 힘 번호.
5. 초안에는 수업 개념을 적용한다: 3C, Power Writing, Hi Five, MECE, 수직 주종/수평 동등, 두괄식/미괄식.
6. 근거가 부족한 사실은 단정하지 않는다. 외부 사실이 필요한 주제라면 최신 웹 검증을 별도 출처로 분리한다.
7. 제출용 문장과 근거 메모를 분리한다. 교수에게 제출할 본문이 출처 표기를 요구하지 않으면, 별도 섹션에만 근거를 남긴다.

## Output Shape

기본 산출물은 다음 순서로 만든다.

```md
# 제목

형식: why/how - 1'(...) - 2'(...) - 2'(...) - 2'(...) - 4'(...)

## 1' 서론

...

## 2' 본론1: ...

...

## 2' 본론2: ...

...

## 2' 본론3: ...

...

## 4' 결론

...

## 암기 핵심 키워드 흐름

...

## 근거 메모

- ...
```

## Final Check

- 제목 또는 헤더가 분명한가? Notes 단서상 헤더를 특히 중요하게 본다.
- 문단 구조가 과제 형식과 맞는가?
- `(1)`, `(2)`, `(3)`, `(4)`의 역할이 섞이지 않았는가?
- 본론 축이 MECE인가?
- 강의자료 근거와 외부 사실이 분리되어 있는가?
- 과장, 추정, 무근거 교수 발언이 없는가?
