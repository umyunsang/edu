## 개념을 연결하는 순서

교재 장 자료는 문제를 입력·출력·정확성으로 명세한 뒤, 시간·공간 복잡도를 비교하는 순서를 취한다.

- 억지 기법과 완전 탐색은 가능한 후보를 모두 확인하는 기준선을 제공한다.
- 축소 정복과 분할 정복은 작은 문제로 변환하거나 나누어 결합한다.
- 공간으로 시간 벌기는 메모이제이션·테이블처럼 저장 공간으로 반복 계산을 줄이는 관점을 제공한다.
- 동적 계획법은 중복 부분 문제와 최적 부분 구조를, 탐욕은 매 단계의 선택과 전역 최적성 조건을 묻는다.
- 백트래킹·분기 한정은 탐색 가지를 잘라내고, NP 완전·근사 자료는 효율적 해법의 한계를 분류한다.

## 원본에서 읽는 적용 장면

| 기법 | 선택 근거 | 검증 질문 |
| :-- | :-- | :-- |
| 완전 탐색 | 후보 공간이 작거나 기준선이 필요함 | 모든 후보를 빠짐없이 보았는가 |
| 분할정복 | 독립 하위 문제와 결합 규칙 | 재귀식과 결합 비용은 무엇인가 |
| 동적 계획법 | 중복 부분 문제 | 상태와 전이식이 닫혀 있는가 |
| 탐욕 | 지역 선택의 교환/최적 구조 | 선택이 전역 최적을 보장하는가 |
| 백트래킹 | 제약 조건 탐색 | 불가능한 가지를 언제 버리는가 |
