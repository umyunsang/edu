## lecture

* [01. 알고리즘의 개요와 문제 해결 프레임워크: 정확성 증명, 기본 연산과 설계 패러다임 분류](./01.%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%EC%9D%98%20%EA%B0%9C%EC%9A%94%EC%99%80%20%EB%AC%B8%EC%A0%9C%20%ED%95%B4%EA%B2%B0%20%ED%94%84%EB%A0%88%EC%9E%84%EC%9B%8C%ED%81%AC.md) - 알고리즘의 엄밀한 수학적 정의(입력, 출력, 명확성, 유한성, 유효성), 문제 해결 4단계 파이프라인(문제 이해 -> 모델링 -> 알고리즘 설계 -> 정확성 및 복잡도 분석), 루프 불변성(Loop Invariant)을 활용한 수학적 귀납법 기반 정확성 증명, 그리고 주요 설계 패러다임(억지 기법, 축소 정복, 분할 정복, 동적 계획법, 탐욕적 기법, 백트래킹, 분기 한정)의 분류를 인터랙티브 유클리드 최대공약수 시뮬레이터로 학습한다.
* [02. 알고리즘 효율성 분석과 점근적 표기법: Big-O·Omega·Theta와 재귀 점화식 풀이](./02.%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20%ED%9A%A8%EC%9C%A8%EC%84%B1%20%EB%B6%84%EC%84%9D%EA%B3%BC%20%EC%A0%90%EA%B7%BC%EC%A0%81%20%ED%91%9C%EA%B8%B0%EB%B2%95.md) - 알고리즘 복잡도의 수학적 분석 체계, 최악/최선/평균 시간 복잡도, 점근적 표기법의 엄밀한 엡실론-델타식 정의(Big-O 상한, Big-Omega 하한, Big-Theta 동치), 주요 복잡도 계층 비교, 재귀 알고리즘의 시간 복잡도 점화식을 해결하는 마스터 정리(Master Theorem: 3대 케이스)와 재귀 트리(Recursion Tree) 분석법을 인터랙티브 복잡도 증가율 비교기로 학습한다.
* [03. 억지 기법과 완전 탐색: 순차 탐색, 선택 정렬, 최근접 점의 쌍과 순열·조합 조합 폭발](./03.%20%EC%96%B5%EC%A7%80%20%EA%B8%B0%EB%B2%95%EA%B3%BC%20%EC%99%84%EC%A0%84%20%ED%83%90%EC%83%89.md) - 문제 해결의 가장 직접적인 접근법인 억지 기법(Brute Force), 순차 탐색과 선택 정렬(Selection Sort), 2차원 평면에서의 최근접 점의 쌍(Closest-Pair $O(n^2)$), 그리고 상태 공간을 전수 탐색하는 완전 탐색(Exhaustive Search)의 3대 대표 문제(외판원 문제 TSP $O(n!)$, 0/1 배낭 문제 $O(2^n)$, 배정 문제)의 조합 폭발(Combinatorial Explosion)을 인터랙티브 순열 공간 증가 계산기로 학습한다.
* [04. 축소 정복 기법: 삽입 정렬, 위상 정렬(DFS·진입차수), 이진 탐색과 가짜 동전 찾기](./04.%20%EC%B6%95%EC%86%8C%20%EC%A0%95%EB%B3%B5%20%EA%B8%B0%EB%B2%95.md) - 문제를 동일한 성질의 더 작은 단일 부분 문제로 점진적 축소하여 해결하는 축소 정복(Decrease-and-Conquer) 패러다임, 상수 축소(Decrease-by-Constant: 삽입 정렬 $O(n^2)$, 위상 정렬 $O(V+E)$), 상수 인자 축소(Decrease-by-Constant-Factor: 이진 탐색 $O(log n)$, 가짜 동전 찾기 삼분법), 그리고 가변 크기 축소(Variable-Size-Decrease: 유클리드 호제법, 선택 알고리즘 QuickSelect $O(n)$)를 인터랙티브 위상 정렬 진입차수 감소 시뮬레이터로 학습한다.
* [05. 분할 정복 기법: 합병 정렬, 퀵 정렬(Hoare vs Lomuto), 스트라센 행렬 곱셈과 Closest-Pair](./05.%20%EB%B6%84%ED%95%A0%20%EC%A0%95%EB%B3%B5%20%EA%B8%B0%EB%B2%95.md) - 문제를 상호 독립적인 부분 문제로 분할하여 각각을 재귀적으로 해결한 후 결합하는 분할 정복(Divide-and-Conquer) 패러다임, 안정 정렬 합병 정렬(Merge Sort $O(n log n)$), 제자리 정렬 퀵 정렬(QuickSort: 호어/로무토 분할, 최악 $O(n^2)$ 방지 피벗 선택), 행렬 곱셈 연산 횟수를 $8 o 7$개로 축소한 스트라센 알고리즘($O(n^{2.81})$), 그리고 2차원 평면 $O(n log n)$ 최근접 점 분할 정복을 인터랙티브 퀵 정렬 피벗 분할 시뮬레이터로 학습한다.
* [06. 공간으로 시간 벌기: 계수 정렬, 해싱(충돌 해결)과 호스풀·보이어-무어 문자열 탐색](./06.%20%EA%B3%B5%EA%B0%84%EC%9C%BC%EB%A1%9C%20%EC%8B%9C%EA%B0%84%20%EB%B2%8C%EA%B8%B0.md) - 추가적인 메모리 공간을 투입하여 알고리즘의 실행 시간을 획기적으로 단축하는 공간-시간 상호보완(Space-and-Time Trade-Offs) 패러다임, 입력 범위 $k$를 활용하여 $O(n + k)$ 선형 시간에 정렬하는 계수 정렬(Counting Sort), 해시 함수와 충돌 해결 기법(체이닝 Chaining, 개방 주소법 Open Addressing), 그리고 이동 테이블(Shift Table)을 사전 계산하여 우측에서 좌측으로 패턴을 고속 매칭하는 호스풀(Horspool) 및 보이어-무어(Boyer-Moore) 알고리즘을 인터랙티브 호스풀 시프트 테이블 계산기로 학습한다.
* [07. 동적 계획법: 메모이제이션, 0/1 Knapsack, 최장 공통 부분 수열(LCS)과 Floyd-Warshall](./07.%20%EB%8F%99%EC%A0%81%20%EA%B3%84%ED%9A%8D%EB%B2%95.md) - 최적 부분 구조(Optimal Substructure)와 중복 부분 문제(Overlapping Subproblems)를 갖는 최적화 문제를 상향식(Bottom-up) 타뷸레이션 또는 하향식(Top-down) 메모이제이션으로 해결하는 동적 계획법(Dynamic Programming)의 수학적 원리, 0/1 배낭 문제의 $O(n W)$ 의사 다항 시간 점화식, LCS(Longest Common Subsequence $O(n m)$), 모든 쌍 최단 경로 Floyd-Warshall($O(V^3)$), 그리고 벨만-포드(Bellman-Ford) 알고리즘을 인터랙티브 0/1 배낭 DP 테이블 시뮬레이터로 학습한다.
* [08. 탐욕적 기법: 최소 신장 트리(Prim vs Kruskal), Dijkstra 최단 경로와 허프만 압축 코딩](./08.%20%ED%83%90%EC%9A%95%EC%A0%81%20%EA%B8%B0%EB%B2%95.md) - 각 단계에서 국소적으로 가장 최적인 선택(Local Optimum)을 반복하여 전역 최적해(Global Optimum)에 도달하는 탐욕적 기법(Greedy Algorithms)의 수학적 원리와 마트로이드(Matroid) 이론, 프림(Prim $O(E log V)$) 및 크루스칼(Kruskal $O(E log E)$ 유니온-파인드) 최소 신장 트리(MST), 음이 아닌 가중치 단일 출발지 최단 경로 다익스트라(Dijkstra), 그리고 빈도수 기반 가변 길이 무손실 압축 허프만 코딩(Huffman Coding)을 인터랙티브 허프만 트리 압축률 시뮬레이터로 학습한다.
* [09. 백트래킹과 분기 한정: 상태 공간 트리, N-Queens 문제, 유망성 검사와 Branch-and-Bound 최적화](./09.%20%EB%B0%B1%ED%8A%B8%EB%9E%98%ED%82%B9%EA%B3%BC%20%EB%B6%84%EA%B8%B0%20%ED%95%9C%EC%A0%95.md) - 지수적 탐색 공간을 상태 공간 트리(State-Space Tree)로 모델링하여 최적해를 찾는 고급 탐색 패러다임, 깊이 우선 탐색(DFS) 중 비유망(Non-promising) 노드를 즉시 가지치기(Pruning)하는 백트래킹(Backtracking: N-Queens, 부분집합의 합), 너비 우선 탐색(BFS) 또는 최선 우선 탐색(Best-first) 중 한계치(Bound)를 계산하여 하위 서브트리를 조기 배제하는 분기 한정(Branch-and-Bound: 0/1 Knapsack, TSP), 그리고 두 기법의 비교를 인터랙티브 4-Queens 백트래킹 체스판 시뮬레이터로 학습한다.

NP-완전성과 근사 알고리즘: P vs NP, 다항 시간 리덕션, Cook-Levin 정리와 외판원 문제 2-근사](./10.%20NP-%EC%99%84%EC%A0%84%EC%84%B1%EA%B3%BC%20%EA%B7%BC%EC%82%AC%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98.md) - 계산 복잡도 이론의 핵심 질문과 난제, 다항 시간 결정 알고리즘 집합 P와 다항 시간 검증 가능 집합 NP, 다항 시간 환원(Polynomial-Time Reduction $<=_P$), 쿡-레빈 정리(Cook-Levin Theorem: SAT의 NP-완전성 증명), 주요 NP-완전 문제 패밀리(3-SAT, Vertex Cover, Hamiltonian Cycle, TSP, 0/1 Knapsack), 그리고 NP-난해 최적화 문제를 다항 시간에 일정 오차 한계 내에서 해결하는 근사 알고리즘(Approximation Algorithms: 삼각 부등식 TSP 2-근사, Vertex Cover 2-근사)을 인터랙티브 P-NP-NPC 포함 관계 분석기로 학습한다.
