* [01. 알고리즘의 개요와 문제 해결 프레임워크: 정의, 3대 소수 판별법, 피보나치 4대 패러다임과 루프 불변성](./01.%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%EC%9D%98%20%EA%B0%9C%EC%9A%94%EC%99%80%20%EB%AC%B8%EC%A0%9C%20%ED%95%B4%EA%B2%B0%20%ED%94%84%EB%A0%88%EC%9E%84%EC%9B%8C%ED%81%AC.md) - 컴퓨팅 문제 해결의 정수인 알고리즘의 5대 조건(입력·출력·명확성·유한성·유효성), 문제 해결 6단계 생명주기(이해-설계-정확성 증명-효율성 분석-구현-테스트), 3대 최대공약수(GCD) 계산 패러다임(유클리드 호제법 vs 연속 정수 검사 vs 에라토스테네스의 체 소인수분해), 피보나치 수열 4대 계산법(단순 재귀 O(2^n), 메모이제이션/DP O(n), 반복 O(n), Q-행렬 거듭제곱 O(log n)), 수학적 귀납법과 루프 불변성(Loop Invariant: 초기화·유지·종료)을 통한 정확성 증명, 그리고 실시간 유클리드 vs 연속 정수 검사 인터랙티브 단계 비교기를 다룬다.
* [02. 알고리즘 효율성 분석과 점근적 표기법: 시간 복잡도, 극한 판별법과 마스터 정리](./02.%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20%ED%9A%A8%EC%9C%A8%EC%84%B1%20%EB%B6%84%EC%84%9D%EA%B3%BC%20%EC%A0%90%EA%B7%BC%EC%A0%81%20%ED%91%9C%EA%B8%B0%EB%B2%95.md) - 알고리즘의 입력 크기 n에 따른 실행 자원 분석 이론, 기본 연산(Basic Operation) 식별 및 카운팅, 최악(Worst-case)·평균(Average-case)·최선(Best-case) 복잡도 모델링, 점근적 표기법 5대 체계(Big-O 상한, Big-Omega 하한, Big-Theta 밀착 상하한, Little-o 엄격 상한, Little-omega 엄격 하한), 극한(Limit)을 이용한 증가 차수 판별(로피탈 정리), 그리고 분할 정복 재귀 알고리즘의 복잡도를 일괄 해결하는 마스터 정리(Master Theorem 3대 케이스)의 수학적 유도와 인터랙티브 계산기를 다룬다.
* [03. 억지 기법과 완전 탐색: 선택·버블 정렬, 최근접 점의 쌍, 볼록 껍질과 조합 폭발](./03.%20%EC%96%B5%EC%A7%80%20%EA%B8%B0%EB%B2%95%EA%B3%BC%20%EC%99%84%EC%A0%84%20%ED%83%90%EC%83%89.md) - 문제 해결의 가장 직접적이고 직관적인 접근법인 억지 기법(Brute Force), 정렬 알고리즘(선택 정렬 O(n^2), 버블 정렬 O(n^2)), 순차 탐색과 단순 문자열 매칭(Brute-Force String Match O(mn)), 기하 알고리즘(최근접 점의 쌍 2D 거리 계산 O(n^2), 극단선 기반 볼록 껍질 Convex Hull O(n^3)), 그리고 상태 공간을 전수 조사하는 완전 탐색(Exhaustive Search: 외판원 문제 TSP O(n!), 0/1 배낭 문제 O(2^n), 작업 할당 문제 O(n!))의 조합 폭발 한계와 최적화 인터랙티브 비교를 다룬다.
* [04. 축소 정복 기법: 상수 크기·상수 비율·가변 크기 축소, 위상 정렬과 선택 알고리즘](./04.%20%EC%B6%95%EC%86%8C%20%EC%A0%95%EB%B3%B5%20%EA%B8%B0%EB%B2%95.md) - 문제를 동일한 성질의 더 작은 크기 부분문제 하나로 줄여 해결하는 축소 정복(Decrease-and-Conquer) 패러다임, 3대 변형 모델(상수 크기 축소: 삽입 정렬 O(n^2), 위상 정렬 Kahn/DFS O(V+E); 상수 비율 축소: 이진 탐색 O(log n), 가짜 동전 찾기 삼분법; 가변 크기 축소: 유클리드 호제법, Quickselect 선택 알고리즘 평균 O(n)), 그리고 DAG(방향 비순환 그래프) 위상 정렬 인터랙티브 시뮬레이터를 다룬다.
* [05. 분할 정복 기법: 합병 정렬, 퀵 정렬의 피벗 전략과 스트라센 행렬 곱셈](./05.%20%EB%B6%84%ED%95%A0%20%EC%A0%95%EB%B3%B5%20%EA%B8%B0%EB%B2%95.md) - 문제를 2개 이상의 독립된 부분문제로 분할하여 각각 정복한 뒤 결합하는 분할 정복(Divide-and-Conquer) 패러다임, 안정 정렬 합병 정렬(Merge Sort O(n log n)), 제자리 정렬 퀵 정렬(QuickSort: 호어/로무토 파티션, 피벗 선정 최적화, 최악 O(n^2) vs 평균 O(n log n)), 최근접 점의 쌍 분할정복 O(n log n), 그리고 기존 O(n^3) 행렬 곱을 O(n^2.807)로 혁신한 스트라센(Strassen) 행렬 곱셈의 7회 곱셈 항 유도와 인터랙티브 시각화를 다룬다.
* [06. 공간으로 시간 벌기: 카운팅 정렬, 호스풀 문자열 매칭과 해시 테이블](./06.%20%EA%B3%B5%EA%B0%84%EC%9C%BC%EB%A1%9C%20%EC%8B%9C%EA%B0%84%20%EB%B2%8C%EA%B8%B0.md) - 추가적인 메모리 공간을 투입하여 계산 시간을 획기적으로 단축하는 공간-시간 트레이드오프(Space-Time Tradeoff), 입력 보강(Input Enhancement: 카운팅 정렬 O(n+k), 호스풀 Boyer-Moore-Horspool 문자열 매칭과 나쁜 문자 이동 테이블 Shift Table), 그리고 사전 구조화(Pre-structuring: 해시 테이블의 충돌 해결 Chaining vs Open Addressing 선형·이차·이중해싱, 2-3 Tree 및 B-Tree 색인)의 이론적 분석과 인터랙티브 시프트 테이블 생성기를 다룬다.
* [07. 동적 계획법: 최적 부분구조, 0/1 배낭 문제, LCS와 플로이드-워셜 알고리즘](./07.%20%EB%8F%99%EC%A0%81%20%EA%B3%84%ED%9A%8D%EB%B2%95.md) - 중복되는 부분 문제들의 해를 테이블에 저장하여 재활용하는 동적 계획법(Dynamic Programming)의 핵심 원리, 2대 성립 조건(최적 부분구조 Optimal Substructure, 중복 부분문제 Overlapping Subproblems), 메모이제이션(하향식) vs 타뷸레이션(상향식), 0/1 배낭 문제(Knapsack DP 점화식 및 역추적 O(nW)), 최장 공통 부분 수열(LCS O(mn)), 모든 쌍 최단 경로 플로이드-워셜(Floyd-Warshall O(V^3)), 그리고 0/1 배낭 DP 테이블 인터랙티브 시뮬레이터를 다룬다.
* [08. 탐욕적 기법: 최소 신장 트리(Prim·Kruskal), 다익스트라 최단 경로와 허프만 코딩](./08.%20%ED%83%90%EC%9A%95%EC%A0%81%20%EA%B8%B0%EB%B2%95.md) - 각 단계에서 눈앞의 최선인 국소적 최적해(Locally Optimal Choice)를 선택하여 전역 최적해(Globally Optimal Solution)에 도달하는 탐욕적 기법(Greedy Method), 2대 성립 요건(탐욕적 선택 속성 Greedy Choice Property, 최적 부분구조), 최소 신장 트리(MST: 프림 Prim O(E log V) vs 크루스칼 Kruskal O(E log E) + Union-Find 서로소 집합), 단일 출발점 최단 경로 다익스트라(Dijkstra O((V+E)log V)), 무손실 압축 허프만 코딩(Huffman Coding의 전위 코드 생성), 그리고 허프만 압축률 인터랙티브 계산기를 다룬다.
