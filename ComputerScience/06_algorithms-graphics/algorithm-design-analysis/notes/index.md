* [02. 알고리즘 효율성 분석 — 시계로 재는 것에서 함수로 재는 것으로](./02.%20%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20%ED%9A%A8%EC%9C%A8%EC%84%B1%20%EB%B6%84%EC%84%9D%EA%B3%BC%20%EC%A0%90%EA%B7%BC%EC%A0%81%20%ED%91%9C%EA%B8%B0%EB%B2%95.md) - 실행시간 측정이 왜 불충분한지에서 출발해 입력 크기·기본 연산·증가율로 이어지는 이론적 분석 틀을 세우고, 빅오·빅오메가·빅세타의 정식 정의와 상호 변환 관계를 강의 필기에 남은 증명과 함께 다룬다. 복잡도 위계, log(n!)의 세타 증명, 반복과 순환 알고리즘의 분석 예제까지 포함한다.

* [05. 분할 정복 기법 — 마스터 정리라는 계산기](./05.%20%EB%B6%84%ED%95%A0%20%EC%A0%95%EB%B3%B5%20%EA%B8%B0%EB%B2%95.md) - 문제를 여러 조각으로 나누어 모두 풀고 합치는 분할 정복을 다룬다. 순환 관계식 T(n)=aT(n/b)+f(n) 과 마스터 정리를 도구로 삼아 병합 정렬·퀵 정렬·이진트리 순회·최근접 쌍·슈트라센 행렬 곱셈을 관통하고, 피보나치를 통해 분할 정복이 실패하는 조건을 밝힌다.
* [06. 공간으로 시간 벌기 — 미리 적어 두면 다시 계산하지 않아도 된다](./06.%20%EA%B3%B5%EA%B0%84%EC%9C%BC%EB%A1%9C%20%EC%8B%9C%EA%B0%84%20%EB%B2%8C%EA%B8%B0.md) - 시간과 공간이 상충한다는 사실을 거래 조건으로 바꾸는 전략들을 다룬다. 비교 없이 배분만으로 정렬하는 기수·카운팅 정렬, 전처리한 시프트 테이블로 건너뛰는 호스풀 문자열 매칭, 그리고 주소를 계산해 버리는 해싱을 원본 예제 그대로 재현해 보인다.
* [07. 동적 계획법: 최적 부분구조, 0/1 배낭 문제, LCS와 플로이드-워셜 알고리즘](./07.%20%EB%8F%99%EC%A0%81%20%EA%B3%84%ED%9A%8D%EB%B2%95.md) - 중복되는 부분 문제들의 해를 테이블에 저장하여 재활용하는 동적 계획법(Dynamic Programming)의 핵심 원리, 2대 성립 조건(최적 부분구조 Optimal Substructure, 중복 부분문제 Overlapping Subproblems), 메모이제이션(하향식) vs 타뷸레이션(상향식), 0/1 배낭 문제(Knapsack DP 점화식 및 역추적 O(nW)), 최장 공통 부분 수열(LCS O(mn)), 모든 쌍 최단 경로 플로이드-워셜(Floyd-Warshall O(V^3)), 그리고 0/1 배낭 DP 테이블 인터랙티브 시뮬레이터를 다룬다.
* [08. 탐욕적 기법: 최소 신장 트리(Prim·Kruskal), 다익스트라 최단 경로와 허프만 코딩](./08.%20%ED%83%90%EC%9A%95%EC%A0%81%20%EA%B8%B0%EB%B2%95.md) - 각 단계에서 눈앞의 최선인 국소적 최적해(Locally Optimal Choice)를 선택하여 전역 최적해(Globally Optimal Solution)에 도달하는 탐욕적 기법(Greedy Method), 2대 성립 요건(탐욕적 선택 속성 Greedy Choice Property, 최적 부분구조), 최소 신장 트리(MST: 프림 Prim O(E log V) vs 크루스칼 Kruskal O(E log E) + Union-Find 서로소 집합), 단일 출발점 최단 경로 다익스트라(Dijkstra O((V+E)log V)), 무손실 압축 허프만 코딩(Huffman Coding의 전위 코드 생성), 그리고 허프만 압축률 인터랙티브 계산기를 다룬다.
* [09. 백트래킹과 분기 한정: 상태 공간 트리, N-Queens 가지치기와 분기 한정 최적화](./09.%20%EB%B0%B1%ED%8A%B8%EB%9E%98%ED%82%B9%EA%B3%BC%20%EB%B6%84%EA%B8%B0%20%ED%95%9C%EC%A0%95.md) - 조합적 최적화 문제의 해 공간을 체계적으로 탐색하는 2대 가지치기(Pruning) 기법, 깊이 우선 탐색(DFS) 기반 백트래킹(Backtracking)의 유망성(Promising) 검사(N-Queens 문제, 부분집합의 합 Subset Sum, 그래프 채색), 너비 우선/최우선 탐색(Best-First Search) 기반 분기 한정(Branch-and-Bound: 상한/하한 Bound 계산을 통한 하위 트리 배제, 0/1 Knapsack 분기한정, 외판원 문제 TSP 행렬 감축), 그리고 N-Queens 백트래킹 인터랙티브 시각화를 다룬다.
