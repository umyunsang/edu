# [2주차] DORA 메트릭 수집 자동화

## 1. DORA 4대 지표 자동 수집 체계 구축
GitHub Actions를 활용하여 개발 생산성과 안정성을 측정하는 4가지 핵심 지표를 자동 수집합니다.

### 수집 대상 지표
*   **Lead Time for Changes**: 코드 커밋부터 프로덕션 배포까지 소요되는 시간
*   **Deployment Frequency**: 성공적인 배포가 수행되는 빈도
*   **MTTR (Mean Time to Restore)**: 장애 발생 시 정상 서비스 복구까지 걸리는 평균 시간
*   **Change Failure Rate**: 배포 후 장애가 발생하여 롤백 또는 핫픽스가 필요한 비율

---

## 2. 시각화 및 결과 보고
수집된 데이터를 팀 구성원이 직관적으로 파악할 수 있도록 구성합니다.

### 대시보드 구성 (Grafana / Chart.js)
*   지표별 추이 그래프 및 현재 상태 요약
*   **구현 결과**: `README.md` 등에 시안 또는 실제 동작 화면 이미지 첨부

---

## 3. (선택 과제) 보고서 자동 생성
수동 리포팅을 최소화하기 위한 자동화 기능을 추가합니다.
*   **JSON 아티팩트**: 수집된 원본 데이터를 JSON 형태로 저장하여 이력 관리
*   **주간 보고서 자동 생성**: 매주 정해진 시간에 `README` 또는 별도 리포트 파일로 자동 업데이트되도록 워크플로우 구성

> [!important]
> **데이터 신뢰성**: 모든 배포는 GitHub Actions를 거쳐야 지표가 누락 없이 정확하게 측정됩니다.
