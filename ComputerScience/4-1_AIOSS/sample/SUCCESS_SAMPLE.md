# 샘플 문제 성공 기준 체크리스트

시험 전 연습용 샘플 1~3의 성공 기준을 한 번에 확인하는 문서입니다.

## 샘플 1. 협업 워크플로우 기초
- [ ] PR 링크 1개를 남겼다.
- [ ] 브랜치 전략 설명을 1문장으로 정리했다.
- [ ] 체크리스트 마크업을 포함했다.

## 샘플 2. CI 파이프라인 기초
- [ ] YML 파일을 작성했다.
- [ ] Actions 실행 링크 1개를 남겼다.
- [ ] 성공 로그를 확인했다.

## 샘플 3. 테스트 기초
- [ ] 테스트 2개를 작성했다.
- [ ] pytest 통과 로그를 남겼다.
- [ ] 실패→성공 흐름이 보이는 커밋 2개를 남겼다.

## 전체 학습 체크
- [ ] 샘플 1을 완료했다.
