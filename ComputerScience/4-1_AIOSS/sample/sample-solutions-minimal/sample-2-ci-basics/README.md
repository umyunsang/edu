# 샘플 2: CI 파이프라인 기초 (minimal)

## 목적
최소 YAML 뼈대에서 GitHub Actions CI 워크플로우를 직접 완성합니다.

## 해야 할 일
1. .github/workflows/ci.yml의 TODO를 채워 push, pull_request 트리거를 완성하세요.
2. checkout, Python 설정, 의존성 설치, lint 단계를 추가하세요.
3. 저장소에 push한 뒤 Actions 실행 결과를 확인하세요.

## 제출 체크
- ci.yml 작성 완료
- Actions 실행 기록 1개 이상
- 성공 또는 실패 로그 확인
