Creative Writing




                       성격의 장점 포인트

긍정적이다 / 변화에 잘 적응한다 / 도전정신이 강하다 / 미래 지향적이다 / 배려심이 강하다/ 사교적이다 / 성실하다 /
순발력이 있다 / 신뢰감을 준다 / 열정적이다 / 융통성이 있다 / 적극적이다/ 진취적이다 / 창의적이다 / 계획적이다 /

 패기가 있다 / 호기심이 많다 / 활동적이다 / 책임감이 강하다/ 자립심이 강하다




                       성격의 단점 포인트

승부욕이 강해 때로 지기 싫어한다 / 처음 본 사람들 앞에서는 말수가 적은 편이다 / 성격이 곧아 바른 말을 할 때가 종종 있
다 / 옳다고 생각하는 부분에서는 자기 주장이 강한 편이다 / 추진력이 강하나 이따금 조심성이 부족하다 / 성격이 급하기
때문에 서두르는 경향이 있다 / 열정이 과해서 주변 사람들이 힘들어 할 때가 있다 / 열등감이 심해 종종 스트레스를 받는다
/ 가끔은 냉정하다 / 한 가지 몰두하면 두루두루 살피지 못하는 편이다 / 주위 사람이 부탁을 하면 거절을 잘 못하는 편이다
/ 감정 컨트롤을 잘 하지만 한번 화가 나면 회복하는데 시간이 걸린다 / 감수성이 예민해 감정의 동요가 심할 때가 있다 /

매사 실수하지 않으려고 노력하다 보니 스트레스가 많은 편이다 / 원칙적인 성향이라 융통성이 부족할 때가 있다 / 보수적
인 성향이다 / 욕심이 많아 많은 일을 동시에 처리하다 보니 꼼꼼하지 못할 때가 있다 / 감정을 잘 드러내지 않는다 / 너무
신중한 나머지 의사결정이 다소 느리다 / 많은 사람들 앞에 설 때 수줍음이 많은 편이다
