## 2. PDF 확인 결과

> [!note] 렌더링 확인
> p.58~149를 PNG로 렌더링하고 주제별 contact sheet를 확인했다. 단순 텍스트 추출보다 손글씨 표시, 밑줄, 번호, 박스 구조가 더 중요하게 보이는 구간이 있었다.

### 2-1. 서론 시작 방법

근거: p.58~67.

| 번호 | 방식 | 판별 단서 |
|---:|---|---|
| 1 | 구체적 사례 | 특정 사건, 자료, 사례에서 출발 |
| 2 | 일반론 | 넓은 사회 현상이나 보편 명제에서 출발 |
| 3 | 인용 | 인물의 말, 문헌, 격언에서 출발 |
| 4 | 상반 견해 | 반대 입장을 먼저 제시한 뒤 반박 방향 |
| 5 | 개념 정의 | 핵심 개념의 의미를 먼저 풀이 |
| 6 | 논제 직접 제시 | 다룰 논쟁이나 논제를 곧바로 제시 |
| 7 | 자신의 경험/생각 | 개인 경험, 감각, 회상에서 출발 |
| 8 | 최근 화제 | 사회적 사건, 최근 뉴스, 시사 문제에서 출발 |
| 9 | 목적/주제 예고 | 글에서 무엇을 다룰지 미리 밝힘 |
| 10 | 두 사실 대조 | 서로 다른 두 사실이나 입장을 대비 |
| 11 | 통계 자료 | p.67에 항목명만 확인됨. 예문은 다음 범위로 넘어가기 전 제목 수준 |

정리 방향: 단순 암기표만으로는 부족하다. 시험이 "내용이 어떤 방법인지 쓰기"라면 PDF에 실린 예문 첫머리의 기능을 보고 분류하는 훈련이 필요하다.

### 2-2. 자기소개서

근거: p.84~98, p.104~127.

| 항목 | 핵심 |
|---|---|
| 작성 목적 | 취업 대비와 자기 이해 과정 |
| 작성 유의사항 | 솔직성, 과장 금지, 자기 경험, 현재와 미래 발전 가능성, 관련 에피소드, 두괄식, 짧은 문장, 인재상 파악 |
| 인재상 키워드 | S 전문성, U 창의성, P 도전정신, E 도덕성, R 주인의식 |
| 자기소개서 특성 3가지 | 복합성, 지속성, 구체성 |
| 작성 3필 | 인성, 열정, 개성 |

| 성격 장단점 핵심 | 장점은 경쟁력으로, 단점은 치명적이지 않게 고르고 개선 근거를 구체화 |

| 성격 장단점 p.126~127 | 전체 고려사항 | 장점/단점 선택 기준과 근거 구체화 기준으로 압축 |

### 2-3. 개조식

근거: p.129~149.

| 항목 | 핵심 |
|---|---|
| 개념 | 번호와 기호를 붙이고 조사/종결어미를 줄여 키워드 중심으로 구조화 |
| 목적 | 독자가 정보를 정확하고 쉽게 파악하도록 하는 정확성/효율성 |
| 장점 | 전체 파악, 요점 파악, 관심사항 선택, 빠른 의미 전달, 재확인 용이, 누락 확인 용이 |
| 작성방법 | 핵심 키워드 선택, 문맥 흐름 구성, 함축적 표현, 중복 제거, 기호와 단문화 활용 |
| 유의사항 | 요점형 압축, 명사형 처리, 문장부호 절제, 조사 최소화, 인과관계 분리, 과분절 주의, 시각정보 활용, 한 줄 한 정보, 평이한 어휘, 중복 제거 |

정리 방향: 3번 문제는 암기형, 4번 문제는 수행형이다. 따라서 "외울 표"와 "PDF 지문 변환 절차"를 분리해야 한다.

## 3. 최종 정리문서 초안 구조 후보

1. 시험 범위 한 장 요약
2. 1번 문제: 서론 시작 방법 판별표 + PDF 지문 판별훈련
3. 2번 문제: 자기소개서 이론 압축
4. 2번 문제: 성장과정 예문 진단표
5. 2번 문제: 성격 장단점 예문 진단표
6. 3번 문제: 개조식 장점/작성방법 암기표
7. 4번 문제: 서술식에서 개조식으로 바꾸는 절차
8. PDF 출제 후보 지문/문제 세트
9. 시험 직전 암기 카드

## 4. 요구사항 루프

### 확정된 요구

- PDF 원문과 렌더링을 모두 근거로 삼는다.
- 교수 공지의 4문항 구조를 최상위 뼈대로 삼는다.
- 자기소개서와 개조식은 단순 요약이 아니라 예문 진단 및 변환 훈련까지 포함한다.
- 최종 문서는 한국어 Obsidian Markdown으로 작성한다.
- 정리문서의 1차 목적은 `암기표 + 진단훈련 + 개조식 변환연습`을 모두 담는 혼합형으로 한다.
- 문서가 길어질 수 있으므로 마지막에 `시험 직전 1장 압축` 섹션을 별도로 둔다.
- 자기소개서 예문 진단표는 `예문 번호별 문제점 + 밑줄 칠 문장 + 시험 답안 문장`까지 포함한다.
- 문제는 새로 생성하지 않는다. PDF에 있는 지문이나 문제에서만 출제된다는 전제로, 정리문서의 훈련문제도 PDF 원문 기반 후보만 다룬다.
- PDF 출제 후보 지문/문제는 범위형으로 추출한다. 즉 `p.58~67`, `p.105~108`, `p.118~120`, `p.140~148`의 지문/문제를 전수 추출한다.
- 손주석 중심 위험도 표는 중간고사 정리와 같은 방식으로 작성한다. 페이지별 손주석, 핵심, 이동 링크까지 포함한 위험도 지도를 둔다.

### 모호성 해소 상태

요구사항 루프의 주요 모호성은 해소됨. 다음 단계는 이 파운데이션을 기준으로 최종 정리문서 [[ComputerScience/07_professional-humanities/creative-writing/기말고사_창의적글쓰기_정리|기말고사_창의적글쓰기_정리]]를 작성하는 것이다.

### Socratic Loop 1

첫 결정 질문: 이 정리문서의 1차 목적은 무엇인가?

- a. 시험장에서 바로 떠올릴 수 있는 암기형
- b. 예문을 보고 문제점을 찾는 진단훈련형
- c. 암기표 + 진단훈련 + 개조식 변환연습을 모두 담는 혼합형

결정: c. 혼합형으로 작성한다. 다만 문서가 길어지므로 마지막에 "시험 직전 1장 압축"을 별도로 둔다.

### Socratic Loop 2

두 번째 결정 질문: 자기소개서 예문 진단표의 깊이는 어디까지 둘 것인가?

- a. 핵심 판단 기준만 정리
- b. 예문 번호별 문제점 + 밑줄 칠 문장까지 정리
- c. 예문 번호별 문제점 + 밑줄 칠 문장 + 시험 답안 문장까지 정리

결정: c. 교수 공지에 "번호를 쓰고 밑줄을 긋고 난 후 무슨 문제가 있는지 쓰기"가 들어 있으므로, 실제 답안 문장까지 준비한다.

### Socratic Loop 3

교정: 신규 예상문제를 만들지 않는다. 문제는 PDF에 있는 지문이나 문제에서만 나온다는 전제로 정리한다.

세 번째 결정 질문: PDF 출제 후보 지문/문제는 어느 깊이까지 추출할 것인가?

- a. 고위험형: 교수 공지와 손주석이 직접 겹치는 지문만 추출
- b. 범위형: p.58~67, p.105~108, p.118~120, p.140~148의 지문/문제를 전수 추출
- c. 답안형: 범위형 전수 추출 + 후보별 밑줄 위치 + 시험 답안 문장까지 작성

결정: b. `p.58~67`, `p.105~108`, `p.118~120`, `p.140~148`의 지문/문제를 전수 추출한다. 단, Socratic Loop 2에서 확정한 자기소개서 예문 진단표는 별도로 `예문 번호별 문제점 + 밑줄 칠 문장 + 시험 답안 문장`까지 작성한다.

### Socratic Loop 4

네 번째 결정 질문: 기존 중간고사 정리처럼 손주석 중심 위험도 표를 넣을 것인가?

- a. 생략: 공지 범위와 PDF 지문 전수 추출만 반영
- b. 간단형: 손주석/공지 겹침 여부만 `상/중/하` 위험도로 표시
- c. 중간고사식: 페이지별 손주석, 핵심, 이동 링크까지 위험도 지도 작성

결정: c. 중간고사식으로 페이지별 손주석, 핵심, 이동 링크까지 포함한 위험도 지도를 작성한다.

## 5. 최종 작성 잠금 사양

최종 정리문서 작성 시 반드시 지킬 사양:

1. PDF 범위: p.58~67, p.84~98, p.104~127, p.129~149.
2. 전수 후보 지문/문제: p.58~67, p.105~108, p.118~120, p.140~148.
3. 자기소개서 예문 진단표: 예문 번호, 밑줄 칠 문장, 문제점, 시험 답안 문장 포함.
4. 문제 생성 금지: PDF 밖의 새 지문/문제는 만들지 않음.
5. 위험도 지도: 중간고사 정리처럼 페이지별 손주석, 핵심, 이동 링크 포함.
6. 최종 구성: 시험 범위 한 장 요약, 서론 판별, 자기소개서 이론/진단, 개조식 암기/변환, PDF 후보 지문/문제, 시험 직전 암기 카드.
