# 컴퓨터비전 코랩 실습 목록

이 폴더는 컴퓨터비전 강의의 주요 알고리즘과 기법들을 Google Colab 환경에서 실습한 노트북 파일들을 담고 있습니다.

## 실습 항목

| 번호 | 실습 명칭 | 주요 내용 | 파일 링크 |
| :-- | :--- | :--- | :--- |
| 1 | **영상 품질 측정** | PSNR 및 SSIM 지표를 활용한 영상 복원 품질 정량 측정 | [노트북](./영상%20품질%20측정%20실습.ipynb) |
| 2 | **슈퍼픽셀 분할** | SLIC 알고리즘을 이용한 이미지의 슈퍼픽셀(Superpixel) 분할 | [노트북](./슈퍼픽셀%20분할%20실습.ipynb) |
| 3 | **최적화 분할** | SLIC 분할 후 N-Cut(Normalized Cut)을 적용한 최적 영역 병합 | [노트북](./최적화%20분할%20실습.ipynb) |
| 4 | **해리스 코너 검출** | Harris Corner Detection 알고리즘을 이용한 특징점(코너) 추출 | [노트북](./해리스%20코너%20검출%20실습.ipynb) |

## 실습 환경
* **Language**: Python 3.10+
* **Library**: OpenCV, NumPy, Scikit-image, Matplotlib
* **Platform**: Google Colab (추천)
