> [!abstract] 이 과목 자료의 성격
> 이 강의의 원본은 성격이 다른 **두 계열**로 되어 있다.
>
> - **교재 슬라이드** — `2주차_리스트`(45쪽)와 `스택과 큐`(51쪽). 완성된 클래스 코드와 수행 시간을 제시한다
> - **교수의 주차별 실습 슬라이드** — 3~13주차. 화살표 그림과 "코드 진행 순서"만 남기고 코드는 학생에게 맡기며, 슬라이드 곳곳에 답 없는 질문을 던진다
>
> 두 계열이 같은 자료구조를 두 번 가르치면서 **서로 다른 설계 결정**을 하고, 때로는 같은 코드를 **정반대로 평가**한다. 아래 정리문서들은 그 차이가 드러나는 지점을 각 장의 척추로 삼았다.

## 원본 자료

`sources/` 의 PDF 22편(총 264쪽)이 전부다. 텍스트 밀도가 매우 낮아(쪽당 평균 100자 남짓) **텍스트가 0자인 페이지 22쪽**에 코드 화면과 추적 그림이 몰려 있으며, 각 노트는 그 페이지들을 본문으로 끌어올려 읽는다. 인용한 슬라이드 이미지는 `assets/` 에 있다.

## 원본에서 발견한 오류

재작성 과정에서 원본 슬라이드와 시험 자료의 오류·불일치 **17건**을 확인했다. 각 노트의 Callout에 근거와 함께 기록해 두었다.
