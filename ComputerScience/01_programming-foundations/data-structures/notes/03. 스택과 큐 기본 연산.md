**스택(Stack)**과 **큐(Queue)**는 데이터의 삽입과 삭제 위치가 엄격히 제한된 선형 자료구조로, 각각 후입선출(LIFO)과 선입선출(FIFO) 규칙을 보장한다.

---

## 1. 스택(LIFO)과 큐(FIFO)의 수학적 대수 모델

### 1) 스택(Stack)의 상태 전이 함수

크기가 $N$인 배열 기반 스택에서 인덱스 $\text{top} \in [-1, N-1]$:

- **공백 및 포화 조건**:
  $$\text{IsEmpty} \iff \text{top} = -1, \quad \text{IsFull} \iff \text{top} = N - 1$$
- **Push 연산**:
  $$\text{top}_{t+1} = \text{top}_t + 1, \quad S[\text{top}_{t+1}] \leftarrow x \quad (\mathcal{O}(1))$$
- **Pop 연산**:
  $$\text{val} \leftarrow S[\text{top}_t], \quad \text{top}_{t+1} = \text{top}_t - 1 \quad (\mathcal{O}(1))$$

### 2) 원형 큐(Circular Queue)의 모듈로($\pmod N$) 대수학

선형 큐의 원소 이동 비용 $\mathcal{O}(n)$과 거짓 포화(False Full) 문제를 해결하기 위해 배열의 양 끝을 환형(Ring)으로 연결한다:

- **포인터 갱신 공식**:
  $$\text{rear}_{t+1} = (\text{rear}_t + 1) \pmod N \quad (\text{Enqueue})$$
  $$\text{front}_{t+1} = (\text{front}_t + 1) \pmod N \quad (\text{Dequeue})$$
- **공백(Empty) vs 포화(Full) 판별 조건**:
  $$\text{IsEmpty} \iff \text{front} = \text{rear}$$
  $$\text{IsFull} \iff (\text{rear} + 1) \pmod N = \text{front}$$
- **현재 큐 내의 유효 원소 개수**:
  $$\text{Count} = (\text{rear} - \text{front} + N) \pmod N$$

## 2. C 언어 원형 큐 구현

```c
#include <stdio.h>
#include <stdbool.h>

#define MAX_QUEUE_SIZE 5

typedef struct {
    int data[MAX_QUEUE_SIZE];
    int front;
    int rear;
} CircularQueue;

void init_queue(CircularQueue *q) {
    q->front = 0;
    q->rear = 0;
}

bool is_empty(CircularQueue *q) {
    return q->front == q->rear;
}

bool is_full(CircularQueue *q) {
    return (q->rear + 1) % MAX_QUEUE_SIZE == q->front;
}

bool enqueue(CircularQueue *q, int item) {
    if (is_full(q)) return false;
    q->rear = (q->rear + 1) % MAX_QUEUE_SIZE;
    q->data[q->rear] = item;
    return true;
}

int dequeue(CircularQueue *q) {
    if (is_empty(q)) return -1;
    q->front = (q->front + 1) % MAX_QUEUE_SIZE;
    return q->data[q->front];
}
```
