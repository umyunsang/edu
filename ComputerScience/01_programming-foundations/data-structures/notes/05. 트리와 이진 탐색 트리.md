\*\*트리(Tree)\*\*는 하나의 루트(Root) 노드와 서로 겹치지 않는 하위 트리(Subtree)들의 계층적 집합으로 이루어진 **비선형 계층 자료구조**이다.

---

## 1. 이진 트리의 수학적 성질과 순회 대수학

### 1) 높이 $h$에 따른 이진 트리의 노드 수 경계 조건

- **최대 노드 수 (포화 이진 트리, Full Binary Tree)**:
  $$N_{\max} = \sum_{i=1}^h 2^{i-1} = 2^h - 1$$
- **단말 노드($n_0$)와 차수가 2인 노드($n_2$)의 관계식 증명**:
  전체 노드 수 $n = n_0 + n_1 + n_2$이고, 전체 간선 수 $e = n - 1 = n_1 + 2 n_2$이므로:
  $$(n_0 + n_1 + n_2) - 1 = n_1 + 2 n_2 \implies n_0 = n_2 + 1$$

### 2) 4대 트리 순회(Traversal)의 재귀적 정의

- **전위 순회 (Preorder, VLR)**: $\text{Visit}(\text{Node}) \to \text{Preorder}(\text{Left}) \to \text{Preorder}(\text{Right})$
- **중위 순회 (Inorder, LVR)**: $\text{Inorder}(\text{Left}) \to \text{Visit}(\text{Node}) \to \text{Inorder}(\text{Right})$ (※ BST에서 오름차순 정렬 출력 보장)
- **후위 순회 (Postorder, LRV)**: $\text{Postorder}(\text{Left}) \to \text{Postorder}(\text{Right}) \to \text{Visit}(\text{Node})$ (※ 트리 전체 메모리 동적 해제에 사용)
- **레벨 순회 (Level-order)**: 큐(Queue)를 이용한 BFS 너비 우선 탐색.

---

## 2. 이진 탐색 트리(BST) 불변식과 3대 삭제 케이스

### 1) BST 불변식 (Invariant)

$$\forall u \in \text{Left}(v), \; \text{key}(u) < \text{key}(v) \quad \land \quad \forall w \in \text{Right}(v), \; \text{key}(w) > \text{key}(v)$$

### 2) 노드 삭제 3대 케이스

- **Case 1: 자식이 없는 리프 노드(Leaf Node)**: 부모의 링크 포인터를 `NULL`로 변경하고 메모리 `free()`.
- **Case 2: 자식이 1개인 노드**: 삭제할 노드의 유일한 자식을 부모 노드에 직결.
- **Case 3: 자식이 2개인 노드**: 오른쪽 서브트리의 최소 노드(Inorder Successor) 또는 왼쪽 서브트리의 최대 노드(Inorder Predecessor)의 값을 복사한 후, 해당 대체 노드를 재귀적으로 삭제.

(function() {
  var bst = [50, 30, 70, 20, 40, 60, 80];
  var view = document.getElementById('bst-view');
  var input = document.getElementById('bst-input');
  var btnAdd = document.getElementById('bst-btn-add');
  var btnInorder = document.getElementById('bst-btn-inorder');
  var btnReset = document.getElementById('bst-btn-reset');

  function renderTree() {
    view.innerHTML = '<div style="color:var(--primary);font-weight:800;margin-bottom:6px">🌲 현재 BST 노드 목록: [' + bst.join(', ') + ']</div>' +
      '<div style="color:var(--muted-foreground);font-size:11px">' +
      '• 루트: <b>' + (bst[0] || '없음') + '</b><br/>' +
      '• 탐색 시간 복잡도: 평균 <b>O(log N)</b>, 최악 <b>O(N)</b>' +
      '</div>';
  }

  btnAdd.addEventListener('click', function() {
    var v = parseInt(input.value, 10);
    if (!isNaN(v) && bst.indexOf(v) === -1) {
      bst.push(v);
      renderTree();
      input.value = v + 5;
    }
  });

  btnInorder.addEventListener('click', function() {
    var sorted = bst.slice().sort(function(a, b) { return a - b; });
    view.innerHTML += '<div style="margin-top:8px;padding:8px;background:var(--card);border:1px solid var(--chart-2);border-radius:var(--radius);color:var(--chart-2);font-weight:800">' +
      '✔ 중위 순회(Inorder) 결과: ' + sorted.join(' ➔ ') +
      '</div>';
  });

  btnReset.addEventListener('click', function() {
    bst = [50, 30, 70, 20, 40, 60, 80];
    renderTree();
  });

  renderTree();
})();
</script>
