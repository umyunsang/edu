트리(Tree)는 계층적(Hierarchical) 관계를 표현하는 비선형 자료구조다. 특히 **이진 탐색 트리(BST, Binary Search Tree)**는 "모든 노드 $x$에 대해 왼쪽 서브트리의 키값은$x.\text{key}$보다 작고, 오른쪽 서브트리의 키값은$x.\text{key}$보다 크다"는 성질을 만족하여 평균$O(\log N)$ 시간에 탐색을 지원한다.

> [!IMPORTANT]
>
> - **순회(Traversal)**: 전위(Preorder: V-L-R), 중위(Inorder: L-V-R, 정렬된 순서 출력), 후위(Postorder: L-R-V, 트리 삭제 및 수식 계산).
> - **BST 삭제 시 3가지 경우**:
>   1. 리프 노드: 즉시 삭제 ($O(1)$).
>   2. 자식이 1개인 노드: 자식을 삭제 노드의 부모에 직접 연결.
>   3. 자식이 2개인 노드: **오른쪽 서브트리의 최솟값(Inorder Successor)** 또는 왼쪽 서브트리의 최댓값으로 노드 값을 교체한 후 해당 후계 노드를 삭제.

## 2. 이진 트리 순회 방식 비교

| 순회 방식 | 방문 순서 | 핵심 용도 및 특징 |
| :--- | :--- | :--- |
| **전위 순회 (Preorder)** | Root $\to$Left$\to$ Right | 트리 구조 복사 및 직렬화 |
| **중위 순회 (Inorder)** | Left $\to$Root$\to$ Right | **이진 탐색 트리의 오름차순 정렬 출력** |
| **후위 순회 (Postorder)** | Left $\to$Right$\to$ Root | 트리 노드 메모리 해제, 수식 트리 계산 |
| **레벨 순회 (Level-order)** | 레벨 0부터 큐를 이용해 순차 방문 | 너비 우선 탐색 (BFS) |

## 3. 시간 복잡도와 편향 트리(Skewed Tree)

- **균형 이진 탐색 트리**: 탐색, 삽입, 삭제 $O(\log N)$
- **경사(편향) 이진 탐색 트리**: 이미 정렬된 데이터($1 \to 2 \to 3 \to 4$)가 순차 삽입될 경우 트리가 한쪽으로 치우쳐 연결 리스트와 동일한$O(N)$으로 성능 저하
- 이러한 최악의 $O(N)$ 성능 저하를 방지하기 위해 **AVL 트리, Red-Black 트리** 같은 자가 균형 트리가 도입된다.
