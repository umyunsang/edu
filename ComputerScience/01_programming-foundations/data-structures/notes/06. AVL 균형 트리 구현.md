AVL 트리는 모든 노드의 **균형 인수(Balance Factor, $BF = \text{Height}(\text{Left}) - \text{Height}(\text{Right})$)**가 항상$\{-1, 0, 1\}$ 범위 내로 유지되도록 보장하는 **자가 균형 이진 탐색 트리(Self-Balancing BST)**다.

> [!IMPORTANT]
> 삽입/삭제 연산으로 인해 어떤 노드의 $\vert BF\vert  \ge 2$가 되는 불균형이 발생하면, 불균형 유형에 따라 4가지 회전 연산 중 하나를 적용하여 트리의 균형을 복구한다.
>
> - **LL 회전**: 왼쪽 자식의 왼쪽에 삽입되어 불균형 발생 $\to$ 우회전(Right Rotation) 1회
> - **RR 회전**: 오른쪽 자식의 오른쪽에 삽입되어 불균형 발생 $\to$ 좌회전(Left Rotation) 1회
> - **LR 회전**: 왼쪽 자식의 오른쪽에 삽입 $\to$ 왼쪽 자식 기준 좌회전 후 부모 기준 우회전 (이중 회전)
> - **RL 회전**: 오른쪽 자식의 왼쪽에 삽입 $\to$ 오른쪽 자식 기준 우회전 후 부모 기준 좌회전 (이중 회전)

## 2. 4가지 회전 요약표

| 불균형 유형 | 삽입 위치 | 회전 연산 | 시간 복잡도 |
| :--- | :--- | :--- | :--- |
| **LL (Left-Left)** | 노드 $A$의 왼쪽 자식의 왼쪽 서브트리 |$A$기준 **우회전(Right Rotate)** 1회 |$O(1)$ |
| **RR (Right-Right)** | 노드 $A$의 오른쪽 자식의 오른쪽 서브트리 |$A$기준 **좌회전(Left Rotate)** 1회 |$O(1)$ |
| **LR (Left-Right)** | 노드 $A$의 왼쪽 자식의 오른쪽 서브트리 | 왼쪽 자식 **좌회전**$\to$ $A$**우회전** (이중 회전) |$O(1)$ |
| **RL (Right-Left)** | 노드 $A$의 오른쪽 자식의 왼쪽 서브트리 | 오른쪽 자식 **우회전**$\to$ $A$**좌회전** (이중 회전) |$O(1)$ |

## 3. AVL 트리의 연산 성능 보장

- **높이 상한**: $N$개의 노드를 가진 AVL 트리의 최대 높이는 약$1.44 \log_2(N + 2) - 0.328$로 엄격하게 제한된다.
- **최악 시간 복잡도**: 탐색, 삽입, 삭제 모두 **$O(\log N)$**을 절대적으로 보장한다.
