컴퓨터는 괄호와 연산자 우선순위가 복잡하게 얽힌 \*\*중위 표기법(Infix Notation, $A + B \times C$)\*\*을 직접 계산하기 어려우므로, 괄호가 필요 없고 선형 스캔으로 즉시 계산 가능한 \*\*후위 표기법(Postfix / Reverse Polish Notation, $A ; B ; C \times +$)\*\*으로 변환하여 처리한다.

---

## 1. 연산자 우선순위 함수와 스택 변환 규칙의 수학적 정의

### 1) 연산자 우선순위 사상 함수 $\text{prec}(\text{op})$

$$\text{prec}(\text{op}) = \begin{cases} 2 & \text{if } \text{op} \in \{ '*', '/' \} \\ 1 & \text{if } \text{op} \in \{ '+', '-' \} \\ 0 & \text{if } \text{op} = '(' \quad (\text{스택 내부}) \end{cases}$$

### 2) 션팅야드(Shunting-yard) 알고리즘의 상태 전이

중위 수식의 토큰 $T$를 좌에서 우로 순차 스캔할 때:

- **피연산자(숫자/변수)**: 즉시 출력 문자열 버퍼에 추가.
- **여는 괄호 `(`**: 스택에 무조건 `push('(')`.
- **닫는 괄호 `)`**: `top() == '('`가 될 때까지 스택에서 `pop()`하여 출력에 추가 후, 여는 괄호는 버림.
- **연산자 $\odot$**: $\text{prec}(\text{top}) \ge \text{prec}(\odot)$인 동안 계속 `pop()`하여 출력에 추가한 뒤, $\odot$을 `push`.

### 3) 후위 표기 수식 평가 (Postfix Evaluation)

후위 수식에서 연산자 $\odot$를 만났을 때의 대수적 계산:

$$b \leftarrow \text{pop}(), \quad a \leftarrow \text{pop}(), \quad \text{push}(a \odot b)$$

---

## 2. 수식 표기법 비교 요약

| 표기 방식 (Notation) | 수식 표현 예시 | 괄호 필요 여부 | 컴퓨터 처리 방식 |
| :--- | :--- | :--- | :--- |
| **중위 표기 (Infix)** | $(A + B) \times (C - D)$ | 필수 (연산 순서 제어) | 인간 친화적, 컴파일러 파싱 필요 |
| **후위 표기 (Postfix / RPN)** | $A ; B + C ; D - \times$ | 불필요 | 스택 1회 선형 주사로 $\mathcal{O}(n)$ 즉시 계산 |
| **전위 표기 (Prefix / Polish)** | $\times ; + ; A ; B ; - ; C ; D$ | 불필요 | 우에서 좌로 역방향 스택 주사 계산 |

(function() {
  var input = document.getElementById('post-input');
  var btn = document.getElementById('post-run-btn');
  var rTxt = document.getElementById('post-res-txt');
  var eTxt = document.getElementById('post-eval-txt');

  function prec(op) {
    if (op === '*' || op === '/') return 2;
    if (op === '+' || op === '-') return 1;
    return 0;
  }

  function process() {
    var raw = input.value.trim();
    // 토큰화
    var tokens = raw.match(/([0-9]+|\+|\-|\*|\/|\(|\))/g) || [];
    var stack = [];
    var output = [];

    for (var i = 0; i < tokens.length; i++) {
      var t = tokens[i];
      if (/^[0-9]+$/.test(t)) {
        output.push(t);
      } else if (t === '(') {
        stack.push(t);
      } else if (t === ')') {
        while (stack.length > 0 && stack[stack.length - 1] !== '(') {
          output.push(stack.pop());
        }
        stack.pop(); // '(' 제거
      } else {
        while (stack.length > 0 && prec(stack[stack.length - 1]) >= prec(t)) {
          output.push(stack.pop());
        }
        stack.push(t);
      }
    }
    while (stack.length > 0) output.push(stack.pop());

    var postfixStr = output.join(' ');
    rTxt.textContent = postfixStr || '(수식 오류)';

    // 후위식 평가
    var evalStack = [];
    for (var j = 0; j < output.length; j++) {
      var tok = output[j];
      if (/^[0-9]+$/.test(tok)) {
        evalStack.push(parseFloat(tok));
      } else {
        var b = evalStack.pop();
        var a = evalStack.pop();
        var res = 0;
        if (tok === '+') res = a + b;
        else if (tok === '-') res = a - b;
        else if (tok === '*') res = a * b;
        else if (tok === '/') res = a / b;
        evalStack.push(res);
      }
    }
    eTxt.textContent = (evalStack.length > 0) ? evalStack[0] : 'N/A';
  }

  btn.addEventListener('click', process);
  process();
})();
</script>
