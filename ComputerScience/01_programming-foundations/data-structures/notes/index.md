* [03. 스택(Stack)과 수식 표기법 변환·괄호 매칭 - LIFO 구조와 Shunting-Yard 알고리즘](./03.%20%EC%8A%A4%ED%83%9D%28Stack%29%EA%B3%BC%20%EC%88%98%EC%8B%9D%20%ED%91%9C%EA%B8%B0%EB%B2%95%20%EB%B3%80%ED%99%98%C2%B7%EA%B4%84%ED%98%B8%20%EB%A7%A4%EC%B9%AD.md) - 스택(Stack)의 LIFO 원리와 노드/배열 구현, 함수 호출 스택 및 괄호 검사 메커니즘, 중위 표기식(Infix)의 후위 표기식(Postfix) 변환과 스택 기반 수식 계산기를 인터랙티브 시뮬레이터로 학습한다.
* [04. 큐(Queue)와 원형 큐·덱(Deque) - FIFO 구조와 원형 버퍼 모듈로 연산](./04.%20%ED%81%90%28Queue%29%EC%99%80%20%EC%9B%90%ED%98%95%20%ED%81%90%C2%B7%EB%8D%B1%28Deque%29.md) - 큐(Queue)의 선입선출(FIFO) 원리, 선형 큐의 거짓 포화(False Overflow) 문제와 원형 큐(Circular Queue)의 모듈로(%) 포인터 인덱싱, 그리고 양방향 덱(Deque)의 4대 기본 연산을 인터랙티브 원형 큐 시뮬레이터로 학습한다.
* [05. 트리(Tree)와 이진 탐색 트리(BST) - 4대 순회(Traversal)와 3단계 노드 삭제 메커니즘](./05.%20%ED%8A%B8%EB%A6%AC%28Tree%29%EC%99%80%20%EC%9D%B4%EC%A7%84%20%ED%83%90%EC%83%89%20%ED%8A%B8%EB%A6%AC%28BST%29.md) - 비선형 계층 자료구조인 트리(Tree)의 용어, 포화·완전·편향 이진 트리의 분류, 전위/중위/후위/레벨 4대 순회 알고리즘, 그리고 BST의 불변성(Invariant)과 3단계 노드 삭제를 인터랙티브 BST 시뮬레이터로 학습한다.
