연결 리스트(Linked List)는 데이터 필드와 다음 노드의 주소를 가리키는 링크(포인터) 필드로 구성된 **동적 자료구조**다. 배열과 달리 연속된 메모리 공간을 요구하지 않으며, 삽입과 삭제 시 원소들의 물리적 이동 없이 링크 수정만으로 $O(1)$ 연산이 가능하다.

> [!IMPORTANT]
>
> - **단일 연결 리스트(Singly Linked List)**: 각 노드가 오직 후속 노드(`next`)만을 가리킴.
> - **이중 연결 리스트(Doubly Linked List)**: `prev`와 `next`를 모두 유지하여 양방향 탐색 가능.
> - **원형 연결 리스트(Circular Linked List)**: 마지막 노드의 `next`가 다시 `head`를 가리켜 순환 루프 형성.

## 2. 노드 삽입 및 삭제 알고리즘 불변식

<Tabs>
  <Tab label="단일 연결 리스트 (Singly)">
    - **중간 노드 삽입 (`pre` 노드 뒤에 `newNode` 삽입)**:
      ```c
      newNode->next = pre->next;
      pre->next = newNode;
      ```
    - **중간 노드 삭제 (`pre` 노드 뒤의 `target` 삭제)**:
      ```c
      pre->next = target->next;
      free(target);
      ```
  </Tab>
  <Tab label="이중 연결 리스트 (Doubly)">
    - **삽입 (`p` 뒤에 `newNode` 삽입)**:
      ```c
      newNode->prev = p;
      newNode->next = p->next;
      if (p->next != NULL) p->next->prev = newNode;
      p->next = newNode;
      ```
    - **삭제 (`target` 삭제)**:
      ```c
      if (target->prev != NULL) target->prev->next = target->next;
      if (target->next != NULL) target->next->prev = target->prev;
      free(target);
      ```
  </Tab>
  <Tab label="원형 연결 리스트 (Circular)">
    - **단일 포인터(`tail`)로 `head`와 `tail` 동시 접근**:
      - `tail`: 마지막 노드
      - `head`: `tail->next`
    - 첫 번째 위치 삽입 시 `newNode->next = tail->next; tail->next = newNode;`
  </Tab>
</Tabs>

## 3. 배열 vs 연결 리스트 시간 복잡도 비교

| 연산 | 순차 리스트 (배열) | 단일 연결 리스트 | 이중 연결 리스트 |
| :--- | :--- | :--- | :--- |
| **임의 인덱스 접근 ($i$번째 조회)** |$O(1)$|$O(N)$|$O(N)$ |
| **맨 앞 삽입 / 삭제** | $O(N)$(전체 원소 이동) |$O(1)$|$O(1)$ |
| **맨 뒤 삽입** | $O(1)$|$O(N)$(Tail 없으면) /$O(1)$|$O(1)$ |
| **중간 노드 삽입 / 삭제 (위치 알고 있을 때)** | $O(N)$(시프트 필요) |$O(1)$|$O(1)$ |
| **메모리 오버헤드** | 정적 고정 할당 | 링크 포인터 1개 추가 | 링크 포인터 2개 추가 |

> [!WARNING]
> 연결 리스트에서 노드를 삭제하기 전에 반드시 `next` 링크를 사전에 저장하거나 연결해야 하며, 그렇지 않으면 후속 노드들의 메모리 주소를 잃어버리는 **메모리 누수(Memory Leak)** 및 단절 문제가 발생한다.
