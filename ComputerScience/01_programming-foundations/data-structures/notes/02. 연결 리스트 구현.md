\*\*연결 리스트(Linked List)\*\*는 데이터 필드와 다음(혹은 이전) 노드의 메모리 주소를 저장하는 링크(포인터) 필드로 구성된 **동적 비연속 선형 자료구조**이다.

---

## 1. 노드 구조와 포인터 사상의 수학적 정의

### 1) 노드(Node)의 대수적 튜플 모델

- **단일 연결 리스트 (Singly Linked List)**:
  $$N_i = \langle d_i, \; \text{next}_i \rangle, \quad \text{next}_i = \&N_{i+1}, \quad \text{next}_k = \text{NULL}$$
- **이중 연결 리스트 (Doubly Linked List)**:
  $$N_i = \langle \text{prev}_i, \; d_i, \; \text{next}_i \rangle, \quad \text{next}_i = \&N_{i+1}, \quad \text{prev}_{i+1} = \&N_i$$
- **원형 연결 리스트 (Circular Linked List)**:
  $$\text{next}_k = \&N_1 \quad (\text{단일 원형}), \quad \text{prev}_1 = \&N_k \quad (\text{이중 원형})$$

### 2) 노드당 메모리 소요량 및 공간 오버헤드

데이터 크기를 $S\_{\text{data}}$, 아키텍처 포인터 크기를 $S\_{\text{ptr}}$ (64-bit 시스템에서 $8\text{ Bytes}$)라 할 때:

$$M_{\text{singly}}(n) = n \cdot (S_{\text{data}} + S_{\text{ptr}})$$

$$M_{\text{doubly}}(n) = n \cdot (S_{\text{data}} + 2 S_{\text{ptr}})$$

---

## 2. 노드 삽입 및 삭제 연산 알고리즘

### 1) 기준 노드 $P$ 뒤에 새 노드 $N\_{\text{new}}$ 삽입 (Singly Linked List)

$$1.\; N_{\text{new}} \to \text{next} \leftarrow P \to \text{next}$$

$$2.\; P \to \text{next} \leftarrow N_{\text{new}}$$

시간 복잡도는 위치 $P$가 주어졌을 때 $\mathcal{O}(1)$이다.

### 2) 기준 노드 $P$ 뒤의 노드 $Q$ 삭제

$$1.\; Q \leftarrow P \to \text{next}$$

$$2.\; P \to \text{next} \leftarrow Q \to \text{next}$$

$$3.\; \text{free}(Q)$$

---

## 3. C 언어 단일 연결 리스트 실습 코드

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 맨 앞(Head)에 새 노드 삽입: O(1)
void insert_head(Node **head_ref, int new_data) {
    Node *new_node = (Node *)malloc(sizeof(Node));
    new_node->data = new_data;
    new_node->next = *head_ref;
    *head_ref = new_node;
}

// 맨 앞(Head) 노드 삭제: O(1)
void delete_head(Node **head_ref) {
    if (*head_ref == NULL) return;
    Node *temp = *head_ref;
    *head_ref = (*head_ref)->next;
    free(temp);
}

// 리스트 전체 순회 출력: O(N)
void print_list(Node *head) {
    Node *curr = head;
    while (curr != NULL) {
        printf("[%d] -> ", curr->data);
        curr = curr->next;
    }
    printf("NULL\n");
}
```
