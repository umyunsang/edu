\*\*자료구조(Data Structure)\*\*는 컴퓨터 메모리 공간에 데이터를 효율적으로 조직·저장·관리하여 탐색, 삽입, 삭제 등의 핵심 연산을 최적의 시간 및 공간 복잡도로 수행하기 위한 전산학의 근간이다.

---

## 1. 추상 데이터 타입(ADT)과 점근적 표기법의 수학적 공식화

### 1) ADT의 대수적 정의

추상 데이터 타입(Abstract Data Type, ADT)은 데이터의 구체적인 구현 방식(배열, 포인터)과 무관하게 데이터 객체 집합 $\mathcal{D}$와 해당 객체에 적용 가능한 연산 집합 $\mathcal{F}$의 순서쌍으로 정의된다:

$$\text{ADT} = \langle \mathcal{D}, \; \mathcal{F} \rangle$$

### 2) 3대 점근적 복잡도(Asymptotic Complexity)의 엄밀한 정의

임의의 알고리즘 실행 시간 함수 $f(n)$과 기준 함수 $g(n)$에 대해:

- **점근적 상한 (Big-O, $\mathcal{O}$)**: 최악의 경우(Worst-Case) 상한선
  $$f(n) \in \mathcal{O}(g(n)) \iff \exists c > 0, n_0 \ge 0 \quad \text{s.t.} \quad \forall n \ge n_0, \; 0 \le f(n) \le c \cdot g(n)$$
- **점근적 하한 (Big-$\Omega$, $\Omega$)**: 최선의 경우(Best-Case) 하한선
  $$f(n) \in \Omega(g(n)) \iff \exists c > 0, n_0 \ge 0 \quad \text{s.t.} \quad \forall n \ge n_0, \; 0 \le c \cdot g(n) \le f(n)$$
- **점근적 상·하한 (Big-$\Theta$, $\Theta$)**: 평균적(Tight Bound) 특성
  $$f(n) \in \Theta(g(n)) \iff f(n) \in \mathcal{O}(g(n)) \;\land\; f(n) \in \Omega(g(n))$$

$$\mathcal{O}(1) < \mathcal{O}(\log n) < \mathcal{O}(n) < \mathcal{O}(n \log n) < \mathcal{O}(n^2) < \mathcal{O}(2^n) < \mathcal{O}(n!)$$

## 2. C 언어 동적 메모리 할당(Dynamic Allocation) 라이프사이클

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int id;
    double score;
} Student;

int main() {
    int n = 5;
    // 1. 힙(Heap) 영역에 메모리 동적 할당
    Student *arr = (Student *)malloc(n * sizeof(Student));
    if (arr == NULL) {
        fprintf(stderr, "메모리 할당 실패 (Out of Memory)\n");
        return 1;
    }

    // 2. 메모리 사용
    for (int i = 0; i < n; i++) {
        arr[i].id = 1000 + i;
        arr[i].score = 90.5 + i;
    }

    // 3. 사용 완료 후 반드시 메모리 해제 (메모리 누수 방지)
    free(arr);
    arr = NULL; // 댕글링 포인터(Dangling Pointer) 방지

    return 0;
}
```

## 3. 주요 자료구조 5대 기본 연산 시간 복잡도 비교

| 자료구조 (Data Structure) | 인덱스 임의 접근 | 원소 검색 (Search) | 맨 앞 삽입/삭제 | 맨 뒤 삽입/삭제 | 메모리 연속성 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **정적 배열 (Array)** | $\mathcal{O}(1)$ | $\mathcal{O}(n)$ | $\mathcal{O}(n)$ | $\mathcal{O}(1)$ | 물리적 연속 (Cache-Friendly) |
| **단일 연결 리스트 (Singly Linked List)** | $\mathcal{O}(n)$ | $\mathcal{O}(n)$ | $\mathcal{O}(1)$ | $\mathcal{O}(n)$ | 포인터 분산 (Heap) |
| **이중 연결 리스트 (Doubly Linked List)** | $\mathcal{O}(n)$ | $\mathcal{O}(n)$ | $\mathcal{O}(1)$ | $\mathcal{O}(1)$ (Tail 보유 시) | 포인터 분산 (2개 링크) |
| **균형 이진 탐색 트리 (AVL)** | $\mathcal{O}(\log n)$ | $\mathcal{O}(\log n)$ | $\mathcal{O}(\log n)$ | $\mathcal{O}(\log n)$ | 비선형 계층 노드 |
| **해시 테이블 (Hash Table)** | N/A | $\mathcal{O}(1)$ (평균) | $\mathcal{O}(1)$ | $\mathcal{O}(1)$ | 버킷 배열 + 체이닝 |
