자료구조는 데이터를 메모리에 효율적으로 조직화하여 문제 해결에 필요한 **탐색·접근·삽입·삭제·갱신** 연산의 시간 및 공간 비용을 최적화하는 전산학의 기본 뼈대다.

> [!IMPORTANT]
>
> - **추상 데이터 타입(ADT, Abstract Data Type)**: 데이터의 논리적 형태와 연산 명세를 정의하며, 구체적인 구현(배열, 포인터)과 분리된다.
> - **시간 복잡도(Time Complexity)**: 입력 크기 $N$에 따른 연산 횟수의 점근적 상한선($O$-표기법).

## 2. 자료구조 핵심 5대 연산

| 연산 | 연산 질문 | 예시 메소드 |
| :--- | :--- | :--- |
| **탐색 (Search)** | 특정 값을 가진 원소가 존재하는가? 위치는 어디인가? | `find(x)`, `indexOf(x)` |
| **접근 (Access)** | $i$번째 위치에 저장된 값을 읽을 수 있는가? | `arr[i]`, `get(i)` |
| **삽입 (Insert)** | 새로운 원소를 지정된 위치에 구조 파괴 없이 추가할 수 있는가? | `push()`, `append()`, `insertAt()` |
| **삭제 (Delete)** | 지정된 위치나 특정 값을 가진 노드를 안전하게 제거할 수 있는가? | `pop()`, `remove()`, `free()` |
| **갱신 (Update)** | 기존 원소의 값을 새로운 값으로 교체할 수 있는가? | `arr[i] = newVal`, `set(i, val)` |
