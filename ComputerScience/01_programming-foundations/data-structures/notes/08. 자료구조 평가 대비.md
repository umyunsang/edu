## 2. 수식 표기 변환 스택 추적 모범 답안

| 순번 | 읽은 토큰 | 스택(Stack) 상태 | 출력(Output) 버퍼 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `A` | `[ ]` | `A` | 피연산자 출력 |
| 2 | `+` | `[ + ]` | `A` | 연산자 Push |
| 3 | `B` | `[ + ]` | `A B` | 피연산자 출력 |
| 4 | `*` | `[ +, * ]` | `A B` | 우선순위 높으므로 Push |
| 5 | `C` | `[ +, * ]` | `A B C` | 피연산자 출력 |
| 6 | `-` | `[ - ]` | `A B C * +` | `*`, `+` Pop 후 `-` Push |
| 7 | `D` | `[ - ]` | `A B C * + D` | 피연산자 출력 |
| 8 | 종료 | `[ ]` | `A B C * + D -` | 스택 비우기 (최종 완료) |
