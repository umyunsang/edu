자료구조 평가는 **구조별 불변식(Invariants), 삽입·삭제 시 포인터 변화 순서, 트리 순회 결과 추적, 정렬 알고리즘의 단계별 상태 및 복잡도 판정**을 중심으로 출제된다.

> [!IMPORTANT]
>
> - **연결 리스트**: 빈 리스트, 첫 노드, 마지막 노드 삽입/삭제 시의 예외 처리(Head 갱신, Tail 갱신) 주의.
> - **BST**: 중위 순회(Inorder) 결과는 반드시 **오름차순 정렬** 상태여야 함.
> - **정렬 복잡도**: 퀵 정렬의 최악 시간은 $O(N^2)$ (이미 정렬된 경우 피벗 편향), 병합 정렬은 항상 $O(N \log N)$이나 $O(N)$의 추가 공간 요구.

## 2. 영역별 핵심 평가 체크리스트

| 영역 | 빈출 핵심 개념 |
| :--- | :--- |
| **선형 구조** | 배열과 연결 리스트의 메모리 배치 및 복잡도 차이, 원형 연결 리스트의 tail 링크 특성 |
| **스택 & 큐** | 스택 LIFO vs 큐 FIFO, 괄호 검사 불변식, 원형 큐의 모듈로 인덱싱 |
| **트리 & BST** | 이진 트리 차수/높이, 중위 순회 정렬 보장, 자식이 2개인 노드 삭제 시 후계자(Inorder Successor) 탐색 |
| **정렬** | 안정/불안정 정렬 구분, 제자리(In-Place) 여부, 각 정렬의 최선/평균/최악 시간 복잡도 |

> [!TIP]
> 객관식 시험에서 "항상", "모든 경우에"라는 단정이 포함된 선택지는 편향 트리, 이미 정렬된 배열 등 최악의 케이스(Worst Case)를 떠올려 반례를 검증하면 정답률을 높일 수 있다.
