> [!abstract] 이 과목은
> 현재 폴더에는 강의용 원본 PDF가 없어, 출처 없는 주제 노트를 새로 만들지 않는다.

## 자료 상태

현재 확인된 항목은 과목 인덱스뿐이다. 원본 PDF가 추가되면 파일명에 01., 02. 순서를 부여하고 실제 강의 흐름을 확인한 뒤 정리문서를 작성한다.

## 정리문서

원본 PDF 부재로 재구성된 정리문서는 없다. 기존에 남아 있던 링크는 현재 문서 트리와 맞지 않아 제거했다.

> [!note] 재개 조건
> PDF가 들어오면 페이지·도식·수치의 근거를 먼저 추출하고, 필요한 경우 승인된 크롭 이미지만 assets/에 추가한다.
