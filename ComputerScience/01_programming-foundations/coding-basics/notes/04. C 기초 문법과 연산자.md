## 1. C 기본 자료형의 메모리 크기와 수치 표현 범위

$n$-비트 정수형에 대해 부호 있는(Signed) 정수와 부호 없는(Unsigned) 정수의 표현 범위:

$$\text{Range}_{\text{signed}} = \left[ -2^{n-1}, \; 2^{n-1} - 1 \right]$$

$$\text{Range}_{\text{unsigned}} = \left[ 0, \; 2^n - 1 \right]$$

| 자료형 (Data Type) | 크기 (Bytes / bits) | 수치 표현 범위 (Representation Range) | 서식 지정자 |
| :--- | :--- | :--- | :--- |
| `char` | 1 Byte (8 bits) | $-128 \sim 127$ (ASCII 매핑) | `%c`, `%d` |
| `unsigned char` | 1 Byte (8 bits) | $0 \sim 255$ | `%u` |
| `int` | 4 Bytes (32 bits) | $-2,147,483,648 \sim 2,147,483,647$ | `%d` |
| `unsigned int` | 4 Bytes (32 bits) | $0 \sim 4,294,967,295$ | `%u`, `%x` |
| `float` | 4 Bytes (32 bits) | $\pm 3.4 \times 10^{\pm 38}$ (유효숫자 7자리) | `%f` |
| `double` | 8 Bytes (64 bits) | $\pm 1.7 \times 10^{\pm 308}$ (유효숫자 16자리) | `%lf` |

## 2. 비트 연산자(Bitwise Operators)의 부울 대수학

비트 연산자는 CPU 레지스터 단위에서 1클록 사이클 내에 즉시 실행되는 초고속 연산이다.

### 1) 비트 조작 기본 공식

- **$k$번째 비트 1로 설정 (Set bit)**:
  $$x_{\text{set}} = x \mid (1 \ll k)$$
- **$k$번째 비트 0으로 해제 (Clear bit)**:
  $$x_{\text{clear}} = x \ \& \sim(1 \ll k)$$
- **$k$번째 비트 반전 (Toggle bit)**:
  $$x_{\text{toggle}} = x \oplus (1 \ll k)$$
- **시프트 연산을 통한 $2^k$ 배수 곱셈 및 나눗셈**:
  $$x \ll k = x \times 2^k, \quad x \gg k = \left\lfloor \frac{x}{2^k} \right\rfloor$$

### 2) 논리 연산자와 단락 평가(Short-Circuit Evaluation)

- `A && B`: $A$가 거짓(`0`)이면 $B$는 평가조차 하지 않고 즉시 `0` 반환.
- `A || B`: $A$가 참(`1`)이면 $B$는 평가조차 하지 않고 즉시 `1` 반환.

## 3. 3대 반복 제어문 비교: for vs while vs do\~while

```c
#include <stdio.h>

int main() {
    // 1. for 루프: 반복 횟수가 명확할 때
    int sum_for = 0;
    for (int i = 1; i <= 10; i++) {
        sum_for += i;
    }

    // 2. while 루프: 조건 만족 시 반복 (사전 조건 검사)
    int n = 1, sum_while = 0;
    while (n <= 10) {
        sum_while += n;
        n++;
    }

    // 3. do-while 루프: 최소 1회 무조건 실행 보장 (사후 조건 검사)
    int k = 1, sum_do = 0;
    do {
        sum_do += k;
        k++;
    } while (k <= 10);

    printf("For: %d, While: %d, Do-While: %d\n", sum_for, sum_while, sum_do);
    return 0;
}
```
