\*\*앱 인벤터(MIT App Inventor)\*\*는 모바일 안드로이드/iOS 스마트폰 하드웨어(카메라, 마이크, 가속도 센서, GPS)와 클라우드 AI 서비스(음성 인식, 웹 API)를 블록 코딩으로 통합 구축하는 이벤트 구동 모바일 애플리케이션 개발 환경이다.

---

## 1. 모바일 음성 AI 파이프라인의 엔드투엔드 지연시간 모델링

스마트폰에서 사용자의 음성을 수신하여 대화형 인공지능 응답을 출력하기까지의 총 소요 시간 $T\_{\text{total}}$:

$$T_{\text{total}} = T_{\text{record}} + T_{\text{net\_up}} + T_{\text{STT}} + T_{\text{intent\_eval}} + T_{\text{TTS}} + T_{\text{audio\_out}}$$

- **음성 인식 (STT, Speech-to-Text)**: 마이크 오디오 샘플 $\mathbf{x}\_{\text{audio}} \xrightarrow{\text{Acoustic Model}} \text{텍스트 문자열 } S$.
- **의도 분류 (Intent Classification)**: 조건문 블록 매칭 또는 유사도 판별 $I = \arg\max_c P(c \mid S)$.
- **음성 합성 (TTS, Text-to-Speech)**: 텍스트 응답 $R \xrightarrow{\text{Vocoder}} \text{스피커 음성 파형}$.

## 3. TinyDB 키-값(Key-Value) 영구 저장소 매핑

앱이 재시작되어도 상태를 유지하기 위한 비휘발성 로컬 데이터베이스 모델:

$$\text{StoreValue}(\text{Tag } K, \; \text{Value } V) \implies \mathcal{D}_{\text{TinyDB}}[K] \leftarrow V$$

$$\text{GetValue}(\text{Tag } K, \; \text{Default } V_0) \implies \begin{cases} \mathcal{D}_{\text{TinyDB}}[K] & \text{if } K \in \text{Keys}(\mathcal{D}) \\ V_0 & \text{otherwise} \end{cases}$$
