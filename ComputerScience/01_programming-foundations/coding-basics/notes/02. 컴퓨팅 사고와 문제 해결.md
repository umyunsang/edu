## 2. 일상 비유와 시스템 아키텍처의 수학적 모델링

### 1) 지역성 기반 캐시 메모리(Cache Memory)

주방 조미료통처럼 자주 사용하는 데이터를 CPU 가까이에 배치하여 평균 접근 시간(Effective Access Time, EAT)을 극대화한다:

$$\text{EAT} = h \cdot T_{\text{cache}} + (1 - h) \cdot T_{\text{RAM}}$$

여기서 $h \in [0, 1]$는 캐시 적중률(Hit Ratio)이다.

### 2) 병렬 처리(Parallel Processing)와 암달의 법칙(Amdahl's Law)

맛집 주방을 2개로 늘려 조리 시간을 단축하듯, $N$개의 프로세서 코어로 프로그램을 병렬 가속할 때의 최대 이론적 속도 향상비(Speedup) $S(N)$:

$$S(N) = \frac{1}{(1 - p) + \frac{p}{N}}$$

- $p$: 프로그램 전체 실행 시간 중 병렬화 가능한 비율 ($0 \le p \le 1$).
- $(1 - p)$: 단일 스레드로만 실행되어야 하는 순차적 병목 비율.

---

## 3. 분할 정복(Divide and Conquer)의 점화식과 시간 복잡도

크기 $n$인 문제를 $b$개의 하위 문제로 분할하고 각각의 크기가 $n/b$일 때, 마스터 정리에 따른 총 수행 시간 $T(n)$:

$$T(n) = a T\left(\frac{n}{b}\right) + \mathcal{O}(n^d)$$

- **이진 탐색(Binary Search)**: $a=1, b=2, d=0 \implies T(n) = \mathcal{O}(\log n)$
- 순차 탐색 $\mathcal{O}(n)$ 대비 검색 공간을 매 스텝마다 절반씩 기하급수적으로 축소한다.

(function() {
  var sP = document.getElementById('ct-p-slider');
  var sN = document.getElementById('ct-n-slider');
  var vP = document.getElementById('ct-p-val');
  var vN = document.getElementById('ct-n-val');

  var tEff = document.getElementById('ct-eff-txt');

    var n = parseInt(sN.value, 10);

    vP.textContent = (p * 100).toFixed(0) + '%';
    vN.textContent = n + ' Cores';

    var speedup = 1.0 / ((1.0 - p) + (p / n));
    var limit = (1.0 - p > 0.0001) ? (1.0 / (1.0 - p)) : 999.0;
    var eff = (speedup / n) * 100.0;

    tSp.textContent = speedup.toFixed(2) + 'x';
    tLim.textContent = (limit >= 999) ? '∞ (무한)' : limit.toFixed(2) + 'x (최대)';
    tEff.textContent = eff.toFixed(1) + '%';
  }

  sP.addEventListener('input', render);
  sN.addEventListener('input', render);
  render();
})();
</script>
