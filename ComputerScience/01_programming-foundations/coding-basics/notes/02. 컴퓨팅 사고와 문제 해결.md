컴퓨팅 사고(Computational Thinking)는 복잡한 문제를 컴퓨터가 효과적으로 수행할 수 있도록 문제를 재구성하고 해결책을 도출하는 **논리적 사고 프로세스**다.

> [!IMPORTANT]
>
> 1. **문제 분해(Decomposition)**: 거대하고 복잡한 문제를 다루기 쉬운 작은 단위의 세부 문제로 쪼갠다.
> 2. **패턴 인식(Pattern Recognition)**: 분해된 문제들 사이의 공통된 규칙이나 반복되는 패턴을 발견한다.
> 3. **추상화(Abstraction)**: 핵심적인 특징에만 집중하고 불필요한 세부 사항(디테일)은 과감하게 제거한다.
> 4. **알고리즘(Algorithm)**: 문제를 해결하기 위한 일련의 명확하고 유한한 절차를 순서대로 정의한다.

## 2. 순서도(Flowchart) 주요 표준 기호

| 기호 명칭 | 형태 및 의미 | 사용처 |
| :--- | :--- | :--- |
| **단말 (Terminal)** | 타원 / 둥근 사각형 | 프로그램의 시작(Start)과 종료(End) |
| **처리 (Process)** | 직사각형 | 변수 대입, 연산 및 값 변경 |
| **입출력 (I/O)** | 평행사변형 | 사용자 키보드 입력 및 화면 출력 |
| **판단 (Decision)** | 마름모 | 조건 비교 분기 (참/거짓 경로 분기) |
| **선 및 화살표** | 화살표 | 제어 흐름의 실행 순서 표시 |
