아두이노(Arduino)는 마이크로컨트롤러를 기반으로 센서 입력을 받아 모터, LED, 스피커 등의 액추에이터를 제어하는 **임베디드 피지컬 컴퓨팅 플랫폼**이다.

> [!IMPORTANT]
> - `setup()`: 아두이노 부팅 시 최초 1회 실행되는 핀 모드(`pinMode`) 초기화 함수.
> - `loop()`: 전원이 공급되는 동안 무한히 반복 실행되는 메인 제어 루프.
> - **PWM (Pulse Width Modulation)**: 디지털 핀에서 듀티 사이클(Duty Cycle, $0 \sim 255$)을 조절하여 아날로그 전압 출력(밝기 조절, 모터 속도)을 흉내 내는 기법.

## 2. 주요 아두이노 기본 함수 레퍼런스

| 함수 | 문법 및 설명 |
| :--- | :--- |
| `pinMode()` | `pinMode(pin, INPUT / OUTPUT / INPUT_PULLUP)` : 핀 입출력 방향 설정 |
| `digitalWrite()` | `digitalWrite(pin, HIGH / LOW)` : 5V 또는 0V 출력 |
| `digitalRead()` | `int state = digitalRead(pin);` : 핀의 0 또는 1 논리 상태 읽기 |
| `analogWrite()` | `analogWrite(pin, 0~255);` : PWM 펄스 폭 변조로 아날로그 신호 출력 |
| `delay()` | `delay(ms);` : 지정된 밀리초(ms) 동안 프로그램 실행 일시 정지 |

## 3. 풀업(Pull-Up) 및 풀다운(Pull-Down) 저항

버튼 스위치 연결 시 핀이 공중에 떠 있어 0과 1이 불규칙하게 요동치는 **플로팅(Floating)** 현상을 방지하기 위해 사용된다.
- **풀업 저항**: 기본 상태를 HIGH(5V)로 유지하고, 버튼을 누르면 LOW(GND)로 떨어짐.
- **아두이노 내부 풀업**: `pinMode(pin, INPUT_PULLUP)`로 외장 저항 없이 간편하게 활성화 가능.
