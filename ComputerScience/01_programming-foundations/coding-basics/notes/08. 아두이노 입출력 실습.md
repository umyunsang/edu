아두이노(Arduino)는 마이크로컨트롤러(ATmega328P 등)를 기반으로 센서 입력을 처리하고 모터·LED 등의 구동기(Actuator)를 제어하는 오픈소스 임베디드 프로토타이핑 플랫폼이다.

---

## 1. 하드웨어 회로 이론과 전기적 계산 수식

### 1) 옴의 법칙(Ohm's Law) 기반 LED 전류 제한 저항 산정

LED의 순방향 전압 강하를 $V_f$ (약 $2.0\text{V}$), 허용 순방향 전류를 $I_f$ (약 $15\text{mA}$), 아두이노 전원 전압을 $V\_{\text{cc}} = 5.0\text{V}$라 할 때, 직렬 보호 저항 $R$의 최적값:

$$R = \frac{V_{\text{cc}} - V_f}{I_f} = \frac{5.0\text{V} - 2.0\text{V}}{0.015\text{A}} = 200\,\Omega \quad (\text{표준 저항 } 220\,\Omega \sim 330\,\Omega \text{ 사용})$$

### 2) 10-bit ADC 전압 변환 및 8-bit PWM 듀티비

- **10-bit ADC (`analogRead`) 전압 분해능**:
  $$V_{\text{in}} = \text{val}_{\text{ADC}} \times \frac{5.0\text{V}}{1023} \quad (\text{분해능 } \Delta V \approx 4.887\text{ mV})$$
- **8-bit PWM (`analogWrite`) 평균 출력 전압**:
  $$V_{\text{avg}} = D \times V_{\text{cc}} = \left( \frac{\text{val}_{\text{PWM}}}{255} \right) \times 5.0\text{V}$$
  - $\text{val}_{\text{PWM}} = 127 \implies D = 50\% \implies V_{\text{avg}} = 2.5\text{V}$

## 3. 디지털 입출력 및 PWM 제어 아두이노 C++ 코드

```cpp
const int LED_PIN = 9;       // PWM 지원 디지털 핀 (~9)
const int BUTTON_PIN = 2;    // 입력 버튼 핀

void setup() {
    pinMode(LED_PIN, OUTPUT);
    // 내부 풀업 저항 활성화 (외부 저항 없이 핀 2번과 GND에 버튼 직결 가능)
    pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
    int buttonState = digitalRead(BUTTON_PIN);

    if (buttonState == LOW) { // 풀업이므로 눌렸을 때 LOW
        // PWM 듀티비 점진적 증가 (페이드 인 효과)
        for (int brightness = 0; brightness <= 255; brightness += 5) {
            analogWrite(LED_PIN, brightness);
            delay(15);
        }
    } else {
        analogWrite(LED_PIN, 0); // 소등
    }
}
```
