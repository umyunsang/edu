스크래치(Scratch)는 텍스트 타이핑 문법 오류 없이 드래그 앤 드롭 블록 결합을 통해 프로그래밍의 논리 구조(이벤트, 반복, 조건, 변수, 방송)를 직관적으로 익히는 **시각적 프로그래밍 언어(EPL)**다.

> [!IMPORTANT]
> - **무대 좌표계**: 중앙이 $(0, 0)$, $x$축 범위는 $-240 \sim +240$, $y$축 범위는 $-180 \sim +180$.
> - **이벤트 기반 프로그래밍**: "깃발을 클릭했을 때", "키보드 스페이스를 눌렀을 때" 등의 이벤트 수신에 의해 스크립트 실행이 트리거된다.
> - **메시지 방송(Broadcast)**: 여러 스프라이트 간의 비동기적 통신 및 협업을 지원하는 핵심 기법.

## 2. 스크래치 8대 블록 카테고리

| 블록 색상/범주 | 대표 기능 | 주요 블록 예시 |
| :--- | :--- | :--- |
| **동작 (Motion, 파랑)** | 스프라이트 이동, 회전, 좌표 지정 | `10만큼 움직이기`, `(0, 0) 위치로 이동하기` |
| **형태 (Looks, 보라)** | 말풍선 표시, 모양/크기 변경, 색상 효과 | `"안녕!" 말하기`, `다음 모양으로 바꾸기` |
| **소리 (Sound, 분홍)** | 사운드 재생, 음량/음높이 조절 | `야옹 재생하기`, `모든 소리 멈추기` |
| **이벤트 (Events, 노랑)** | 스크립트 실행 시작 조건 트리거 | `⚑ 클릭했을 때`, `[스페이스] 키 눌렀을 때` |
| **제어 (Control, 주황)** | 반복 루프 및 조건 분기 | `10번 반복하기`, `무한 반복하기`, `만약 ~라면` |
| **감지 (Sensing, 하늘)** | 마우스, 벽, 다른 스프라이트 충돌 감지 | `[벽]에 닿았는가?`, `마우스 x좌표` |
| **연산 (Operators, 초록)** | 사칙연산, 난수, 비교, 논리 결합 | `(1)부터 (10) 사이의 난수`, `< > =`, `그리고/또는` |
| **변수 (Variables, 짙은주황)** | 데이터 저장 및 리스트 관리 | `점수를 (1)만큼 바꾸기`, `[항목]을 리스트에 추가` |
