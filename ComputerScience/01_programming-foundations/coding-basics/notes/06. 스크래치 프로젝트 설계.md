\*\*스크래치(Scratch)\*\*는 MIT 미디어랩에서 개발한 교육용 블록 기반 시각적 프로그래밍 언어(EPL)로, 텍스트 문법 오류 없이 이벤트·반복·조건·변수·메시지 방송의 핵심 컴퓨터 과학 논리를 직관적으로 구현한다.

---

## 1. 2D 무대 좌표계와 이동 벡터의 수학적 공식화

### 1) 평면 직교 좌표계와 위치 갱신 벡터

스크래치 무대(Stage)는 중앙을 원점 $(0, 0)$으로 하며, 가로 $x \in [-240, 240]$, 세로 $y \in [-180, 180]$ 영역을 갖는다.

각도 $\theta$ ($0^\circ$: 위쪽, $90^\circ$: 오른쪽, $180^\circ$: 아래쪽, $270^\circ$: 왼쪽)를 바라보는 스프라이트가 속도 $v$만큼 전진할 때의 위치 전이식:

$$\mathbf{p}_{t+1} = \mathbf{p}_t + v \cdot \begin{pmatrix} \sin \theta \\ \cos \theta \end{pmatrix} = \begin{pmatrix} x_t + v \sin \theta \\ y_t + v \cos \theta \end{pmatrix}$$

### 2) "벽에 닿으면 튕기기" 경계 반사 벡터 법칙

- **좌우 벽 ($|x| \ge 240$) 충돌 시**:
  $$\theta_{\text{new}} = -\theta \pmod{360^\circ}$$
- **상하 벽 ($|y| \ge 180$) 충돌 시**:
  $$\theta_{\text{new}} = (180^\circ - \theta) \pmod{360^\circ}$$

### 3) 메시지 방송(Broadcast) 이벤트 디스패치 모델

발행인(Publisher) 스프라이트가 메시지 $m$을 방송하면, 해당 메시지를 구독하는 모든 수신자(Subscriber) 스프라이트의 핸들러가 비동기 병렬로 트리거된다:

$$\text{Broadcast}(m) \implies \forall k \in \text{Subscribers}(m), \quad \text{Execute}\big( \text{WhenIReceive}(m, k) \big)$$

(function() {
  var posX = 0, posY = 0;

  document.getElementById('sc-btn-down').addEventListener('click', function() { posY -= 20; update(); });

  document.getElementById('sc-btn-right').addEventListener('click', function() { posX += 20; update(); });
  document.getElementById('sc-btn-reset').addEventListener('click', function() { posX = 0; posY = 0; bubble.style.display = 'none'; update(); });
  document.getElementById('sc-btn-say').addEventListener('click', function() {

    setTimeout(function() { bubble.style.display = 'none'; }, 1500);
  });
})();
