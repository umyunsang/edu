C 프로그램은 값을 담을 변수에서 시작해 여러 값을 배열로 묶고, 반복되는 작업을 함수로 분리한다.

> [!IMPORTANT]
> 자료의 진행 순서인 변수 선언 → 데이터 형식 → 배열 → 함수의 입력·처리·반환을 유지했다.

---

## 1. 변수와 데이터 형식

변수는 값을 담는 이름 있는 공간이다. 같은 형식은 쉼표로 연속 선언할 수 있고, 세미콜론으로 문장을 분리한다. 자료는 정수형·실수형과 char를 구분하며 char는 1바이트(8비트), -128~127 범위로 설명한다.

```mermaid
flowchart LR
  A["선언: 형식 + 이름"] --> B["대입: 값 저장"]
  B --> C["식에서 참조"]
  C --> D["새 값으로 갱신"]
```

---

## 2. 배열은 0번 인덱스에서 시작한다

배열은 같은 형식의 변수를 나란히 연결한 것이다. 네 개의 정수 배열은 aa[0]부터 aa[3]까지 사용하며, 반복문으로 인덱스를 바꾸면 여러 변수에 같은 연산을 적용할 수 있다.

<Tabs>
  <Tab label="변수">한 값을 이름으로 저장하고 대입 연산자로 갱신한다.</Tab>
  <Tab label="배열">같은 형식의 여러 값을 인덱스로 접근한다. 인덱스는 0에서 시작한다.</Tab>
  <Tab label="반복문 결합">for의 인덱스 i를 aa[i]에 넣어 선언·입력·출력을 자동화한다.</Tab>
</Tabs>

---

## 3. 함수의 입력·처리·반환

함수는 자판기처럼 매개변수를 입력받아 처리하고 반환값을 돌려준다. 반환값이 없으면 void로 표시한다. 자료는 값의 전달(call by value)과 주소·참조로 전달되는 경우를 비교한다.

| 구성 | 확인할 질문 |
| --- | --- |
| 매개변수 | 호출할 때 무엇을 넘기는가? |
| 처리 | 함수 내부에서 어떤 변환을 하는가? |
| 반환값 | 결과를 호출한 쪽에 돌려주는가? |
| 전달 방식 | 원본 값이 유지되는가, 주소를 통해 바뀌는가? |

```html preview
<div style="font-family:system-ui,sans-serif;padding:20px;color:var(--foreground)">
```

<details>
<summary>호출 방식 점검</summary>

값으로 전달하면 함수 안에서 복사된 값이 바뀌어 호출자 변수는 원래 값을 유지한다. 주소 또는 참조로 전달하면 원본을 가리키는 방식이므로 함수 밖 값의 변화 여부를 별도로 확인해야 한다.

</details>

> [!TIP]
> 배열과 함수는 함께 사용하면 반복되는 데이터를 한 곳에서 처리하고 결과를 반환하는 구조를 만들 수 있다.
