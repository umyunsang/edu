변수는 메모리 상의 특정 위치에 이름을 부여한 공간이며, \*\*배열(Array)\*\*은 동일한 자료형의 원소들을 연속된 메모리 공간에 일괄 할당하여 인덱스로 빠르게 접근하는 자료구조이다.

---

## 1. 다차원 배열의 행 우선(Row-Major) 메모리 주소 사상 공식

### 1) 1차원 배열 인덱스 주소 계산

크기가 $N$이고 요소당 바이트 크기가 $S$인 1차원 배열 $A$의 $i$번째 원소 메모리 주소:

$$\text{Address}(A[i]) = \text{BaseAddress}(A) + i \times S$$

모든 인덱스 접근은 $\mathcal{O}(1)$ 상수 시간에 직접 계산된다.

### 2) 2차원 배열 ($R \times C$) 행 우선 연속 사상

$R$행 $C$열을 가진 2차원 배열 $A[R][C]$에서 $(i, j)$ 위치 원소의 물리 메모리 주소:

$$\text{Address}(A[i][j]) = \text{BaseAddress}(A) + (i \times C + j) \times S$$

## 3. C 포인터 기반 Swap 함수 실습 코드

```c
#include <stdio.h>

// 1. 값에 의한 전달 (실패: 복사본만 교환됨)
void swap_by_val(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

// 2. 주소에 의한 참조 전달 (성공: 원본 메모리 교환)
void swap_by_ref(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;

    swap_by_val(x, y);
    printf("After swap_by_val: x = %d, y = %d (불변)\n", x, y); // x=10, y=20

    swap_by_ref(&x, &y);
    printf("After swap_by_ref: x = %d, y = %d (교환 성공)\n", x, y); // x=20, y=10

    return 0;
}
```
