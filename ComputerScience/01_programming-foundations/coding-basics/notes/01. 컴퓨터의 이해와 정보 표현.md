컴퓨터는 데이터를 입력받아 중앙처리장치(CPU)와 주기억장치를 통해 처리한 뒤 의미 있는 정보로 출력하거나 보조기억장치에 영구 저장하는 전자 정보 처리 시스템이다.

> [!IMPORTANT]
> - **비트(bit)**: 0 또는 1을 저장하는 정보 표현의 최소 단위.
> - **바이트(Byte)**: $1 \text{ Byte} = 8 \text{ bits}$ ($0 \sim 255$ 또는 $-128 \sim 127$).
> - **진법 체계**: 2진수($0, 1$), 10진수($0 \sim 9$), 16진수($0 \sim 9, \text{A} \sim \text{F}$). 16진수 1자리는 2진수 4비트(Nibble)와 정확히 $1:1$ 대응된다.

## 2. 하드웨어 5대 핵심 장치 구조

| 장치 | 역할 | 주방 비유 |
| :--- | :--- | :--- |
| **중앙처리장치 (CPU)** | 명령어 해석 및 산술·논리 연산 | 총괄 주방장 (조리 수행) |
| **주기억장치 (RAM)** | 현재 실행 중인 프로그램과 데이터 적재 | 도마/조리대 (빠른 임시 작업 공간) |
| **보조기억장치 (SSD/HDD)** | 대용량 데이터의 영구적 보관 | 재료 저장 창고/냉장고 |
| **입력장치 (Input)** | 키보드, 마우스, 터치센서 데이터 전달 | 식재료 주문 및 입고 |
| **출력장치 (Output)** | 모니터, 프린터, 스피커로 결과 표시 | 완성된 요리 서빙 |

## 3. 정보 단위 체계

$$1 \text{ Byte} = 8 \text{ bits}$$
$$1 \text{ KB} = 2^{10} \text{ B} = 1,024 \text{ Bytes}$$
$$1 \text{ MB} = 2^{20} \text{ B} = 1,024 \text{ KB}$$
$$1 \text{ GB} = 2^{30} \text{ B} = 1,024 \text{ MB}$$
$$1 \text{ TB} = 2^{40} \text{ B} = 1,024 \text{ GB}$$
