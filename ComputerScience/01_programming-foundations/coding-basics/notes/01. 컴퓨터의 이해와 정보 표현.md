## 2. 수치 데이터 표현과 진법 변환의 수학적 공식화

### 1) $r$-진법 가중치 전개식 (Positional Number Representation)

기저(Base)가 $r$인 수 체계에서 정수부 $n$자리, 소수부 $m$자리로 구성된 임의의 수 $N_r = (d\_{n-1} d\_{n-2} \dots d_0 . d\_{-1} \dots d\_{-m})\_r$의 10진수 환산 가중치 합 공식은 다음과 같다:

$$N_{10} = \sum_{i=-m}^{n-1} d_i \cdot r^i = d_{n-1} r^{n-1} + \dots + d_0 r^0 + d_{-1} r^{-1} + \dots + d_{-m} r^{-m}$$

- **2진수(Binary, $r=2$)**: $d_i \in {0, 1}$
- **8진수(Octal, $r=8$)**: $d_i \in {0, 1, \dots, 7}$ (2진수 3비트 묶음: $2^3 = 8$)
- **16진수(Hexadecimal, $r=16$)**: $d_i \in \{0, \dots, 9, \text{A}, \dots, \text{F}\}$ (2진수 4비트 묶음: $2^4 = 16$)

### 2) 보수(Complement)와 2의 보수 음수 가산기

$n$-비트 2진수 $A$에 대해 1의 보수 $\bar{A}\_1$ 및 2의 보수 $\bar{A}\_2$는 다음과 같이 정의된다:

$$\bar{A}_1 = (2^n - 1) - A \quad (\text{모든 비트 반전 } 0 \leftrightarrow 1)$$

$$\bar{A}_2 = 2^n - A = \bar{A}_1 + 1$$

컴퓨터의 ALU는 감산기(Subtractor) 회로를 별도로 구현하지 않고, 2의 보수 음수를 가산기(Adder)에 통과시켜 $A - B$를 연산한다:

$$A - B \equiv A + \bar{B}_2 \pmod{2^n}$$

### 3) IEEE 754 단정밀도(32-bit Single Precision) 부동소수점

실수 $V$는 부호(Sign, 1-bit), 지수(Exponent, 8-bit, Bias $127$), 가수(Mantissa/Fraction, 23-bit)로 표현된다:

$$V = (-1)^s \times (1.m)_2 \times 2^{e - 127}$$

## 3. 디지털 멀티미디어 인코딩 수학

### 1) 래스터 이미지(비트맵) 메모리 소요량

가로 $W$ 픽셀, 세로 $H$ 픽셀, 색상 비트 심도(Color Depth) $B$ 비트에 대해:

$$\text{Image Size (Bytes)} = \frac{W \times H \times B}{8}$$

- 24-bit TrueColor (RGB 각 8-bit): $1920 \times 1080 \times 3 \text{ Bytes} \approx 6.22 \text{ MB}$ (비압축 원본 1프레임).

### 2) 디지털 오디오 나이퀴스트-섀넌 표본화 정리(Nyquist-Shannon Theorem)

아날로그 음성 신호의 최고 주파수가 $f\_{\max}$일 때, 에일리어싱(Aliasing) 왜곡 없이 원음을 완벽히 복원하기 위한 최소 표본화 주파수(Sampling Rate) $f_s$는 다음과 같다:

$$f_s \ge 2 f_{\max}$$

- CD 품질 오디오: 인간 가청 주파수 상한 $20\text{kHz}$에 따라 $f_s = 44.1\text{kHz}$, 16-bit, 2채널(Stereo):
  $$\text{Bitrate} = 44,100 \text{ Hz} \times 16 \text{ bits} \times 2 = 1.4112 \text{ Mbps}$$

(function() {
  var sIn = document.getElementById('cb-dec-input');
  var sSli = document.getElementById('cb-dec-slider');
  var tBin = document.getElementById('cb-bin-txt');

    var binStr = unsignedVal.toString(2).padStart(8, '0');

    var ascii = (unsignedVal >= 32 && unsignedVal <= 126) ? "'" + String.fromCharCode(unsignedVal) + "' (" + unsignedVal + ")" : '(제어코드)';

    tBin.textContent = binStr;
    tHex.textContent = hexStr;
    tAscii.textContent = ascii;

    bCont.innerHTML = '';
    for (var i = 0; i < 8; i++) {
      (function(idx) {
        var bit = binStr[idx];
        var btn = document.createElement('button');
        btn.style.width = '34px';
        btn.style.height = '34px';
        btn.style.borderRadius = '4px';
        btn.style.border = '1px solid var(--border)';

        btn.style.color = (bit === '1') ? '#fff' : 'var(--muted-foreground)';
        btn.style.fontWeight = '800';
        btn.style.fontSize = '12px';
        btn.style.cursor = 'pointer';
        btn.textContent = bit;

        btn.addEventListener('click', function() {
          var arr = binStr.split('');
          arr[idx] = (arr[idx] === '1') ? '0' : '1';
          var newUnsigned = parseInt(arr.join(''), 2);
          var newSigned = (newUnsigned >= 128) ? (newUnsigned - 256) : newUnsigned;
          update(newSigned);
        });

        bCont.appendChild(btn);
      })(i);
    }
  }

  sIn.addEventListener('input', function() { update(sIn.value); });
  sSli.addEventListener('input', function() { update(sSli.value); });
