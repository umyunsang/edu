알고리즘은 주어진 문제를 해결하기 위한 유한한 규칙과 단계들의 집합이다. 모든 알고리즘은 **순차(Sequence), 선택(Selection), 반복(Iteration)**의 3대 기본 제어 구조의 조합으로 구성된다.

> [!IMPORTANT]
>
> - **순차 구조**: 위에서 아래로 명령어가 순서대로 실행됨.
> - **선택 구조**: 조건식의 참/거짓 평가 결과에 따라 실행 흐름이 분기됨 (`if-else`, `switch-case`).
> - **반복 구조**: 조건이 만족되는 동안 특정 코드 블록을 되풀이 실행 (`for`, `while`).

## 2. 프로그래밍 언어의 발전 계보

| 세대 | 언어 유형 | 대표 언어 | 특징 |
| :--- | :--- | :--- | :--- |
| **1세대** | 기계어 (Machine Code) | `0100 1101 ...` | CPU가 직접 해독하는 2진 코드, 가독성 전무 |
| **2세대** | 어셈블리어 (Assembly) | `MOV`, `ADD`, `JMP` | 기계어와 1:1 대응되는 기호(Mnemonic) 사용 |
| **3세대** | 절차/객체지향 고급언어 | C, Java, C++, Python | 사람이 이해하기 쉬운 영어 문장 및 수식 구조 |
| **4세대** | 비절차적 특수언어 | SQL, R | "어떻게(How)"가 아닌 "무엇을(What)" 처리할지 명시 |

## 3. 좋은 알고리즘의 5대 조건

1. **입력(Input)**: 외부에서 제공되는 0개 이상의 명확한 입력.
2. **출력(Output)**: 적어도 1개 이상의 결과를 도출.
3. **명확성(Definiteness)**: 각 명령어의 의미가 모호하지 않고 명료해야 함.
4. **유한성(Finiteness)**: 유한한 단계 후에 반드시 종료되어야 함.
5. **유효성(Effectiveness)**: 모든 연산이 컴퓨터로 실행 가능해야 함.
