격자(Grid) 기반 알고리즘은 2차원 평면에서 주변 $8$개 방향(상, 하, 좌, 우, 대각선 $4$개)의 상대 좌표 **델타 배열(`dx`, `dy`)**을 활용하여 경계 조건(`0 <= nx < N`)을 검사하며 순회하는 전형적인 코딩 테스트 및 실기 시험 유형이다.

> [!IMPORTANT]
>
> - **8방향 델타 정의**:
>
>   ```python
>   dr = [-1, -1, -1, 0, 0, 1, 1, 1]
>   dc = [-1, 0, 1, -1, 1, -1, 0, 1]
>   ```
>
> - **경계 체크**: `0 <= r + dr[k] < rows and 0 <= c + dc[k] < cols` 조건을 반드시 먼저 만족해야 유효한 인덱스로 접근한다.

## 1. 4x4 지뢰찾기 격자 & 8방향 탐색 인터랙티브 시뮬레이터

타일을 클릭하여 지뢰를 피하고 주변 8칸의 지뢰 개수를 확인해보세요.

```html preview
<div style="font-family:system-ui,-apple-system,sans-serif;padding:18px;background:var(--card);color:var(--card-foreground);border:1px solid var(--border);border-radius:var(--radius);max-width:100%">

    <button id="mine-btn-reset" style="padding:6px 12px;background:var(--chart-1);color:#fff;border:none;border-radius:var(--radius);cursor:pointer;font-weight:600;font-size:12px">새 게임 시작</button>
  </div>

  <!-- 4x4 지뢰 격자 -->
  <div id="mine-grid" style="display:grid;grid-template-columns:repeat(4, 50px);gap:6px;justify-content:center;margin-bottom:14px"></div>

  <!-- 로그 설명 -->
  <div id="mine-log" style="font-size:12px;color:var(--muted-foreground);text-align:center">
    총 4x4 격자 중 3개의 지뢰가 숨겨져 있습니다.
  </div>
</div>

<script>
(function() {
  var size = 4;
  var mineCount = 3;
  var board = [];
  var revealed = [];
  var gameOver = false;

  var gridEl = document.getElementById('mine-grid');
  var statusEl = document.getElementById('mine-status');
  var logEl = document.getElementById('mine-log');
  var btnReset = document.getElementById('mine-btn-reset');

  var dr = [-1, -1, -1, 0, 0, 1, 1, 1];
  var dc = [-1, 0, 1, -1, 1, -1, 0, 1];

  function initGame() {
    gameOver = false;
    board = [];
    revealed = [];
    statusEl.textContent = '게임 진행 중: 타일을 클릭하세요';
    statusEl.style.color = 'var(--primary)';

    for (var r = 0; r < size; r++) {
      board[r] = [];
      revealed[r] = [];
      for (var c = 0; c < size; c++) {
        board[r][c] = 0;
        revealed[r][c] = false;
      }
    }

    // 지뢰 무작위 3개 배치
    var placed = 0;
    while (placed < mineCount) {
      var rr = Math.floor(Math.random() * size);
      var cc = Math.floor(Math.random() * size);
      if (board[rr][cc] !== -1) {
        board[rr][cc] = -1; // mine
        placed++;
      }
    }

    // 주변 지뢰 수 계산
    for (var r = 0; r < size; r++) {
      for (var c = 0; c < size; c++) {
        if (board[r][c] === -1) continue;
        var cnt = 0;
        for (var k = 0; k < 8; k++) {
          var nr = r + dr[k];
          var nc = c + dc[k];
          if (nr >= 0 && nr < size && nc >= 0 && nc < size) {
            if (board[nr][nc] === -1) cnt++;
          }
        }
        board[r][c] = cnt;
      }
    }

    renderGrid();
  }

  function renderGrid() {
    gridEl.innerHTML = '';
    for (var r = 0; r < size; r++) {
      for (var c = 0; c < size; c++) {
        var cell = document.createElement('button');
        cell.style.width = '50px';
        cell.style.height = '50px';
        cell.style.border = '1px solid var(--border)';
        cell.style.borderRadius = '6px';
        cell.style.fontSize = '14px';
        cell.style.fontWeight = '700';
        cell.style.cursor = 'pointer';

        if (revealed[r][c]) {
          cell.style.background = 'var(--background)';
          if (board[r][c] === -1) {
            cell.textContent = '💣';
            cell.style.background = 'var(--destructive)';
          } else if (board[r][c] === 0) {
            cell.textContent = '';
            cell.style.color = 'var(--muted-foreground)';
          } else {
            cell.textContent = board[r][c];
            cell.style.color = 'var(--chart-1)';
          }
        } else {
          cell.style.background = 'var(--card)';
          cell.style.color = 'var(--foreground)';
          cell.textContent = '■';
        }

        (function(row, col) {
          cell.addEventListener('click', function() {
            if (gameOver || revealed[row][col]) return;
            revealed[row][col] = true;
            if (board[row][col] === -1) {
              gameOver = true;
              statusEl.textContent = ' 지뢰를 밟았습니다! 게임 오버';
              statusEl.style.color = 'var(--destructive)';
              // 전체 공개
              for (var i = 0; i < size; i++) {
                for (var j = 0; j < size; j++) revealed[i][j] = true;
              }
            } else {
              checkWin();
            }
            renderGrid();
          });
        })(r, c);

        gridEl.appendChild(cell);
      }
    }
  }

  function checkWin() {
    var unrevealedSafe = 0;
    for (var r = 0; r < size; r++) {
      for (var c = 0; c < size; c++) {
        if (board[r][c] !== -1 && !revealed[r][c]) unrevealedSafe++;
      }
    }
    if (unrevealedSafe === 0) {
      gameOver = true;
      statusEl.textContent = ' 축하합니다! 모든 안전한 칸을 찾았습니다!';
      statusEl.style.color = 'var(--chart-2)';
    }
  }

  btnReset.addEventListener('click', initGame);
  initGame();
})();
</script>
```

## 2. 중간고사 빈출 2차원 리스트 문제 체크리스트

| 문제 유형 | 핵심 해결 전략 |
| :--- | :--- |
| **격자 테두리 패딩(Padding)** | 상하좌우를 `0`으로 둘러싸 경계 분기문을 생략하는 기법 |
| **대각선 원소 합** | 주 대각선(`matrix[i][i]`) 및 부 대각선(`matrix[i][N-1-i]`) 인덱싱 |
| **전치 행렬 (Transpose)** | `list(map(list, zip(*matrix)))` 또는 `[[row[i] for row in matrix] for i in range(len(matrix[0]))]` |
