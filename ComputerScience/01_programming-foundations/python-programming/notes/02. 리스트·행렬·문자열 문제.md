2차원 리스트(행렬)와 문자열 인덱싱, 그리고 수학적 알고리즘(유클리드 호제법)을 결합하여 복합적인 데이터 조작을 구현한다.

> [!IMPORTANT]
>
> - **행렬의 덧셈**: $C[i][j] = A[i][j] + B[i][j]$ (이중 루프 또는 `zip()` 활용).
> - **유클리드 호제법**: $\gcd(a, b) = \gcd(b, a \pmod b)$ 이며, 최소공배수 $\text{LCM}(a, b) = \frac{a \times b}{\gcd(a, b)}$.
> - **이상한 문자 만들기**: 각 단어별로 짝수번째 알파벳은 대문자, 홀수번째 알파벳은 소문자로 변환.

## 2. 파이썬 2차원 리스트 생성 및 제어 문법

- **안전한 2차원 배열 초기화**:

  ```python
  matrix = [[0] * cols for _ in range(rows)]
  ```

  *(주의: `[[0]*cols]*rows`는 얕은 복사로 인해 한 행을 수정하면 모든 행이 함께 바뀌는 버그 발생)*
- **행렬 덧셈 1줄 표현**:

  ```python
  answer = [[c + d for c, d in zip(r1, r2)] for r1, r2 in zip(arr1, arr2)]
  ```
