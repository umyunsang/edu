## 1. 수학적 원리와 수식 공식화

### 1) 3진법 뒤집기 및 10진수 복원 대수학

10진수 $n$을 3진수 계수열 $(d_k, d\_{k-1}, \dots, d_0)\_3$ ($0 \le d_i < 3$)으로 표현할 때:

$$n = \sum_{i=0}^k d_i \cdot 3^i$$

이를 앞뒤로 반전시킨 계수열 $(d_0, d_1, \dots, d_k)_3$의 10진수 값 $n_{\text{rev}}$:

$$n_{\text{rev}} = \sum_{i=0}^k d_i \cdot 3^{k - i}$$

### 2) 약수의 개수 홀짝성 정리 (Divisor Parity Theorem)

임의의 자연수 $n$의 양의 약수의 개수 $d(n)$이 홀수일 필요충분조건은 \*\*$n$이 완전제곱수($n = k^2, k \in \mathbb{N}$)\*\*인 경우뿐이다:

$$d(n) \equiv 1 \pmod 2 \iff \sqrt{n} \in \mathbb{N}$$

따라서 $left \sim right$ 구간의 합산 함수:

$$\text{Sum} = \sum_{x=\text{left}}^{\text{right}} \begin{cases} -x & \text{if } \sqrt{x} \in \mathbb{N} \\ +x & \text{otherwise} \end{cases}$$

### 3) 놀이기구 이용료의 등차수열 합

$1$회차 $P$, $2$회차 $2P$, $\dots$, $c$회차 $c P$의 총 필요 금액:

$$\text{Cost}_{\text{total}} = P \sum_{i=1}^c i = P \cdot \frac{c(c + 1)}{2} \implies \text{Deficit} = \max\big(0, \; \text{Cost}_{\text{total}} - M\big)$$

## 2. Python 핵심 풀이 코드

```python
import math

# 1. 3진법 뒤집기 (O(log3 n))
def solution_ternary_reverse(n: int) -> int:
    digits = []
    while n > 0:
        digits.append(str(n % 3))
        n //= 3
    return int(''.join(digits), 3)

# 2. 약수의 개수와 덧셈 (O(right - left))
def solution_divisor_sum(left: int, right: int) -> int:
    total = 0
    for x in range(left, right + 1):
        if math.isqrt(x) ** 2 == x:
            total -= x
        else:
            total += x
    return total

# 3. 놀이기구 부족 금액 계산 (O(1))
def solution_deficit(price: int, money: int, count: int) -> int:
    total_cost = price * count * (count + 1) // 2
    return max(0, total_cost - money)
```
