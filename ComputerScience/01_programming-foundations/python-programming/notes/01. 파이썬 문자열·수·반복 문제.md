파이썬은 강력한 내장 고정밀 정수(Arbitrary-Precision Integers)와 직관적인 문자열 슬라이싱(`s[::-1]`), 리스트 컴프리헨션(List Comprehension)을 통해 기초 정수론 및 문자열 탐색 알고리즘을 간결하게 표현한다.

---

## 1. 기초 정수론 문제의 수학적 공식화

### 1) 하샤드 수 (Harshad / Niven Number)

양의 정수 $x$의 10진법 각 자릿수의 합을 $S(x)$라 할 때, $x$가 $S(x)$로 나누어떨어지면 하샤드 수이다:

$$S(x) = \sum_{k=0}^{\lfloor \log_{10} x \rfloor} \left( \left\lfloor \frac{x}{10^k} \right\rfloor \bmod 10 \right), \quad x \bmod S(x) = 0$$

### 2) 콜라츠 추측 (Collatz Conjecture / $3n+1$ 문제)

수열 ${a_k}$의 점화식:

$$a_{k+1} = \begin{cases} \frac{a_k}{2} & \text{if } a_k \equiv 0 \pmod 2 \\ 3a_k + 1 & \text{if } a_k \equiv 1 \pmod 2 \end{cases}$$

$a_k = 1$에 도달하는 반복 횟수 $T(x)$를 계산하며, $T(x) \ge 500$이면 $-1$을 반환한다.

### 3) 완전제곱수 판별과 다음 제곱수 계산

자연수 $n$에 대해 $\sqrt{n} \in \mathbb{N}$이면 다음 제곱수 $(x+1)^2$를, 아니면 $-1$을 반환:

$$f(n) = \begin{cases} (\sqrt{n} + 1)^2 & \text{if } \sqrt{n} - \lfloor \sqrt{n} \rfloor = 0 \\ -1 & \text{otherwise} \end{cases}$$

## 2. Python 핵심 구현 코드

```python
import math

# 1. 하샤드 수 판별
def is_harshad(x: int) -> bool:
    digit_sum = sum(int(d) for d in str(x))
    return x % digit_sum == 0

# 2. 콜라츠 추측 스텝 수 계산
def collatz_steps(n: int) -> int:
    for step in range(500):
        if n == 1:
            return step
        n = n // 2 if n % 2 == 0 else 3 * n + 1
    return -1

# 3. 완전제곱수 판별
def next_square(n: int) -> int:
    root = math.isqrt(n)
    return (root + 1) ** 2 if root * root == n else -1
```
