> [!abstract] 이 과목 자료의 성격
> 이 과목의 원본은 네 편, 총 **27쪽**뿐이다. 지금까지 재작성한 어느 과목보다 짧다. 그런데 짧은 만큼 **한 문장 한 줄이 사양으로서 하는 일**이 크고, 그래서 네 편이 공통으로 드러내는 성질이 하나 있다.
>
> **말로 적힌 규칙과, 예시로 보여준 것이 서로를 검증하지 못한다.**
>
> - `문제풀이_1_10` — 표에 실린 예시는 거의 언제나 정답과 오답을 구분하지 못하는 입력이다. 사양은 `제한 조건` 블록에 있다
> - `문제풀이_11_20` — 17번의 제한 조건은 두 해석을 말로 갈라 놓았지만, 유일한 예시가 그 둘을 구분하지 못한다
> - `과제 02_지뢰찾기` — 반대다. 설명 네 문장이 정하지 못한 것을 **예제 다섯 개가 대신 정한다**
> - `23-2 중간고사` — 순서도로 준 두 문항은 "그대로 옮기라"고 요구하는데, 그대로 옮기면 어긋난다
>
> 네 편의 정리문서는 각각 그 어긋남을 척추로 삼았다.

## 원본 자료

`sources/` 의 PDF 4편(총 27쪽)이 전부다. 인용한 슬라이드 이미지는 `assets/` 에 있다.

중간고사 2·3쪽은 **텍스트가 23자뿐**이고 나머지가 전부 순서도 그림이라, 렌더링한 이미지를 직접 읽어 상자와 화살표를 옮겼다. 텍스트 추출만으로는 이 시험지의 4분의 3을 놓친다.
