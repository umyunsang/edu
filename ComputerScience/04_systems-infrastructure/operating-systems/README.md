- `3. 프로세스와 프로세스 관리 2.pdf`는 같은 자료의 macOS 복제본으로 별도 노트를 만들지 않았다.
- `BankerAlgorithm.pdf`, `FCFS 과제.pdf`, `MemoryAlloc.pdf`, `SJF 과제.pdf`, `SRTF 과제.pdf`, `페이지교체 알고리즘.pdf`는 추출본에 MYBOX 뷰어 URL만 남아 학습 사실을 재구성할 근거가 부족해 제외했다.
- `자동채점기 사용 방법 안내.pdf`는 학습 개념이 아닌 운영 안내이므로 제외했다.
- 보조 자료에는 원문 오탈자, 불명확 표 문자, 일부 답안·입력 부재가 있어 노트에서 고치지 않고 해당 한계만 명시했다.
