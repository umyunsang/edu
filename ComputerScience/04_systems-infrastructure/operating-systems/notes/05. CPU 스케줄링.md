\*\*CPU 스케줄링(CPU Scheduling)\*\*은 준비 큐(Ready Queue)에 있는 프로세스들 중 어떤 프로세스에 CPU 코어를 할당할지 결정하여 \*\*CPU 이용률(Utilization)\*\*과 \*\*처리량(Throughput)\*\*을 극대화하고 **반환 시간(Turnaround Time)** 및 \*\*대기 시간(Waiting Time)\*\*을 최소화하는 핵심 OS 기작이다.

---

## 1. 스케줄링 성능 지표와 알고리즘별 대수 공식화

### 1) 주요 성능 평가 지표

$n$개의 프로세스에 대해 도착 시간 $AT_i$, 버스트 시간 $BT_i$, 완료 시간 $CT_i$:

- **반환 시간 (Turnaround Time, $TAT$)**:
  $$TAT_i = CT_i - AT_i$$
- **대기 시간 (Waiting Time, $WT$)**:
  $$WT_i = TAT_i - BT_i = (CT_i - AT_i) - BT_i$$
- **평균 대기 시간 (Average Waiting Time, $AWT$)**:
  $$AWT = \frac{1}{n} \sum_{i=1}^n WT_i$$

### 2) 4대 핵심 스케줄링 알고리즘 비교

| 알고리즘 | 선점 여부 | 스케줄링 기준 | 특징 및 한계 |
| :--- | :--- | :--- | :--- |
| **FCFS** | 비선점형 (Non-preemptive) | 도착 순서 ($AT$) | 호위 효과(Convoy Effect)로 긴 대기 시간 발생 |
| **SJF** | 비선점형 (Non-preemptive) | 최단 CPU 버스트 ($BT$) | 수학적으로 최소 $AWT$ 보장, 기아(Starvation) 가능 |
| **SRTF** | 선점형 (Preemptive) | 최단 잔여 시간 ($Remaining$) | 실행 도중 짧은 작업 도착 시 즉시 문맥 교환 |
| **Round Robin** | 선점형 (Preemptive) | 타임 퀀텀 ($q$) 순환 | $q \to \infty$이면 FCFS, $q \to 0$이면 문맥 교환 오버헤드 폭증 |

(function() {
  var in1 = document.getElementById('os-p1');

  var in3 = document.getElementById('os-p3');
  var rFcfs = document.getElementById('os-res-fcfs');

    // FCFS: P1(0), P2(P1), P3(P1+P2)
    var fcfsAwt = (0 + p1 + (p1 + p2)) / 3.0;

    // SJF: sort burst times
    var bursts = [p1, p2, p3].sort(function(a,b){return a-b;});
    var sjfAwt = (0 + bursts[0] + (bursts[0] + bursts[1])) / 3.0;

    rFcfs.textContent = fcfsAwt.toFixed(2) + ' ms';
    rSjf.textContent = sjfAwt.toFixed(2) + ' ms';
  }

  [in1, in2, in3].forEach(function(el){ el.addEventListener('input', update); });
  update();
})();
