> [!abstract] 핵심 요약
> **교착상태(Deadlock)**는 복수의 프로세스가 각자 다른 프로세스가 점유한 자원을 무한정 기다리며 시스템 전체의 진행이 영구 중단되는 현상이다.
> 교착상태가 발생하기 위한 **코프만 4대 조건(상호배제, 점유대기, 비선점, 환형대기)**을 이해하고, 자원 요청 시 시스템이 항상 **안전 상태(Safe State)**를 유지하도록 보증하는 **은행원 알고리즘(Banker's Algorithm)**의 `Need = Max - Allocation` 안전 순서열 탐색은 OS 시험과 시스템 설계의 핵심이다.

---

## 1. 교착상태 4대 필요조건 (Coffman Conditions)

```mermaid
flowchart TD
    ROOT["교착상태(Deadlock) 4대 필요조건 (동시 만족 시 발생)"]
    ROOT --> C1["1. 상호 배제 (Mutual Exclusion)<br/>최소 하나 이상의 자원이 비공유 독점 모드로 점유됨"]
    ROOT --> C2["2. 점유와 대기 (Hold and Wait)<br/>최소 하나의 자원을 점유한 상태에서 다른 자원을 추가 요청하며 대기"]
    ROOT --> C3["3. 비선점 (No Preemption)<br/>다른 프로세스가 점유한 자원을 강제로 빼앗을 수 없음"]
    ROOT --> C4["4. 환형 대기 (Circular Wait)<br/>P₀ ➔ P₁ ➔ P₂ ➔ ... ➔ P₀ 형태의 자원 대기 순환 고리 형성"]
```

## 2. 안전 상태(Safe State)와 은행원 알고리즘 (Banker's Algorithm)

$$\text{Need}[i][j] = \text{Max}[i][j] - \text{Allocation}[i][j]$$

```mermaid
sequenceDiagram
    autonumber
    participant Proc as 프로세스 Pi 자원 요청
    participant OS as 커널 (은행원 알고리즘)
    participant Safe as 안전 상태 검증기

    Proc->>OS: Request <= Need 및 Request <= Available 검사
    OS->>Safe: 가상 할당: Available -= Req, Alloc += Req, Need -= Req
    Safe->>Safe: Work = Available, Finish[all] = False
    loop 모든 프로세스 탐색
        Note over Safe: Finish[i] == False 이고 Need[i] <= Work 인 Pi 탐색
        Note over Safe: Work += Allocation[i], Finish[i] = True (순서열 추가)
    end
    Safe-->>OS: 모든 Finish == True ? (안전 순서열 존재 여부)
    OS-->>Proc: 안전 순서열 존재 시 실제 자원 할당 승인, 없으면 대기(Rollback)
```

    document.getElementById('runBankerBtn').onclick = function() {
      var n = 5, m = 3;
      var avail = [3, 3, 2];
      var alloc = [
        [0, 1, 0],
        [2, 0, 0],
        [3, 0, 2],
        [2, 1, 1],
        [0, 0, 2]
      ];
      var max = [
        [7, 5, 3],
        [3, 2, 2],
        [9, 0, 2],
        [2, 2, 2],
        [4, 3, 3]
      ];
      var need = [];
      for (var i = 0; i < n; i++) {
        need[i] = [];
        for (var j = 0; j < m; j++) {
          need[i][j] = max[i][j] - alloc[i][j];
        }
      }

      var work = [avail[0], avail[1], avail[2]];
      var finish = [false, false, false, false, false];
      var safeSeq = [];

      for (var k = 0; k < n; k++) {
        for (var i = 0; i < n; i++) {
          if (!finish[i]) {
            var possible = true;
            for (var j = 0; j < m; j++) {
              if (need[i][j] > work[j]) {
                possible = false;
                break;
              }
            }
            if (possible) {
              for (var j = 0; j < m; j++) {
                work[j] += alloc[i][j];
              }
              finish[i] = true;
              safeSeq.push("P" + i);
            }
          }
        }
      }

      var isSafe = safeSeq.length === n;
      if (isSafe) {
        document.getElementById('bankerResOut').innerHTML = "<span style='color:var(--chart-2);font-weight:800'>✅ 시스템은 안전 상태(Safe State)입니다!</span><br/>안전 순서열: <b>" + safeSeq.join(" ➔ ") + "</b>";
      } else {
        document.getElementById('bankerResOut').innerHTML = "<span style='color:var(--destructive,#ef4444);font-weight:800'>⛔ 교착상태 위험 (Unsafe State)</span>";
      }
    };
  </script>
</div>
