> [!abstract] 핵심 요약
> **프로세스 동기화(Synchronization)**는 여러 실행 흐름이 공유 자원에 동시 접근할 때 데이터의 일관성(Consistency)을 유지하기 위한 핵심 규약이다.
> 공유 변수를 수정하는 코드 구간인 **임계구역(Critical Section)**은 **상호 배제(Mutual Exclusion)**, **진행(Progress)**, **유한 대기(Bounded Waiting)**의 3대 조건을 반드시 만족해야 하며, 이를 위해 하드웨어적 원자적 연산(**CAS**)과 OS 수준의 **뮤텍스(Mutex)** 및 **세마포어(Semaphore $P/V$)**가 사용된다.

---

## 1. 임계구역 문제 해결의 3대 필수 조건

```mermaid
flowchart TD
    ROOT["임계구역(Critical Section) 해결 3대 원칙"]
    ROOT --> COND1["1. 상호 배제 (Mutual Exclusion)<br/>한 프로세스가 임계구역에서 실행 중이면 다른 어떤 프로세스도 진입 불가"]
    ROOT --> COND2["2. 진행 (Progress)<br/>임계구역에 실행 중인 프로세스가 없을 때, 진입을 희망하는 프로세스만이 결정을 내림"]
    ROOT --> COND3["3. 유한 대기 (Bounded Waiting)<br/>프로세스의 진입 요청 후 허가될 때까지 다른 프로세스의 진입 횟수에 제한이 있어야 함 (기아 방지)"]
```

## 2. 세마포어(Semaphore)의 $P$ (wait) / $V$ (signal) 원자적 연산

```mermaid
sequenceDiagram
    autonumber
    participant P as 생산자 (Producer)
    participant S_EMPTY as 세마포어 empty = N
    participant S_MUTEX as 세마포어 mutex = 1
    participant BUF as 유한 버퍼 (Buffer)

    P->>S_EMPTY: P(empty) : 빈 공간 감소 (0이면 블록)
    P->>S_MUTEX: P(mutex) : 버퍼 접근 락 획득
    P->>BUF: 버퍼에 데이터 삽입 (임계구역)
    P->>S_MUTEX: V(mutex) : 버퍼 락 해제
    P->>S_EMPTY: V(full) : 찬 공간 증가 ➔ 소비자 깨움
```
