\*\*페이징(Paging)\*\*은 가상 주소 공간과 물리 메모리를 동일한 고정 크기 블록인 \*\*페이지(Page)\*\*와 \*\*프레임(Frame)\*\*으로 분할하여 외부 단편화(External Fragmentation)를 원천 차단하는 가상 메모리 관리 기법이다.

---

## 1. 페이징 주소 분해와 TLB EAT의 수학적 공식화

### 1) 논리 주소에서 물리 주소로의 변환

페이지 크기가 $2^n$ 바이트일 때 $m$비트 논리 주소는 상위 $m-n$비트의 페이지 번호($p$)와 하위 $n$비트의 오프셋($d$)으로 분해된다:

$$\text{Logical Address} = [p \mid d] \implies \text{Physical Address} = [f \mid d]$$

- 여기서 프레임 번호 $f = \text{PageTable}[p]$ 이며, 유효-무효 비트(Valid-Invalid Bit)가 $0$이면 페이지 부재(Page Fault) 트랩 발생.

### 2) TLB(Translation Lookaside Buffer)와 유효 접근 시간 (EAT)

고속 연관 캐시인 TLB 적중률 $\alpha$ ($0 \le \alpha \le 1$), TLB 탐색 시간 $t\_{\text{TLB}}$, 메인 메모리 접근 시간 $t_m$에 대해:

$$\text{EAT} = \alpha (t_{\text{TLB}} + t_m) + (1 - \alpha) (t_{\text{TLB}} + 2 t_m) = t_{\text{TLB}} + (2 - \alpha) t_m$$

- **유도 과정**:
  - TLB 적중 시($\alpha$): $\text{TLB 탐색} + \text{데이터 접근} = t\_{\text{TLB}} + t_m$
  - TLB 미적중 시($1-\alpha$): $\text{TLB 탐색} + \text{페이지 테이블 접근} + \text{실제 데이터 접근} = t\_{\text{TLB}} + 2 t_m$
