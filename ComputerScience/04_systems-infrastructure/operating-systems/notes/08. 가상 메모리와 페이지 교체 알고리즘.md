> [!abstract] 핵심 요약
> **가상 메모리(Virtual Memory)**는 물리 RAM 크기의 한계를 극복하여 프로세스가 연속된 거대한 논리 메모리 공간을 독점하는 것처럼 환상을 제공하는 핵심 기법이다.
> 필요한 페이지만 물리 메모리에 올리는 **요구 페이징(Demand Paging)**에서 페이지 부재(Page Fault) 발생 시 희생 프레임을 선정하는 **FIFO(벨레이디 변칙 발생)**, **LRU(과거 참조 기반)**, **Clock(참조 비트 활용)** 교체 알고리즘과, 메모리 부족으로 디스크 I/O만 폭증하는 **스레싱(Thrashing)** 방지 기법을 마스터해야 한다.

## 1. 페이지 부재(Page Fault) 7단계 처리 시퀀스

```mermaid
sequenceDiagram
    autonumber
    participant CPU as CPU (메모리 접근)
    participant MMU as MMU 하드웨어
    participant OS as OS 커널 (Page Fault ISR)
    participant Disk as 스왑 영역 (Swap Space / Disk)
    participant RAM as 물리 메모리 (Frame)

    CPU->>MMU: 1. 가상 주소 참조 (Page Table 조회)
    MMU-->>OS: 2. 유효 비트 i(Invalid) 감지 ➔ Page Fault Trap 발생
    OS->>OS: 3. 정상 접근 여부 및 빈 프레임 확인
    alt 빈 프레임 없음
        OS->>RAM: 희생 페이지(Victim Page) 선정 후 스왑 아웃
    end
    OS->>Disk: 4. 스왑 영역에서 해당 페이지 디스크 I/O 읽기 요청
    Disk-->>RAM: 5. 할당된 물리 프레임에 페이지 적재 완료
    OS->>MMU: 6. 페이지 테이블 (Frame 매핑, Valid 비트 v) 갱신
    OS-->>CPU: 7. 트랩 복귀 후 실패했던 직전 명령어 재실행 (Restart)
```

## 2. 4대 페이지 교체 알고리즘(Page Replacement) 비교

```mermaid
flowchart TD
    ROOT["페이지 교체 알고리즘 분류"]
    ROOT --> OPT["1. 최적 교체 (OPT / Belady's Min)<br/>• 미래에 가장 오랫동안 쓰이지 않을 페이지 교체<br/>• 이론상 최소 부재율, 실현 불가능 (성능 기준선)"]
    ROOT --> FIFO["2. FIFO (First-In First-Out)<br/>• 가장 먼저 들어온 페이지 교체<br/>• Belady의 변칙(프레임 늘려도 부재수 증가) 발생"]
    ROOT --> LRU["3. LRU (Least Recently Used)<br/>• 가장 오랫동안 참조되지 않은 페이지 교체<br/>• 시간 지역성 기반 우수 성능, 카운터/스택 하드웨어 필요"]
    ROOT --> CLK["4. 클록 알고리즘 (Clock / Second Chance)<br/>• 참조 비트(0/1) 원형 큐 순환 포인터 방식<br/>• LRU의 저비용 실용적 근사 알고리즘"]
```

    function runSim() {
      var str = document.getElementById('refStringInput').value;
      var refs = str.split(',').map(function(s) { return parseInt(s.trim()); }).filter(function(v) { return !isNaN(v); });
      var numFrames = parseInt(document.getElementById('inFrameCount').value) || 3;

      // 1. FIFO
      var fifoFrames = [];
      var fifoFaults = 0;
      for (var i = 0; i < refs.length; i++) {
        var p = refs[i];
        if (fifoFrames.indexOf(p) === -1) {
          fifoFaults++;
          if (fifoFrames.length < numFrames) {
            fifoFrames.push(p);
          } else {
            fifoFrames.shift();
            fifoFrames.push(p);
          }
        }
      }

      // 2. LRU
      var lruFrames = [];
      var lruFaults = 0;
      for (var i = 0; i < refs.length; i++) {
        var p = refs[i];
        var idx = lruFrames.indexOf(p);
        if (idx === -1) {
          lruFaults++;
          if (lruFrames.length < numFrames) {
            lruFrames.push(p);
          } else {
            lruFrames.shift();
            lruFrames.push(p);
          }
        } else {
          lruFrames.splice(idx, 1);
          lruFrames.push(p);
        }
      }

      document.getElementById('fifoResOut').textContent = "페이지 부재: " + fifoFaults + " 회 (" + ((fifoFaults / refs.length) * 100).toFixed(1) + "%)";
      document.getElementById('lruResOut').textContent = "페이지 부재: " + lruFaults + " 회 (" + ((lruFaults / refs.length) * 100).toFixed(1) + "%)";
    }

    document.getElementById('calcPageBtn').addEventListener('click', runSim);
    runSim();
  </script>
