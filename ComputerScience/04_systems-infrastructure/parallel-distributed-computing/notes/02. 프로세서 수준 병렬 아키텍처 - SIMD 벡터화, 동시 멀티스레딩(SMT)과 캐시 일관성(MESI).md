> [!abstract] 핵심 요약
> 현대 CPU는 단일 코어 내부에서도 **SIMD 벡터 연산 유닛**과 **SMT(동시 멀티스레딩)**을 통해 다차원적 병렬성을 구현한다.
> 다중 코어가 L1/L2 프라이빗 캐시를 보유하면서 발생하는 데이터 불일치를 해결하기 위한 **스누핑(Snooping) 기반 MESI 캐시 일관성 프로토콜**과, 서로 다른 변수가 동일 64바이트 캐시 라인에 위치해 불필요한 버스 트래픽을 유발하는 **거짓 공유(False Sharing)** 병목을 해결하는 원리를 이해해야 한다.

## 1. Flynn의 아키텍처 분류와 SIMD vs MIMD

```mermaid
flowchart TD
    ROOT["플린의 컴퓨터 구조 분류 (Flynn's Taxonomy)"]
    ROOT --> SISD["1. SISD (단일 명령, 단일 데이터)<br/>전통적인 순차 단일 코어 CPU"]
    ROOT --> SIMD["2. SIMD (단일 명령, 다중 데이터)<br/>하나의 명령어로 여러 데이터 레인을 동시 계산 (AVX, GPU, ISPC)"]
    ROOT --> MISD["3. MISD (다중 명령, 단일 데이터)<br/>동일 데이터에 다른 연산 적용 (내고장성 우주 시스템)"]
    ROOT --> MIMD["4. MIMD (다중 명령, 다중 데이터)<br/>각 코어가 서로 다른 명령어와 데이터를 독립 실행 (멀티코어 CPU, 클러스터)"]
```

## 2. MESI 캐시 일관성 프로토콜 4대 상태 전이

| 상태 | 상태 명칭 (State) | 캐시 라인 유효성 | 타 코어 보유 여부 | 메인 메모리와의 일치성 |
| :--: | :-- | :--: | :--: | :-- |
| **M** | **Modified (수정됨)** | 유효 (Valid) | **단독 보유 (No)** | **불일치 (더티, 메모리보다 최신)** |
| **E** | **Exclusive (독점 클린)** | 유효 (Valid) | **단독 보유 (No)** | 일치 (클린) |
| **S** | **Shared (공유됨)** | 유효 (Valid) | 타 코어도 보유 가능 | 일치 (클린, 읽기 전용) |
| **I** | **Invalid (무효화됨)** | **무효 (Invalid)** | - | 사용 불가 (캐시 미스 발생) |

```mermaid
stateDiagram-v2
    [*] --> Invalid
    Invalid --> Shared: PrRd (BusRd 수신, 타 코어 S 상태)
    Invalid --> Exclusive: PrRd (BusRd 수신, 타 코어 미보유)
    Invalid --> Modified: PrWr (BusRdX 브로드캐스트)
    Shared --> Modified: PrWr (BusUpgr로 타 캐시 무효화)
    Exclusive --> Modified: PrWr (내부 쓰기)
    Modified --> Shared: BusRd 감지 (메모리에 플러시 후 S로 강등)
    Shared --> Invalid: BusRdX 또는 BusUpgr 감지 (타 코어가 쓰기 수행)
```
