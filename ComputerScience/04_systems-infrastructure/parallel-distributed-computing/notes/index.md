* [01. 병렬 컴퓨팅의 필요성과 하드웨어 아키텍처](./01.%20%EB%B3%91%EB%A0%AC%20%EC%BB%B4%ED%93%A8%ED%8C%85%EC%9D%98%20%ED%95%84%EC%9A%94%EC%84%B1%EA%B3%BC%20%ED%95%98%EB%93%9C%EC%9B%A8%EC%96%B4%20%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98.md) - 무어의 법칙과 전력 장벽(Power Wall), 암달의 법칙(Amdahl's Law), 플린의 컴퓨터 분류(SISD, SIMD, MISD, MIMD) 및 멀티코어 메모리 구조를 학습한다.
* [01. 병렬 컴퓨팅의 필요성과 하드웨어 패러다임 전환 - 무어의 법칙 한계, 전력 장벽(Power Wall)과 암달·구스타프슨 법칙](./01.%20%EB%B3%91%EB%A0%AC%20%EC%BB%B4%ED%93%A8%ED%8C%85%EC%9D%98%20%ED%95%84%EC%9A%94%EC%84%B1%EA%B3%BC%20%ED%95%98%EB%93%9C%EC%9B%A8%EC%96%B4%20%ED%8C%A8%EB%9F%AC%EB%8B%A4%EC%9E%84%20%EC%A0%84%ED%99%98.md) - 단일 코어 클록 스케일링(Dennard Scaling)의 종말과 전력 장벽(Power Wall), 암달의 법칙(Amdahl's Law) vs 구스타프슨의 법칙(Gustafson's Law)의 강/약 스케일링, 만델브로트(Mandelbrot) 프랙탈 병렬화 작업 분할, 그리고 멀티코어로의 패러다임 전환을 인터랙티브 암달-구스타프슨 가속도 시뮬레이터로 학습한다.
* [02. 공유 메모리 병렬화와 OpenMP 프로그래밍](./02.%20%EA%B3%B5%EC%9C%A0%20%EB%A9%94%EB%AA%A8%EB%A6%AC%20%EB%B3%91%EB%A0%AC%ED%99%94%EC%99%80%20OpenMP%20%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D.md) - 스레드 풀과 포크-조인(Fork-Join) 모델, OpenMP 컴파일러 디렉티브, 루프 스케줄링(Static, Dynamic, Guided) 및 동기화 기법을 학습한다.
* [02. 프로세서 수준 병렬 아키텍처 - SIMD 벡터화, 동시 멀티스레딩(SMT)과 캐시 일관성(MESI)](./02.%20%ED%94%84%EB%A1%9C%EC%84%B8%EC%84%9C%20%EC%88%98%EC%A4%80%20%EB%B3%91%EB%A0%AC%20%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98%20-%20SIMD%20%EB%B2%A1%ED%84%B0%ED%99%94%2C%20%EB%8F%99%EC%8B%9C%20%EB%A9%80%ED%8B%B0%EC%8A%A4%EB%A0%88%EB%94%A9%28SMT%29%EA%B3%BC%20%EC%BA%90%EC%8B%9C%20%EC%9D%BC%EA%B4%80%EC%84%B1%28MESI%29.md) - 플린(Flynn)의 컴퓨팅 아키텍처 분류, 단일 명령 다중 데이터(SIMD) 벡터 레지스터 연산(AVX-512), 하드웨어 동시 멀티스레딩(SMT/하이퍼스레딩), 스누핑 기반 MESI 캐시 일관성 상태 머신, 그리고 거짓 공유(False Sharing) 방지 기법을 인터랙티브 MESI 캐시 상태 전이기 시뮬레이터로 학습한다.
* [03. 공유 메모리 병렬 프로그래밍 - OpenMP 지시어, 루프 스케줄링(static/dynamic)과 동기화 원어](./03.%20%EA%B3%B5%EC%9C%A0%20%EB%A9%94%EB%AA%A8%EB%A6%AC%20%EB%B3%91%EB%A0%AC%20%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D%20-%20OpenMP%20%EC%A7%80%EC%8B%9C%EC%96%B4%2C%20%EB%A3%A8%ED%94%84%20%EC%8A%A4%EC%BC%80%EC%A4%84%EB%A7%81%EA%B3%BC%20%EB%8F%99%EA%B8%B0%ED%99%94.md) - 공유 메모리 멀티스레딩 모델(Fork-Join), OpenMP 핵심 컴파일러 지시어(#pragma omp parallel for), 변수 스코프(shared, private), 루프 스케줄링 전략(static vs dynamic 청크 크기), 동기화 원어(barrier, critical, atomic), 그리고 병렬 축약(reduction)을 인터랙티브 OpenMP 루프 분배 시뮬레이터로 학습한다.
* [03. 분산 메모리 시스템과 MPI 통신 프로토콜](./03.%20%EB%B6%84%EC%82%B0%20%EB%A9%94%EB%AA%A8%EB%A6%AC%20%EC%8B%9C%EC%8A%A4%ED%85%9C%EA%B3%BC%20MPI%20%ED%86%B5%EC%8B%A0%20%ED%94%84%EB%A1%9C%ED%86%A0%EC%BD%9C.md) - 메시지 전달 인터페이스(MPI), 점대점 통신(MPI_Send/Recv) vs 집합 통신(MPI_Bcast, Scatter, Gather, Reduce) 및 통신 토폴로지를 학습한다.
* [04. 병렬 성능 최적화 기법 - 로드 밸런싱, 작업 훔치기(Work Stealing)와 메모리 지역성](./04.%20%EB%B3%91%EB%A0%AC%20%EC%84%B1%EB%8A%A5%20%EC%B5%9C%EC%A0%81%ED%99%94%20%EA%B8%B0%EB%B2%95%20-%20%EB%A1%9C%EB%93%9C%20%EB%B0%B8%EB%9F%B0%EC%8B%B1%2C%20%EC%9E%91%EC%97%85%20%ED%9B%94%EC%B9%98%EA%B8%B0%28Work%20Stealing%29%EC%99%80%20%EC%A7%80%EC%97%AD%EC%84%B1.md) - 병렬 소프트웨어의 성능 저하 원인(로드 불균형, 통신 오버헤드, 락 경합), 양방향 큐(Deque) 기반 작업 훔치기(Work Stealing) 스케줄링 알고리즘, 캐시 라인 블록화(Loop Tiling)를 통한 공간/시간적 지역성 극대화, 그리고 통신-계산 비율 최적화를 인터랙티브 Work Stealing 시뮬레이터로 학습한다.
