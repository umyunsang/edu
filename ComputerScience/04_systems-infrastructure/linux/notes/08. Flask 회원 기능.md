> [!abstract]
> 회원 가입과 로그인은 사용자 입력과 서버 상태를 연결하는 웹 애플리케이션 기능이다.

## 핵심 구성

<Tabs>
<Tab title="입력">회원 정보 요청</Tab>
<Tab title="처리">서버 측 검증</Tab>
<Tab title="상태">로그인 결과 유지</Tab>
</Tabs>

```mermaid
flowchart LR
 A[입력] --> B[처리]
 B --> C[상태]
 C --> D[결과]
```

> [!important]
> 회원 정보 요청와 서버 측 검증를 분리해 이해하면 문제 위치를 찾기 쉽다.

```html preview h=120px
<div style="font-family:system-ui,sans-serif;padding:14px;border:1px solid var(--border);border-radius:12px;background:var(--card);color:var(--foreground)"><strong>08. ```
```

<details><summary>왜 흐름을 분리할까?</summary>

입력·처리·상태·결과를 구분하면 실패 원인과 검증 지점을 찾기 쉽다.
</details>

## 점검

==작은 예시로 먼저 입력과 결과의 연결을 확인한다.==

```html preview h=115px
<div style="font-family:system-ui,sans-serif;padding:14px;border:1px solid var(--border);border-radius:12px;background:var(--card);color:var(--foreground)">입력 <b>→</b> 처리 <b>→</b> 결과</div>
```

<details><summary>실습 전 확인</summary>

대상 환경·입력·권한과 기대 결과를 기록한다.
</details>

> [!warning]
> 환경 차이나 상태를 확인하지 않으면 같은 절차도 다른 결과를 낼 수 있다.

다음 관찰을 작업 순서에 넣는다.

> [!tip]
> 변경 하나마다 결과를 확인해 문제 범위를 좁힌다.
