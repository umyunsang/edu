> [!abstract] 핵심 요약
> **도커(Docker)**는 응용 프로그램과 그 실행에 필요한 모든 런타임 환경을 **컨테이너(Container)**라는 격리된 패키지로 표준화하는 오픈소스 플랫폼이다.
> 무거운 게스트 OS를 설치하는 전통적 가상 머신(VM)과 달리, 리눅스 커널의 **네임스페이스(Namespaces - 격리)**와 **cgroups(자원 제한)**를 활용하여 호스트 커널을 직접 공유함으로써 수 초 만에 기동되는 초경량 가상화를 실현한다.

---

## 1. 가상 머신(VM) vs 도커 컨테이너(Docker Container) 아키텍처

```mermaid
flowchart TD
    subgraph VM["1. 가상 머신 (VM)"]
        H1["호스트 하드웨어"] --> OS1["호스트 OS"]
        OS1 --> HYP["하이퍼바이저 (Type-2 Hypervisor)"]
        HYP --> G1["게스트 OS (Guest OS 1)<br/>+ Bins/Libs + App 1"]
        HYP --> G2["게스트 OS (Guest OS 2)<br/>+ Bins/Libs + App 2"]
    end

    subgraph DOCKER["2. 도커 컨테이너 (Docker)"]
        H2["호스트 하드웨어"] --> KERNEL["호스트 리눅스 커널 (Namespaces / cgroups)"]
        KERNEL --> DENG["도커 데몬 엔진 (Docker Engine)"]
        DENG --> C1["컨테이너 1 (App 1 + Libs)<br/>(커널 무복사 격리)"]
        DENG --> C2["컨테이너 2 (App 2 + Libs)<br/>(커널 무복사 격리)"]
    end
```

## 2. Dockerfile 지시어와 빌드 파이프라인

```mermaid
flowchart LR
    DF["Dockerfile 스크립트 작성<br/>• FROM python:3.11-slim<br/>• COPY . /app<br/>• RUN pip install -r req.txt<br/>• CMD ['python', 'app.py']"] -- "$ docker build -t my-app ." --> IMG["불변 도커 이미지 (Image)<br/>• Read-Only 레이어 누적<br/>• Docker Hub 배포 가능"]
    IMG -- "$ docker run -d -p 80:5000 my-app" --> CONT["실행 중인 컨테이너 (Container)<br/>• R/W 쓰기 가능 컨테이너 레이어<br/>• 격리된 독립 프로세스"]
```
