> [!abstract]
> 데이터베이스는 프로그램 데이터를 구조적으로 저장하고 필요한 형태로 조회하기 위한 학습 주제다.

## 핵심 구성

<Tabs>
<Tab title="저장">구조화된 데이터</Tab>
<Tab title="조회">필요한 레코드 선택</Tab>
<Tab title="연결">응용프로그램과 데이터 계층</Tab>
</Tabs>

```mermaid
flowchart LR
 A[입력] --> B[처리]
 B --> C[상태]
 C --> D[결과]
```

> [!important]
> 구조화된 데이터와 필요한 레코드 선택를 분리해 이해하면 문제 위치를 찾기 쉽다.

```html preview h=120px
<div style="font-family:system-ui,sans-serif;padding:14px;border:1px solid var(--border);border-radius:12px;background:var(--card);color:var(--foreground)"><strong>10. 데이터베이스 기초</strong><div style="display:flex;gap:8px;margin-top:10px"><span style="padding:8px;border:1px solid var(--border);border-radius:7px">저장</span><span style="padding:8px;border:1px solid var(--border);border-radius:7px">조회</span><span style="padding:8px;border:1px solid var(--border);border-radius:7px">연결</span></div></div>
```

<details><summary>왜 흐름을 분리할까?</summary>

입력·처리·상태·결과를 구분하면 실패 원인과 검증 지점을 찾기 쉽다.
</details>

## 점검

==작은 예시로 먼저 입력과 결과의 연결을 확인한다.==

```html preview h=115px
<div style="font-family:system-ui,sans-serif;padding:14px;border:1px solid var(--border);border-radius:12px;background:var(--card);color:var(--foreground)">입력 <b>→</b> 처리 <b>→</b> 결과</div>
```

<details><summary>실습 전 확인</summary>

대상 환경·입력·권한과 기대 결과를 기록한다.
</details>

> [!warning]
> 환경 차이나 상태를 확인하지 않으면 같은 절차도 다른 결과를 낼 수 있다.

> [!tip]
> 변경 하나마다 결과를 확인해 문제 범위를 좁힌다.
