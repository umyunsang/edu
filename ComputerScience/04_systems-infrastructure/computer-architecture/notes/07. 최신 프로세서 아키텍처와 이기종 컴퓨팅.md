> [!abstract] 핵심 요약
> 현대 프로세서 아키텍처는 단순 단일 코어 클럭 경쟁에서 벗어나 **이기종 SoC(System on Chip)** 설계로 진화했다.
> 고성능 코어(Performance Core)와 고효율 코어(Efficiency Core)를 결합한 **ARMv9 big.LITTLE**, 초미세 반도체 공정(TSMC 3nm), 인공지능 텐서 연산을 전담하는 **16코어 Neural Engine(NPU)**, 그리고 CPU·GPU·NPU가 데이터 복사 없이 캐시를 공유하는 **통합 메모리 아키텍처(UMA)**는 최신 컴퓨팅의 핵심 표준이다.

---

## 1. 이기종 SoC 아키텍처 블록도 (Apple Silicon M-Series / ARMv9)

```mermaid
flowchart TD
    subgraph SOC["차세대 이기종 SoC (System-on-Chip)"]
        subgraph CPU_CLUSTER["이기종 CPU 클러스터"]
            PCORE["P-코어 (4x Performance Cores)<br/>초고속 IPC / 3.5GHz+ / L2 캐시 공유"]
            ECORE["E-코어 (4x Efficiency Cores)<br/>저전력 백그라운드 / 0.5W 이하"]
        end
        NPU["16-Core Neural Engine (NPU)<br/>초당 15조~38조 회(TOPS) AI 행렬 연산"]
        GPU["고성능 모바일 GPU 클러스터<br/>레이 트레이싱 & 셰이더 하드웨어 가속"]
        ISP["고급 이미지 신호 처리기 (ISP)<br/>4K HDR 실시간 비디오 인코딩"]
    end

    SOC <--> UMA["통합 메모리 아키텍처 (UMA: Unified Memory)<br/>CPU·GPU·NPU 간 무복사(Zero-Copy) 버스 대역폭 공유"]
```

## 2. P-코어 vs E-코어 워크로드 동적 스케줄링

```mermaid
sequenceDiagram
    autonumber
    participant OS as 운영체제 스케줄러 (Thread Director)
    participant E as E-코어 (효율 코어)
    participant P as P-코어 (성능 코어)
    participant NPU as NPU (신경망 엔진)

    Note over OS: 백그라운드 음악 재생 & 메일 동기화 감지
    OS->>E: 낮은 TDP 효율 코어에 스레드 할당 (전력 절감)
    Note over OS: 4K 렌더링 / 고사양 3D 게임 실행 감지
    OS->>P: 고성능 코어로 즉각 스케줄링 (최대 클럭 가속)
    Note over OS: 온디바이스 LLM / 비전 추론 요청 감지
    OS->>NPU: 텐서 연산 NPU 전용 가속기에 오프로딩
```
