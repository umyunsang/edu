## 1. 보수의 개념과 음수

#### 최상위비트(MSB)를 부호비트로 사용

- 양수(+) : 0
- 음수(-) : 1

#### 2진수 음수를 표시하는 방법

- 부호와 절대값(sign-magnitude)
 	- 부호비트만 양수와 음수를 나타내고 나머지 비트들은 같다.

  <!-- 원본 이미지 없음: computer-architecture__2. 정수 표현__2진수 음수를 표시하는 방법.png -->
  
- 1의 보수(1's complement)
 	- 0 -> 1, 1 -> 0으로 변환

  <!-- 원본 이미지 없음: computer-architecture__2. 정수 표현__2진수 음수를 표시하는 방법 2.png -->
 
- 2의 보수(2's complement)
 	- 1의 보수 + 1 = 2의 보수

#### `overflow`

```C
unsigned char ubVar = 0;
signed char bVar = 0;

for(int i=0; i<257; i++)
{
 printf("%d ", ubVar);
 ubVarr++;
}
printf("\n");

for(int i=0; i<257; i++)
{
 printf("%d ", bVar);
 bVar++;
}
print("\n");
```

#### `underflow`

```C
unsigned char ubVar = 255;
signed char bVar = 255;

for(int i=0; i<257; i++)
{
 printf("%d ", ubVar);
 ubVarr--;
}
printf("\n");

for(int i=0; i<257; i++)
{
 printf("%d ", bVar);
 bVar--;
}
print("\n");
```
