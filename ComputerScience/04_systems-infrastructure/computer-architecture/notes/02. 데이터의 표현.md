컴퓨터 하드웨어는 모든 정보를 2진 비트 열(Bit Stream)로 인코딩하며, 정수의 음수 표현에는 덧셈기로 뺄셈을 수행하는 **2의 보수(2's Complement)** 체계를, 실수의 표현에는 **IEEE 754 부동소수점 표준**을 사용한다.

---

## 1. 정수 보수 대수학과 IEEE 754 부동소수점 공식화

### 1) 2의 보수(2's Complement)와 오버플로(Overflow) 판별

$n$비트 2의 보수 정수의 표현 범위:

$$-2^{n-1} \le X \le 2^{n-1} - 1$$

- **감산 연산의 가산 변환**:
  $$A - B = A + (-B) = A + (\bar{B} + 1)$$
- **오버플로(Overflow $V$) 판정식**:
  최상위 부호 비트(MSB)로 들어오는 올림수 $C_{n-1}$과 나가는 올림수 $C_n$의 XOR 연산:
  $$V = C_{n-1} \oplus C_n \quad (V=1 \text{이면 산술 오버플로 발생})$$

### 2) IEEE 754 단정밀도(32-bit Single Precision) 부동소수점 표준

비트 구성: 부호 비트 $s$ ($1$비트), 지수부 $E$ ($8$비트, 바이어스 $127$), 가수부 $M$ ($23$비트):

$$V = (-1)^s \times 2^{E - 127} \times (1.M)_2$$

- **특수 값 표현**:
  - $E = 255, ; M = 0 \implies \pm\infty$ (무한대)
  - $E = 255, \; M \ne 0 \implies \text{NaN}$ (Not a Number)
  - $E = 0, ; M = 0 \implies \pm 0$ (영)
  - $E = 0, \; M \ne 0 \implies (-1)^s \times 2^{-126} \times (0.M)\_2$ (비정규화 수, Denormalized Number)

(function() {
  var inVal = document.getElementById('fp-in-val');
