> [!abstract] 핵심 요약
> **디지털 논리 회로(Digital Logic Circuits)**는 컴퓨터의 연산 장치(ALU)와 메모리를 구축하는 물리적 기본 블록이다.
> 현재의 입력만으로 출력이 결정되는 **조합 논리 회로(가산기, MUX, 디코더)**와, 내부 상태를 기억하여 과거의 이력과 클럭(Clock)에 따라 동작하는 **순서 논리 회로(RS, D, JK, T 플립플롭)**로 구분된다.

---

## 1. 전가산기(Full Adder)와 4:1 멀티플렉서(MUX)

### 1) 전가산기 불 대수식 (Sum & Carry Out)
$$\text{Sum} = A \oplus B \oplus C_{\text{in}}$$
$$C_{\text{out}} = AB + C_{\text{in}}(A \oplus B) = AB + BC_{\text{in}} + AC_{\text{in}}$$

```mermaid

    subgraph Combinational["조합 논리 회로 (Combinational)"]
        FA["전가산기 (Full Adder)<br/>입력: A, B, Cin<br/>출력: Sum, Cout"]
        MUX["멀티플렉서 (MUX 4:1)<br/>선택선 S₁, S₀로<br/>4개 입력 중 1개 선택"]
        DEC["디코더 (Decoder 2:4)<br/>n비트 입력 ➔ 2ⁿ 활성화선"]
    end
```

## 2. 순서 논리 회로와 4대 플립플롭(Flip-Flop) 특성표

```mermaid
flowchart TD
    ROOT["순서 논리 회로 (Flip-Flop) 4대 계층"]
    ROOT --> RS["1. RS 플립플롭<br/>S=1, R=0 ➔ Set (1)<br/>S=0, R=1 ➔ Reset (0)<br/>S=1, R=1 ➔ 부정 (금지 상태)"]
    ROOT --> D["2. D 플립플롭 (Data)<br/>Q(t+1) = D<br/>(입력 D를 다음 클럭에 그대로 지연 복제)"]
    ROOT --> JK["3. JK 플립플롭 (RS의 부정 상태 해결)<br/>J=1, K=1 ➔ 토글 (Toggle: Q̄)<br/>Q(t+1) = J Q̄ + K̄ Q"]
    ROOT --> T["4. T 플립플롭 (Toggle)<br/>T=1 ➔ 반전 (Q̄), T=0 ➔ 유지 (Q)<br/>Q(t+1) = T ⊕ Q"]
```

      if (inJ === 0 && inK === 0) {

        stateQ = 0; // 리셋
      } else if (inJ === 1 && inK === 0) {
        stateQ = 1; // 셋
      } else if (inJ === 1 && inK === 1) {
        stateQ ^= 1; // 토글
      }
      updateJK();
    };

    updateJK();
