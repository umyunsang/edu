\*\*메모리 계층 구조(Memory Hierarchy)\*\*는 프로그램의 시간적·공간적 참조 국소성(Locality of Reference)을 활용하여 고속의 고비용 메모리와 대용량의 저비용 메모리를 결합함으로써 시스템의 평균 메모리 접근 시간을 최소화한다.

---

## 1. 캐시 사상 구조와 유효 접근 시간의 수학적 공식화

### 1) 3대 캐시 사상(Mapping) 아키텍처

- **직접 사상 (Direct Mapping)**:
  $$\text{Cache Block Index} = (\text{Memory Block Address}) \pmod{\text{Total Cache Blocks}}$$
  - 주소 분해: $[ \text{Tag} \mid \text{Block Index} \mid \text{Word Offset} ]$
- **완전 연관 사상 (Fully Associative Mapping)**:
  메모리 블록이 캐시의 임의의 위치에 적재 가능 (주소 분해: $[ \text{Tag} \mid \text{Word Offset} ]$, 고가의 병렬 비교기 필요).
- **$k$-way 세트 연관 사상 ($k$-Way Set Associative)**:
  $$\text{Set Index} = (\text{Memory Block Address}) \pmod{\text{Total Sets}}$$

### 2) 유효 메모리 접근 시간 (EAT, Effective Access Time)

캐시 적중률 $h$ ($0 \le h \le 1$), 캐시 접근 시간 $t_c$, 메인 메모리 접근 시간 $t_m$에 대해:

$$\text{EAT} = h \cdot t_c + (1 - h) \cdot t_m = t_c + (1 - h) \cdot \text{Miss Penalty}$$

- **2단계 다계층 캐시 ($L_1, L_2$)의 EAT**:
  $$\text{EAT} = t_{L1} + (1 - h_{L1}) \big( t_{L2} + (1 - h_{L2}) t_m \big)$$
