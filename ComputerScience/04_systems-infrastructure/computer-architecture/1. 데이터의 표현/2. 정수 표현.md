- 뺄셈에서 2의 보수 방식을 사용하는 이유는 뺄셈을 가산기를 사용하여 수행할 수 있기 때문

#### `overflow`

```C
unsigned char ubVar = 0;
signed char bVar = 0;

for(int i=0; i<257; i++)
{
	printf("%d ", ubVar);
	ubVarr++;
}
printf("\n");

for(int i=0; i<257; i++)
{
	printf("%d ", bVar);
	bVar++;
}
print("\n");
```

#### `underflow`

```C
unsigned char ubVar = 255;
signed char bVar = 255;

for(int i=0; i<257; i++)
{
	printf("%d ", ubVar);
	ubVarr--;
}
printf("\n");

for(int i=0; i<257; i++)
{
	printf("%d ", bVar);
	bVar--;
}
print("\n");
```
