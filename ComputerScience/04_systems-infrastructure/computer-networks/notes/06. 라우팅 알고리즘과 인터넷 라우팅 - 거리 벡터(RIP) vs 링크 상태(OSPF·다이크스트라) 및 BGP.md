> [!abstract] 핵심 요약
> **라우팅(Routing)**은 패킷이 목적지까지 이동할 최적의 전체 경로를 결정하는 제어 평면(Control Plane)의 알고리즘이다.
> 이웃 노드와만 비용을 교환하는 **거리 벡터(Distance Vector / Bellman-Ford / RIP)**와 전체 네트워크 토폴로지를 공유한 후 각자 최단 트리를 계산하는 **링크 상태(Link State / Dijkstra / OSPF)**의 수렴 속도 및 루프 방지 원리를 비교하고, 전 세계 인터넷을 연결하는 **AS 간 외부 라우팅 BGP**를 이해하는 것이 핵심이다.

---

## 1. 거리 벡터(RIP) vs 링크 상태(OSPF) 알고리즘 비교

```mermaid
flowchart TD
    ROOT["인터넷 내부 라우팅 알고리즘 (IGP)"]
    ROOT --> DV["1. 거리 벡터 (Distance Vector / RIP)<br/>• 벨만-포드(Bellman-Ford) 방정식 기반: $D_x(y) = \min_v [c(x,v) + D_v(y)]$<br/>• 이웃 라우터와만 주기적으로 라우팅 테이블 전체 교환<br/>• 단점: 무한 계수(Count-to-Infinity) 문제 ➔ 포이즌 리버스로 보완<br/>• 홉(Hop) 수 기준 (최대 15홉 제한)"]
    ROOT --> LS["2. 링크 상태 (Link State / OSPF)<br/>• 다이크스트라(Dijkstra) 최단 경로 트리 기반<br/>• 모든 라우터에게 LSA 패킷을 플러딩(Flooding)하여 동일 토폴로지 구성<br/>• 대역폭(Bandwidth) 기반 코스트 계산, 빠른 수렴(Fast Convergence)"]
```
