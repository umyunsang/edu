> [!abstract] 한 줄 요약
> LAN의 데이터 링크 기능은 논리 연결 제어와 매체 접근 제어로 나뉘며, 여러 호스트가 같은 매체를 쓰는 규칙을 제공한다.

```mermaid
flowchart LR
    A["상위 요청"] --> B["LLC"]
    B --> C["MAC"]
    C --> D["매체"]
```

> [!info] 핵심 원리
> LLC는 두 노드의 논리적 연결과 프레임 송수신 방식을 다루고, MAC은 연결 형태·전송 방법·헤더 같은 LAN의 구체 규칙을 정의한다. LAN 표준은 IEEE 802 계열에서 다뤄진다.

## 공유 매체에서의 순서

이더넷은 현재 별 형태로 널리 구성되며, CSMA/CD는 매체가 사용 중인지 확인한 뒤 전송하고 충돌이 나면 중지·대기·재전송하는 경쟁 방식이다. MAC 주소는 장치의 물리적 주소로 소개되며, IP 주소와 역할이 다르다.
