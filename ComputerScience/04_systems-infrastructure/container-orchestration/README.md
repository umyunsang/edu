> [!abstract] 이 과목은
> 현재 폴더에는 강의용 원본 PDF가 없어, 출처 없는 Docker·Kubernetes 노트를 새로 만들지 않는다.

## 자료 상태

현재 확인된 항목은 과목 인덱스뿐이다. 원본 PDF가 추가되면 Docker에서 Kubernetes로 이어지는 실제 수업 순서를 확인하고 번호를 부여한다.

## 정리문서

원본 PDF 부재로 재구성된 정리문서는 없다. 기존 링크는 현재 문서 트리와 맞지 않아 제거했다.

> [!note] 재개 조건
> PDF의 아키텍처 도식처럼 HTML/SVG로 충분히 전달되지 않는 부분에만 승인된 크롭을 사용한다.
