### [Page 4]
Then, Why Deep Learning?
• Learnable Representations
• Neural models can learn embeddings for categorical and numerical features, 
capturing richer similarity and structure than raw values alone
• End-to-end Feature Interactions
• MLPs and Transformers can jointly learn complex non-linear interactions 
among features, rather than constructing them via sequential tree splits
• Extensibility Beyond Standard Prediction
• Neural architectures naturally extend to pretraining, retrieval, multitask 
learning, and multimodal modeling with text, images, or time series

### [Page 16]
Deep Learning from Nearest Neighbors
• Motivation: Similar rows can provide useful information for prediction
• KNN uses nearby training samples directly
• Neural networks usually compress training data into model parameters
• Question: Can we combine neural representations with nearest-
neighbor reasoning?
• Two recent directions
• TabR: Retrieve similar training samples and use them inside a neural network
• ModernNCA: Learn an embedding space where soft nearest-neighbor 
prediction works well
16

### [Page 21]
ModernNCA
• ModernNCA revisits Neighborhood Components Analysis (NCA) 
with a learnable embedding function (i.e., neural network) 𝝓
• This is also known as soft nearest neighbor (soft-NN)
• Why "modern"?
• Better embedding with a neural network and PLR-style numerical encoding
• Better optimization
• Efficient neighborhood training with Stochastic Neighborhood Sampling (SNS)
• Simpler and faster than more complex retrieval-based models such as TabR
21
Ye et al., Revisiting Nearest Neighbor for Tabular Data: A Deep Tabular Baseline Two Decades Later, ICLR 2025

What is Attention?
• Attention identifies relevant relationships among items and

• Attention can flexibly capture interactions among items
• Attention has been widely used across diverse domains, including text, 
images, time-series, and so on
• Scaled dot-product attention

### [Page 30]
Why Attention for Tabular Data?
• Tabular prediction often depends on interactions among columns
• E.g., "Debt" becomes meaningful when considered together with "Income"
• A tabular row can be represented as a set of column tokens
• Numerical and categorical features are embedded into vectors
• Attention allows each feature token to incorporate information from other 
relevant features
• Attention operation is permutation-equivariant
• Tabular columns have no natural order
• Reordering feature tokens should not change the prediction
30

TabTransformer
• Core idea: Treat each categorical column as a token, and pass these 
tokens through a Transformer
• Each categorical embedding becomes contextualized 
by all other categorical values
• What about numerical features?
• Numerical columns are kept as scalars
• They are concatenated with the contextual 
categorical embeddings before the MLP head

### [Page 42]
Attention across Data Samples
• Main Idea
• Allow samples to interact with other samples during prediction via attention
• Related rows can provide useful contextual information
• Strengths
• Captures sample-level relationships
• Acts like a learned, flexible version of nearest-neighbor reasoning
• Useful when similar samples provide complementary evidence
• Limitations
• Higher computational and memory cost
• Requires care to avoid target leakage

Summary: Attention-based Architectures
• Attention-based models focus on learning interactions
• Feature-level interactions within each row
• Sample-level interactions across rows
• Structured or constrained interactions for tabular data
• Recent models improve plain self-attention by asking
• Which features should interact?
• Which samples should interact?
• Which interactions should be restricted or emphasized?
Attention gives tabular models a flexible way to model relationships 
among features and samples
