Worker: Poincare the 11th  
Access date: 2026-06-26

## Key Findings

- Use one role-first variant per application rather than keyword-stuffing all target roles into one headline.
- Strong keyword clusters for this profile:
  - AI/Applied AI: LLM Agents, RAG, Tool Calling, Evals, Hugging Face.
  - ML: NLP, PyTorch, Fine-Tuning, LoRA, QLoRA, PEFT, Quantization.
  - SWE: Python, TypeScript, APIs, Data Structures, System Design, SQL, Testing.
  - Frontend: JavaScript, TypeScript, Three.js/WebGL, mobile-first UI, web performance.
- MLOps can be a future bridge through vLLM/Docker/Kubernetes, but should not dominate the headline without stronger deployed/production proof.
- UMMAYA/GovOn supports Applied AI, LLM agents, tool calling, K-EXAONE, FriendliAI, and public-service workflow phrasing.
- Hugging Face GovOn/EXAONE assets support Hugging Face, LoRA, AWQ, model merging, civil/legal datasets, and LLM fine-tuning.
- DigitalPublishing supports Three.js, WebGL, mobile-first UI, and frontend/publishing proof.
- IlluOps should stay out of headline unless framed only as planning/evidence workflow.
