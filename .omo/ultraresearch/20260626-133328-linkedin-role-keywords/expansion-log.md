## Leads

- AI Engineer postings repeatedly pair LLM products with evals, tool/function calling, RAG, observability, latency/cost, and agent frameworks.
- Korean AI/ML postings strongly preserve Python, PyTorch, Hugging Face, RAG, vector search, LLM fine-tuning, and benchmark/evaluation vocabulary.
- MLOps postings converge on Kubernetes, Docker, CI/CD/GitOps, MLflow/Kubeflow/Argo, vLLM/Triton/TorchServe, Terraform, monitoring, drift, and GPU infrastructure.
- Frontend postings converge on React, TypeScript, Next.js, responsive UI, API integration, state management, performance, SSR/SEO, Core Web Vitals, and cross-browser compatibility.
- Software engineering postings still value core CS terms: data structures, algorithms, distributed systems, system design, code review, testing, operations, and ownership.
- LinkedIn/NACE guidance supports skills-first framing and current AI/LLM emphasis, but also supports communication, teamwork, critical thinking, professionalism, and technology adaptability for graduate readiness.
