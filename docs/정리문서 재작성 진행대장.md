> [!important] 이 문서의 역할
> 매일 새벽 3시경 실행되는 자동 루틴이 **가장 먼저 읽는 문서**다. 방침과 절차가 여기 있고, 어디까지 했는지도 여기 적힌다. 루틴은 작업을 마치면 아래 진행 표를 갱신해 커밋한다.

## 1. 확정된 방침

사용자가 명시적으로 정한 사항이다. 임의로 바꾸지 않는다.

| 방침 | 내용 |
| --- | --- |
| **기존 문서 무시** | 기존 정리문서는 참고하지 않는다. 근거는 **원본 PDF뿐** |
| **템플릿 금지** | 자료마다 중요도와 구성이 다르므로, **매번 그 자료에 맞는 구조를 새로 기획**한다. 결과적으로 모든 문서가 서로 다른 구조를 갖는다 |
| **인터렉티브 시각자료** | `html preview`(JS)·SVG·Mermaid·원본 슬라이드 크롭을 적극 활용 |
| **분량** | 적지 않게. 기준선은 노트당 **20~40KB**, 인터렉티브 2~4개 |
| **페이스** | 하루 **10개** — 더 하지 않는다 |

## 2. 작업 절차

### 2.1 대상 선정

아래 §4 진행 표에서 **위에서부터 미완료 과목**을 고른다. 한 과목을 끝내고 다음으로 넘어가되, 10개를 채우면 과목 중간이라도 멈춘다.

### 2.2 근거 자료 확보

추출 번들은 `.ok/local/pdf-extract/<도메인>__<과목>__<slug>/` 에 만들어진다 — `text.md`(페이지별 텍스트) + `pages/pNNN.png`(렌더) + `meta.json`.

이 디렉터리는 **gitignore되어 있으므로 클라우드 환경에는 없다.** 다룰 과목의 PDF만 그때그때 추출한다.

```bash
# poppler-utils 필요 (pdftotext, pdftoppm, pdfinfo)
python3 scripts/pdf_lecture_extract.py \
  "ComputerScience/<도메인>/<과목>/sources/"*.pdf
```

### 2.3 원본 읽기 — 순서가 중요하다

1. `meta.json` 의 `page_chars` 로 **텍스트가 0자인 페이지**를 찾는다
2. `text.md` 전체를 읽어 강의 흐름을 파악한다
3. **0자 페이지와 핵심 도표 페이지의 이미지를 직접 본다**

> [!warning] 0자 페이지가 알맹이다
> 이 강의자료들은 페이지당 40~200자로 텍스트가 빈약하고, **텍스트가 전혀 없는 페이지는 교수의 손글씨 필기인 경우가 많다**. 02장은 32쪽 중 네 쪽이 필기였고, 그 안에 빅오 증명·표기법 상호관계·$\log(n!)$ 증명이 들어 있었다. 슬라이드 텍스트만 읽으면 강의의 절반을 놓친다.

### 2.4 구조 기획

자료를 다 읽은 뒤 **이 강의가 실제로 하려는 말**을 한 문장으로 잡고, 그것을 문서의 척추로 삼는다. 앞서 작업한 10개의 척추가 모두 달랐다.

- 01장 — gcd(60,28)을 구하는 세 가지 길
- 02장 — 무게 중심이 슬라이드가 아니라 필기에 있다
- 04장 — 세 가지 축소 형태가 복잡도를 가른다
- 08장 — 탐욕은 기법이 아니라 재판이다

이런 식으로 **자료가 가진 고유한 긴장을 찾아** 구성을 짠다. 절 번호를 그대로 나열하는 방식은 쓰지 않는다.

### 2.5 집필

- MCP `write` 로 작성한다. 한 번에 5~8KB씩 `position: append` 로 나누어 보낸다
- **한글은 유니코드 이스케이프로 보내는 편이 안전하다** — 단, `루`를 `\ub8¬`로 쓰는 식의 불완전 이스케이프가 가끔 발생하므로 거부되면 해당 글자를 의심한다
- 인용할 슬라이드는 `<과목>/assets/chNN-pNN-설명.png` 로 복사하고 `../assets/` 상대경로로 참조한다
- **인터렉티브는 원본의 수치를 그대로 쓴다.** 쓰기 전에 파이썬으로 계산해 원본 표와 대조한다
- 색상은 반드시 테마 토큰(`var(--chart-1)`, `var(--foreground)` 등)을 쓴다. 하드코딩 금지

### 2.6 검증과 마무리

```text
1. lint({ document, fix: true })          — 노트마다
2. audit({ path: "<과목>/notes" })        — 과목을 끝냈을 때
3. 미인용 이미지 정리                     — 과목을 끝냈을 때
4. 진행 표 갱신 후 커밋
```

미인용 이미지 정리는 이렇게 한다.

```bash
cd "ComputerScience/<도메인>/<과목>"
grep -oh '\.\./assets/[^)]*' notes/*.md | sed 's|../assets/||' | sort -u > /tmp/cited.txt
(cd assets && ls > /tmp/all.txt)
comm -13 /tmp/cited.txt /tmp/all.txt | tr '\n' '\0' | xargs -0 -r rm -f
```

> [!caution] macOS 파일명 주의
> 한글 파일명이 NFD로 저장되어 있어 **문자열로 직접 경로를 쓰면 찾지 못한다**. 반드시 글로브로 접근한다 — `D=$(ls -d *과목__02* | head -1)`. 공백 든 파일명은 `-print0 | xargs -0` 로 다룬다.

발견한 **원본 오류·불일치 37건**. 수치는 전부 파이썬(유리수·정수 연산, 전수 탐색)으로 재계산해 대조했다.

`계산 오류 — 값이 틀린 것`

- **AI `Perceptron (이론)` 22번 ↔ 23번** — 22번이 $x=5$ 의 예측을 **65**로 적고 23번이 그 모델로 $y = 8x+10$ 을 준다. 넣으면 **50**이다. 같은 식은 네 훈련점 중 $x=10$ 하나만 맞히고($8\cdot3+10=34$ 대 데이터 50), 최소제곱 적합 $y=6.6x+22.9$ 는 $x=5$ 에서 55.9다. **셋 다 다른 값**이고, 22번 그래프의 세로축 눈금이 데이터 값 자리에만 찍혀 있어 65가 선 위에 있는 것처럼 보인다
- **AI `Perceptron (이론)` 58번** — 본문 `$b_{00}$ = -0.7 (NAND Gate 구현)` 인데 같은 슬라이드 그림은 **0.7**. 50번과 실습 덱 6번이 모두 $+0.7$ 이다. 본문 값으로 계산하면 NAND의 $s_1$ 이 네 입력에서 모두 0이 되어 **XOR 전체가 네 입력 모두 0을 내는 상수 함수**가 된다
- **AI `MLP(이론)` 12번의 tanh 식** — $\frac{1-e^{-x}}{1+e^{-x}}$ 는 $\tanh(x/2)$ 다(네 점에서 확인). 출력 범위는 같지만 원점 기울기가 0.5 대 1.0으로 갈리고, 같은 슬라이드의 「Sigmoid보다 최대 기울기가 큼」이 **네 배에서 두 배로 깎인다**
- **ai-system-design 4주차 21번 SF 표** — 베른의 `34(32%)` 는 $34/108 = 31.48\%$ 라 31%, 웰즈의 `9(11%)` 는 $9/86 = 10.47\%$ 라 10%다. 둘 다 정직하게 반올림하면 행 합이 99가 되므로 **한 칸씩 올려 100을 만든 것**으로 보이고 표시는 없다. 벨리에프 행만 분모가 50이라 손대지 않아도 100이 된다. 개수는 세 행 모두 정확하다
- **ai-system-design 2주차 39번 `1377년 금속활자(한국, 고려 초 직지심경)`** — 고려는 918~1392년이므로 1377년은 **고려 말**이다

`같은 것이 두 값을 갖는 것`

- **AI `Perceptron (이론)` 29번 ↔ 30번** — 같은 제목의 「학습용 데이터셋 예시」인데 Pass 두 줄이 다르다(`(90,80)·(75,60)` 대 `(75,90)·(80,60)`). Non-pass 두 줄은 같고, **30번의 산점도는 30번 표와 일치**한다
- **AI `Perceptron (이론)` 11번 ↔ 15번** — 퍼셉트론 발표 연도가 1958과 1957로 갈린다
- **AI `Perceptron (이론)` 55·56번 ↔ 57~60번** — 같은 그림의 같은 네 선이 $w_{00}\,w_{01}\,w_{03}\,w_{04}$(02 건너뜀)에서 $w_{00}$~$w_{03}$ 으로 이름을 바꾼다
- **ai-system-design 2주차 17번 ↔ 18번** — 같은 「AI 응답 시간」이 `2초 이내`(예시)와 `500ms 이내`(절대 규격)로 두 장 연속 다르게 인쇄된다. 절대 기준이 예시보다 네 배 엄격한데 설명이 없다
- **ai-system-design 4주차 3번 ↔ 22번** — 같은 「초기발표」에 서로 다른 일곱 항목. 셋만 겹치고, 3번은 경쟁사·개발일정을, 22번은 SDGs 번호·기술 트렌드·시스템 아키텍처를 각각 상대에 없는 항목으로 요구한다
- **prob-stat 23번 덱 39번 ↔ 49번** — 같은 요약 상자가 $\prod_{j}$ 와 $\prod_{i}$ 로 첨자가 갈린다

`반복되는 표기 오류`

- **prob-stat 23번 덱 40·45·47·54·57번** — 훈련 목록의 **네 번째 항이 다섯 장 모두 $\hat P(X_j=0\mid Y=0)$** 이다($Y=1$ 이어야 하고, 현재는 둘째 항과 완전히 같은 식이 중복된다). 한정사도 $\forall i$ 인데 첨자는 $j$ 이고, **54번 한 장에서만 $\forall j$ 로 고쳐졌다가 57번에서 되돌아간다**
- **prob-stat 23번 덱 전체** — $\arg\max$ 의 아래첨자가 `y={0,1}` 이다($y \in \{0,1\}$ 이어야 한다). 한 번도 고쳐지지 않는다
- **AI `MLP(이론)` 12번 제목 `Hypergolic tangent`** — `Hyperbolic` 의 오타

- **13번 덱 35번 `255.06`** — 참값은 **255.77**이다($2.20 \times 2.54 \times \frac{2197}{48}$). 원인까지 추적된다: 인쇄된 $E[2.54H] = 133.99$ 가 참값 133.985의 반올림이라 $138.05 \times 0.005 = 0.690$ 이 깎이고, $E[XY]$ 의 반올림에서 0.017이 더 깎여 정확히 $-0.707$ 이다. **18,750 근처의 두 수를 소수 둘째 자리에서 빼면 차이인 255의 셋째 자리가 날아간다** — 공분산의 $E[XY]-E[X]E[Y]$ 형태가 수치적으로 위험하다는 교과서적 사례에 슬라이드가 직접 걸렸다. 게다가 **여백의 잉크가 지름길($2.20\cdot2.54\cdot45.77$)로 옳은 값 255.76에 도달해 놓고 인쇄값에 맞춰 `≈ 255.06` 이라 적었다.** 그 슬라이드의 결론이 「공분산은 부호가 크기보다 의미 있다」인 것이 공교롭다
- **20번 덱 36번 `59.5`** — $(1/0.6)^7 = 35.72$ 이고 인쇄된 59.5는 $(1/0.6)^8$ 의 값이다. 같은 슬라이드의 다른 두 보기는 지수를 $7$·$6$ 으로 맞게 쓴다. 결론(B가 최대)은 안 바뀌지만 **「참값이 몇 배로 지는가」가 59.5배에서 35.7배로 달라진다**
- **20번 덱 17번** — $f(x) = -x^2+4$ 인데 $\frac{d}{dx}(x^2+4) = 2x$ 로 인쇄되어 있다. **마이너스가 두 번 사라졌다**(괄호 안과 결과). 해 $\hat x = 0$ 은 우연히 같고, 같은 슬라이드가 2계 조건 확인을 *"We'll ignore it here too"* 로 면제하므로 잡아 줄 검산도 없다
- **11번 덱 13번** — 인쇄된 $E[X]=1686$, $\sigma=23.3$ 을 그대로 나누면 $z = 2.5536 \to 2.55$ 인데 슬라이드는 $\Phi(2.54)$ 로 넘어간다. 실제 계산은 반올림 전 값($np = 1686.4$, $\sigma = 23.2303$)으로 이뤄졌다. 최종 답 0.0055는 옳지만 **인쇄된 중간값만 따라가면 0.0054가 나온다**
- **11번 덱 7번** — 연속성 보정 결과를 $\approx 0.0018$ 로 적는데 $1-\Phi(2.9) = 0.0018658$ 이라 유효숫자 둘로는 **0.0019**다. 이항의 정확값(0.0017588)에 맞춘 반올림으로 보인다

`표기 오류`

- **11번 덱 24번** — 주변분포 열의 둘째 값만 **소수점이 빠진 `38`** 이다(`.39` · `38` · `.19` · `.04`). 같은 슬라이드 아래쪽에서는 같은 수가 `.38` 로 제대로 찍혀 있다 (300 dpi 확인)
- **13번 덱 14번** — $E[Y] = E[Y_0] + E[\mathbf{Y_k}] + \cdots + E[Y_{k-1}]$ 에서 둘째 항의 아래첨자가 1이어야 하는데 $k$ 다. 정의되더라도 $E[Y_k] = \frac{k}{k-k}$ 로 분모가 0이 된다. 윗줄과 아랫줄은 정확하다 (300 dpi 확인)
- **12번 덱 12번** — 포아송 합 증명에서 이항정리를 적용하는 등호가 **`:=`(콜론 등호)** 로 인쇄되어 있다. 같은 증명의 나머지 등호 다섯 개는 평범한 `=` 다 (300 dpi 확인)
- **19번 덱 7번** — *"we can't **obverse** the entire population"*. `observe` 의 철자 오류이고, 같은 슬라이드 여백의 잉크는 정확히 `observe` 로 적었다
- **19번 덱 62번 ↔ 67번** — p-값 정의의 부등호가 `>=` 와 `>` 로 갈린다. 의사코드 본문이 `if diff >= observed_diff` 이므로 67번만 등호가 빠졌다
- **13번 덱 38번** — 네 번째 그림의 식은 $Y = X^2$ 인데 **가로축이 0~6이고 꼭짓점이 $x \approx 3$** 이다. 표시된 축 그대로면 $\rho$ 는 0이 아니라 1에 가깝다. $\rho=0$ 은 $X$ 가 꼭짓점 기준으로 대칭일 때만 성립하고, 그것은 26번의 반례($X \in \{-1,0,1\}$)와 같은 구조인데 덱은 둘을 잇지 않는다

`인쇄되지 않은 것 — 잉크가 채운 자리`

- **15번 덱은 핵심이 통째로 여백에 있다** — 베이즈망의 인수분해 공식 $P(x_1,\ldots,x_n) = \prod_i P(x_i \mid \text{parents}(x_i))$ 가 **어느 슬라이드에도 인쇄되어 있지 않고** 20번 여백의 잉크가 네 줄로 쓴 것이 전부다. 15번 정의를 읽는 법(비순환 · 경로 없으면 조건부독립 · 실제로는 인과)도 전부 잉크다
- **12번 덱 17번** — *"Is $X+Y$ a Binomial? **no, because p parameters of each differ!**"* 가 여백에만 있다. 4번의 *"If only it were always so simple"* 이 가리키는 내용이 이것인데, 인쇄물만 읽으면 $p$ 가 달라도 되는 줄 알기 쉽다
- **19번 덱 26번** — $SE$ 가 편향추정량이라는 사실($E[SE] < \text{SD}(\bar X)$, 젠센 부등식)이 *"More info: wikipedia"* 링크 한 줄로 처리되고 실제 내용은 잉크에만 있다
- **17번 덱 35번** — *"$f_D(4)$ is just a scaling constant. **Why?**"* 라고 굵게 묻는데 **답이 인쇄된 슬라이드가 없다**

`재계산해 얻은 것 (원본에 없는 보충)`

- **11번 덱**: 연속성 보정의 상대오차가 $k=69$ 와 $70$ 사이에서 뒤집힌다(보정 없음 19.3% 대 보정 22.5%). 원본의 적용 조건($np(1-p)>10$)은 분포 전체에 대한 것이지 꼬리의 어디까지인지는 말하지 않는다
- **12번 덱**: 잉크의 「$X+Y$ 는 이항이 아니다」를 분산으로 확정했다 — $\text{Var} = 1.277$ 인데 평균 1.3인 어떤 이항도 이 값을 못 가진다($n = 73.478\ldots$ 로 정수가 아니다)
- **13번 덱**: 덱의 유일한 실데이터인 사람 열두 명의 **상관계수를 덱이 끝내 계산하지 않는다.** 직접 구하면 $\rho = 0.8143$ 이고 단위를 바꿔도 같다 — 45.77과 255.77이라는 두 값이 하나로 합쳐지는 자리다
- **15번 덱**: 덱이 고른 질문은 기각 표집에 **가장 유리한** 경우다($P(\text{관측}) = 0.656$, 10만 개 중 65,600개 생존). 21번이 푼 질문은 0.0189 라 1,890개만 남고 표준오차가 다섯 배가 된다. **수학은 관측이 희귀해도 비용이 같고 표집은 정확히 그 자리에서 무너지는데**, 덱은 「지겹다 vs 표집」 한 축으로만 비교한다
- **16번 덱**: 32번의 다트 모형대로면 $P(0 \le X \le 900) = 0.6827$ 이라 **다트 50만 개 중 약 17만 5천 개(35%)가 화면 밖**에 떨어진다. 3번은 그 그림이 다트로 만들어졌다고 말한다
- **17번 덱**: 38번 잉크의 「$3\sqrt2$ 보다 약간 가깝다」가 정확히 얼마인지 — 대각선 위에서 지수가 $r$ 의 두 이차식 합이 되므로 **정밀도 가중평균**이고, $r^\star = 4.04853$, 관측 쪽으로 정확히 80% (격자 탐색으로도 확인)
- **19번 덱**: 네 추정치의 정확값(1.886) 대비 오차는 −0.90% · +5.62% · +6.20% 다. **공식과 부트스트랩의 차이(0.58%p)가 둘과 정확값의 차이(약 6%)보다 훨씬 작다** — 부트스트랩의 오차는 재표집이 아니라 표본 자체($S^2 = 793$ 대 $\sigma^2 \approx 711$)에서 온다
- **22번 덱**: 두 사후 최빈값의 차이가 **정확히 $\frac{4}{n+9}$** 로, 데이터 내용과 무관하게 $n$ 만으로 정해진다(분자 4 = 두 사람이 상상한 앞면 수의 차이, 9 = 둘 다의 상상 시행 수). 25번 주황 상자의 「사전분포가 점점 덜 중요해진다」를 정량화한다. 그리고 12번의 삼차방정식을 실제로 풀면 $\theta_{MAP} \approx 0.8698$ 로 **MLE 0.875에서 0.0052밖에 못 움직인다** — 어려운 만큼 효과가 있는 것도 아니다
