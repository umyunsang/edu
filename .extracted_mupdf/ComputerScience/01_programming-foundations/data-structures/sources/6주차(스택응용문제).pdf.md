●수식중위(Infix) 표기/ 후위(Postfix) 표기

중위표기: 수식에서+, -, *, /  와같은이항연산자는2개의피연산자사이에위치

후위표기: 컴파일러는중위표기수식을후위표기로바꾼다.

※ 후위표기방식은괄호없이중위표기수식을표현할수있음.

전위(Prefix) 표기: 연산자를피연산자들앞에두는표기법


| 중위 표기 | 후위 표기 | 전위 표기 |
| --- | --- | --- |
| A + B | A B + | + A B |
| A + B – C | A B + C – | + A – B C |
| A + B * C – D | A B C * + D – | – + A * B C D |
| (A + B) / (C – D) | A B+ C D – / | / + A B – C D |

●괄호짝맞추기– ‘{‘, ‘}’, ‘(‘, ‘)’

왼쪽괄호( ‘{‘ or ‘(‘ )는스택에PUSH, 오른쪽괄호( ‘}’ or ‘)’ ) 일경우스택에있는괄호기호하나POP

POP 된괄호와오른쪽괄호가다를경우False, 같으면다음괄호읽음

모든입력된괄호를검사한후오류가없고, 스택이Empty 이면True

모든입력된괄호를검사한후스택이empty 가아니면False
