지뢰찾기게임판

지뢰찾기게임에서는M x N 크기의격자판에서일부칸에지뢰가숨겨져있습니다. 각칸에는숫자
가표시되는데, 이숫자는주변8칸(상, 하, 좌, 우, 대각선4방향)에있는지뢰의수를나타냅니다.
격자판의크기와각칸에지뢰가있는지없는지의정보가주어질때, 모든칸에대한주변지뢰의수
를계산하는프로그램을작성하세요.

[입력]

[[-, *, -, -, -],
[-, -, -, *, -], 
[-, *, -, -, -], 
[-, -, -, -, -]]

[출력]

[[1, *, 2, 1, 1],
[2, 2, 3, *, 1], 
[1, *, 2, 1, 1], 
[1, 1, 1, 0, 0]]
