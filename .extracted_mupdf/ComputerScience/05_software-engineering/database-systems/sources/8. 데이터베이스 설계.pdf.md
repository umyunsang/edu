E-R 다이어그램을릴레이션스키마로변환하는규칙

• 규칙1 : 모든개체는릴레이션으로변환한다.

• 규칙3 : 일대다(1:n) 관계는외래키로표현한다.

• 규칙4 : 일대일(1:1) 관계는외래키로표현한다.

• 규칙5 : 다중값속성은릴레이션으로변환한다.

변환규칙을순서대로적용하되, 해당되지않는규칙은제외함
