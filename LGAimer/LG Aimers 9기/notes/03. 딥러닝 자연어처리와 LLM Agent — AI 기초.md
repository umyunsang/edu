> [!abstract] 핵심 요약
> 자연어처리는 단어의 통계적 분포를 연속 벡터 공간에 매핑하는 임베딩에서 출발하여, 문맥 전체를 $O(1)$ 경로로 가중합하는 **Transformer Self-Attention**을 통해 비약적으로 발전하였다.
> 최근의 생성형 LLM은 단순 텍스트 완성을 넘어 계산기, 웹 검색, 코드 실행기를 자율적으로 호출하는 **ReAct(Reasoning + Acting) Agent**로 진화하여 복합 비즈니스 문제를 해결한다.

---

## 1. Transformer Self-Attention 파이프라인

$$	ext{Attention}(Q, K, V) = 	ext{softmax}\left(rac{Q K^T}{\sqrt{d_k}}ight) V$$

```mermaid
flowchart TD
    INPUT["토큰 입력 시퀀스 ($X$)"] --> EMB["토큰 임베딩 + 포지셔널 인코딩"]
    EMB --> PROJ["가중치 사상: $Q = X W_Q, K = X W_K, V = X W_V$"]
    PROJ --> MATMUL["어텐션 스코어: $S = Q K^T / \sqrt{d_k}$"]
    MATMUL --> MASK["(인과적 마스킹 - 디코더)"]
    MASK --> SOFT["소프트맥스 가중치: $A = 	ext{softmax}(S)$"]
    SOFT --> CONTEXT["문맥 벡터: $C = A \cdot V$"]
    CONTEXT --> FFN["피드포워드 신경망 (FFN) + Residual"]
```

## 2. LLM 에이전트 ReAct 아키텍처 흐름

```mermaid
flowchart LR
    QUERY["사용자 복합 질문"] --> THOUGHT["1. Thought: 상황 추론 및 계획"]
    THOUGHT --> ACT["2. Action: Tool 호출"]
    ACT --> ENV["3. 외부 환경 API 실행"]
    ENV --> OBS["4. Observation: 결과 수집"]
    OBS --> LOOP{"추가 추론 필요?"}
    LOOP -- "Yes" --> THOUGHT
    LOOP -- "No" --> FIN["최종 답변 도출"]
```
