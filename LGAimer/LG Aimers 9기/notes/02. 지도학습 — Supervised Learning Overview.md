# 02. 지도학습 — Supervised Learning Overview

> [!abstract] 한 줄 요약
> 이미지·텍스트·번역·가격 예측 예시에서 출발해 함수 근사, 손실, 일반화와 선형 회귀·분류의 지도학습 설정을 정리한다.

<Tabs>
  <Tab label="핵심 개념">
- **지도학습** — 입력과 기대 출력(label)이 함께 주어진 데이터로 함수의 예측 능력을 학습한다.
- **함수 근사** — 알 수 없는 true function을 선택한 function class 안의 모델로 주어진 데이터에서 근사한다.
- **일반화** — 훈련에 사용하지 않은 입력에서도 비슷한 함수 값을 내는 능력으로 평가한다.

3. pointwise loss를 평균해 학습 목표를 만든다.
4. 훈련·검증·테스트로 일반화를 확인한다.
  </Tab>

- 훈련 손실이 낮아도 일반화가 나쁠 수 있는 이유는 무엇인가?
  </Tab>

## 단계별 정리

### 문제 유형

- CIFAR10 이미지 분류, 감성 텍스트 분류, 다음 단어 예측, 번역, 가격 예측이 예시다.
- 출력은 이산 label일 수도 있고 연속적인 실수일 수도 있다.
- 같은 지도학습 틀이라도 입력 표현과 평가 기준은 과업마다 달라진다.

### 규칙 기반에서 학습으로

- 규칙 기반 알고리즘은 전문가가 모든 조건을 명시해야 하므로 복잡한 과업에 취약하다.
- 머신러닝은 데이터와 알고리즘이 경험에서 패턴을 학습하도록 한다.
- Samuel의 정의처럼 명시적으로 프로그래밍하지 않고 성능이 향상되는 것이 핵심이다.

### 함수 근사 설정

- 관측 데이터와 label로 true function을 직접 알 수 없으므로 함수 클래스에서 근사 함수를 찾는다.
- 모든 입력에서 완벽히 근사하는 것은 불가능하므로 주어진 데이터에서 유사한 출력을 목표로 한다.
- 데이터셋·모델 클래스·손실 함수가 지도학습 문제를 구성한다.

### 손실과 일반화

- 예측과 정답의 차이를 pointwise loss로 측정하며 MSE·cross-entropy가 예시다.
- 훈련 손실만 낮추면 과적합할 수 있으므로 보지 않은 데이터의 일반화를 봐야 한다.
- 손실 함수는 모델 파라미터를 비교·최적화하는 공통 언어다.

### 학습 루프

- label이 있는 데이터셋을 준비하고 함수 클래스를 정한다.
- 손실을 최소화하는 파라미터를 찾은 뒤 검증·테스트로 근사 품질을 확인한다.
- 분류·회귀에 따라 출력 공간과 평가 지표를 맞춘다.

| 단계 | 원본에서 관찰할 신호 | 학습 산출물 |
| --- | --- | --- |
| 과업 | 이미지·텍스트·번역·가격 | 입력·출력 형식 |
| 설정 | true function·function class | 근사 공간 |
| 목표 | MSE·cross-entropy | pointwise·평균 손실 |
| 검증 | 훈련·테스트 일반화 | 보지 않은 데이터 성능 |

> [!warning] 읽을 때의 주의점
> 강의의 함수 근사 설명은 개념적 모델이다. 특정 데이터셋에서 최적 함수가 실제로 존재하거나 유일하다고 가정하지 않는다.
