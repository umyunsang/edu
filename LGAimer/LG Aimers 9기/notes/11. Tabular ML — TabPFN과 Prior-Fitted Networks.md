## 단계별 정리

### Tabular foundation 질문

- 표마다 모델을 새로 맞추는 대신 여러 과업에 전이 가능한 foundation model을 묻는다.
- 작은 데이터와 제한된 label에서 빠른 inference가 핵심 요구다.
- 사전학습 분포가 실제 과업과 얼마나 맞는지가 성능의 전제다.

### Prior-Fitted Networks

- 훈련 중 과업을 predefined prior에서 샘플링하고 transformer qθ를 학습한다.
- 테스트 과업에서 별도 adaptation 없이 y_test의 posterior predictive를 낸다.
- Transformers Can Do Bayesian Inference 논문이 아이디어의 근거로 제시된다.

### TabPFN v1

- TabPFN은 표 행·열을 transformer 입력으로 처리하고 prior 기반 추론을 적용한다.
- 작은 tabular classification에서 수 초 수준의 빠른 runtime을 목표로 한다.
- 데이터 분포가 prior와 어긋나거나 규모가 커지면 한계가 생긴다.

### TabPFN v2

- v2는 feature heterogeneity와 다양한 데이터셋을 겨냥해 prior와 모델 범위를 확장한다.
- 학습된 foundation representation을 활용해 적은 데이터에서도 강한 예측을 노린다.
- v2 역시 데이터 크기·도메인·계산 자원에 따른 제한을 가진다.

### 적용 판단

- TabPFN은 작은 표 분류와 빠른 baseline 비교에 적합한 후보가 된다.
- 실제 성능은 prior·feature 타입·결측·class imbalance·평가 분할에 민감하다.
- foundation model이라는 이름보다 적용 조건과 실패 사례를 먼저 검증한다.

| 단계 | 원본에서 관찰할 신호 | 학습 산출물 |
| --- | --- | --- |
| 목표 | Tabular foundation | 다수 과업·작은 데이터 |
| 학습 | PFN prior sampling | 사전 과업 분포 |
| 모델 | TabPFN v1·v2 | transformer·posterior |
| 판단 | 적합성·한계 | 도메인·규모·검증 |

> [!warning] 읽을 때의 주의점
> TabPFN의 장점은 강의가 다룬 작은 표 분류 조건에 묶여 있다. 모든 표 과업에서 기존 모델을 대체한다고 해석하지 않는다.
