## 단계별 정리

### 왜 딥러닝인가

- 트리 기반 모델은 여전히 강하지만 신경망은 learnable representation을 만들 수 있다.
- 수치·범주 feature의 유사성과 상호작용을 end-to-end로 학습한다.
- 멀티모달·전이학습과 연결되는 확장성이 동기다.

### MLP baseline

- 각 수치 열을 스칼라로 넣고 dense layer를 쌓는 plain MLP를 만든다.
- ResNet-like MLP는 residual 연결로 깊은 표현을 안정화한다.
- 약하게 튜닝한 baseline과 잘 설계한 MLP를 혼동하지 않는 것이 핵심이다.

### 수치 feature embedding

- 각 수치 feature를 하나의 scalar가 아니라 학습 벡터로 표현한다.
- Piecewise Linear Encoding은 구간·분위수 경계를, Periodic Activation은 주기적 기저를 사용한다.
- 표 데이터에서는 backbone보다 feature 표현 방식이 성능을 크게 좌우할 수 있다.

### RealMLP recipe

- RealMLP는 robust preprocessing, 수치·범주 embedding, learnable scaling을 함께 사용한다.
- 개선된 activation·initialization·regularization과 meta-tuned default를 제공한다.
- 잘 조정된 단순 MLP가 강한 accuracy-efficiency trade-off를 보일 수 있다.

### TabR retrieval

- TabR은 MLP에 kNN-like retrieval module을 추가한다.
- embedding 공간의 상위 이웃 표현·label·차이를 attention처럼 결합한다.
- 훈련 데이터의 유사 샘플을 활용해 새로운 deep tabular 해법을 만든다.

| 단계 | 원본에서 관찰할 신호 | 학습 산출물 |
| --- | --- | --- |
| 동기 | 표현·상호작용·전이 | 딥러닝의 장점 |
| 기본 | Plain·ResNet MLP | baseline 강도 |
| 표현 | PLE·Periodic embedding | 수치 열 구조 |
| 확장 | RealMLP·TabR | recipe·이웃 검색 |

> [!warning] 읽을 때의 주의점
> 강의의 논문 비교는 동일한 benchmark 조건의 결과다. MLP·TabR이 모든 표 데이터에서 트리 모델보다 우수하다는 주장을 만들지 않는다.
