# LG Aimers 9기 지원서 초안

> [!note] 작성 근거
> - 9기 콘셉트: LG AI연구원 주관 청년 AI 전문가 양성 프로그램, 국내 최고 교수진의 AI 강의와 LG 계열사 실제 데이터 해커톤, 특히 9기는 `AI + 야구` 및 LG 스포츠 / LG 트윈스 데이터분석팀 협업 기반 야구 데이터 해커톤으로 공개됨.
> - 8기 경험: `LG Aimers / LLM Compression` 수료, `EXAONE 모델 경량화` 해커톤, 성능과 추론 속도를 함께 보는 평가 구조, `vLLM` 및 HuggingFace 호환 모델 제출 환경을 학습함.
> - 글쓰기 적용 기준: 창의적 글쓰기 강의자료의 Technical Writing 3C, 독자 중심 서술, Power Writing의 `주장-근거-사례-주장강조`, 자기소개서의 `구체적 경험-과정-결과-발전 가능성` 구조를 반영함.

## 1. 지원동기

저는 8기에서 배운 `성능과 실행 가능성을 함께 보는 AI 문제 해결 방식`을 9기의 야구 데이터 해커톤으로 확장하고 싶어 지원했습니다. LG Aimers 8기 EXAONE 모델 경량화 과제는 단순히 모델 정확도를 높이는 대회가 아니었습니다. 기준 모델 대비 성능을 유지하면서도 토큰당 추론 시간을 줄여야 했고, 제한된 실행 시간 안에서 모델 로드, 추론, 결과 파싱까지 안정적으로 동작해야 했습니다. 이 과정에서 AI 모델은 성능 수치만으로 평가되는 것이 아니라 실제 환경에서 빠르고 재현 가능하게 작동해야 의미가 있다는 점을 배웠습니다.

이번 9기는 `AI + 야구`를 키워드로 LG 스포츠 및 LG 트윈스 데이터분석팀과 협업해 야구 데이터를 다루는 과정이라는 점에서 8기 경험과 자연스럽게 이어집니다. 야구는 선수 기록, 상대 전적, 경기 흐름, 상황별 전략이 함께 작용하는 데이터 중심 스포츠입니다. 따라서 높은 점수를 얻는 모델뿐 아니라 왜 그런 예측이 나왔는지 설명하고, 현장의 판단에 연결할 수 있는 분석 과정이 중요하다고 생각합니다. 저는 8기에서 쌓은 실전형 모델 평가 경험을 바탕으로, 9기에서는 스포츠 데이터의 맥락을 이해하고 문제 해결에 적용하는 AI 인재로 성장하고자 합니다.

## 2. 향후 비전 및 포부(수행계획)

9기 과정의 목표는 리더보드 점수 향상에 그치지 않고, 실제 스포츠 데이터 분석 현장에서 설명 가능한 문제 해결 흐름을 만드는 것입니다. 이를 위해 먼저 데이터 구조와 평가 지표를 정확히 파악하겠습니다. 야구 데이터는 시간 흐름과 경기 맥락이 중요하므로, 데이터 누수 가능성이 있는 변수를 구분하고 학습-검증 기준을 명확히 세우겠습니다. 그 다음 단순하고 재현 가능한 베이스라인을 만든 뒤, 선수별 최근 경기력, 상대 전적, 팀 상황, 경기 상황별 특징을 단계적으로 추가하겠습니다.

모델링에서는 복잡한 기법을 먼저 적용하기보다, 해석 가능한 모델로 문제 구조를 확인한 뒤 필요한 경우 앙상블이나 시계열적 특징을 반영하는 방식으로 확장하겠습니다. 모든 실험은 가설, 변경 사항, 지표 변화를 함께 기록해 팀원과 공유하고, 성능이 오르지 않은 실험도 다음 의사결정의 근거로 남기겠습니다. 8기에서 성능과 추론 효율을 함께 고려했던 경험을 이번에는 정확도, 설명 가능성, 재현성까지 갖춘 분석 결과로 발전시키겠습니다.

장기적으로는 산업 현장의 데이터를 실제 의사결정과 연결하는 AI 엔지니어로 성장하고 싶습니다. LG Aimers 9기를 통해 스포츠 데이터라는 구체적인 도메인에서 문제 정의, 특징 설계, 모델 개선, 결과 해석을 경험하며, 데이터가 현장의 판단을 돕는 방식으로 AI를 설계하는 역량을 쌓겠습니다.

## 3. 관련 경력(경험) 기술

저의 가장 직접적인 관련 경험은 LG Aimers 8기 `LLM Compression` 과정 수료와 EXAONE 모델 경량화 해커톤입니다. 당시 과제는 EXAONE-4.0-1.2B 모델을 기준으로 제출 모델의 성능 비율과 토큰당 추론 시간 감소 비율을 함께 평가하는 구조였습니다. 저는 이 과정에서 성능 지표만 보는 것이 아니라 모델이 정해진 환경에서 실제로 로드되고 추론되며 제한 시간 안에 결과를 생성하는지까지 확인해야 한다는 점을 학습했습니다.

또한 HuggingFace `AutoTokenizer`, `AutoModelForCausalLM` 호환 구조와 고정된 vLLM 서빙 환경을 정리하며, 모델 개발과 평가 환경을 분리해서 볼 수 없다는 것을 체감했습니다. 강의 과정에서는 LLM 압축, 경량화 모델의 비용 최적화, LLM 애플리케이션 및 평가, NLP와 LLM Agent, EXAONE 모델 구조, AI 윤리 등을 학습했습니다. 이 경험은 모델 성능뿐 아니라 비용, 지연 시간, 배포 가능성, 윤리적 사용까지 함께 고려하는 관점으로 이어졌습니다.

전공 학습에서는 머신러닝, 신경망, 데이터베이스, 알고리즘, 빅데이터 분석 관련 과목을 통해 데이터 전처리와 모델링의 기초를 쌓았습니다. 9기에서는 이 기반을 야구 데이터 분석 문제에 적용해 기록 기반 특징 설계, 검증 전략 수립, 실험 결과 공유를 맡고 싶습니다. 8기에서 얻은 실전 평가 경험을 바탕으로 팀 안에서 안정적으로 문제를 구조화하고 개선 방향을 제시하겠습니다.

## 1500byte 제출형 버전

### 지원동기

저는 LG Aimers 8기에서 배운 성능과 실행 가능성을 함께 보는 AI 문제 해결 방식을 9기의 야구 데이터 해커톤으로 확장하고 싶어 지원했습니다. 8기 EXAONE 모델 경량화 과제에서는 정확도만이 아니라 토큰당 추론 시간, 제한된 실행 시간, HuggingFace와 vLLM 기반 평가 환경까지 함께 고려해야 했습니다. 이 경험을 통해 AI 모델은 높은 점수보다 실제 환경에서 안정적으로 동작하고 설명 가능한 결과를 낼 때 가치가 커진다는 점을 배웠습니다. 9기는 LG 스포츠 및 LG 트윈스 데이터분석팀과 협업해 야구 데이터를 다루는 과정입니다. 야구는 선수 기록, 상대 전적, 경기 흐름, 상황별 전략이 복합적으로 작용하는 데이터 중심 스포츠이므로, 8기에서 익힌 실전 평가 경험을 현장 데이터 분석 역량으로 발전시키고 싶습니다.

### 향후 비전 및 포부(수행계획)

9기에서는 리더보드 점수 향상에 그치지 않고, 설명 가능하고 재현 가능한 분석 흐름을 만드는 것을 목표로 하겠습니다. 먼저 데이터 구조와 평가 지표를 정확히 이해하고, 야구 데이터의 시간 순서와 경기 맥락을 고려해 데이터 누수 가능성을 점검하겠습니다. 이후 단순한 베이스라인을 빠르게 구축하고, 선수별 최근 경기력, 상대 전적, 팀 상황, 경기 상황별 특징을 단계적으로 추가하겠습니다. 모델링은 해석 가능한 접근에서 출발해 필요할 때 앙상블이나 시계열 특징을 반영하는 방식으로 확장하겠습니다. 모든 실험은 가설, 변경 사항, 지표 변화를 함께 기록해 팀과 공유하겠습니다. 최종적으로 정확도뿐 아니라 현장의 판단에 연결될 수 있는 결과물을 만들고, 산업 데이터를 의사결정에 연결하는 AI 엔지니어로 성장하겠습니다.

### 관련 경력(경험) 기술

저는 LG Aimers 8기 LLM Compression 과정을 수료하며 EXAONE-4.0-1.2B 모델 경량화 과제를 경험했습니다. 당시 과제는 기준 모델 대비 성능 비율과 토큰당 추론 시간 감소 비율을 함께 평가했고, 제한된 실행 시간 안에서 모델 로드와 추론이 안정적으로 이루어져야 했습니다. 또한 HuggingFace AutoTokenizer, AutoModelForCausalLM 호환 구조와 고정된 vLLM 서빙 환경을 정리하며 모델 구조와 평가 조건을 함께 보는 습관을 길렀습니다. 강의 과정에서는 LLM 압축, 경량화 모델의 비용 최적화, LLM 애플리케이션 및 평가, NLP와 LLM Agent, EXAONE 모델 구조, AI 윤리 등을 학습했습니다. 전공 학습으로는 머신러닝, 신경망, 데이터베이스, 알고리즘, 빅데이터 분석 기반을 쌓았고, 이를 9기 야구 데이터 해커톤의 문제 정의, 특징 설계, 검증, 결과 해석에 적용하겠습니다.
