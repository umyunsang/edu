## 단계별 정리

### 왜 압축하는가

- OPT-175B·LLaMA 계열처럼 큰 모델은 저장·연산·전력 비용이 높다.
- 압축 목표는 정확도를 유지한 채 빠르고 메모리 효율적이며 에너지 효율적인 모델을 만드는 것이다.
- 거대한 사전학습 모델을 대상으로 압축 알고리즘 자체의 비용도 고려해야 한다.

### Pruning

- 임계값보다 작은 가중치를 제거해 연결 수를 줄인다.
- pruning 뒤 재학습하고, 효과적인 연결을 찾기 위해 반복적으로 제거할 수 있다.
- LeNet·AlexNet·VGGNet 실험에서 원본 대비 약 10배 압축 사례가 소개된다.

### Knowledge Distillation

- 큰 teacher 모델의 soft target과 정답 라벨을 가중 결합해 작은 student를 훈련한다.
- temperature가 커지면 분포가 부드러워져 클래스 간 관계를 전달한다.
- BERT 압축과 MiniLM의 self-attention distillation이 사례로 제시된다.

### Uniform Quantization

- 일반적으로 8비트 이하의 bit-width를 사용해 저장 폭을 줄인다.
- round-to-nearest는 scale Δ와 zero-point z를 계산해 값을 정수 격자로 보낸다.
- weight-only는 곱셈 전 dequantization이 필요하고 activation 양자화는 calibration이 필요하다.

### PTQ·QAT와 LoRA

- PTQ는 재학습 없이 효율적으로 적용하지만 정확도 손실이 있을 수 있다.
- QAT는 양자화 효과를 학습에 반영해 정확도는 높지만 비용이 크다.
- SmoothQuant·QuaRot은 activation outlier를 다루고 Q-LoRA·QA-LoRA는 저비용 미세조정을 연결한다.

| 단계 | 원본에서 관찰할 신호 | 학습 산출물 |
| --- | --- | --- |
| 구조 | Pruning·반복 재학습 | 연결 수·모델 크기 |
| 지식 | Teacher→Student soft target | 작은 모델 정확도 |
| 정밀도 | RTN·activation calibration | bit-width·메모리 |
| 보정 | SmoothQuant·QuaRot·Q-LoRA | outlier·미세조정 |

> [!warning] 읽을 때의 주의점
> 강의의 일부 수치와 벤치마크는 특정 논문·모델 조건의 결과다. 모든 LLM에 동일한 압축률이나 정확도 보장을 일반화하지 않는다.
