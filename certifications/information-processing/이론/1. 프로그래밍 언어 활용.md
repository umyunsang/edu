# 1. 프로그래밍 언어 활용

## 1. 개요
*   **프로그래밍 언어**: 문제 해결을 위한 명령어 집합(프로그램)을 작성하는 도구.
*   **자료의 단위**:
    *   **Bit**: 정보의 최소 단위 ($2^1=2$개 표현).
    *   **Byte**: 8 Bit.
*   **코드 체계**: 아스키코드(ASCII), 유니코드(Unicode).

## 2. C언어 기본 구조
```c
#include <stdio.h> // 전처리기 + 표준 입출력 헤더

main() {
    // 코드 작성
    printf("Hello");
}
```

## 3. 데이터 타입 및 변수

### 3.1 변수 (Variable)
*   **정의**: 값을 저장하기 위한 메모리 공간.
*   **작성 규칙**:
    *   영문자, 숫자, 언더바(`_`) 사용.
    *   숫자로 시작 불가.
    *   예약어 사용 불가.
    *   공백 불가.

### 3.2 데이터 타입 비교 (C / Java / Python)

| 구분 | C (System 의존) | Java (크기 고정) | Python |
| :--- | :--- | :--- | :--- |
| **정수형** | `int` (4B), `long` (주로 4B) | `int` (4B), `long` (8B) | `int` (크기 제한 없음) |
| **실수형** | `float` (4B), `double` (8B) | `float` (4B), `double` (8B) | **`float` (8B, C의 double)** |
| **문자형** | `char` (1B) | `char` (2B, Unicode) | `str` |
| **논리형** | `_Bool`, `0`/`1` | `boolean` (1bit~1B) | `bool` |

> [!important] 시험 대비 암기 포인트
> *   **C언어 `long` vs `int`**: C언어에서 `long`은 4Byte인 경우가 많아 **`int`와 크기가 같을 수 있음**을 기억해야 함. (반면 Java `long`은 무조건 8Byte)
> *   **Python `float`**: 단정밀도(4Byte)가 아니라 **배정밀도(8Byte, double)** 임.

> [!example] 상수 (Constant)
> 프로그램 종료 시까지 변경되지 않는 불변의 값 (예약어 - **C**: `const`, **Java**: `final`)

## 4. 연산자

### 4.1 증감 연산자 (`++`, `--`)
*   **특징**: 단독 사용 시 결과 동일하나, 문장 내 사용 시 시점(전치/후치)에 따라 결과가 달라짐.
```c
int a = 5, b;
a++; ++a; // 단독: 결과 동일 (단순 1 증가)

b = ++a;  // 전치: 증가 후 대입 (a=6, b=6)
b = a++;  // 후치: 대입 후 증가 (b=5, a=6)
```

### 4.2 산술 연산자

*   `+`, `-`, `*`, `/`, `%`

```c

int a = 7, b = 3;

printf("%d", a / b); // 결과: 2 (정수형 나눗셈은 소수점 이하 절삭)

printf("%d", a % b); // 결과: 1 (7을 3으로 나눈 나머지)

double c = 7.0 / 3;  // 결과: 2.333... (피연산자 중 하나가 실수면 실수 연산)

```

*   **`%` (Mod)**: 나눗셈의 나머지를 구함 (홀수/짝수 판별, 배수 판별 등에 사용).

### 4.3 논리 연산자

*   `&&` (AND), `||` (OR), `!` (NOT) 

> [!warning] Short-circuit Evaluation

> *   `A && B`: A가 거짓이면 B는 실행(평가)하지 않음.

> *   `A || B`: A가 참이면 B는 실행(평가)하지 않음.

### 4.4 관계 연산자

*   `>`, `<`, `>=`, `<=`, `==` (같다), `!=` (다르다)

*   결과값은 참(`1`) 또는 거짓(`0`)으로 반환.    

### 4.5 기타 연산자 (대입, 조건, Cast, Sizeof)

1.  **대입 연산자**: `=`, `+=`, `-=`, `*=` 등 (우변의 값을 좌변에 저장).

2.  **조건(삼항) 연산자**: `조건식 ? 참일_때_값 : 거짓일_때_값`

3.  **Cast 연산자**: `(int)3.14` (강제 형 변환).

4.  **sizeof**: 자료형이나 변수의 메모리 크기(Byte) 반환.    

### 4.6 비트 연산자

| 연산자  | 설명          | 특징                 |     |
| :--: | :---------- | :----------------- | --- |
| `&`  | AND         | 둘 다 1일 때 1         |     |
|  | | OR          | 하나라도 1이면 1         |     |
| `^`  | XOR         | 서로 다르면 1           |     |
| `~`  | NOT         | 비트 반전 (0->1, 1->0) |     |
| `<<` | Left Shift  | 값 $ 	imes 2^n$     |     |
| `>>` | Right Shift | 값 $\div 2^n$       |     |

> [!tip] XOR 연산 암기법
> **1의 개수가 홀수면 1, 짝수면 0** (Parity Check 등에 활용)
> *   패딩 비트(Padding Bit): 구조체 등에서 메모리 정렬을 위해 채우는 비트.

## 5. 입출력 함수 (C언어)

### 5.1 서식 문자 (Format Specifier)

### 5.3 입력 함수 (scanf)
*   `scanf("%d", &num);
*   **주의사항**:
    *   변수 앞에 주소 연산자 `&` 필수.
    *   **배열(문자열) 변수명은 그 자체로 주소이므로 `&` 생략.**

## 6. 제어문

### 6.1 반복문
*   **while**: 조건 검사 후 실행 (0회 실행 가능).
*   **do ~ while**: **무조건 1회 실행** 후 조건 검사.
*   **continue**: 아래 문장을 건너뛰고 반복문의 선두(조건식/증감식)로 이동.

### 6.2 조건문
*   **switch ~ case**:
    *   조건 값에 따라 분기.
    *   `break` 생략 시 **다음 case문까지 계속 실행 (Fall-through)**.

> [!warning] break 생략 주의
> 의도치 않은 실행 흐름을 막기 위해 `break` 작성 여부 반드시 확인.

## 7. 배열 (Array)

### 7.1 선언 및 초기화
1.  `int arr[3] = {1, 2, 3};` (완전 초기화)
2.  `int arr[5] = {1, 2};` (나머지 0으로 자동 채움 → `{1, 2, 0, 0, 0}`)
    *   **인덱스**: 0부터 시작.

### 7.2 2차원 배열
*   `int arr[행][열];`
*   행 우선(Row-major) 순서로 메모리에 저장됨.

## 8. 문자열 (String)
*   C언어는 문자열 자료형 없음 → `char` 배열 사용.
*   `char str[10] = "Hello";`
*   **주의사항**:
    *   ==배열 크기 생략 시 반드시 초기값 지정해야 함.== (`char str[] = "Test";`)
    *   ==이미 선언된 배열에는 문자열 대입 연산 불가.== (`str = "World";` (X))
    *   `strcpy(str, "World");` 함수 사용하여 대입.

## 9. 함수 (Function)
*   **구성**: 리턴형, 함수명, 매개변수, 리턴문.
*   **void**: 리턴값이 없을 때 사용.
*   **return**: 값을 반환하고 함수 종료. `main`의 `return 0;`는 정상 종료 의미.

## 10. 구조체 (Structure)
*   **정의**: 서로 다른 자료형의 묶음 (Java의 Class와 유사).
*   **관례**: 구조체 이름은 대문자로 시작.

### 10.1 선언 방식
```c
// 1. 선언과 초기화
struct Person {
    char name[10];
    int age;
} p1 = {"Kim", 20};

// 2. 선언 후 초기화
struct Person p2;
p2.age = 30; // 멤버 접근 연산자 (.).

// 3. typedef 이용 (별칭)
typedef struct {
    int x;
    int y;
} Point;

Point pos = {10, 20}; // struct 키워드 생략 가능
```

> [!summary] typedef 핵심
> ==`typedef`로 구조체 별칭을 만들면 변수 선언 시 `struct` 키워드를 생략할 수 있다.==
