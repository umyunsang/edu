# 1. 프로그래밍 언어 활용
## 1. 개요
* **프로그래밍 언어**: 문제 해결을 위한 명령어 집합(프로그램)을 작성하는 도구.
* **자료의 단위**: Bit(최소 단위, 2개 표현), Byte(8 Bit).
* **코드 체계**: 아스키코드(ASCII), 유니코드(Unicode).
## 2. C언어 기본 구조
```c
#include <stdio.h> // 전처리기 + 표준 입출력 헤더
main() {
    // 코드 작성
    printf("Hello");
}
```
## 3. 데이터 타입 및 변수
### 3.1 변수 (Variable)
* **정의**: 값을 저장하기 위한 메모리 공간.
* **작성 규칙**: 영문자, 숫자, 언더바(_) 사용. 숫자로 시작 불가. 예약어 및 공백 불가.
### 3.2 데이터 타입 비교 (C / Java / Python)

| 구분      | C (System 의존)               | Java (크기 고정)                | Python                      |
| :------ | :-------------------------- | :-------------------------- | :-------------------------- |
| **정수형** | `int` (4B), `long` (주로 4B)  | `int` (4B), `long` (8B)     | `int` (크기 제한 없음)            |
| **실수형** | `float` (4B), `double` (8B) | `float` (4B), `double` (8B) | **`float` (8B, C의 double)** |
| **문자형** | `char` (1B)                 | `char` (2B, Unicode)        | `str`                       |
| **논리형** | `_Bool`, `0`/`1`            | `boolean` (1bit~1B)         | `bool`                      |
> [!important] 시험 대비 암기 포인트
> * **C언어 `long` vs `int`**: C언어에서 `long`은 4Byte인 경우가 많아 **`int`와 크기가 같을 수 있음**을 기억해야 함. (반면 Java `long`은 무조건 8Byte)
> * **Python `float`**: 단정밀도(4Byte)가 아니라 **배정밀도(8Byte, double)** 임.

> [!example] 상수 (Constant)
> 프로그램 종료 시까지 변경되지 않는 불변의 값 (예약어 - **C**: `const`, **Java**: `final`)
## 4. 연산자
### 4.1 증감 연산자
| 구분 | 연산자 | 기능 및 시점 |
| :--- | :---: | :--- |
| **전치** | `++a`, `--a` | **먼저 1 증가/감소 후** 문장 실행 (증가 후 대입) |
| **후치** | `a++`, `a--` | 문장 실행 **후 1 증가/감소** (대입 후 증가) |
```c
int a = 5, b;
a++; ++a; // 단독: 결과 동일 (단순 1 증가)
b = ++a;  // 전치: 증가 후 대입 (a=6, b=6)
b = a++;  // 후치: 대입 후 증가 (b=5, a=6)
```
* **특징**: 단독 사용 시 결과 동일하나, 문장 내 사용 시 시점(전치/후치)에 따라 결과가 달라짐.
### 4.2 산술 연산자

| 연산자 | 설명 |
| :---: | :--- |
| `+`, `-`, `*`, `/` | 더하기, 빼기, 곱하기, 나누기 |
| `%` | **나머지 (Mod)**: 나눗셈의 나머지를 구함 (홀/짝, 배수 판별) |
```c
int a = 7, b = 3;
printf("%d", a / b); // 결과: 2 (정수형 나눗셈은 소수점 이하 절삭)
printf("%d", a % b); // 결과: 1 (7을 3으로 나눈 나머지)
double c = 7.0 / 3;  // 결과: 2.333... (피연산자 중 하나가 실수면 실수 연산)
```

### 4.3 논리 연산자
| 기호 | 명칭 (영문) | 명칭 (국문) |
| :---: | :--- | :--- |
| `!` | NOT | 논리부정 |
| `&&` | AND | 논리곱 |
| `\|\|` | OR | 논리합 |
> [!important] 우선순위
> **NOT (`!`)** $\rightarrow$ **AND (`&&`)** $\rightarrow$ **OR (`||`)**
>> [!example] 논리 연산 예제
>> ```c
>> int x=3, y=4, z=0, rs;
>> rs = x || y && z; // 결과: 1 (참)
>> ```
>> **연산 순서**:
>> 1. `y && z`: `4 && 0` $\rightarrow$ `0` (거짓)
>> 2. `x || 0`: `3 || 0` $\rightarrow$ `1` (참)
>> 3. 최종 결과 `rs = 1` (AND가 OR보다 우선순위가 높음)
### 4.4 관계 연산자
* `>`, `<`, `>=`, `<=`, `==` (같다), `!=` (다르다)
* 결과값은 참(1) 또는 거짓(0)으로 반환.
### 4.5 기타 연산자 (대입, 조건, Cast, Sizeof)
1. **대입 연산자**: `=`, `+=`, `-=`, `*=` 등 (우변의 값을 좌변에 저장).
2. **조건(삼항) 연산자**: `조건식 ? 참일_때_값 : 거짓일_때_값`
3. **Cast 연산자**: `(int)3.14` (강제 형 변환).
4. **sizeof**: 자료형이나 변수의 메모리 크기(Byte) 반환.
### 4.6 비트 연산자

| 연산자  | 설명          | 특징                 |
| :--: | :---------- | :----------------- |
|  &   | AND         | 둘 다 1일 때 1         |
|  \|  | OR          | 하나라도 1이면 1         |
|  ^   | XOR         | 서로 다르면 1           |
|  ~   | NOT         | 비트 반전 (0->1, 1->0) |
|  <<  | Left Shift  | 값 $\times 2^n$     |
| `>>` | Right Shift | 값 $\div 2^n$       |

- **패딩 비트(Padding Bit)**: 시프트 연산 후 생기는 빈자리에 채우는 비트.

> [!tip] XOR 연산 암기법
> **1의 개수가 홀수면 1, 짝수면 0** (Parity Check 등에 활용)

## 5. 입출력 함수 (C언어)
```c
// 1. 출력 함수 (printf)
printf("값: %d\n", 100); // 서식 문자(%d)와 제어 문자(\n) 사용
// 2. 입력 함수 (scanf)
int num;
scanf("%d", &num); // 일반 변수는 주소 연산자(&) 필수
char str[10];
scanf("%s", str);  // 문자열(배열)은 & 생략
```

> [!warning] scanf 사용 주의사항
> * **일반 변수**: 값을 저장할 메모리 주소가 필요하므로 **`&` 연산자**를 반드시 붙임.
> * **배열/문자열**: 배열명 자체가 **시작 주소**를 의미하므로 **`&`를 붙이지 않음**.

>[!summary] 서식 문자 (Format Specifier)
>| 서식 | 자료형 | 서식 | 자료형 |
>| :---: | :--- | :---: | :--- |
>| `%d` | 정수 (10진수) | `%f` | 실수 |
>| `%c` | 문자 | `%s` | 문자열 |
> | `%o` | 8진수 | `%x` | 16진수 |
>
> > [!warning] 함정 문제 주의

## 6. 제어문
### 6.1 반복문
* **while**: 조건 검사 후 실행 (0회 실행 가능).
* **do ~ while**: **무조건 1회 실행** 후 조건 검사.
* **continue**: 실행 후 반복문의 선두(조건식/증감식)로 이동.
### 6.2 조건문 (switch)

> [!warning] switch ~ case 주의사항
> 조건 값에 따라 분기하며, **break 생략 시 다음 case문까지 계속 실행**되는 특징(Fall-through)이 있음.
> ```c
> switch(n) {
>     case 1: printf("A"); // break가 없으면 case 2까지 실행됨
>     case 2: printf("B"); break;
>     default: printf("C");
> }
> ```

## 10. 구조체 (Structure)
* **정의**: 서로 다른 자료형의 묶음 (Java의 Class와 유사)
* **관례**: 구조체 이름은  대문자 사용.
### 10.1 선언 방식
```c
// 1. 선언과 초기화
struct PERSON {
    char name[10];
    int age;
} p1 = {"Kim", 20};

// 2. 선언 후 초기화
struct PERSON p2;
p2.age = 30;
strcpy(p2.name, "Lee"); // 문자열 멤버는 strcpy 사용 필수

// 3. typedef 이용 (별칭)
typedef struct {
    char name[10];
    int age;
} PERSON_T;

PERSON_T p3 = {"Park", 25}; // struct 키워드 생략 가능
```
> [!summary] typedef 핵심
> ==`typedef`로 구조체 별칭을 만들면 변수 선언 시 `struct` 키워드를 생략할 수 있다.==
