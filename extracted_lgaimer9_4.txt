• The notion of "closest" depends on a distance metric:
• The default choice is Euclidean distance:
• You can use other distance metrics (e.g., Manhattan or Cosine distances)

• E.g., "Annual Income" may overwhelm "Age" unless scaled
• Feature representation also matters
• Irrelevant features can distort neighborhoods
• Categorical and missing values require careful preprocessing

Decision Trees: Underfitting & Overfitting
• Tree complexity controls underfitting vs overfitting
• Too shallow → miss important patterns → underfitting
• Too deep → memorize noise in training data → overfitting
• A fully grown tree can achieve nearly perfect training accuracy, but generalize poorly

### [Page 27]
Decision Trees: Underfitting & Overfitting
• Tree complexity controls underfitting vs overfitting
• Too shallow → miss important patterns → underfitting
• Too deep → memorize noise in training data → overfitting
• A fully grown tree can achieve nearly perfect training accuracy, but generalize poorly
• How to control tree complexity?
• Pre-pruning: Stop growing the tree before it becomes too complex
• E.g., max_depth, min_samples_leaf, min_impurity_decrease
• Post-pruning: Grow a large tree first, then remove unnecessary branches
• Cost-complexity pruning balances predictive fit and tree size

Decision Trees
• Strengths
• Rule-based predictions that are easy to understand
• Captures non-linear patterns and feature interactions
• Requires little preprocessing; no feature scaling required

Random Forests
• Random Forest (RF) is a bagged decision tree with an extra trick to 
decorrelate the predictions
• Utilize two sources of randomness: Bagging and random feature 
vectors
• Random dataset: Each tree is grown using bootstrap sampling
• Random feature vectors: At each node, the best split is chosen from a 
random subset of attributes instead of all the attributes
• Despite the simplicity, it often works well
• It is one of the widely used models in Kaggle competitions

### [Page 43]
GBDT: Gradient Boosting Decision Trees
• GBDT gradually builds a strong model from many shallow trees
• Why shallow decision trees?
• Capture non-linearities and feature interactions out of the box
• Efficiently learn pseudo-residuals
• Add natural piecewise-constant corrections to the ensemble
• Key Hyperparameters
• Number of trees → more expressive, but may overfit
• Learning rate 𝜂→ faster correction, but less conservative
• Tree depth / number of leaves → capture more interactions, but may overfit
• Subsampling → improve robustness
• GBDT combines weak corrective trees into a powerful predictor, 
but requires careful tuning

### [Page 47]
+ Isolation Forest for Anomaly Detection
• Key Idea: Anomalies are easier to isolate by random splits
• Building an Isolation Tree
• Randomly sample a subset of the training data
• At each node, randomly choose a feature and a split value
• Repeat until a sample is isolated or a maximum depth is reached
• From Isolation Tree to Isolation Forest
• Build many random isolation trees
• Measure the average path length of each sample
Shorter average path length → Higher anomaly score
• No class labels or anomaly labels are required
